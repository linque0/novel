> 调研对象：`excalidraw@zcode-plugins-official` 插件（画板交互模型 + 面向 AI 的读写操作协议）。
> 与《[大纲功能优化方案.md](大纲功能优化方案.md)》（嵌套收纳 / 侧栏关系 / 引用浮窗）**并行互补、零重叠**：那篇解决「画布容量与检索」，本篇解决「编辑效率 / AI 协作 / 结构复用 / 出图」。两篇可各自独立排期。
> 落地纪律照《[开发流程.md](开发流程.md)》：一个版本一个特性粒度，四处版本同步，两画布共享底层改动双侧回归。

## 0. 结论摘要

| # | 借鉴方向 | 一句话方案 | 核心收益 | 代价 | 建议批次 |
|---|---|---|---|---|---|
| 一 | **多选与批量操作** | 左键空白拖框选 + Shift 加选 + Ctrl+A；批量拖动/删除/改属性；平移改空格+拖或中键 | 从「一次只能动一个」到白板级编辑效率；是《大纲功能优化方案》「框选归组」的前置底座 | 中 | 第一批 |
| 二 | **复制粘贴与副本** | Ctrl+C/V/D、Alt 拖拽复制；payload 走系统剪贴板 → 跨窗口/跨作品搬情节结构；含子树与内部连线 | 复制情节链、跨卷/跨书复用结构——写作者最高频动作 | 中 | 第一批 |
| 三 | **键盘与导航** | 方向键微调（1px / Shift 10px）、缩放到选区、缩放范围放宽至 10%–300%、空格/中键平移 | 精确摆位与大局俯瞰；低成本高感知 | 低 | 第一批 |
| 四 | **AI 画布操作与结构诊断** | 接在既有 `application.js` 提案管线上：AI 输出「画布操作批」（容器/连线/移动/改属性）→ 校验 → 一步应用一步撤销；再增结构诊断高亮 | 恍然梦从「读节点」升级到「动画布」；守卫/审计/窗口锁全部复用 | 中高 | 第二批 |
| 五 | **模板库** | 「存为模板」选区（含连线/层级）→ 作品级 + 全局；内置三幕/章级升级为数据；JSON 导入导出 | 情节套路（反转链/伏笔组）资产化，跨作品复用 | 中低 | 第二批 |
| 六 | **对齐与分布** | 多选 ≥2 六向对齐、≥3 等距分布 | 手动排版收尾刚需，纯几何 | 低 | 第二批 |
| 七 | **智能参考线** | 拖拽时与其它节点边/中线对齐提示 + 轻吸附（与网格吸附分级共存） | 治「怎么摆都不齐」，减手工微调 | 中 | 第三批 |
| 八 | **锁定与层级** | lock（完全锁定）与 pin（整理不动）分离；z-order 上移/下移/置顶/置底 | 参考型模块防误动；便签/文本框叠放可控 | 低 | 第三批 |
| 九 | **连线端点重接** | 拖已有连线终点改挂模块/端口/连接点；拖线全程目标高亮 | 免「删线重画」；接线反馈明确 | 中 | 第三批 |
| 十 | **画布出图（可选）** | 导出 PNG（手动 Canvas 绘制，零新依赖）：全图/当前视图/选区 | 分享/存档/给合作者看结构 | 中 | 按需 |

**建议顺序：一 → 二 → 三（一个交互批）→ 四（AI 批，与 ai-assistant 线直接衔接）→ 五·六 → 七·八·九 → 十。**
**如果只做三件事**：多选+剪贴板（日常刚需）、AI 画布操作批（能力面扩张且管线已备）、模板库（结构资产化）。

## 1. 调研对象拆解：Excalidraw 的能力模型

Excalidraw 的能力可拆成三层，恰好对应本项目画布的三个薄弱面：

### 1.1 数据 / 操作层（面向程序与 AI——插件核心）

| 能力 | 语义 | 对本项目的启示 |
|---|---|---|
| 稳定短 id | 所有元素（形状/箭头/绑定文字）都有稳定 id，文字与容器绑定 | 本项目节点/连线已有 id（`olnodes.id` / `rel.id`），可直接作为寻址基础 |
| 局部操作 | `apply_operations`：add / update / delete 按 id 局部修改；**禁止全量重建覆盖用户布局** | AI 操作必须增量：不重排、不覆盖用户已有坐标 |
| 修订（revision） | 读取时拿 revision，写回前校验；冲突则重读重规划 | 已有对应物：`proposalGuard` 的 sourceHash / bookRevision / 窗口锁 |
| 操作幂等 | 重试保留 operationId，不重复提交 | 操作批需批次号去重（现 `appliedActions` / `airuns` 已同构） |
| 原子编辑 | **一次应用 = 一个完整编辑动作**，工具操作与手工编辑共享同一撤销栈 | 一次批量操作 = 一次 `olnodePushUndo(true)`；AI 应用走审计撤销 |
| 导出 | `.excalidraw` 原生文件 + PNG/SVG | 对应「模板/画布 JSON 出入」与「出图」（方案五·十） |

### 1.2 桌面交互层（编辑效率对标）

多选（框选 / Shift 加选 / Ctrl+A）、组与解组、剪贴板（复制/粘贴/副本/Alt 拖拽复制）、层级（置顶/置底/上移/下移）、锁定、对齐与分布、方向键微调、对象吸附参考线、缩放至选区与快捷键、空格/中键平移、元素库（选区存为可复用组件）、元素超链接、连续创建。

### 1.3 输出 / 排版原则层（内容质量对标）

先按含义分组、节点尺寸一致、限制层级密度、颜色表达分组而非唯一信息载体、只画有证据支持的关系——既是 Excalidraw 的排版建议，也应直接写进「AI 生成大纲」的系统提示与应用层校验（方案四）。

## 2. 现状盘点（代码事实）与逐项对照

### 2.1 已具备、且不逊于 Excalidraw 的资产（不动）

- 四向锚点拖线、严格端口（`fromSide/toSide` 建边即记录）、避障正交路由（Hanan 网格 A* + 拉直收敛）、贝塞尔/折线切换（`outline/canvas-model.js` `routeEdge` 等）；
- **连接点**（连线上建点、线连到线、随宿主路径实时派生）——Excalidraw 无对应物，本项目独有强项；
- 连线塑形（单控制点弯曲 / 双击拉直）、单条连线线宽 / 箭头缩放 / 线型 / 颜色 / 标签；
- 容器「拖入即归组」+ 折叠递归收纳 + 派生盒；整理布局（`relayoutAll`）；16px 网格吸附；
- 断线检测（烂尾/缺铺垫 + 定位闪烁）、双链卫星与悬停预览、章节/卷锚点、引用卡；
- 快照撤销栈（60 级、1.2s 文本合并，`work.js` `olnodePushUndo`）、拆窗多窗口；
- AI 提案管线：`application.js` 的 `proposalGuard`（来源哈希 / bookRevision / `isPopped` 窗口锁 / 重复应用拦截）+ 租约互斥 + 审计撤销（`undoAiApplication`）。

### 2.2 对照表（借鉴判定）

| 能力 | Excalidraw | 恍然梦画布现状 | 判定 |
|---|---|---|---|
| 多选/框选/加选 | ✔ | ✘（仅 `selOlnodeId` 单选） | **借鉴（方案一）** |
| 复制/粘贴/副本 | ✔ | ✘ | **借鉴（方案二）** |
| 方向键微调 / 缩放至选区 / 深缩放 | ✔ | ✘（缩放 30%–220%） | **借鉴（方案三）** |
| 空格/中键平移 | ✔ | ✘（左键空白拖 = 平移） | **借鉴（方案一/三，范式切换）** |
| AI 增量操作协议 | ✔（插件核心） | 半：`plan` 卡只能往选中节点下批量建事件链（无坐标/容器/连线种类） | **借鉴 + 扩展（方案四）** |
| 结构问题定位 | —（插件无此概念） | 断线检测已有，无 AI 诊断 | **借 AI 做成诊断闭环（方案四）** |
| 元素库/模板复用 | ✔（Library） | 仅 2 个硬编码模板（三幕/章级） | **借鉴（方案五）** |
| 对齐/分布 | ✔ | ✘（只有自动整理） | **借鉴（方案六）** |
| 对象吸附参考线 | ✔ | ✘（仅网格吸附） | **借鉴（方案七）** |
| 锁定 / 层级 | ✔ | 半（`pin` 只管整理不重排；z 固定按类型） | **借鉴（方案八）** |
| 连线端点重接 | ✔ | ✘（端口建边即锁定，改向要删线重画） | **借鉴（方案九）** |
| 画布出图 | ✔（PNG/SVG） | ✘ | **借鉴（方案十·可选）** |
| 连接点（线上接线） | ✘ | ✔ | 保留优势 |
| 避障正交路由 | 基础（elbow） | ✔ 全局最优 A* | 保留优势 |
| 自由绘制 / 激光 / 协作 / 图片 | ✔ | ✘ | **不借鉴（§5）** |

### 2.3 关键结论

1. **最大差距不是「画」，是「编辑」**：本项目在连线几何上已超过 Excalidraw（连接点、避障路由），缺的是选择、剪贴板、键盘、层级、锁定这套「效率壳」——使用频率最高、投入产出比最大。
2. **第二个差距是「AI 能不能动画布」**：`application.js` 已具备完整的提案守卫与审计撤销，`plan` 卡也已能往节点下批量建事件+因果链；缺「画布级操作批」（容器、坐标、连线种类/标签、移动、删除）与基于画布快照的结构诊断。Excalidraw 插件暴露的 read / apply / revision / 幂等模型正好是现成范式，且与本仓库已有管线同构，边际成本低。
3. 出图与模板复用是「从个人工具到可分享/可复用」的缺口，代价可控。

## 3. 分项方案

每项给出：交互规格 / 落文件 / 边界与风险 / 验收口径。

### 方案一 · 多选与批量操作（第一批）

**交互规格**

| 交互 | 规格 |
|---|---|
| 框选 | 左键在空白拖出虚线矩形，实时高亮命中节点（含容器派生盒判定）；松开成选；拖距 ≤3px 视为点击（清空选择） |
| 加/减选 | Shift+点选切换单个节点；Ctrl+A 全选可见节点；Esc 清空 |
| 平移（范式切换） | **空格+左键拖、或中键拖 = 平移**；滚轮滚动、Ctrl+滚轮缩放不变（现行为） |
| 批量拖动 | 选中集整体拖动（各节点连带自身子树，沿用容器连带逻辑）；落点吸附同现状 |
| 批量删除 | Delete 删除整个选中集（一次确认：「删除 n 个模块（含子模块 m 个）？」），一步撤销 |
| 批量属性 | 右键菜单在多选时作用于全体：颜色/形状/自定义类型/固定/（后续）锁定 |
| 选中呈现 | 全部选中节点加描边；「主选中」（最后点击者）保留现有高亮，兼容侧栏联动/AI 发送/焦点定位 |

**落文件**：`OutlineCanvas.vue`（marquee 状态机、`selOlnodeIds: Set`、批量拖动/删除/属性）、`stores/work.js`（`selOlnodeIds`；`olnodeRemoveMany` / 批量 patch，均单次 `olnodePushUndo(true)`）、`services/graphview.js` `onPanStart` 条件化（空格/中键才平移）。

**边界与风险**
- 本方案唯一的**习惯破坏点**：左键空白拖动从「平移」变「框选」。对齐 Excalidraw 与《大纲功能优化方案.md》§3.2 已定的「左键空白拖框」；平移改空格/中键，并在空画布引导文案与首次使用提示中说明。
- 备选（求稳用，不推荐）：Shift+拖 = 框选、保留左键平移——发现性差，且与同批快捷键语义打架。
- 拆窗面板共用同一组件，行为自动一致；多窗口不做选中集同步（各窗口独立选择，符合直觉）。
- 框选与右键菜单、双击建节点不冲突（各自独立入口）。

**验收口径**（新增 `tools/olcanvas-edit-verify.mjs`）：框选 2 个事件 → 拖动 32px → 两节点坐标同时落库且相对距离不变；Shift 点选可减选；Ctrl+A 后 Delete → 一步撤销恢复全部（含连线与连接点）。

### 方案二 · 复制粘贴与副本（第一批）

**交互规格**

| 交互 | 规格 |
|---|---|
| 复制 | Ctrl+C 复制选中集：节点属性全集 + **两端都在选区内的连线**（外部边不复制）+ 容器选中时连带子树 |
| 粘贴 | Ctrl+V 落点 = 鼠标位置（缺省视口中心）；相对布局保持，整体偏移 24px 防重叠；一次粘贴 = 一步撤销 |
| 副本 | Ctrl+D = 复制 + 就地粘贴；Alt+拖拽 = 拖动即复制（原节点不动） |
| 跨窗口/跨作品 | payload 写系统剪贴板（复用现有 `clip:writeText/readText` IPC，`electron/main.js` L344）；跨作品粘贴时 id 全部重映射、`refId` 保留（失效目标走现有「已删章节/未选择目标」兜底）、落根级 |
| 剪贴板格式 | `{ v:1, kind:'olcanvas', nodes:[…], edges:[…] }` JSON；粘贴前 schema + 版本校验，非法则忽略 |

**边界与风险**：连接点（`rel.junctions`）与连接点引出的 `_out` 连线要一并重映射（含 `toJunction/fromJunction` 指向重写）；跨作品粘贴不携带折叠态（展开后落位）；系统剪贴板为纯文本 JSON——若用户剪贴板里是其它 JSON，靠 schema 校验拒绝。**不复制**软删行；`canvasX/Y` 按落点重算。

**落文件**：`OutlineCanvas.vue`（快捷键、Alt 拖拽分支）、新增 `src/components/outline/clipboard.js`（payload 序列化/反序列化/id 重映射纯函数，node 直测）、`stores/work.js`（`olnodePaste(payload, {x, y})` 单事务）。

**验收口径**：复制 3 节点 + 2 内部边 + 1 外部边 → 粘贴出 3 新节点、2 新边、无外部边；撤销一步回到粘贴前；库内行数与 DOM 数一致；模拟「面板窗口复制 → 主窗口粘贴」成功。

### 方案三 · 键盘与导航（第一批）

| 交互 | 规格 |
|---|---|
| 方向键微调 | 1px/次；Shift = 10px；多选时整组移动；松开即落库（连续按键 1.2s 内合并撤销，沿用现合并窗口） |
| 缩放快捷键 | Ctrl+0 复位 100%；Ctrl+1 适应全图；Ctrl+2 缩放到选区 |
| 缩放范围 | 现 30%–220% → 放宽 **10%–300%**（大画布俯瞰需求；`graphview.js` 与工具栏两处 clamp 同步抽常量） |
| 平移 | 空格+拖 / 中键拖（方案一引入）；光标 grab/grabbing、框选 crosshair |
| 微项 · 连续新建 | 右键空白菜单选定类型后，双击空白继续建「同类」（记住上次类型，Esc 复位） |

**落文件**：`OutlineCanvas.vue` `onKey` 与工具栏、`graphview.js`（`ZOOM_MIN/ZOOM_MAX` 常量两侧共用）。
**风险**：缩放上限放宽不影响几何与「整理/适应」；`CharacterGraph` 复用 `graphview.js`，常量共享改动需跑 `chargraph-verify`、`relfollow-verify` 回归。
**验收口径**：选节点按 → 坐标 +1、撤销可回；Ctrl+2 后视口包围盒 ≈ 选区；10%/300% 边界可停住。

### 方案四 · AI 画布操作与结构诊断（第二批 · 与 ai-assistant 线衔接）

**现状（代码事实）**：`src/services/ai/application.js` 的 `applyProposal` 已对 `plan` 卡实现「选中节点下批量建事件 + 因果/伏笔/冲突标签连线 + 切画布视图并聚焦」；守卫含 sourceHash / bookRevision / `isPopped` 窗口锁 / `appliedActions` 重复拦截 / 租约互斥 / 审计撤销。缺：画布级操作（容器、坐标、移动、删除、连线种类/线型/标签）、批量事务一致性校验、基于画布快照的诊断。

**借鉴要点（Excalidraw 数据层四件套）**：稳定 id 寻址；外科手术式操作；修订校验与幂等；一次应用 = 一步撤销；不重排 / 不覆盖用户布局。

**提案**

1. **画布快照（读）**：`canvasSnapshot(work)` 输出紧凑 JSON——节点 `{id,kind,title,text≤N,parentId,x,y,w,h,fold,mtype}`、连线 `{ownerId,relId,toId,kind,label,arrows,style,junctions}`；供 AI 上下文与诊断共用（复用 `snapshotWork` 思路，受 `fitMessages` 预算约束）。
2. **操作批 schema（写）**：
   ```
   { op:'addNode', tempId, kind, parentId?, x?, y?, title?, text?, shape?, color? }
   { op:'updateNode', id, patch:{ title|text|shape|color|mtype|pin|w|h|opacity } }
   { op:'deleteNode', id }            // 级联子树 + 关联连线 + 连接点
   { op:'moveNode', id, x, y }        // 或 moveSelection(delta)
   { op:'addEdge', from, to, kind?, label?, arrows?, style?, fromSide?, toSide? }
   { op:'updateEdge', ownerId, relId, patch }
   { op:'deleteEdge', ownerId, relId }
   { op:'group', childIds, title }    // 建容器并归组
   { op:'relayout' }                  // 显式整理（默认不触发）
   ```
3. **应用管线**：validator 先行（id 存在性 / 自环与重复边 / 连接点完整性 / 删除级联 / 坐标缺省用 `freeSpotFor` 避重叠）→ 单事务（`olnodePushUndo(true)` + `aiApplying` 抑制重复快照 + 批量 mark）→ 全量校验失败即整体不落；应用后 `fitView` / 聚焦新节点。
4. **修订与幂等**：操作批带 `batchId`，复用 `appliedActions` / `airuns` 去重。**注意**：`rowHash`（`project/text.js`）含 `canvasX/rels`——用户拖一下节点就会让含该行的提案失效。画布操作卡建议改用「内容子集哈希」（title/text/kind/parentId 等结构字段，新增 `canvasContentHash`），否则拖拽会频繁顶掉 AI 提案；该哈希同时用于提示「画布已变化，请重新生成」。
5. **呈现**：复用 ai 面板卡片范式（`PlanCard` 已有 applied 状态与定位提示）——操作批以「新增 n / 修改 m / 连线 k」清单 + 点击定位（画布闪烁）呈现，确认后应用；应用后卡片提供「撤销」（走 `undoAiApplication`）。
6. **结构诊断（增值闭环）**：AI 读画布快照 + 断线检测现状（烂尾/缺铺垫）+ 孤岛检测 → 输出问题清单（含伏笔未回收候选、节点过载容器）→ 每条可「定位」高亮（复用 `flashIds` / `locateBroken`）；可一键把诊断转成操作批（补铺垫 = 加边、拆过载容器 = group + move）。

**边界与风险**：写操作的爆炸半径大——validator 必须先行拒绝一切非法批（宁拒不错）；`aiApplying` 期间的用户操作与重复快照沿用现开关抑制；多窗口沿用租约与 `isPopped` 拦截；诊断建议不得自动应用，必须卡片确认（沿用「用户决定」原则）。

**验收口径**（新增 `tools/olcanvas-ai-verify.mjs`，用 `tools/mock-ai.mjs`）：mock 操作批含 add/update/edge/group → 画布结构对应生成且容器派生盒正确；撤销一步全部回退；重复 batchId 不重复应用；来源哈希过期时拒绝并提示重新生成；删除节点后连线/连接点无残留。

### 方案五 · 模板库（第二批）

**交互规格**：空画布快速开始处展示模板列表（内置：三幕式、章级清单；自定义：用户存档）；工具栏「存为模板」（有选区时可用）；模板管理（重命名/删除/导出 JSON/导入 JSON）。
**存储**：`oltpl:<workId>`（作品级）与 `oltpl:global`（全局，跨作品）走 `appconfig`（与 `canvasPrefs` 同款）；结构即 `{ id, name, rows, edges }`（`rows/edges` 与 `tplThreeAct` 同构），**零 schema 变更**。
**边界**：插入时 id 全量重映射、`refId` 保留（跨作品时章节锚点自然失效为「已删章节」）；插入到视口中心并 `freeSpotFor` 找空位；容器嵌套模板待《大纲功能优化方案》方案一落地后自然支持。
**落文件**：`canvas-model.js`（模板序列化/实例化纯函数 + 内置模板改数据）、`OutlineCanvas.vue`（入口/管理 UI）、`work` store（`olTemplateSave/List/Remove`）。
**验收口径**：三幕模板回归（现 `olcanvas-verify` 已覆盖）；「框选 → 存模板 → 删除 → 插入」结构与连线还原、id 全新；导入非法 JSON 被拒。

### 方案六 · 对齐与分布（第二批）

多选 ≥2 出六向对齐（左/水平居中/右/上/垂直居中/下），≥3 出等距分布（水平/垂直）；容器以「派生盒边界」参与对齐；一次操作一步撤销。纯几何函数进 `canvas-model.js`（`alignRects` / `distributeRects`），node 直测。
**验收口径**：三节点左对齐后 `x` 相等；分布后相邻间距差 < 1px；撤销一步回位。

### 方案七 · 智能参考线（第三批）

拖拽（含批量拖动）时与其它可见节点的 6 条边/中线比对，距离 < 6px 显示对齐辅助线并吸附（优先级：对象吸附 > 网格吸附 > 无）；辅助线画在 SVG 层（`oc-edges` 同级），松手即清；复用 `dragPos` 临时态，不改数据模型。
**风险**：与 16px 网格吸附耦合——「吸附」chip 改三态（对象+网格 / 仅网格 / 关）。
**验收口径**：拖节点至与另一节点水平中线对齐时出现参考线，落点数值与参考线一致。

### 方案八 · 锁定与层级（第三批）

- **锁定**：新字段 `lock`（与 `pin` 语义分离：`pin` = 整理不重排；`lock` = 不可拖动/编辑/删除/接线，右键「解锁」；渲染加锁角标，拖拽手柄与锚点隐藏）。删除/连线/拖拽入口统一过滤 `lock`。
- **层级**：新字段 `z`（缺省 null；渲染在现有规则 `container=1 / node=3 / selected=6 / editing=8` 上叠加），右键菜单「上移一层 / 下移一层 / 置顶 / 置底」。
- **风险**：与「选中/编辑强制置顶」规则冲突——选中置顶保留，`z` 只在同级间生效。
- **验收口径**：两便签重叠，置底者不再遮挡置顶者；锁定节点拖不动、Delete 不删、锚点不出接线。

### 方案九 · 连线端点重接（第三批）

普通连线（非连接点两端）在两端渲染圆点手柄：拖动**终点**手柄 → 命中其它模块端口 / 连接点 → 更新 `toId/toSide`（或 `toJunction`）；**起点重接（改 owner）本期不做**，涉及 rel 迁移，二期视需要。拖线全过程命中目标高亮 + 端口提示（Excalidraw 的绑定反馈风格）。
**风险**：`custom` 弯曲控制点在重接后可能荒谬——重接即清 `custom`（回自动路由）；与 `startEdgeShape`（按住连线拖动塑形）的 mousedown 优先级：手柄元素优先。
**验收口径**：A→B 终点拖到 C → `rel.toId=C`、箭头跟随、撤销可回；重接口无残留旧端口。

### 方案十 · 画布出图（按需）

导出 PNG：手动 Canvas 2D 绘制——节点矩形/形状描边、标题与正文截断、连线 path（复用 `routeEdge` / `customEdgeGeom` / `pointAtT` 几何）、箭头三角形、连线标签；零新依赖、可 node 直测。选项：全图 / 当前视图 / 选区、2× 清晰度、含背景。
**风险**：节点内富文本与双链卫星 v1 不绘制（只画纯文本行）——导出为「结构图」而非「界面截图」。
**验收口径**：导出文件存在、像素尺寸覆盖全图包围盒、抽检 3 条连线颜色与库内一致。

## 5. 不借鉴清单（划界）

| 不借鉴 | 理由 |
|---|---|
| 自由绘制 / 橡皮擦 / 激光笔 | 画布词汇是剧情结构（事件/便签/引用/容器），不是通用草图 |
| 实时协作 / 在线分享 | 本地单机工具；已有拆窗/多窗口路径 |
| 帧裁剪 / 幻灯片演示 | 容器已承担收纳；演示需求可用轻量「巡览」替代（可选） |
| 图片 / 媒体嵌入、形状材质填充 | 与创作数据结构无关，徒增存储与导出复杂度 |
| 工具数字快捷键体系（1–9） | 无多工具状态机；只借「连续创建同类」微交互（方案三） |

## 6. 总风险与依赖

1. **交互范式切换**（左键空白拖 = 框选）是唯一需要对用户解释的变更——落版时同步空画布引导文案与《产品介绍》《使用手册》。
2. **共享引擎双画布**：`graphview.js` / `canvas-model.js` 被 `OutlineCanvas` 与 `CharacterGraph` 共用（后者引用 `usePanZoom/anchorsOf/freeSpotFor/dashOf/EDGE_STYLES/sideBetween/routeEdge`）——任何签名/常量改动都必须双侧回归。
3. **快照撤销栈内存**：批量操作必须「一次动作一次 `force` 快照」，避免逐节点压栈放大 60 级栈内存。
4. **多窗口一致性**：剪贴板走系统剪贴板（schema 校验）；AI 应用沿用租约 + `isPopped`。
5. **哈希口径**：`rowHash` 含坐标/连线，拖动即刷新——AI 画布卡建议专用内容哈希（方案四 §4），避免「拖一下画布就顶掉提案」。
