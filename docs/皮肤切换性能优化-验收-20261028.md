# 皮肤切换性能优化验收

2026-10-28，Windows 本机。覆盖引力书舱、琉光画境、赤月戏；原版工坊参与全部方向的切换回归。

## 实现

- 静态封面使用共享、按需启动的 Worker；赤月戏主书使用独立 Worker。纹理、模型、WebGL 初始化/绘制与图像编码均在后台完成。
- 首屏保留可操作的静态封面，精细图像完成后替换。保持现有材质、分辨率、姿态、字体、旋转/缩放/键盘操作。
- 对同一封面合并请求，按主书、配角、目录排序；不可见作品不启动绘制。卸载、隐藏、元信息变化会取消请求，过期结果不更新组件。
- 成功封面跨皮肤保留，LRU 同时受 48 项、编码字符串估算 16 MiB 限制。无使用者时终止 Worker 并释放 GPU；空书架不保留 Worker。
- 隐藏时暂停初始化/新绘制和超时计时，恢复后继续。工作请求可见期间超过 15 秒或发生 Worker/WebGL 错误时，保留可打开的静态封面。
- 修复异步截图可能读到已清空帧缓冲的问题，以及每次旋转重复修改 GPU 画布尺寸的问题。

## 性能结果

临时独立页面的修复前复现：6 本书，引力书舱产生约 3.15–3.26 秒主线程长任务。

最终使用独立 Edge 无头页面，包含首次渲染模块加载、冷切换、全部 12 个方向、重复切换；不提前导入渲染模块进行预热。

| 场景 | 可操作首屏 | 主线程长任务 |
|---|---:|---|
| 6 本书，20 个切换样本 | 11–64 ms，P95 42 ms | 采样窗口内未观测到 ≥50 ms 长任务 |
| 首次引力书舱 | 42 ms | 无 |
| 首次琉光画境 | 64 ms | 无 |
| 首次赤月戏 | 28 ms | 无 |
| 100 本书，引力书舱 | 106 ms | 最长 68 ms |

另外用真实浏览器操作验证冷切换后的皮肤菜单、搜索，端到端响应约 120 ms、41 ms（包含自动化通信开销）。切回已缓存的引力书舱时绘制计数不增加。

这些指标衡量首屏可操作及 JavaScript 阻塞，不等同于完整封面已生成。首次 GPU 预热仍观测到最长约 233 ms 的合成帧间隔，可能短暂掉帧；未承诺固定 60 FPS。结果来自本机，其他显卡/驱动与设备仍可能有差异。

- `node tools/book-poster-queue-test.mjs`：请求合并、独立取消、隐藏暂停、优先级、LRU 双上限、失败重试、释放后过期结果。
- `node tools/book-worker-client-test.mjs`：响应、取消、过期回包、幂等释放、错误、15 秒超时、平台不支持。
- `node tools/book-worker-lifecycle-verify.mjs`：截图像素非透明、旋转不重设画布尺寸、真实 Worker WebGL 上下文丢失、字体加载时隐藏后暂停与恢复。审查发现的两个问题及隐藏初始化问题均完成失败复现与修复后通过。
- `node tools/book-worker-verify.mjs`：0/6/100 本书、全部切换方向、连续快速切换、缓存命中、键盘交互、离开后 GPU/Worker/请求归零。
- `node tools/dual-book-art-verify.mjs`：70 项双皮肤外观、布局、六款材质、多姿态、交互和静态回退检查。
- `node tools/crimson-book-viewer-verify.mjs`：50 项视角、拖动、滚轮、触屏、键盘、菜单、状态、回退与释放检查。
- `node tools/skin-unit-verify.mjs`、`node tools/book3d-interaction-test.mjs`、`node tools/book-theme-layout-test.mjs`：皮肤、手势和中文/英文排版契约。
- `node tools/book-electron-verify.mjs`：全新隔离 profile，三套皮肤在 Electron 开发地址加载 Worker/字体/绘画；并运行原皮肤集成脚本，验证保存失败、原主题保留、重载持久化、设置窗口同步。
- `node tools/book-electron-verify.mjs --production`：隔离 profile，三套皮肤在正式 `app://` 地址成功加载 Worker、字体与绘画；已检查截图。
- `npm run build`：通过。保留现有大分包提示；未新增依赖、升级版本或发布安装包。

## 实施取舍

复用用户当前功能分支工作目录，保留其已有未提交内容；未提交、推送或操作用户正在使用的实例。代价是没有额外工作树隔离，因此仅核对、修改本次渲染相关文件。

性能验收分别记录首屏可操作时间、JavaScript 长任务和合成帧间隔，不将后两者混为一个指标；代价是通过主线程目标仍不能代表首次 GPU 预热完全不掉帧。

原皮肤脚本曾假定新建且未打开的作品自动排在所有最近打开作品之前，与现行排序规则不符；已改为按创建作品的身份查找并操作。正式产品排序行为未改动。
