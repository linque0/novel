2026-10-25。按批准方案完成四皮肤共用的三套装帧，去除赤月戏右下角折角。默认使用轻装帧，保留深色与浅色皮肤原有明暗方向。

## 使用与表现

- 正文格式工具栏 → **纸面**；工具栏不足 720px 时进入 **更多格式 → 纸面**。
- **设置 → 外观 → 正文纸面装帧**：三张材料选项与实时纸面预览共用状态、材料和保存动作。
- 轻装帧使用淡纸纹、薄页边；旧纸手稿使用低对比纤维与自然纸色；精装使用装订凹槽、叠页与外沿衬边。正文中心保持均匀，未加入污渍、裂纹、反光或翻页效果。
- 阅读与沉浸沿用材料并减弱边缘。赤月戏正文和页边札记使用一致材料，其余皮肤保留批注栏布局。
- 切换不改变正文行宽、字号、字体、行高或内边距，不重建编辑器、不写正文和撤销记录。长标题保留原单行编辑方式，显示省略号并可悬停查看完整标题。

## 实现与兼容

新增应用级偏好 `writingPaperStyle`，限定 `booklet / manuscript / hardcover`。沿用 `appconfig` 和现有偏好广播，不升级数据库；缺失或无效值回退 `booklet`。保存成功后才应用并同步，失败保留原样、显示提示；保存期间禁止重复选择。恢复外观默认值同时恢复轻装帧。

使用本地静态 SVG 纤维纹理、背景与阴影绘制材料，不引入外部请求或持续动画。关闭了正文区域旧竖纹覆盖层，清除了折角源样式；材质没有覆盖正文输入的装饰 DOM。工具栏通过可选接口接收纸面控件，其他编辑工具实例保持原样。现有菜单过渡继续由组件库处理，材料直接切换，不增加动效。

已保留所有此前未提交改动，不升级版本，不自动提交。AI/writing store、AI 服务、写作 repository 的32个既有核心文件与上轮基线哈希全部一致。
