## 3. 全部条目

- 视图：`表格 / 卡片`（默认按窗口宽 `<768` 选卡片）；**无分页、无无限滚动、无虚拟化、无分组**（全量 `.map`）。
- 路由参数：`?cat` `?tag` `?incomplete=1` `?new=1`。
- 过滤：搜索（220px，匹配 name/summary/tags；`!` 前缀 = 字面搜索）· 分类下拉（层级用 `└` 缩进）· 状态 · 重要度 · 标签 · 排序 · 复选「仅看未完成」（评分 <85）。
- 排序：updated/created（降序）· name（zh-CN）· importance（权重降序）· relations（度数降序）；**收藏项恒置顶**。
- 行/卡：分类图标 · 名称(+别名) · 收藏星 · 分类名 · ≤3 标签 · 状态 chip · 关系数 · 完整度 Meter（≥80 绿 / ≥45 黄 / 否则红）+ 数值 · 相对更新时间 · 悬停「…」菜单。卡片额外有 2 行摘要与重要度徽章；**不显示封面缩略图**。
- 批量操作：先点「批量操作」进入模式 → 表头全选（= 当前筛选集）+ 行复选 → 底部悬浮条 `已选 N 项` + `批量打标签` / `改状态…` / `移动分类…` / `删除` / `取消`。删除确认：`删除 N 个条目` / `所选条目及其关系、版本记录将一并删除。`
- 空态：`还没有设定条目`（+ 新建）/ `没有匹配的条目`（+ 重置筛选）。

## 4. 标签管理

- 单列 `Panel divide-y`，`max-w-[1000px]`；行 = 色点 · 名称(120px) · **前 5 个使用该标签的条目名**（点击跳转；无则斜体「未被使用」）+ `等 N 个` · `N 条目` 计数。
- 行操作：6 个色块快选 · `重命名` · `合并到其他标签` · `删除标签`。右键菜单同 + 颜色子菜单（带勾选）。
- 改名：`重命名标签` 弹窗（400px，回车/保存）→ `updateTag` 重写**所有条目里的标签串**；toast `标签已重命名` + `所有引用该标签的条目已同步更新`。
- 合并：`合并标签` 弹窗（420px，副标题「将当前标签的使用全部转移到目标标签，原标签删除」，单选列出其它标签及各自条目数）→ toast `「A」已并入「B」`。
- 删除：确认 `删除标签「X」` + `该标签正被 N 个条目使用，删除后会从这些条目上移除。`
- **未登记标签**面板：列出「出现在条目上但标签表里没有」的名字 + `全部登记`。

## 5. 灵感清单与快速捕捉

- 快速捕捉（520px）：标题（必填、自动聚焦、占位「这个想法是关于……」）· 内容（4 行，占位「场景、对话、画面、临时设定……」）· 灵感类型（10 种）· 标签；说明「成熟度默认为「原始想法」，可在灵感清单中调整。」；两个出口：**「保存为待整理条目」**（建 `status:"inspiration"` 的条目，摘要取内容前 120 字，写 `fields:{inspiration_type, maturity:"原始想法"}`，然后跳条目页）与 **「保存为灵感」**（建 `inspirations` 记录）。
- 灵感记录：`{title, content, type, tags, maturity(raw/developing/ready), linkedEntryIds, createdAt}`；`linkedEntryIds` 用于把灵感挂到已存在的条目上。

## 6. 地点与地图

- 两个视图：`层级列表` 与 **`地图占位`**（原站第二个按钮字面就叫「地图占位」，说明该视图仍在建设中）。
- 数据：`project.maps[{id,name,image,pins:[{id,entryId,x,y}]}]`；旧字段 `mapImage/mapPins` 自动迁移为单张「主地图」。
- **坐标是容器百分比 0–100（保留 1 位小数）**，不是 0–1；导入校验允许 ±1e6（UI 才 clamp）。
- 平移/缩放：`zoom ∈ [1,5]` + `pan`，`transform: translate(...) scale(...)` + `transformOrigin:0 0`；`clampPan` 保证图始终铺满；滚轮 `factor = exp(-0.0016*deltaY)` **光标锚定**；按钮 `缩小(1/1.4) / 放大(1.4) / 重置视图`（按钮文字显示 `{round(zoom*100)}%`）；双指捏合。
- 指针分发顺序：双指 → 图钉（优先于交互元素白名单）→ `button/label/input/a` 忽略 → 平移。拖动图钉位移 >3px 才落库（toast `标记位置已更新`）；无位移则选中（右栏详情卡）。
- **点击放置**：先在「放置标记」下拉选地点（只列该图上还没有标记的地点）→ 在图上点击 → 落 `{id, entryId, x: 0.1 精度, y}`（toast `地点标记已放置`）；已存在时提示 `该地点已在本地图上` + `可直接按住标记拖动调整位置`。光标：`grab / grabbing / crosshair`。
- 图钉渲染：`-translate-x-1/2 -translate-y-full` 的按钮（底尖对齐坐标），`map-pin` 19px，`fill:var(--accent-soft)`，下方 18px 处名称标签（`rgba(8,9,12,.72)`）；失效图钉显示红色 `未知地点` 卡。
- 底图上传：`支持 JPG / PNG / WebP，最大 3MB，超出将自动压缩`；>30MB 直接拒绝；压缩策略 = 长边 ≤4096，尺寸档 `[1,.85,.7,.55,.4]` × 质量档 `[.92,.85,.75,.65,.55,.45,.35]`，取首个 `0.75*base64长度 ≤ 目标字节` 的结果（WebP 优先，回退 JPEG）。封面图另有更激进的压缩（长边 1600，目标 320KB）。
- 多地图：右栏 `地图分类` + 计数；每行 切换 / 图钉数 / `重命名` / `删除地图`（仅当 >1，原生 confirm）；底部 `新建地图`。
- **层级列表**：`geography` 用途分类下的条目递归平铺（`paddingLeft = 16 + 22*depth`），父子关系解析顺序 = `entry.parentId`（需无环）→ 首条 `位于` 关系（推断出的层级会标「该层级由「位于」关系推导」）。行内列：封面缩略（40×40，`objectPosition: coverFocus.x% coverFocus.y%`）· 名称 + `{place_type} · {region}` · **控制势力**（`w-[150px]`，来自 `控制`/`统治` 关系的来源方，点击打开「控制势力」弹窗可就地增删这些关系）· **危险度**胶囊（`安全/低危→--ok`、`中危→--warn`、其它→`--danger`）· `N 关系` · `N 子区域`。
- 预置字段：`place_type`（19 项：大陆/国家/城市/聚落/要塞/遗迹/森林/山脉/海洋/沙漠/地下城/秘境/空间站/废墟/神殿/学院/港口/边境地带）、`danger`（5 项）、`region, climate, terrain, resources, population, culture`。
- **无区域多边形/形状绘制**（只有图钉）。

## 7. 人物与角色

`index:"NPC"`。工具栏：搜索（占位「搜索姓名、种族、职业」，匹配 name + `fields.race` + `fields.occupation` + summary + 卡片字段值）· `角色状态` 下拉（选项来自现有 `fields.char_state` 取值）· `重要度` · `卡片字段（N）` 配置 · 右侧 `新建角色`。
卡片网格（1/2/3 列）：64×64 封面（`coverFocus`）或名称首二字 · 名称（`core` 时带「核心」徽章）· 别名行 · 所选卡片字段 ` · ` 连接（缺省 `["occupation","race"]`，存 `localStorage["ws_char_fields_{projectId}"]`）· **≤2 个关系 chip，仅 `效忠于`/`隶属于`**（含对端图标与分类色）· ≤2 标签 · 页脚：`char_state` 圆点（存活=ok / 死亡=danger / 失踪,封印=warn / 空=`状态未定`）+ 条目状态点 + `N 关系`。
与通用条目列表的差异：用途限定的子集、卡片而非表格、无排序/无批量、按项目持久化「卡片字段」偏好、两条状态轴并排展示。

## 10. 移植备忘
