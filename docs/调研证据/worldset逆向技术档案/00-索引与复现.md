## 3. 原始产物位置与复现

压缩代码与美化解压产物**不入库**（第三方 minified 代码，体积约 3.5MB），保留在工作区 `.rev-ashes/`（已加入 `.gitignore`）：

```
.rev-ashes/
  prj_ashes.html        首屏 SSR
  routes/*.html         11 条子路由 SSR（用于发现路由级 chunk）
  chunks/  chunks2/  pages/        原始压缩资源（26 / 45 / 13）
  pretty/  pretty2/  pretty-pages/ 对应美化版
  beautify.mjs          本目录同名脚本
  assets.txt all-chunks.txt pages.txt
```

复现步骤：

```bash
# 1) 首屏资源
curl -sSL -A "Mozilla/5.0" https://myworldstudio.cn/p/prj_ashes -o prj_ashes.html
#    抽出 HTML 内 /_next/... 引用 → 逐个下载到 chunks/

# 2) 懒加载 chunk：webpack 运行时里含文件名映射
#    "static/chunks/"+(id)+"."+({id:hash,...})[id]+".js"    ← 解析这个映射（本例 45 个）
#    形成 all-chunks.txt → 下载到 chunks2/（含 29 套主题特效层）

# 3) 路由级 page chunk：SSR HTML 直接引用，形如
#    /_next/static/chunks/app/p/%5BprojectId%5D/<route>/page-<hash>.js
#    注意正则要允许 "/"，只匹配文件名会全部漏掉
#    → pages.txt（11 个）→ pages/

# 4) 美化（自研美化器：字符串/模板/正则感知，仅用于阅读）
node beautify.mjs chunks pretty
node beautify.mjs chunks2 pretty2
node beautify.mjs pages pretty-pages
```

## 4. 边界与免责

- 仅反编译**前端 bundle**。服务端 `/api/*`（`auth/*`、`cloud/*`、`license/*`、`collab/relay`、`desktop/*`）只见到调用点，无实现。
- 变量名在压缩中已丢失（`e/t/a` 等），档案中所有结论均回查过源码并附 {文件, 行号} 依据；标称「不可确定」处即确实无法从 bundle 判定。
- 本档案记录的是**设计、数据形状与算法常数**，供学习与重写参考；**不要直接搬运原站代码**到 novel-studio（技术栈不同，且属于他人作品）。
- 原站自身存在若干缺陷，档案中已单独标注（如引用选择器「新建并引用」返回本地临时 id、callout 类型导出 Markdown 后不可逆、隐藏/剧透内容仍保留在 DOM、横轴「今天」标记缺失等），移植时不应复刻。
