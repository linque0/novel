# 03 · 关系图谱（Worldset Studio）

来源：`pretty-pages/graph.pretty.js`（306→831 行，主实现）。**无第三方图库**：平面视图为手写 inline SVG，3D「星球」视图为手写 Canvas 2D 投影。
页面结构：`PageHeader{title:"关系图谱", index:"NET"}` → 过滤 Panel → `grid grid-cols-12`（画布 `col-span-9` / 详情轨 `col-span-3`）。

## 1. 双渲染器

| 视图 | 实现 | 持久化 |
| --- | --- | --- |
| `flat`（平面）默认 | inline `<svg width={940*z} height={560*z} viewBox="0 0 940 560">`，外层 div 用 CSS transform 做平移 | `localStorage["worldset-graph-view"]` |
| `sphere`（星球） | `<canvas>` + 手写球面投影 | 同上 |

**平面世界坐标固定 940×560**，节点/边全部画在这套坐标里；缩放 = SVG 尺寸放大（`z ∈ [0.3, 2.2]`），平移 = 外层 `translate`。适配按钮：`zoom=1, pan={0,0}`。

### 1.1 平面力导向（Fruchterman–Reingold 变体，逐帧、位置积分）

```js
k        = 0.62 * Math.sqrt(940*560 / N)      // 理想距离
restLen  = 1.45 * k                           // 弹簧静止长度
// 每帧：
repulsion:  f = k*k / d² * alpha              // 库仑斥力，全对全；d≈0 时加随机抖动
spring:     x = (d - restLen) / d * 0.06 * alpha
gravity:    a += ({x:470,y:280} - pos) * 0.0015 * alpha
stepClamp:  |Δ| > 0.12*k 则按比例缩到 0.12*k
bounds:     x ∈ [24,916], y ∈ [24,536]
alpha    *= 0.985 每帧；alpha < 0.02 归零并停止 rAF 循环
拖拽节点：  fx/fy 钉住，vx=vy=0
```

- **位置积分，无速度状态**（`vx/vy` 仅被清零，从不参与位移）。
- 种子：环状 `θ = i/max(N,1)*2π - π/2`，半径 `560*(完整重排?0.36:0.34+0.1*rand)`，中心 `(470,280)`；α 置 `1`（完整重排）或 `max(α,0.7)`（增量）。
- 重排触发：工具栏「重新布局」+ 画布右键「重新布局」。
- **适配视图**：350ms 与 1800ms 各跑一次；包围盒 `+140/+120` 余量，`z = max(0.3, min(rect.w/w', rect.h/h', 1))`，若 `z<1` 则 `pan = {-(midX-470)*z, -(midY-280)*z}`；**任何手动缩放会置 `adjusted=true` 后不再自动适配**。

### 1.2 3D 星球（Fibonacci 球 + 球面松弛，一次性，非逐帧）

```js
// 种子：黄金角球面，单位长度（y 轴为主轴）
l = 1 - i/max(N-1,1)*2 ; a = sqrt(max(0,1-l²)) ; θ = goldenAngle * i
pos = { x: cos θ * a, y: l, z: sin θ * a }

// 松弛（N≥3）：迭代 n = min(120, 40+2N) 次，alpha 由 1 线性降到 0
ideal = max(0.55, 2.4 / sqrt(N))
repulsion = 0.0016 * s / d²      // s = 1 - iter/n
spring    = (max(dist,1e-4) - ideal) * 0.012 * s
每轮把位移累加后 clamp 到 |acc| ≤ 0.05，再 v = normalize(v + acc)   // 始终贴在单位球上

// 摄像机
yaw=.6, pitch=-.25, camDist=2.4（clamp [1.7,4]）
投影：screen = center + (rotated.xy) * R * (camDist/(camDist - z))，R = 0.36*min(w,h)
惯性：vyaw*=0.94, vpitch*=0.94；闲置自转 yaw += 0.0016/帧（尊重 prefers-reduced-motion）
聚焦：yaw/pitch 以 0.12 系数 lerp 到目标，两者差 <0.01 时吸附
线框：4 条纬线 + 6 条经线，48 段，alpha 0.1/0.08，z<-0.02 段剔除
DPR 上限 min(devicePixelRatio, 1.5)；画家算法按 z 排序
深度表现：alpha = 0.18 + 0.82*((z+1)/2)，z>0.55 画白色高光
边：大圆 slerp，14 段，半径带 1+0.06*sin(t·π) 的凸起
```

## 2. 节点模型

- 节点 = 通过过滤的条目（分类多选 + 单标签）；**无节点上限**。
- 半径：平面 `5 + 1.6*importanceWeight`（8.2…13）；星球 `4 + 1.2*weight`（5.2…10）。
- 颜色：**仅用分类色**（`category.color || "#c99b5f"`），不体现状态/重要度。
- 描边：`weight≥4` 时 `strokeWidth 1.8` + 外环。
- 图标/封面：**不渲染**。
- 标签：单行截断 `name.length>8 ? slice(0,8)+"…"`，字号 10，`paint-order:stroke` 描边防压边。
- LOD：只有星球视图在 `N>500` 时隐藏非选中/悬停/ego 标签；平面无 LOD。

## 3. 边模型

- 边 = 两端都在当前节点集里的 relation；**悬空边直接丢弃**。
- 箭头：仅 `!isBidirectional` 时画（9px 长、±4px 宽的多边形），并**把线缩短到箭头根部**。
- 标签：平面在 `关系名` 开关打开或选中时画；屏幕距离足够（`> 两端半径 + 30`）时画 1/3 与 2/3 两处，否则中点一个，双向不同名时显示 `A ⇄ B`。星球只在聚焦节点的关联边上标注（14 段中的第 5.04 / 8.96 段）。
- CJK 文本宽度估算：`码点 > 11904 ? size : 0.55*size`。
- 样式：选中 `--accent` 1.6px，默认 `--line-strong` 0.9px；**`relation.status` 完全不参与样式**。
- 路由：平面是直线，星球是大圆 slerp；无正交、无 junction、无 bundling。
- **谱系边投影**（开关，`localStorage["worldset-graph-kinship"]`）把 `lineageLinks` 投影成伪关系：
  ```js
  { id:"ln_"+id, relationType: spouse→配偶 / adoptive→收养 / evolution→演化 / sibling→手足 / else→亲属,
    reverseRelationType:"", description:note,
    isBidirectional:(kind==="spouse"||kind==="sibling"), status:"active" }
  ```
  这些边以 `strokeDasharray:"4 3"` 呈现（靠 `id.startsWith("ln_")` 判定）。

## 5. 详情轨（右栏 col-span-3）

- 选中态：分类图标 + 条目名 + 分类名 + 关闭；摘要（3 行截断，空则「暂无摘要」）；度数切换（一度/二度）；关系行列表 —— `←`/`→` 方向 + 视角标签 + 对端分类图标 + 对端名 + 描述，双向不同名时附 `⇄ 对方视作「…」`；行点击重新居中；底部 `打开条目详情`。
- 未选中态：空态 + 前 8 个分类的图例 + 说明 `节点大小随重要程度变化`。

## 6. 空态与护栏

- 加载中：共享页面骨架屏。
- 过滤后为空：覆盖层 `当前筛选条件下没有节点` / `调整分类或标签过滤以显示更多设定。`
- 头部计数：`{节点数} 节点 · {边数} 边`。
- **无节点上限、无性能告警、无错误边界**；隐性护栏 = 星球松弛 ≤120 次迭代、N>500 隐藏标签、DPR ≤1.5。

## 8. 移植备忘（→ novel-studio）

- novel-studio 已有 `services/graphview.js`（`usePanZoom`、四向锚点、`edgePath/edgeGeom/arrowHead/hitRect`）与 `components/outline/canvas-model.js`（`routeEdge`、正交/贝塞尔路由、junction、`freeSpotFor`、`relayoutAll`），**基础设施强于原站**。建议：图谱直接用现有引擎，节点域从「仅人物」泛化到「任意设定节点 + 人物」。
- 原站可低成本借用的增量：**ego 一度/二度聚焦 + 变暗**、**关系名显示开关**、**谱系边虚线投影**、**过滤 chips（含层级缩进与隐藏计数）**、**详情轨的关系行（含 `⇄ 对方视作` 双向不同名提示）**。
- 原站缺失而 novel-studio 已有：**拖动建边、边标签编辑、手动布局持久化、端口（fromSide/toSide）**。移植后能力应超过原站。
- 星球视图（3D 球）是纯视觉噱头，成本 ≈300 行 + 调参，**建议后置或不做**；若要，直接照抄上面常数即可。
