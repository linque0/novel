# 04 · 时间线（Worldset Studio）

来源：`pretty-pages/timeline.pretty.js`（1737 行）、`pretty-pages/timeline-extra.pretty.js`（事件编辑器的条目选择器）、`pretty/chunks__3007-*`（日期与排序工具）。
**主视图无 canvas/SVG：纯 DOM + 绝对定位（x 用 `%`，y 用 `px`）**；只有「时间树」视图用 SVG。

## 1. 四种视图（置于工具栏，互斥）

| 状态 | 标签 | tooltip | 禁用条件 |
| --- | --- | --- | --- |
| `vertical` | 竖向 | — | — |
| `horizontal` | 横向对比 | 「分段纪年下各纪元独立计年，共享年份轴的横向视图不适用；请用竖向 / 树 / 双线对比」 | 分段纪年时禁用 |
| `compare` | 双线对比 | 「并排查看与编辑两条时间线」 | — |
| `tree` | 树 | 「时间树：主线为干，事件节点可扇出挂载支线，支线可再分叉」 | — |

配套：排序方式 `按时间排序 / 手动排序`；手动模式下再有 `拖动=插入 / 拖动=交换`（`localStorage["worldset-tl-drag-mode"]`）。头部右侧还有 `纪年`（打开纪元对话框）、条目过滤下拉（首项 `全部条目关联`）、`新增事件`。
页面宽度：compare/tree/horizontal 用 `max-w-[1500px]`，其余 `max-w-[1000px]`。

## 2. 竖向视图（默认）

每个纪元一个区块：纪元名（mono + accent）+ 细线分隔 + `{n} 事件`；区块内左侧 `101px` 处画一条竖向轴线。

单行三列：
1. **日期列** `w-[86px]` 右对齐：`num-mono text-[12.5px]`，颜色取 `timeType`；显示 `dB(ev)`；有 `endYear` 时第二行 `至 {TA(ev)}`；有 `displayDate` 时第三行。
2. `9×9` 圆点：`border-2`（颜色同 timeType），底 `var(--panel)`。
3. `.panel` 卡片：名称（链接到事件详情）；日期缺失或非确定时间时加徽章（`传说时代`/`秘密历史`/`模糊时间`）；地点 chip；摘要；参与 chips；悬停显示编辑/删除按钮。

排序：`手动排序` → 按 `manualOrder`；`按时间排序` → 按 `rY(e)`（见 §7）再按 `name.localeCompare(,"zh-CN")`。
重排：`▲/▼` 按钮 = 与相邻事件 `swapEventOrder`；拖动仅在手动模式启用（HTML5 DnD），拖动过半判定插入位置，虚线落点线；跨分线拖放显示「复制到此分线」徽章；拖动到视口边缘自动滚动（rAF，阈值 110px，步长 `⌈距离/6⌉`）；空纪元有虚线投放区。

## 3. 横向视图（唯一可缩放）

- 缩放级别 `N ∈ [1,8]`，步长 0.5（`Math.round(2*z)/2`），`localStorage["worldset-htl-zoom"]`；`Ctrl/⌘+滚轮` ±0.5；按钮 `−` / `+` / `适应`；标签 `1===N ? "适应" : N+"×"`。
- 轨道 `minWidth:860`，`N>1` 时宽度 = 容器宽 × N，靠原生横向滚动。
- 年份轴：
  ```js
  pad     = 0.04 * max(1, maxYear-minYear)
  minYear = floor(min-pad) ; maxYear = ceil(max+pad) ; span = max(1, maxYear-minYear)
  minSpan = 0.012 * span                       // 点事件的视觉最小宽度
  刻度步长 = nice(span/6)                       // 1/2/5 × 10^k 取整
  M(year) = (year-minYear)/span                 // → 0..1
  z(x)    = round(minYear + clamp01(x)*span)    // → 年份
  ```
- 纪元年带：按占用贪心排行（相邻需 `≥0.5%` 间隙），渲染为圆角胶囊，`top: 30 + 22*行号`，`height:18`。
- 事件条：同纪元内按占用区间 `[occStart, occEnd]` 排列（先按 start 再按 end 排序）；`point = endYear<=startYear`（含 endYear 为空）；
  ```js
  barW   = (point ? start+minSpan : end - start) / span * 轨道宽
  labelW = 11 * name.length + 8                 // 估算
  barW ≥ 52        → 标签在条内
  否则右侧有空      → 标签在右，并扩展占用
  否则             → 标签在左
  ```
  样式：`background: point ? transparent : color-mix(in srgb, 色 26%, transparent)`；`border: 1px solid|dashed`（非 `confirmed` 用虚线）；`height:22`；点事件画 8×8 圆点帽。悬停放大 + 210px tooltip。
- 指针游标：竖线 + 16px 圆形年标 + `{YQ(year)} · 点击新建`；**点击标尺或泳道空白即按该年份新建事件**（泳道点击会带上该纪元）。
- 未定时间区：`时间未定` + `{n} 事件` + 名称 chips 换行流。
- 纪元底部图例：4 个 timeType 色块 + 标签。

## 4. 双线对比 / 时间树

**双线对比**：`grid-cols-2`，每列一个分支下拉（主线名 = `project.mainBranchName || "主线"`）+ 计数 + 重命名 + `+ 事件`；两列共用「合并后的纪元顺序」以保证纪元分区对齐；跨列拖放 = 复制到另一条线（`duplicateEventToBranch`）。

**时间树**（SVG，`role="tree"`）：
```js
y(row)   = 34 + 66*row
x(主线)  = 320 ; x(支线) = ±(150 + (depth-1)*130)     // 左右交替，按子树行数平衡
subtreeRows(b) = max(1, 该支线事件数) + Σ 子支线
anchor(b) = 事件挂载点行号 ?? 父线中 |startYear - mountAtYear| 最近的事件行 ?? 0
```
- 边为三次贝塞尔（`mx=(x0+x1)/2`），描边用分支色，主线主干 `--line-strong` 2px + 14px 尾桩。
- 节点圆半径：主线 11 / 支线 9 / 空占位 7；标签两行（名称 + 年份或 `未定时间`，手动定位时附 `· 已手动定位`）。
- 悬停出现 `+` 开岔按钮；折叠徽章 `+N` / `−`；未挂载的支线画虚线占位节点「{name}（空 · 点击去添加事件）」。
- 节点可拖动自由定位，落点写入 `event.treeDx/treeDy`；工具栏 `复位布局` 清空全部（toast `已复位 {n} 个节点的位置` / `没有手动定位的节点`）。
- 挂载支线为根时显示面包屑：`挂载于 {parent} · {anchor}（点击回到父线）`。

## 5. 过滤与控制（原站很克制）

**只有两个过滤条件**：分支 chip 条 + 单个条目下拉。
```js
events(branchId) = E.filter(e => (有效branchId ?? "") === branchId)
                    .filter(e => !entryId || e.participantEntryIds.includes(entryId)
                              || e.locationEntryId===entryId || e.relatedEntryIds===entryId)
```
无纪元/时间性质/参与者/地点/标签/全文过滤，无密度控制。
分支 chip 条：主线 chip + **无挂载的独立分线**（按 `sort`）+ `+ 分线`；双击重命名；右键菜单（重命名 / 设为主线 / 删除分线）；有挂载支线时显示 chevron 展开嵌套列表（带 `挂载于 {parent} · {anchor}`）。

## 6. 事件编辑器（Dialog width 880，可缩放，`storageKey:"ws-dlg-event"`）

| 字段 | 控件 | 备注 |
| --- | --- | --- |
| 事件名称 | text，必填 | 占位「例如：黑潮大污染」 |
| 纪元 | text + 选择浮层 | 自由文本；浮层列出现有纪元（带 `· {n} 事件`），排除 `未分纪元`；留空即 `未分纪元` |
| 时间精度 | select `仅年 / 年月 / 年月日` | 降级会清空月/日 |
| 开始 / 结束 | 年（负数=前纪年；分段纪年时标签改为「本纪开始/本纪结束」）+ 月 + 日 | |
| 显示公元时间 | text，**仅分段纪年渲染** | 「纯展示文本，只在时间线上显示；不影响排序」 |
| 时间性质 | select（4 值） | |
| 所属分线 | select（主线 + 分支按 sort） | |
| 加入世界时间线 | checkbox（默认勾选） | 关闭 = `inWorld:false`，只在「条目时间线」显示 |
| 发生地点 | select（`未指定` + geography 用途分类下的条目） | |
| 参与 | 条目选择器（顺序：势力 / 人物 / 地点 / 组织 / 物品） | |
| 关联条目 | 条目选择器（全部条目） | |
| 摘要 | textarea rows=2 | |
| 事件正文 | 富文本，`minHeight:200` | 占位「撰写事件详情……输入 / 唤起块菜单」 |

条目选择器（`EntryPicker`）：搜索框（150px，占位「搜索名称…」，清除按钮）+ 计数 `共 N · 已选 M · 命中 K` + 点击切换 chips；**已选置顶**，分隔文字「以下未选」；未选默认封顶 60 条，超出显示「另有 N 个未显示 —— 输入关键词搜索全部」；`maxHeight:110`。

写入载荷（新增事件另加 `projectId`，`manualOrder = max(现有,-1)+1`）：
```js
{ name, era: era.trim()||"未分纪元", displayDate, branchId: b||null,
  startYear: x===""?null:Number(x), endYear: y===""?null:Number(y),
  startMonth, startDay, endMonth, endDay,        // 经 IC() 校验，非法→null
  timeType, locationEntryId: l||null, participantEntryIds, relatedEntryIds,
  description, content, inWorld }
// store 层：era 归一 "未分纪元"、timeType 归一 "confirmed"、补 createdAt；
// true 时省略 inWorld 字段，空时省略 displayDate
```

## 7. 纪元与纪年

**两种纪年方式**（对话框「纪年与纪元顺序」，width 560）：
- `统一纪年 linear`：所有事件共用一条年份轴（如公元），纪元先后由年份决定。
- `分段纪年 segmented`：每个纪元各自从 1 计年，纪元先后由手排顺序决定，年份只在同一纪元内比较。

**纪元顺序解析**：
```js
UNTAGGED = "未分纪元"
derive(events) = 按 rY 排序后首次出现的纪元顺序
resolve(events, project):
  if (!segmented) return derive(events)
  out = eraOrder 过滤空值/未分纪元/去重
  derive 中未见过的纪元追加到尾部
  若 eraOrder 或 derive 含「未分纪元」→ 强制追加到**最后**
```
`eraOrder` 管理：仅分段纪年可拖拽排序（也可 ↑↓）；改名**同步改写该纪元下所有事件**，改成已有名字即合并；`未分纪元` 是内置桶（不可改名/不可作为纪元名，恒定排最后）；删除纪元会把其事件移到 `未分纪元`。

## 8. 分支持久化语义

```js
createBranch(projectId, {name,color,description,mount})
  → { id:"br_*", projectId, name, color: color||"#c99b5f", description,
      sort: 该项目分支数, createdAt, ...(mount ? {mountParentId,mountEventId,mountAtYear} : {}) }
setBranchMount(id, mount|null)      // 环保护：沿父链 ≤64 跳；null 清空三字段
setMainBranch(id)                   // 交换 mainBranchName ↔ branch.name，并调整事件的 branchId ↔ null
deleteBranch(id, "reassign"|"delete")
  // reassign：事件 branchId 置 null（归回主线）；delete：连同事件删除
  // 两种模式都会清空子分支的挂载三字段
```
删除确认强制二选一：`事件归回主线`（推荐，默认） / `连同事件一起删除`。

## 9. 事件排序的存储语义（移植要点）

```js
swapEventOrder(a,b)                    // 同时交换 manualOrder 与 era（跨纪元交换）
insertEventAt(src, target, before)     // 把目标纪元内 manualOrder 重排为 1 基稠密序号；era 不同时随迁
moveEventToEra(id, era)                // manualOrder = 目标纪元(+分支)内最大 + 1
duplicateEventToBranch(id, branchId, {targetId,before}|undefined, eraOverride?)
  // 复制事件（新 ev_ id、新 createdAt，**不复制 manualOrder**），插入后对目标纪元稠密重排
```
`deleteEntry` 会清理时间线引用（`participantEntryIds` / `locationEntryId` / `relatedEntryIds`）。

## 10. 日期工具（建议逐条照抄语义）

```
YQ(year, unit="年")  = null/NaN → "未确定"；year<0 → `前 {|year|} {unit}`；否则 `{year} {unit}`
fmtYM({year,month,day}) = YQ(year) [+ ` {month} 月` [+ ` {day} 日`]]
dB(ev) = 开始日期的 fmtYM ;  TA(ev) = 结束日期的 fmtYM ;  NV(ev) = endYear==null ? dB : `${dB} 至 ${TA}`
rY(ev) = startYear==null ? MAX_SAFE_INTEGER : 10000*startYear + (startMonth??0)*100 + (startDay??0)
IC(year,month,day) = 公历校验（闰年感知），非法 → {month:null,day:null}
```
注意 `rY` 是**年为大权重**：月/日不可能越过年份差。

## 11. 空态与护栏

- 空态标题：`时间线还是空的` / `没有匹配的事件`（过滤后为空）/ `「{分支}」还没有事件`；条目过滤生效时不显示「新增事件」动作。
- 导入上限：events ≤20000、branches ≤500；坐标 clamp：`startYear/endYear ∈ [-1e7,1e7]`、`months ∈ [1,12]`、`days ∈ [1,31]`、`manualOrder ∈ [-1e9,1e9]`、`treeDx/treeDy ∈ [-1e6,1e6]`、`era ≤500 字`。
- **无导出、无分享、无打印、无「今天」标记、无 minimap**（横向视图的指针游标只是新建事件的交互，不是当前时间指示）。
- 无虚拟化；横向轨道用 `ResizeObserver` 重算宽度。

## 12. 移植备忘（→ novel-studio）

- 时间线是小说创作的刚需（多线叙事、闪回、平行世界），而 novel-studio **完全没有**。建议分两步：
  1. **竖向 + 横向对比**（DOM 定位，最省）——事件表 + 纪元（先只做自由文本 era，`eraOrder` 后置）+ `rY/dB/NV/IC` 日期工具；
  2. **分支/挂载支线 + 时间树**（SVG，复用 `graphview.js` 的 pan/zoom）——这一层是原站的差异化能力，成本中等。
- 可直接复用的 novel-studio 资产：`services/graphview.js`（panzoom/锚点/箭头）、`components/outline/OutlineCanvas.vue` 的绝对定位节点 + `svgBox` 负象限方案、`canvas-model.js` 的 `routeEdge/freeSpotFor`。
- 建议一并移植的**交互细节**：横轴的「指针处显示年份 + 点击即新建」、拖动时边缘自动滚动、点事件的 `minSpan` 最小宽度、标签左/右/内三态避让。
