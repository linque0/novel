# 大纲画布 · 纸本叙事工作台

预览：<http://127.0.0.1:5173/docs/outline-canvas-preview/>

> 合并稿（2026-10-19）：[大纲工作台](../outline-workbench-preview/) 把这张纸本画布与层级大纲的容器能力合成一个可连续使用的设计稿；本页保留为素材与平面画布方向的参考。

这是一份独立、可操作的前端设计稿，用于评审素材和画布视觉；未接入正式大纲组件或作品数据。所有节点文字均为虚构的设计内容。交互状态只在当前页面内有效，刷新恢复初始内容。

## 方向与素材

用纸本材料区分模块，把质感集中在边缘、折角、页层和书签。正文使用 HTML，连线、箭头、图标使用 SVG，缩放时保持清晰。使用项目现有京华老宋、霞鹜文楷字体；字体不重复打包。

| 模块 | 素材 | 前端处理 |
| --- | --- | --- |
| 事件 | 冷白棉纸、压印边线 | 类型标识、事件编号、标题与正文层级 |
| 便签 | 浅麦纸纹、右下折角 | 轻微旋转、手写字体、柔和投影 |
| 引用卡 | 象牙书纸、压印引号、叠页边 | 引用正文与来源栏分离 |
| 文本框 | 无材质、透明背景 | 直接书写文字，悬停或选中时显示编辑边界 |
| 容器 | 无材质、可换色框线 | 分组标题与事件计数；双击后可调整分组颜色 |
| 章节锚点 | 帘纹纸、布面书签 | 章节编号、状态点 |
| 卷 | 深松色布纹、黄铜细线 | 索引式排版、浅色文字 |

五类内容卡使用内置 imagegen 生成的原图，原始 PNG 为 1536 × 1024；前端使用 900 × 600 WebP。容器和文本框不使用图片材质，素材一览与下载包中也已移除这两类。提示词见 `assets/prompts.json`，原图见 `assets/originals/`。没有烘焙标题或正文，因此换文字不会破坏素材。

## 连线与交互

- 1.6px 圆头细线，小型收尖箭头；用关系类型的颜色绘制箭头，伏笔使用虚线。
- 流畅曲线 / 圆角折线切换；关联、因果、伏笔、冲突四种颜色。
- 单向、双向、无箭头可切换；点击关系标签或线条打开属性。
- 关系标签有轻底托；18px 透明命中区域便于选择细线；悬停和选中有细淡描边反馈。
- 拖动节点实时更新连线；拖动容器时随带三个主线事件。
- 双击模块编辑标题、正文；左侧工具箱可添加七类模块；方向键可以微调有焦点的模块。
- 空白处拖动或滚轮平移；Ctrl/⌘ + 滚轮以指针为中心缩放；底部按钮缩放、恢复100%和适应全图。
- 窄屏默认保留可读字号、允许平移查看，适应画布按钮可切换完整总览。
- 材质开关可对比纯色表面；素材一览支持逐张下载原图及完整素材包。

动效集中在悬停投影、选择描边、开关与属性浮层，持续约 150–200ms；拖动和连线更新直接跟随指针。遵守系统减少动态效果设置。

## 验收与范围

保留类型小标以识别七类模块；章节卡窄色边用于章节索引识别，与书签素材呼应。删去了画布背景上的装饰句，避免和分组标题抢位置。没有引入皮肤切换或无关功能。

设计稿展示矩形事件卡、常规节点关系；未实现生产画布的完整绘图编辑、任意端口新增连接、吸附、撤销历史、复杂交叉路由、存储和章节跳转。后续接入应复用现有 `OutlineCanvas.vue` 的节点数据、几何算法、端口和透明连线命中层，替换表面表现，保留已有业务能力。

检查结果及独立视觉评审记录在 `REVIEW.md`。2026-10-19 同步修改正式大纲画布：容器沿用分组配色，不应用纸卡表面；文本框移除底色层，全部皮肤下透明显示。已有作品数据不迁移。
