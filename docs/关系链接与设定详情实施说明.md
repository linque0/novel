# 关系链接与设定详情实施说明（2026-10-15）

三项交付：**「双链」改名「关系链接」**、**条目级关联关系**（设定↔设定 / 设定↔人物，行尾卡片 + 悬停浮层）、**设定详情页**（面包屑 + 关系列表 + 可拖动关系图谱 + 子条目树）。

## 一、兼容底线（改名只动文案，不动数据契约）

「双链」→「关系链接」的改名覆盖全部用户可见文案与注释（正文/幕布/大纲/灵感右键菜单、选择面板、悬浮窗、AI 草案错误提示、使用手册 §9 等）。**底层存储标记一律不改**，否则用户已写的全部行内链接失效：

- 富文本：`<span class="dl-link" data-dl-target="kind:id" data-dl-title="标题">`（正文 TipTap / 幕布 / 大纲节点）
- 纯文本：`[[标题]]` / `[[标题|显示文字]]` 令牌
- TipTap 标记名 `dlLink`、服务与组件文件名（DLinkPicker / DLinkPopover / DLinkTextMenu / doublelinks.js）、验证书标题「双链验证书」

## 二、数据模型

### 1. `lorelinks` 表（Dexie v12，`database.js`）

```js
{ id, workId,
  fromKind: 'mubu' | 'character', fromId,
  toKind, toId,
  label,          // 正向类型（from 视角），如「位于」，≤12 字
  reverseLabel,   // 反向显示名（to 视角，如「包含」），'' = 同 label
  description,    // 描述（图二右侧灰字），≤120 字
  color,          // '' = 按类型 hash 取色（复用 tagcolors）
  createdAt, updatedAt }
```

- **单向存储、双向展示**：入向在目标侧以 `reverseLabel`（缺省用 `label`）呈现；
- 去重：同 (from, to, label) 复用既有行并顺带更新描述 / 反向名；禁止自连；删除 = 硬删（同 `relations` 表惯例）；
- 端点半存活性：`liveLoreLinks` 过滤掉软删端点（回收站里的条目关系保留，还原即恢复）；
- **级联**：`mubuPurge`（含子树）与 `purgeItem`（mubu / characters 行）彻底删除条目时连带清理其关系；`mubuRemove` / `deleteCharacter`（软删）不清理；
- **备份**：`repo.loadWorkBundle` 增载、备份表清单加入 `'lorelinks'`（随备份迁移/恢复）；**不加入 `SOURCE_TABLES`**——AI 读模型（aidoc/aiedge 投影与哈希）本期不动，避免影响 project 管线与既有验收基线。

### 2. `loreGraph:<workId>`（appconfig）

图谱布局按**中心条目**分组记忆：`{ 'mubu:<中心id>': { '<kind:id>'(邻居): { x, y } } }`。
**落库必须用纯快照**（`JSON.parse(JSON.stringify(map))`）——IndexedDB 无法克隆 Vue 响应式代理，直接传 store 态会抛 `DataCloneError` 导致布局静默丢失（本次验收真实抓到并修复）。

## 三、服务与 store

- `src/services/relation-kinds.js`：类型预设 `REL_PRESETS`（位于/包含、属于/拥有、控制/被控制、影响/受影响、关联；含图标）+ `relIconFor / relReverseFor / relColor`（颜色沿用 tagcolors 的 FNV-1a hash，同名同色）；
- `OIcon` 新增 `map-pin / landmark / megaphone / user` 四个内联 SVG；
- `work` store：getters `liveLoreLinks`（含端点存活过滤 + 稳定排序）与 `loreLinkSummary`（`'kind:id' → { count, label, color }`，行尾卡片 O(1) 查询）；actions `loreLinksOf(kind,id)`（出向在前、入向按反向名、解析对端标题）、`addLoreLink / updateLoreLink / removeLoreLink / purgeLoreLinksFor / loadLoreGraph / saveLoreGraph`；
- `ui` store：`loreRelationPanel: { kind, id, x, y } | null`（设置面板，全局单例）、`loreDetailId`（详情页当前节点）。

## 四、界面

| 组件 | 职责 |
|---|---|
| `MubuView.vue` | 行尾**关系卡片**（彩色胶囊：首条类型 + 计数 `+N`，与标签卡片同款）→ 悬停自绘浮层（进出 220ms 宽限，移入保持、移出消失）；点击卡片开设置面板；**双击行**打开详情页（按钮/标签卡/关系卡/行内链接上让位）；右键新增「设置关系…」「打开详情页」 |
| `LoreRelRows.vue` | 关系行（图二样式）：`[类型胶囊(图标+色)] [方向 →/←] [目标名] [描述] [↗]`；`removable` 出 ×；`hoverLink` 供图谱联动高亮；四处共用（浮层/详情页/面板/人物区） |
| `LoreRelationPanel.vue` | 关联关系设置面板（可拖动、位置 session 记忆）：已有关系列表（× 即删）+ 新建（NSelect 搜索目标（设定+人物）→ 预设 chips 或自定义类型 + 反向名 + 描述 → 添加）；点面板外 / Esc 关闭（naive 下拉浮层不算点外） |
| `LoreDetail.vue` | 全屏详情页：面包屑（点击祖先就地切换）/ 大标题 + 标签卡片（点击 → 侧栏检索联动）/ 关联关系列表 / 图谱 / 子条目树（递归缩进，点击下钻）；「幕布中定位」、返回、Esc（浮层打开时不抢 Esc） |
| `LoreGraph.vue` | 关系图谱：中心条目固定原点、邻居环形自动落位（无记忆位置时）；复用 `graphview`（pan/zoom、箭头）与 `canvas-model`（`routeEdge` 贝塞尔 + A* 正交避障）；邻居**可拖动**（mouseup 后 350ms 防抖落库，重开保持）；连线带方向箭头（出向 → 邻居、入向 → 中心）与类型标签；悬停节点/连线与列表联动高亮；适应视图 |

入口与挂载：幕布行双击/右键、`MubuTree` 树行双击、`CharacterCenter` 人物详情「关联关系」区（「＋ 添加关联」）；`LoreDetail` / `LoreRelationPanel` 挂载于 `App.vue` 与 `PanelHost.vue`（拆窗可用）。样式集中在 `themes.css`（`.ob-relchip / .ob-relpop / .rel-row / .lrp-* / .ldt-* / .lg-*`），全部走主题 token。

## 五、验收

`tools/lorelink-verify.mjs`（《星尘旅人》实书 + 基线/还原 + `__检验` 幂等清理）**19/19 通过**：

1. 基线（关系数 / 图谱布局）；2. 行右键「设置关系…」面板打开；3. 新建关系落库（目标搜索 + 位于 + 反向名 + 描述）；4. 行尾卡片出现；5. 悬停浮层内容齐全；6. 浮层移入保持 / 移出消失；7. 双向展示（目标侧入向「包含」+ 卡片同步）；8. 人物侧「添加关联」（人物 属于 地点，反向名自定义）；9–10. 备份 JSON 含 `lorelinks`、端点 purge 级联清理；11. 双击详情页（标题/面包屑/子条目数与幕布一致）；12. 详情关系列表 + 图谱节点/连线数；13. 图谱拖动邻居（位置跟随 + 落库）；14. 重开保持；15. 图谱邻居点击切换详情、关系行点击切回；16. 人物入向行点击关闭并跳人物模块；17. 卡片点击开面板 + × 删除；18. 还原基线无残留；19. 三态截图（行尾卡片+浮层 / 详情页 / 图谱拖动后）。

## 六、取舍与后续

- **双击语义**：双击整行即进详情页，代价是双击选词会被详情页打断（拖选/键盘选词不受影响）；右键「打开详情页」与树双击是等价入口，若要改成「仅双击圆点/空白」，只需收紧 `MubuView.onRowDblClick` 的目标判断；
- 人物↔人物继续用既有 `relations` 表 + 人物关系图（本期不合并进关系链接）；
- AI 读模型（`aiedge`）暂不投影 `lorelinks`；全局搜索暂不检索关系内容；
- 图谱为一度星形（可拖动 + 记忆）；二度展开、关系类型自定义色板、关系批量重命名等列为后续。
