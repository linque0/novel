# 通用书封 · 图片素材与前端组合

2026-10-18 用户调整方向：不按四套界面皮肤制作，使用有材质的图片素材形成通用封面；书名与作者保留为可编辑的前端文字。

## 四款素材

| 名称 | 材质与画面 | 字体与构图 |
| --- | --- | --- |
| 布面典藏 | 深蓝布面织纹、银杏金饰、拱形框饰 | 老宋体，短书名上方居中两行 |

由内置 `image_gen` 每款单独生成一张无字原图；不使用上一轮拼图或将文字烘焙进素材。原图 1024×1536 PNG 保存在 `assets/originals/`，网页使用同构图的 768×1152 WebP（ffmpeg 编码 quality 84，四图总计约 656 KiB）。没有裁切或替换画面元素。完整生成提示词见 `assets/prompts.json`，排版元数据见 `assets/manifest.json`。

## 前端设计稿

入口：`/docs/book-cover-preview/`，也可打开 `universal.html`。页面的标题、作者、同屏比较、无字素材、书架尺寸、深浅衬底、原图放大与素材下载均可操作。设置写入预览 URL，刷新后读回；不接触正式作品存储。四款没有皮肤标识或使用限制。

- 图片负责纸纹、布纹、插画和烫金视觉；HTML 文字负责书名与作者。烫金为图片表现，不声称有真实光照反射。
- 悬停抬升 4px、首次错峰进入 450–600ms，控件与衬底转换约 200–280ms；遵守减少动态效果偏好。
- 保留上一轮稿：`code-only-v1.html`（原有 CSS/SVG 方案，与新版素材相互独立）。
- 本轮只交设计稿和素材，不修改 `src/components`，不接入正式书架。
- 删去上一轮的皮肤名、重复装饰标签和两行说明，改为一行材质说明。
