# 书籍封面设计稿

**当前版本为通用图片材质封面**，入口 `index.html`，完整设计说明见 [UNIVERSAL.md](UNIVERSAL.md)。四款不绑定任何界面皮肤；使用此次生成的独立无字素材与可编辑文字排版。素材及整包下载位于 `assets/`，新版运行截图位于 `screenshots/universal-*`。

以下是上一轮纯代码稿的历史记录，入口已保留为 `code-only-v1.html`，不代表当前版本。

## 第一版历史记录

目标：将「纸上藏书、深空回响、琉光叠影、赤月山笺」做成可运行、可替换书名和作者的前端封面，同屏比较后由用户评审。此阶段不接入正式书架。

## 打开

在仓库根目录启动本地服务，例如 `python -m http.server 8768 --bind 127.0.0.1`，然后访问 <http://127.0.0.1:8768/docs/book-cover-preview/>。也可以通过项目现有的 Vite 开发服务访问 `/docs/book-cover-preview/`。

- `index.html`：四款独立的封面结构与内联 SVG。
- `covers.css`：封面材质、构图、container query 单位、响应式排版。
- `preview.js`：替换书名和作者、大小切换、明暗衬底、恢复默认。
- 复用仓库自带的京华老宋与霞鹜文楷，使用 `../../src/assets/fonts/fonts-user.css`。请在仓库内运行以保留字体路径。

## 视觉选择

1. **纸上藏书**：象牙纸纹、靛蓝布脊、不对称宋体竖题、作者朱印。标题 5–8 字改横排，9 字以上按长度缩小。去掉无关插画，文字为主角。
2. **深空回响**：深海蓝、铜色轨道、局部星体。上半部专供标题；下半部为矢量星图。短题拆为两行。
3. **琉光叠影**：冰青、透明矢量叠片、折射边缘、文楷题名。无外部图像，文字始终独立于材质。
4. **赤月山笺**：墨绿纸纹、暗朱圆月、三层金线山形。短题右侧竖排，长题横排，作者相应移至底部。

全部书名和作者均为真实 DOM 文本，不以图片代替。装饰由 CSS / SVG 绘制，不使用上轮生成的位图。默认使用同一虚构书名《山海来信》和作者「林舟」作对照。

## 预览操作

修改顶部输入框会同步四款封面。书架尺寸为 148px 宽，窄屏为 128px；页面从四列变两列。操作值写入本地预览 URL，刷新后读回，不接触作品存储。书名为空时显示「未命名作品」，作者为空时隐藏作者文字和作者印。

动效仅包括首次错峰进入（总计 680ms）、封面悬停抬升 4px、控件 200ms 反馈与衬底 300ms 转换；支持减少动态效果偏好。该稿只进行主 Agent 视觉自检，不作独立评审或评分。截图与检查记录保存在 `screenshots/`。

## 边界

这是设计预览，正式书架组件尚未更改。64 字以内书名采用分级字号，整本书名可通过原生标题提示和无障碍名称读取。书架小图中的作者、版次和装饰属于次级信息，重点检查书名辨识与构图。
