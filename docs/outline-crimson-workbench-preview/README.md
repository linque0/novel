# 赤月戏 · 大纲工作台适配设计稿

地址：<http://127.0.0.1:5173/docs/outline-crimson-workbench-preview/>

本轮只制作设计稿，全部新增文件位于本目录，未修改正式 `src/`、正式作品或数据库。页面挂载实际 Workbench 与大纲组件，使用独立的《山海来信》内存内容，禁用此页的自动保存与偏好写入。刷新恢复初始状态。

## 设计方向

让大纲成为赤月戏的墨色戏本工作台：深墨承接导航与结构索引，暖纸承载故事内容，旧金用于边界和辅助信息，朱砂强调进入与当前层级。沿用实际软件的七模块导航、花月横带、底栏及京华老宋字体，不新增花纹和图片。

- 顶栏68px、模块横带76px、侧栏252px；压缩内层重复的标题和入口，把空间留给画布。
- 深墨侧栏配朱砂书脊、金色结构目录、七类工具和本层列表。常态目录只显示容器层级；事件等叶子放在本层列表，搜索和类型筛选时仍显示匹配叶子，减少重复。
- 画布用暖纸与低对比点阵；已有事件纸面作暖色适配，便签保留麦黄色，引用纸保留叠页。容器只显示颜色分组，文本框透明。
- 进入容器保留原镜头过渡与面包屑，就地展开仍在全书画布；缩略节点收敛文字排版，“编辑”入口在悬停、焦点或选中时显现。
- 设置抽屉延续暖纸、深墨正文和朱砂主按钮，颜色选择与进入/展开各有入口。
- 小于900px时将侧栏收进“故事结构”抽屉，顶部模块导航可横向滚动；适配窗口使用780×900验证。

## 交互和范围

可体验容器展开/收起、进入/返回、层级搜索、纸面材质开关、连线样式、设置面板与窗口缩放。继承实际组件交互，不代表本轮已正式上线。

`label-layout.js` 是设计稿专用的标签排版：展开容器时，将碰到标题区域的关系标签移到容器上方，表达“内容不被连线标签遮挡”的目标。它不改正式路由几何；正式接入时应与项目统一的连线几何、标签锚点一起处理，不能直接作为路由算法上线。本轮没有验收生产规模性能、实际持久化或安装包。

## 视觉评审与证据

完成一轮独立的存量界面润色评审，不打分。已处理：展开标签压住容器内容、引用缩略卡裁切、金色使用过多导致正文层级偏淡；提高正文对比，统一缩略卡可用空间，移除重复的“文本视图”“容器内部”“工具箱”文案。保留实际赤月戏外壳和已确认的容器结构。

主要动效沿用真实组件的420ms进入、300ms返回、原地展开与抽屉反馈；设计稿尊重减少动效设置。层级进入返回连续三轮通过，等待过渡层消失后检查，不使用固定延时。未另录制动效视频。

JavaScript语法检查及CSS解析通过；浏览器中检查进入/展开分离、三轮进入返回、搜索折叠叶子、嵌套定位、窄窗结构抽屉。控制台error日志为空。未运行生产构建或全量测试。
