# 大纲优化方案：容器封装与层级画布

## 本轮设计决定

长篇大纲通过容器组织：同一种容器负责分类、颜色、故事封装和递归嵌套，不增加独立的“情节块”模块。展开时是分组框，收起时是故事摘要；事件、便签和透明文本继续使用各自的模块形态。

这次仍是独立前端设计稿，不改正式作品数据和数据库。原“普通容器／情节块”双对象方案已按本轮反馈合并。

## 不能混淆的两种动作

| 动作 | 就地展开／收起内容 | 进入容器／返回上层 |
| --- | --- | --- |
| 意图 | 在全局比较一段故事的细节 | 专注这一段故事继续写作 |
| 当前画布范围 | 不变；相邻容器仍可见 | 变为这个容器的内部 |
| 面包屑与标题 | 不变 | 更新到当前容器，并标记“容器内部” |
| 控件 | 容器右上，低强调 | 容器左下，“进入容器”，绿色强调 |
| 动效 | 子项短距揭示，不播放进入动画 | 从触发容器的边界向内部画布推进；返回反向收回 |
| 状态 | 只改变这个容器的展开状态 | 保存各层滚动位置与原展开状态，不偷偷展开或收起 |

“完成”与“收起”独立。未完成的容器也可以收起，完成的容器仍能展开修改。

## 容器如何封装故事

- 工具栏保留事件、便签、文本和容器入口。容器可直接新建为空，进入后继续添加模块。
- 多选当前层的模块后，点击“容器”或选择条的“用容器封装”，填写名称与摘要。
- 选中对象归入新容器，原编号、内容和全部关系保留；新容器收起为摘要单元。容器可以再次放入更大的容器。
- 同一模块只有一个结构父级；禁止结构环。人物、地点、主题使用引用，不复制剧情。
- 容器设置统一编辑名称、颜色和收起摘要；一次提交、一次撤销。六个配色是初稿选项，正式版沿用原调色能力。
- 容器只有纯色边界与淡色底，不使用专用纸纹或图像；文本模块背景透明。

## 层级进入动画

进入约 440ms，返回约 300ms。触发的容器边界扩大到画布范围，新层内容向前展开；返回时边界收回到上层容器。导航状态立即提交，不等待动画结束才能操作。

快速连续进入、返回或 Esc 会清理上一段动画，不残留遮罩。Esc 停止视觉动画，保留已经到达的层级；它不会撤销故事内容。减少动态效果偏好下，直接显示最终状态。搜索定位直接到达目标父层并高亮，不把搜索误表现为逐层进入。

原型中保存每层滚动位置；正式画布接入后应改为保存相机的平移、缩放与当前选择。连线使用未变换的最终几何生成，动画期间统一随画布变换，结束后重算，避免箭头漂移。

## 折叠时连接不能丢

- 关系存真实事件编号。隐藏端点投影到最近可见容器边界，展开后恢复到原事件。
- 内部连线在收起时隐藏，穿出容器的关系继续显示。因果和伏笔分别聚合，点击可查看真实来源与去向。
- 进入容器后，范围外关系显示为前接／后续接续卡，点击可定位。
- 正式接入要保留模块接线、线接线及宿主依赖，不因折叠重写宿主编号和连接点。

## 快速整理与查看

结构树、面包屑、标题与画布来自同一份结构。搜索覆盖隐藏的标题与摘要，结果显示完整路径。总览只收起当前层容器；展开一层只打开直接子容器；收起已完成不修改状态或正文。

进度只统计事件，便签、文本和容器本身不充当事件。没有事件的容器显示待展开，不显示 0/0。摘要由作者填写，不默认调用 AI 或覆盖手写内容。

## 正式接入顺序

1. 复用现有容器、父子归属与折叠字段，补齐收起摘要几何和最近可见祖先映射。当前正式画布的折叠后代端点会返回空几何，外联投影必须先补齐。
2. 接入进入／返回、相机状态、面包屑与结构搜索，确保观看偏好按作品隔离。
3. 容器封装、移入／移出、解散采用整体事务，复用自动保存及撤销重做。解散时处理摘要去向。
4. 对可见范围做布局和避障，缓存统计与宿主路径；不更换既有画布框架。

验收包括四层以上嵌套、双向导航、原位展开、快速打断、跨两层外联、宿主分支、刷新读回、撤销重做和大作品性能。字段扩展须核对正式序列化及导入导出。

## 当前设计稿边界

已做：容器新建和封装、名称颜色摘要设置、嵌套展开、进入／返回动画、滚动位置恢复、事件／便签／透明文本添加、真实关系投影、结构树、搜索和修改撤销。

未做：正式作品保存、自由拖动布线、完整画布模块库、节点删除与解散、重做、所有皮肤适配和大规模性能验收。初稿沿用示例数据，刷新重置；原正式画布与之前纸面设计稿保留。
