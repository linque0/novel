## 本轮可体验

1. 容器右上“就地展开／收起内容”：保留当前画布、标题和面包屑，只显示或隐藏子项。
2. 容器左下“进入容器”：切换到内部画布，显示“容器内部”，从原容器边界向画布推进约 440ms；面包屑返回约 300ms 反向收回。
3. 返回后恢复上层滚动位置与原展开状态；动画可被快速导航或 Esc 打断。搜索不播放层层进入动画，直接定位真实事件。
4. 多选同层模块，点击工具栏“容器”或选择条“用容器封装”，封装后保留原内容与关系，并可一次撤销。
5. 不选择模块时点“容器”可创建空容器。进入后，工具栏可添加事件、便签、透明文本或新的容器。
6. “设置”统一编辑容器名称、颜色和收起摘要，保存后一次撤销恢复。容器不使用专用纸纹。
7. 原有结构树、跨层搜索、跨容器因果／伏笔投影、总览、展开一层、收起已完成均保留。

进度只统计事件；便签、文本、容器不充当事件。

## 实现与边界

`index.html` / `blocks.css` / `blocks.js` 是独立前端。`model.js` 使用容器父子结构和原始关系；`model-test.mjs` 检查结构、投影和封装的实际约束。

没有接入生产持久化、自由拖动和布线、完整模块库、节点删除、容器解散、重做或正式画布的宿主连接点。正式项目接入顺序及验收写在方案中，不把原型当作已完成的产品功能。
