OVERVIEW

五个创作要素，
收进同一个本地工作台

面向长篇作者的桌面写作软件 · Windows x64 · 另提供 DSH 插件同步版

小说工坊把「正文 / 大纲 / 设定 / 人物 / 灵感」收进同一个可联动的工作台，并深度整合「恍然梦」AI 创作协同。 软件以输入即存为第一原则：输入防抖 1 秒落盘、30 秒兜底、失焦与切章与关窗前强制保存，配合章节自动版本快照与回收站，尽力让每一句话都不丢。作品数据全部留在本机；除你主动配置并调用的模型服务外，不联网、不上传、不登录。

它着重解决长篇小说创作中最常见的四个断裂：

创作痛点小说工坊的做法
结构散失
正文与大纲分离		 大纲提供分层自由画布与文本幕布双视图同源切换；事件、便签、引用、文本框、章节锚点、卷与容器自由摆位，四类语义连线自动绕障；正文可拆窗与大纲并排。
资料割裂
人物与设定散落多处		 人物配备卷宗档案 + 关系剧场；设定是一棵无限嵌套的幕布树，配有阅读视图与可交互关系星系；三者都能与正文通过关系链接互相引用、悬停预览。
灵感难落地
零散点子无从归档		 灵感采用按标签分组的单一拼板，支持图钉拖拽排序与跨组归类，并在侧栏抽屉中一键转为章节或设定（保留原灵感）。

版本混乱、AI 难把控		 三道自动保存 + 最近 30 份版本快照 + 回收站 + JSON 全库备份；「恍然梦」所有写稿与设定修改均先生成候选与提案，经作者确认才写入正式稿件。

BOOKSHELF & FLOW BACKDROP

3D 轮播书架与 WebGL 幻流背景

自 v1.2.4 起，桌面版界面收敛为统一的「幻流」皮肤语言，覆盖书架、工作台、设置与拆出的独立窗口。顶部胶囊集中切换六大模块（书架 / 正文 / 大纲 / 设定 / 人物 / 灵感），右侧常驻保存状态、搜索、统计、设置、锁屏与「恍然梦-入梦」入口；主舞台以 3D 透视轮播生成式书封，支持按创作状态（全部 / 连载 / 完结 / 构思 / 搁置）筛选、键盘左右切换及「继续写作 / 打开工作台」双入口，底部票根实时记录上次阅读章节与进度。

WebGL 实时流场

可选择跟随作品封面自动取色，也可切为自定义两色（RGB / 色板 / 五组推荐配色），支持 0–2× 流动速度调节（0× 静止）与深/浅面板明暗切换。

多配置隔离与单实例保护

同一数据目录仅允许单实例运行以防并发损坏；启动加 --profile=名字 即可隔离独立书库目录。

03 · 正文
FOCUS · ANNOTATIONS · CONTEXT

专注写稿 · 批注双链共存 · 阅读模式

点击左右分隔手柄即可将章节目录与批注栏收起为极窄竖轨标签（「批注」「章节」），让稿面在屏幕中央安静展开，且每块区域的栏宽与收起状态会随布局偏好持久化记忆。在正文中选中文字右键，即可就地呼出 Word 式快捷操作栏，直接完成排版、加批注或添加关系链接。

文内标记视觉样式能力说明
正文批注 实线下划线（偏下 + 淡底） 可选 6 种用途色或自定义色；右栏逐条对应，点击定位并闪烁；删批注不删原文，整段删文后自动标「已失效」可一键清理。
关系链接 点状下划线（贴字主题色） 选中右键或输入 [[标题]] 关联章节 / 人物 / 设定；与批注同句叠放互不覆盖；悬停弹出可拖动钉住的预览窗。
阅读模式 只读宽栏排版 收起编辑工具条，巨排章号随正文滚动，左侧细边条滑出章节列表，Esc 两级退出恢复编辑。

RELATIONSHIP THEATER

人物 · 关系剧场

08 · 恍然梦 AI 协同
DREAM ASSISTANT & KNOWLEDGE

恍然梦 · 入梦与浅眠双模式协同

作者握有最终取舍权：先生成候选与审稿证据，再经确认写入正式稿件

「恍然梦」从书架、顶栏与编辑工具栏无缝接入创作全流程，分为沉浸共创的「入梦」与工坊侧边辅助的「浅眠」两种形态，并配备全书记忆队列与知识库检索。

恍然梦-入梦（故事现场）

面向连贯推进故事的沉浸舞台：支持「AI 叙事主写」与「角色参与」、写稿与剧情讨论切换、章节确认锁定、旅程记录回溯、独立审稿清单（含原文证据定位）与修稿前后对照；内置「高级创作工具」支持最多 10 章批量规划、写稿、审稿与复核流水线及 Token 预算控制。

恍然梦-浅眠（工坊助手）

不离开当前正文、大纲、设定、人物或灵感界面，随时在右侧呼出协同面板；在正文编辑器内选中文字点击「发送给恍然梦」即可围绕选中段落请求续写、改写或审修建议，同时支持人物 / 关系 / 设定状态联合提案。

底层能力工作机制与安全边界
全书知识库索引 本地索引全书设定、大纲、连线、人物、关系、灵感与批注；构建全文事实摘要前会弹窗确认范围；检索支持关键词与可选向量模型（Embeddings）语义检索（失败自动回落关键词）。
章节记忆队列 采纳正文后自动登记增量记忆更新任务；以内容指纹防止过期覆盖，异常中断后支持租约回收与重试；切换作品或启用隐私模式时自动取消在跑作业。
多供应商与凭据加密 「设置 → 模型设置」支持多供应商预设（Base URL / API 格式 / Key）、拉取或手动管理模型列表、温度与上下文预算控制；API Key 经系统凭据加密存储在本机，不写入备份文件。
隐私与本地边界 所有作品与设置默认保存在本机。只有当你主动配置模型服务并触发「恍然梦」请求（或手动构建全文事实时），才会向你设定的 API 端点发送必要上下文；开启「隐私模式」可限制发送范围。

WRITING ANALYTICS · OVERVIEW

写作分析 · 速览浮窗、创作历程与作品对照

完全基于本机保存日志实时生成 · 无需联网 · 支持 7 / 30 / 90 日及自选日期区间

创作历程（单作品 / 全库）
