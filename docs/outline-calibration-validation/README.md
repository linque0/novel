# 正式大纲工作台 · 纸面视觉校准

2026-10-19。以 `../outline-workbench-preview/` 已确认设计为参考，直接调整正式 Vue 组件。北极星：低饱和鼠尾草绿与纸色的写作工作台，宋体标题、真实纸面模块、轻量工具。

## 实际变更

- 侧栏改为作品书脊入口、故事结构树、七类模块工具箱、本层模块列表；搜索、类型管理、重命名、删除、AI 入口及断线检测保留。
- 目录折叠使用临时状态，与画布就地展开、进入容器分离。作品入口返回全书；定位结果使用原有层级跳转及进入动画。
- 画布标题、工具栏、点阵、纸面素材、标题正文间距与缩放控件统一校准；所有皮肤的大纲内部共用纸面语言，外层导航保留皮肤原貌。
- 详细卡片使用更适合正文阅读的默认尺寸；已保存的手动宽高优先，小尺寸卡片采用紧凑文字。容器仍用可变颜色分组，文本框保持透明。
- 折叠容器投影连线取消常驻粗高亮，选择与悬停才显示反馈；20px 透明命中层保留。没有改写路由算法或关系数据。
- 没有新增材质图、数据库迁移、批量改写旧作品，也没有制作安装包。

## 验收页

运行中的 Vite 地址：`http://127.0.0.1:5173/docs/outline-calibration-validation/`。

该页直接挂载正式 `Workbench.vue`、正式大纲组件与 stores，采用设计稿的《山海来信》内容，数据仅在内存中；禁用此页自动保存和偏好写入。可用 `?skin=gravity`、`?skin=glaze`、`?skin=crimson` 检查其他皮肤。它不是另写的静态仿制界面。实际应用根入口也以专用作品“画布验证书A”走通书架→大纲→画布。

## 独立视觉评审及修正

进行一轮无历史上下文的“存量已有界面润色评审”，不打分。评审使用修改前、批准参考及四皮肤当前截图，不查看代码。

评审指出：投影分支连线过粗、全书标题下有重复横带、操作小字偏淡、点阵较强，底栏装饰文案混杂。已取消投影线常驻高亮；宽屏全书搜索并入标题区，保留容器内部面包屑；增强章节和工具文字对比；减淡点阵；删除“纸的温度，故事的秩序。”及重复“全书画布”。保留书脊、宋体书名、便签与引用纸差异、透明文本和外层导航。

沿用已有容器进入/退出镜头动画；新增工具按钮仅有轻微悬停反馈，尊重减少动效设置。本次未另录制动效视频。
