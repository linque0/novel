# 小说工坊 · 使用手册

> 本地优先的长篇小说桌面创作空间（**幻流**工作台），将正文、大纲、人物、设定、灵感与写作分析收进同一处，编辑时输入即存。当前软件版本号可在「⚙ 设置 → 帮助与关于」中查看。

---

## 1. 启动与数据安全

| 启动方式 | 命令 / 入口 | 用途 | 本地数据目录 |
|---|---|---|---|
| **安装版** | 安装程序 `novel-studio-setup-x.x.x.exe` | 日常创作与分发使用 | `%APPDATA%\小说工坊`（正式作品库） |
| **生产源码启动** | `npm start` | 本地源码启动正式桌面端 | `%APPDATA%\小说工坊` |
| **开发调试版** | `npm run dev` | 源码热更新调试 | `%APPDATA%\小说工坊-dev`（隔离测试书目） |

- **纯本地工作**：所有作品稿件、大纲连线、人物关系与统计记录默认保存于本机硬盘，不联网、不主动上传内容。
- **单实例防冲突**：同一数据目录同一时间仅允许运行一个窗口实例，以免多实例并发写入损坏本地库；若同时开启多个实例，请附加独立目录参数 `--profile=自定义名称`（对应目录为 `小说工坊-自定义名称`）。
- **彻底退出调试环境**：开发完成后执行 `npm run stop` 优雅退出所有实例并确保本地数据落盘、端口释放。

## 2. 界面总览（幻流工作台）

- **书架顶栏**：左侧品牌与当前皮肤标识，右侧提供书目搜索框（按书名 / 作者 / 类型实时过滤）、写作统计、⚙ 设置、锁屏及「＋ 新建作品」入口。
- **作品内统一顶栏**：左侧品牌标，居中胶囊导航可在「**书架 / 正文 / 大纲 / 设定 / 人物 / 灵感**」六大工作区之间顺滑切换；右侧常驻当前保存状态（「已保存」）、全局搜索 🔍、写作统计 📊、⚙ 设置、锁屏 🔒 及独立拆窗入口。在「设置 → 外观与排版」中可开启「默认隐藏顶栏」，留出更纯净的写作视野。
- **可调工作区面板**：多数工作区左侧目录边栏可拖拽右缘调整宽度（或一键折叠成窄边标签），双击分隔手柄恢复默认宽幅。

## 3. 书架、导入与整库备份

- **3D 书封陈列与进度票根**：书架中央以带流场光影的 3D 轮播书封展示当前选中的作品，顶部标签支持按「全部 / 连载 / 完结 / 构思 / 搁置」快速筛选；卡片信息行给出当前万字数与章数，下方票根提示上次阅读停靠的章节；鼠标悬停或展开菜单即可打开、编辑作品信息或软删除入回收站。
- **多格式智能导入**：在「⚙ 设置 → 备份与数据 → 导入作品…」中支持导入 **TXT / Markdown / DOCX / PDF / EPUB**：
  - TXT 自动识别 UTF-8 / GBK 等常见编码并按「第 X 章」智能分卷分章；DOCX 依据标题样式保留基础排版解析；PDF 按书签目录拆分（扫描件支持逐页存为插图）；所有导入均可在落库前预览分章结构。
  - **图片导入**需先进入具体作品后在正文右侧「本章插图」或设定编辑器内插入。
- **整库备份与存储迁移**：在「⚙ 设置 → 备份与数据」中可查看并**一键迁移作品库存储位置**，或导出包含全部章节与插图的 **JSON 全库备份文件**；换机重装后通过「恢复备份」先预览摘要再整库还原，建议每周备份一份到移动硬盘或个人网盘。

## 4. 文 · 正文写作台

正文采用**左目录、中稿纸、右批注栏**的三栏协同架构，兼顾长篇结构梳理与沉浸式敲字：

- **章节目录（左栏）**：分卷—章两级结构，支持关键词搜章、★ 书签收藏与拖拽排序，底部随时「＋ 新建章 / 新建卷」。
- **稿面与工具栏（中栏）**：基于 TipTap 富文本编辑器，顶部实时显示章节标题与目标字数进度条；格式工具栏集成撤销/重做、正文与 `H1–H3` 标题、加粗 / 斜体 / 下划线 / 删除线、字号、字体颜色、突出显示、左中右及两端对齐、有序/无序列表、引用、超链接与清除格式。选中正文右键即可呼出快捷编辑菜单，就地添加**批注**或**关系链接**。
- **随章「批注栏」（右栏）**：随当前选定章节实时刷新五项关联内容——**本章批注**、**本章大纲**（要点速记，可直接衔接大纲画布）、**本章出场人物**（自动识别）、**本章插图**（支持拖拽或粘贴上传）以及**本章信息**（字数 / 状态 / 最近更新时间）。
- **批注管理**：选中文字右键「添加批注…」并选择用途色（待改红 / 疑问蓝 / 伏笔紫 / 灵感绿 / 考据橙 / 待定灰或自定义色）。被批注文字呈现**实线下划线与同色淡底**，在右侧栏可点击闪光定位、改色、编辑或摘除（摘除批注不删正文文字）；若对应正文被整段删去，侧栏批注标为「已失效」，支持一键清理。
- **专注视角与阅读模式**：
  - 点击左右分隔手柄可将目录与批注栏折叠为贴边竖向快捷标签（「章节」「批注」），稿纸在屏幕居中展开。
  - 点击顶部「阅读」可切入只读**阅读模式**——呈现巨排章号、居中限宽排版与底部实时字数，左侧细边条滑出章节目录抽屉（选章切换后自动收起，支持逐级 `Esc` 退出）。
- **零丢稿保存与版本快照**：输入防抖 `1 秒` 自动落盘 + `30 秒` 兜底 + 失焦 / 切章 / 关窗前强制存盘；每章按 `5 分钟` 冷却策略自动留存最近 `30 份` 历史版本快照，随时预览并一键回滚。

## 5. 纲 · 分层自由大纲（画布 / 文本双视图）

右上角可随时在**画布视图**与**文本视图**间无损切换，两者共享同一份底层结构数据。

### 5.1 文本视图（幕布大纲）

适合快速梳理章节梗概与嵌套层级：支持缩进升级、拖拽排序、行内编辑、`MD / TXT` 按标题层级导入，以及在文字间插入 `[[关系链接]]`。

### 5.2 画布视图（分层自由画布）

- **模块摆放**：底部居中工具条提供**事件**（支持矩形 / 菱形 / 平行四边形 / 椭圆 4 种描边形状，以及已完成 / 正在写 / 待修改 / 待展开 4 种状态）、**便签**、**引用**（挂载人物 / 设定 / 章节）、**文本框**（可调透明度）、**锚点**（绑定或新建章节）、**卷**（绑定分卷）与**容器**。在画布空白处双击或右键均可快捷创建节点。
- **容器与分层下钻**：
  - 拖入模块即归属该容器；容器支持八向调整尺寸（高密度容纳时内容区可滚动）及右上角调色区分分支。
  - 根层仅平铺直接子节点，子容器呈章节卡片；点击「**进入容器 ↗**」钻入次级自由画布（面包屑逐级返回并恢复各层视野记忆），或点击「**就地展开 ＋**」在当前画布把容器展开为两列迷你卡（迷你卡支持直接改字、拖端口连线、内部排序或拖出回当前层）。
- **语义连线与 Hanan A\* 绕障**：从任意模块四向锚点拖线到目标即可建立连接，右键连线可在浮层中修改标签、**关系类型**（关联蓝 / 因果红 / 伏笔紫 / 冲突橙）、箭头方向（单向 / 双向 / 无向）、线型（实线 / 虚线 / 点线）、颜色、单条线宽与箭头大小。连线严格锁定建立时的两端接口方向——节点挪位绝不漂移，途经其它模块按 **Hanan 稀疏网格 A\*** 全局最短路径自动绕开（暂无可行通道时以虚线「路径受阻」提示，拉开卡片即恢复）；编辑浮层在屏幕内保持固定字号并自动选在避开连线本体的一侧弹出。
- **连接点（线连到线）与曲线塑形**：
  - 右键连线打开编辑浮层点击「**在此处创建连接点**」（或拖线直接落到既有连线本体上），即可在线路中途钉出双向接线柱；建点瞬间呈高亮圆环提示位置，随后淡出为精致微点，既可再分出多条分支也可被其它连线接入；右键连接点可连带清理分支。
  - 左键按住连线拖动可自由弯曲塑形，拖近直线或双击连线立即恢复自动路由。
- **关系投影与多选整理**：折叠或跨层连线会自动投影到最近可见容器卡与上/下接续卡，避免失去脉络；工具条「多选」勾选 ≥ 2 个同层节点可一次封装为新容器；`Ctrl+K` 全层级检索节点并自动跨层定位。
- **画布偏好设置**：右上角画布⚙支持独立调节底图透明度（20–100%，仅影响背景与点阵）、全局默认线宽与箭头比例、曲线/折线模式、16px 网格吸附与点阵显隐；📌 固定的模块在执行「整理布局」时保持不动。

### 5.3 故事结构侧栏

左侧「故事结构」同步展示全书层级的树形目录，点击直接居中定位节点，并随进入容器自动展开祖先并标出「本层」；点击侧栏收起按钮可在画布左缘留存竖向快捷标签以让出最大构图空间。

## 6. 人 · 人物卷宗与关系剧场

人物模块内置**人物卷宗**与**关系剧场**两种视角，从档案细节到人际网脉络一目了然：

- **三栏人物卷宗**：
  - **左栏（人物名录）**：支持按姓名 / 别名 / 标签搜索，以及按角色定位和标签双重筛选。
  - **中栏（档案主体）**：支持上传自定义头像、填写多个以 `/` 分隔的角色定位（内置主角 / 配角 / 反派 / 导师 / 盟友 / 旁观者 / 龙套胶囊并支持自定义）、标签、**多篇带独立标题的人物小传**（点击「＋ 添加小传」自由增删，旧版单篇自动兼容）以及自由增删的自定义字段（默认预置外貌、性格）。
  - **右栏（故事坐标）**：直观展示当前人物的一度关系迷你坐标与关联设定列表，点击「在关系图中查看」直达剧场。
- **关系剧场（人物关系图）**：
  - **统一拖线手势**：从节点拖线落到另一人物即新建带名关系（如「师徒 / 宿敌 / 共生契约」）；拖线落到**已有关系边**上则直接打开编辑浮层修改或删除。
  - **构图辅助**：支持「一度关系 / 全部人物」聚焦切换、圆形 / 网格一键排布、孤岛人物提示，画布增删与卷宗列表实时双向同步；右键节点支持快速发送为大纲引用卡或打开详卡。

## 7. 设 · 世界观设定体系

设定把全书世界观收进一棵统一节点树，在右上角自由切换三种视图模式：

1. **节点大纲（幕布树）**：任意节点地位平等、支持无限嵌套与三区插入拖拽排序（悬停折叠项自动展开），支持内联富文本格式、快照级撤销重做、快捷复制粘贴与 `MD / TXT` 按标题层级导入。
2. **三栏阅读视图**：左栏全局目录、中栏展示同级条目预览卡片（带标签筛选与关联计数）、右栏为当前条目的详读卡（面包屑路径、子节点 / 后代统计、关联列表及编号子条目逐级下钻）。
3. **视觉导图（层级导图 & 关系星系）**：切换到「关系星系」后，全书设定集化作围绕作品核心的同心轨道星系，清楚区分条目织网（虚线）、集内关系与跨集关系（实线）；支持左键旋转、中键平移、滚轮缩放、拖动边缘调整条目大小、**独立拖拽轨道与靠近并轨**，以及自定义轨道间距、入口半径与星体公转/自转速度。

> **条目级双向关联与详情页**：对任意设定条目右键「设置关系…」或点击行尾关系卡片，即可为「设定↔设定」或「设定↔人物」建立带方向和反向名称的关系；**双击设定条目**还可进入专属详情页，操作可拖动记忆布局的关系图谱与子条目树。

## 8. 灵 · 灵感拼板

灵感以直观的单屏拼板模式收纳随时闪现的创作念头，并支持一步送进作品正文或世界观结构：

- **按标签分栏拼板**：卡片依标签分组排开（「未标记」及各类自定义分组），拖动卡片顶部**图钉**即可调整组内顺序或跨栏更换所属标签组。
- **可控的看板节奏**：左下角控制排序（最新 / 最早 / 手动）、画板缩放比例、**卡片大小**（`80–125` 连续滑杆调节）及 6 种柔和配色标签（默认 / 玫瑰 / 琥珀 / 苔绿 / 雾蓝 / 藤紫），并配备独立回收站防止误删。
- **片段整理与一键转化**：点选任意卡片打开右侧「片段整理」抽屉，在完善标题、正文、标签与关联后，可直接点击「**转为章节**」或「**转为设定**」落入正式结构，**原灵感卡片自动保留**以便回溯出处。

## 9. 关系链接系统（`[[双链]]`）

在正文、大纲文本、设定幕布、人物小传与灵感中，均可通过两种互为补充的方式织就全书关联网：

- **文内关系链接**：选中文字右键「添加关系链接…」或直接键入 `[[标题]]` 创建跳转令牌（指向章节 / 人物 / 设定等），**条目改名时链接自动随动不断链**。鼠标悬停即弹出带平滑动画的预览窗；**按住预览窗标题栏拖动**即可将它钉在屏幕任意位置常驻对比（随后悬停其它链接将在原位切换内容），停靠坐标在会话内记忆，**双击标题恢复跟随鼠标**。
- **与正文批注同句共存**：文内关系链接呈**贴字点状下划线**（随主题色），正文批注呈**偏下 2px 实线下划线与淡底色**，两者错位叠加于同一段文字上互不覆盖、各自响应点击或悬停。

## 10. 写作统计与分析

所有统计图表均基于本机保存记录与 ECharts 离线计算生成，无需联网：

- **写作速览浮窗**：无论在书架还是作品内部，点击顶栏统计图标 📊 均可呼出速览卡片，呈现当前正文字数、正式章节数、今日净增与近 7 日柱状图，点击任一日期柱即可查看当日保存记录。
- **完整写作分析台（九视图）**：在速览内点选「查看完整分析」开启独立分析窗口（幻流背板），按四层视角检视创作进度：
  - **总览**：**创作历程**（区间累计净增曲线、180 天活跃日历与每日明细）与 **作品对照**（双作品同屏曲线对比与分卷对比）；
  - **正文**：**章节结构**（分卷字数分布、中位数与完成度筛选）与 **改稿轨迹**（章节 × 日期热力矩阵回看每章存稿净差与快照版本）；
  - **大纲 / 设定 / 人物 / 灵感分析**：逐项统计故事容器完成度与四态分布、设定根分支节点规模、角色群组分布与关系网络高亮、灵感标签趋势与最近新增，并支持点击图表直接联动右侧检查器查看条目。

## 11. 正文导出详解

入口：**⚙ 设置 → 备份与数据 → 导出正文（选章节 · TXT / MD / Word）…**

| 选中范围 | 导出规则 |
|---|---|
| **单章** | 直接保存为 `章节名.格式` |
| **多章（≤ 阈值，默认 30 章）** | **逐章分批输出**：仅首章确认保存目录，其余所选章节自动按顺序写入同一目录；整卷或全选未超阈值时同样遵循此规则 |
| **超过设定阈值** | 弹出模式选择：① **合并为单个文件**（以书名命名顺序汇总）；② **按章打包 `.zip`**（按分卷建子目录，文件以 `序号-章节名` 命名） |

- 支持三种格式：**TXT 纯文本**、**Markdown** 与 **Word（`.docx`）**——`.docx` 由 JSZip 原生组装标准 OOXML，保留加粗、斜体、下划线、删除线、字色、标题层级、对齐方式、列表与引用缩进及 A4 版式。
- 批量阈值可在导出框内直接调整（`2–500` 章），修改后自动记忆。

## 12. 全局工具与设置面板

点击顶栏 **⚙ 设置** 开启统一设置工作区（支持顶部关键词即时过滤设置项）：

- **外观与排版**：
  - **流动背景与明暗**：开启面板深/浅调偏、默认隐藏顶栏；幻流着色器背景可选择**跟随作品封面自动取色**，或自定义双色（色板 / RGB / 5 组预设方案），支持 `0–2×` 调节流速（`0×` 为静止）。
  - **中西文分离排版**：中文字体可选思源宋体 / 霞鹜文楷 / 京华老宋体 / 朝华标题 / 云游手书 / 系统黑体（6 款），西文字体可选跟随中文 / Playfair Display / Montenegrin Gothic One（3 款），正文字号 `13–24px` 调节并支持实时预览；书架书封书名与圆印同步跟随中文字体。所有字库均为随包本地 OFL 授权 woff2 字体，零网络请求。
- **备份与数据**：集中提供作品导入、正文导出、全库 JSON 备份恢复、全模块统一回收站以及**作品库存储位置查看与一键迁移**。
- **帮助与关于**：查看当前桌面端版本、内置**应用内检查更新**（拉取 GitHub Releases 校验 SHA-512）、写作概览统计、常用快捷键表及随时呼出本使用手册。

**其他随手效率工具**：

- **独立拆窗 ⧉ & 实体锁**：正文、大纲、人物、设定、灵感与写作分析均可拆出为独立窗口并排参考（如左写正文、右看大纲或设定）；主进程内置**实体锁**保护——正在独立窗口中编辑的条目在主窗口自动转为只读提示并提供「前往窗口」一键跳转，关闭独立窗口即自动解锁，严格避免多窗双写。
- **全局搜索（`Ctrl + Shift + F`）**：跨正文、大纲、人物、设定、灵感全库检索并分组高亮命中片段，点击直达位置。
- **分类回收站**：正文、人物、设定与灵感删除后均先进回收站留存，确认无用后再彻底清除。

## 14. 常见问题与版本展望

| 常见现象 | 处理方式与说明 |
|---|---|
| 无法启动或提示 `DatabaseClosedError` | 相同数据目录下已有小说工坊实例正在运行，关闭旧窗口后重开；多开测试请使用 `--profile=名称` |
| 开发调试报 `5173` 端口被占用 | 执行 `npm run stop` 清理残留 Electron 与 Vite 进程 |
| 误删章节、人物、设定或灵感 | 打开「⚙ 设置 → 备份与数据 → 回收站」恢复（未彻底清除均可找回） |
| 大纲连线绕得比较远 | 连线创建时会锁定两端接入方向以避免挪位乱跳；删去连线后向更近一侧重新拖线即可 |
| 换电脑或整理硬盘如何迁数据 | 可通过「⚙ 设置 → 备份与数据 → 存储位置」直接迁移文件夹，或用「备份全部数据」导出 JSON 到新设备「恢复备份」 |
| 导出时未出现合并或打包选择框 | 只有当选中章节超过批量阈值（默认 `30`，可在导出窗口调至 `2–500`）时才出现；阈值内默认按章批量写到指定目录 |
| `npm run dev` 与正式版/安装包书目不同 | 设计如此：开发调试版使用隔离目录 `小说工坊-dev`，绝不污染作者正式作品库 |

> **关于正在更新中的功能**：「**恍然梦**」创作协同 Agent 目前仍在持续研发与稳定性打磨中，待长篇上下文协同与知识库检索体验完善后，将在后续版本逐步正式开放，本手册暂不对未定型流程作展开说明。
