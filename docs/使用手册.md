# 小说工坊 · 使用手册

> 适用版本 v1.0.7 · 本地优先的小说创作软件：正文 / 大纲 / 人物 / 设定 / 灵感一站式管理，输入即存，永不丢稿。

---

## 1. 启动与数据

| 启动方式 | 命令 | 用途 | 数据目录 |
|---|---|---|---|
| 正式版 | `npm start` | 日常写作 | `%APPDATA%\小说工坊`（真实书目） |
| 开发调试版 | `npm run dev` | 改代码（热更新） | `%APPDATA%\小说工坊-dev`（验证书） |
| 安装版 | 安装程序 novel-studio-setup-x.x.x.exe | 分发使用 | 同正式版 |

- 全部数据保存在本机（IndexedDB），不联网、不上传；
- **同一数据目录同一时间只能开一个实例**，否则报 `DatabaseClosedError`；
- 多开隔离：加参数 `--profile=名字`（数据存到 `小说工坊-名字`）；
- 全部退出：`npm run stop`（同时清理开发服务，校验 5173 端口释放）。

## 2. 界面总览

- **顶栏**：← 书架 ｜ 书名 · 保存状态点 ｜ 🔍 搜索 ｜ ⧉ 拆窗 ｜ ⬇ 导入 ｜ 导出 ▾（正文导出 / 备份 / 恢复） ｜ 统计 ｜ 回收站 ｜ 🔖 书签 ｜ 主题 ｜ 沉浸
- **左侧导航（竖排单字）**：文 正文 · 纲 大纲 · 人 人物 · 设 设定 · 灵 灵感；底部 ☀/🌙 一键昼夜切换
- **内容区**：条目栏（拖右缘调宽，双击手柄恢复默认）+ 主工作区

## 3. 书架与备份

- **新建作品**：书架页创建（可带首卷）；
- **导入**：支持 **txt / md / docx / pdf / epub** 自动按章拆分为新作品；图片需先打开一个作品；
- **备份**：导出 ▾ → 备份全部数据（JSON，含全部书目）→ 换机 / 重装时「恢复备份」一键还原；建议每周备份到网盘或移动盘。

---

## 4. 文 · 正文

- **章节树**：新建 / 重命名 / 删除（进回收站可恢复）；章节前 ★ = 已加书签；
- **富文本工具栏**：撤销/重做 ｜ 标题一/二/三 ｜ 加粗、斜体、下划线、删除线 ｜ 字体颜色、突出显示、底色 ｜ 有序/无序列表 ｜ 引用 ｜ 左/中/右对齐、两端对齐 ｜ 超链接 ｜ 清除格式 ｜ ☆ 书签收藏；
- **右键菜单**：选中文字右键——剪切/复制/粘贴 + **添加双链**；
- **自动保存**：输入即存，顶栏实时显示保存状态。

## 5. 纲 · 大纲（文本幕布 / 自由画布，右上角切换）

### 5.1 文本视图（幕布式大纲）
节点树：缩进层级、拖拽排序、行内编辑、导入 md/txt（标题层级自动转节点层级）、双链。

### 5.2 画布视图（自由模块画布）
- **放模块**：空白右键新建，或侧栏「＋」添加：事件（4 种形状可切换）、便签、引用卡、文本框（透明度可调）、容器、**连接点**、章节锚点、卷；
- **连接点（线连线）**：把连线接到另一条连线上的接线柱——**右键连线 →「创建连接点」**，在右键落点处生成吸附在该连线上的连接点（也可拖线直接落在连线上自动生成）；连接点可自由拖动、四向锚点可再拖线，作为连线中转（不遮挡其他连线走线）；
- **模块操作（右键菜单）**：**右键模块**弹出操作栏——形状▸ / 编辑内容 / 透明度滑杆（文本框）/ 自定义类型▸ / 固定·取消固定 / 删除（红标）/ 容器分支调色板。**点选模块不再弹任何遮挡栏**；关闭菜单 = 点空白 / Esc / 执行删除或编辑；双击模块 = 行内编辑；
- **容器**：拖入即归组，▾ 折叠/展开，分支自动配色；**调整大小实时跟随鼠标**（平滑过渡动画）；
- **连线**：拖模块四向锚点到目标模块/连线/连接点即建立；**右键连线 →「创建连接点 / 编辑连线」**——编辑含标签、线型（实/虚/点线）、颜色、箭头（→ / ↔ / —）、**线宽与箭头大小滑杆（单条覆盖全局）**；连线从锁定端口出入，按**全局最短路径**自动绕开途经模块；
- **⚙ 设置**：连线粗细（0.8–5px）、**箭头大小（0.5–3.0×）**——全局默认值，单条连线可在编辑浮层单独覆盖；卡片密度、连线样式（曲线/折线）、16px 网格吸附；
- **视图**：整理（📌 固定项豁免）、缩放 ±、适应；撤销 ↶ / 重做 ↷。

### 5.3 大纲侧栏
模块条目树（点击定位画布）、搜索、类型筛选、自定义类型管理（⚙）。

## 6. 人 · 人物

- **列表/详情**：小传 + 自定义字段（字段名可改），角色定位（主角/配角/反派/龙套）与标签；
- **关系图**：拖人物节点四向锚点到另一人物建关系（输标签如 师徒/宿敌）；点选关系线改标签/线型/颜色；悬停高亮一度关系网；角色·标签筛选；孤岛提示；◯ 圆形 / ▦ 网格排布；右键节点发送为大纲引用卡 / 打开详情；连线粗细跟随画布设置。

---

## 7. 设 · 设定 与 8. 灵 · 灵感

- **设定**：幕布式统一节点树（无限层级、图片、双链），世界观/力量体系/地理皆宜；
- **灵感**：片段收集箱，按时间排列，好点子可发展为设定或大纲节点。

## 9. 双链系统

- 正文/幕布/小传/灵感中：**选中文字 → 右键 → 添加双链…** 或手输 `[[标题]]`；
- 画布上双链显示为卫星令牌，点击跳转目标（章节/人物/设定节点等）。

## 10. 正文导出详解

入口：顶栏 导出 ▾ → **导出正文（选章节 · TXT/MD/Word）…**

| 选中范围 | 导出行为 |
|---|---|
| **1 章** | 直接以 `章节名.格式` 导出 |
| **多章（≤阈值，默认 30）** | **逐章分批**：仅首次确认导出位置，之后自动按顺序写入同目录，每章一个文件（章节名命名）；首步取消即中止。整卷/全选但章节数未超阈值时同样走此路径 |
| **超过阈值** | 弹出导出方式选择：<br>① **合并为单个文件**（按顺序合并，书名命名）<br>② **按章打包 zip**（每章一个文件，`序号-章节名`、按卷分目录，`书名-N章.zip`） |

- 格式三选：**TXT 纯文本 / Markdown / Word (docx)**；docx 保留加粗/斜体/下划线/删除线/字色、标题样式、对齐、列表与引用缩进；
- **阈值可调**：批量选择区数字控件直接改（2–500），即改即存。

## 11. 全局工具

- **搜索**（🔍 / Ctrl+Shift+F）：跨全书搜索，命中选段定位；
- **统计**：字数曲线（按日）、章节分布图表；
- **回收站**：删除的章节/人物/片段恢复或彻底删除（彻底删除不可恢复）；
- **书签**：章节快捷收藏夹；
- **拆窗 ⧉**：大纲/人物等模块拆为独立窗口（边看大纲边写正文），窗口内可切换条目；
- **主题**：宣纸 / 羊皮纸 / 暗夜书房（导航底部 ☀/🌙 快速昼夜切换）；**沉浸**：专注写作模式。

## 12. 键位详解

### 全局

| 键 | 功能 |
|---|---|
| `Ctrl+Shift+F` | 全局搜索 |
| `Esc` | 关闭搜索/弹窗/画布右键菜单/连线编辑浮层 |

### 正文编辑器

| 键 | 功能 |
|---|---|
| `Ctrl+Z / Ctrl+Y` | 撤销 / 重做（编辑器内） |
| `Ctrl+S` | 手动保存（平时自动保存，此键兜底） |
| 选中文字 + 右键 | 剪切/复制/粘贴 + **添加双链** |

### 大纲画布

| 键 | 功能 |
|---|---|
| `Delete / Backspace` | 删除选中模块（容器连子模块，输入态不劫持） |
| `Ctrl+Z / Ctrl+Y` | 画布撤销 / 重做（↶ ↷ 同） |
| `Esc` | 关闭右键菜单 / 连线编辑 |
| 双击模块 | 行内编辑（`Ctrl+Enter` 提交，`Esc` 取消） |

### 幕布大纲（文本视图）

| 键 | 功能 |
|---|---|
| `Enter` | 新建同级节点 |
| `Shift+Enter` | 节点内换行 |
| `Tab / Shift+Tab` | 缩进 / 升级（子级 ⇄ 同级） |
| `Backspace`（行首） | 删除节点并并入上一行 |
| `Alt+↑ / Alt+↓` | 上移 / 下移节点 |
| `Ctrl+Z / Ctrl+Y`（`Ctrl+Shift+Z`） | 撤销 / 重做 |
| `Ctrl+B` | 加粗 |

### 人物关系图

| 键 | 功能 |
|---|---|
| `Delete / Backspace` | 删除选中人物（软删，回收站可恢复） |
| 双击节点 | 打开人物详情 |

### 搜索弹窗

| 键 | 功能 |
|---|---|
| `Enter` | 执行搜索 |

## 13. 常见问题

| 现象 | 处理 |
|---|---|
| 打不开 / DatabaseClosedError | 同数据目录已有实例在运行，关旧窗口再开 |
| dev 报 5173 端口占用 | `npm run stop` 一键清理（含 vite 残留） |
| 误删章节/人物 | 回收站恢复 |
| 画布连线绕远 | 连线严格使用建立时端口；删除重建即改用就近端口 |
| 换电脑 | 导出 ▾ → 备份（JSON）→ 新机恢复备份 |
| 导出时批量选择区没出现 | 仅在选中章节数超过阈值（默认 30）时出现；未超阈值的多章（含整卷/全选）默认逐章导出 |
| npm run dev 与 npm start 书不同 | 设计如此：调试版数据已隔离 |
