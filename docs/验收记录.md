## 读取方式

每一项验收都在 `pre-cleanup-20261112` 这个 tag 里有完整快照（含截图、对照页、验证日志）。需要复查时按需取回单个文件：

```bash
# 列出该目录当时有哪些文件
git ls-tree -r --name-only pre-cleanup-20261112 -- docs/outline-calibration-validation

# 取回整个目录到工作区（不切换分支、不影响当前改动）
git checkout pre-cleanup-20261112 -- docs/outline-calibration-validation
```

> `pre-cleanup-20261112` 指向 `6dfdfee`（功能线已提交、文档尚未清理的状态）。之后的清理提交都可单独 `git revert`。
