# 恍然梦助手对话界面改版

交付日期：2026-10-25。目录沿用任务启动日期。已按批准方案实现对话主界面、输入框功能栏、对话内可编辑卡片与四套皮肤适配。

## 界面结果

顶部保留一个标题及原拆窗、关闭入口。作品讨论与正文工作流共用对话滚动区；作者消息靠右，助手消息自然排版。任务、参数、模型和预设移入底部输入框功能区，300px 时预设进入功能菜单。关闭浮层、打开菜单和切换专用任务不会清空未发送输入。

方向卡可以直接编辑，编辑与选择独立；保留、更多及按方向续写紧邻内容。正文候选保留编辑、预览、采纳、撤销、接着写草稿和独立更新记忆。来源阻断与错误保持可见，原始文本、推理、资料与预算、核查说明默认折叠。阅读旧消息或编辑卡片时，新回复提供“有新内容”入口。

主浮层与 AI 独立窗口复用 `AiAssistantPanel.vue`。方向绑定自身真实消息与作品/任务 ID，正文卡复用原候选对象；未被历史消息呈现的已保存结果使用恢复区展示，不插入伪消息，不复制持久化记录。

输入法覆盖 composing/229，Shift+Enter 不发送，Enter 只触发一次原讨论动作。检查同时覆盖未配置模型、停止、失败和来源阻断的可见提示。正文端到端覆盖流式期间编辑、迟到结果、方向版本保护、原位置采纳、撤销、继续草稿和多窗口迟到保存。

所有检查仅使用隔离 `booksource-verify` profile 与登记验证书。UI 接线检查拦截内存中的模型动作，流式端到端使用本地确定性 SSE，不请求真实模型，不评价模型创作质量。

## 视觉复核与取舍

沿用用户选定的清爽对话结构，用留白分组和局部皮肤变量降低表单感；不增加插画、光效或打字机效果。已移除重复标题、英文副标题、独立工作流页与顶部横排功能按钮。功能、状态、对象名称和写回保护继续保留。

完成一轮独立截图评审，评分 8/10，未发现可确认的裁切或不可读问题。随后减轻选中方向的重复强调、将方向编辑区改为透明表面，并增强原版辅助文字对比度。剩余提升空间是功能菜单内部权重与微小排版细节；静态评审未验证动效。现有菜单展开与按钮反馈沿用组件库，输入框聚焦和卡片状态约 140–150ms，支持减少动效偏好。

另做独立定向代码复核，两处卡片修复无新增阻断，32 个业务核心文件一致。实现没有修改服务接口、任务协议、数据库版本、存储格式或默认模型配置；未升级版本、未自动提交，保留原有未提交改动。
