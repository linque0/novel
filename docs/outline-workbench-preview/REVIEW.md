# 大纲工作台设计稿：验收记录

2026-10-19。范围：把纸本画布与层级大纲两稿合成一个可连续使用的工作台；独立前端设计稿，不读写正式作品数据。按存量界面润色标准复核，不打分。

## 本轮边界与规范

用户要求两稿合一，模拟真实版使用。保留已确认的方向：奶油纸色、灰绿主色、京华老宋标题；事件／便签／引用／锚点／卷使用纸面材质，事件有四种形状；容器只用可换色框线、不用纸纹；文本框透明；“就地展开”只显示子项，“进入容器”才切换层级与面包屑；四种关系色与 1.6px 细线沿用纸本画布。

示例数据为《山海来信》，四层嵌套；刷新重置。界面中不出现“示例／未接入”一类制作说明。

## 合并时确定的关键处理

- **两套布局**：每层容器各自保存画布坐标；就地展开改用两列紧凑网格，只读快览，不读内部坐标。
- **展开不压内容**：展开时下方同列模块同步推开并滑动到新位；收起不回收，「整理布局」重新打包。
- **关系不丢**：关系存真实事件编号；收起时投影到最近可见容器，线变淡并在落点画空心圆点；跨展开容器边界的关系绕外侧通道；直接连线会横穿展开容器时，改从容器上/下（或左/右）绕行；同一对模块的多条关系错开 24px。
- **方向正确**：包络与绕行路径都从 from 端拼到 to 端，箭头落在真实目标上。
- **首屏可读**：初始按 74% 下限展示故事开头，整图过宽时靠左可平移；「适应画布」显示全图（62%）。

## 主代理验证

- `node docs/outline-workbench-preview/model-test.mjs`：**63/63**。覆盖父子结构、四层深度、只统计事件的进度、可见集、投影分组与合并、跨层接续、封装、添加（含卷）、删除与关系清理。
- `esbuild` 解析 `story.js` / `workbench.js` 无错误。
- 浏览器实测（1440×900 与 750×864，Chromium DevTools）：
  - 首屏渲染、投影连线与标签、四类关系色与伏笔虚线；
  - 就地展开：4 张迷你卡（2×2 对齐），下方模块同步推开；收起即消失；
  - 进入／返回：面包屑、容器内部标识、前接／后续接续卡、相机与展开状态恢复；动画结束后 `aria-busy` 归位、portal 清除；
  - 嵌套进入：在迷你容器卡上打开设置并直接进入「守塔人的证词」，面包屑为三级；
  - 跨层搜索（“铜印”3 条结果带完整路径）定位到四层深事件；
  - 多选 2 项用容器封装，连线数量不变；1 项时按钮禁用；
  - 端口拖拽建线（雾港来信 → 便签），可在上方改类型／箭头／标签；双击连线或「详情」查看实际连接的事件；
  - 事件形状切换（矩形→菱形，尺寸 250×210）、状态切换参与进度；
  - 抽屉改容器颜色／名称／摘要，标题输入即时同步到抽屉抬头与图层；
  - 两步删除与撤销（拖动、删除、封装的撤销均回到操作前）；
  - 方向键微调、Esc 退出多选／抽屉、Ctrl+K 聚焦搜索；
  - 整理布局无重叠并重新适配；展开一层／收起已完成／总览；
  - 空容器显示空状态提示；素材一览 4+4 张；卷可添加且不计入事件；
  - 窄屏无横向溢出，「结构」抽屉可开合、可滚动到「容器 ＋」。
- 控制台无报错。

自查中发现并修复的实际缺陷：选中重绘导致拖动句柄失效、撤销快照时机错误（拖回原位的撤销无效）、包络路径方向反转、窄屏没有结构入口、素材库“卷”添加静默失败、抽屉标题不随输入更新、选 1 个模块也能封装。

## 独立评审及处理

由一个隔离上下文的评审者只看当前版本截图与约束完成一轮「存量已有界面润色评审」，未读源码、不改文件、不打分。逐条处理：

**必要修正（已全部处理）**

1. **图例线型与画布不一致**：图例把“关联”画成虚线、“伏笔”画成实线。已改为关联=灰绿实线、因果=陶土实线、伏笔=灰紫虚线、冲突=赭黄实线，与线条一一对应。
2. **关系线横穿菱形事件、压住标题**：已为展开的容器加入绕行判断，直连会穿过的关系改从容器上/下（或左/右）外侧走，实测“决定再赴灯塔 → 第三章 · 灯塔”改走容器下方。
3. **迷你容器按钮与顶层不一致**：迷你容器右上改为 ＋/−“就地展开”，操作行只保留“进入容器 ↗ / 设置”，与顶层容器的位置和措辞对齐。
4. **窄屏结构抽屉被截断**：窄屏隐藏固定品牌块，让内容整体滚动；去掉抽屉头重复的“故事结构”，只保留树上方一处。实测滚到底后“容器 ＋”完整可见且可点击。

**精修（已处理）**

- 迷你卡 2×2 的便签因旋转错位约 7px：迷你卡内的便签不再旋转，四张卡共享两条竖轴。
- 画布标题右侧四项操作只有“整理布局”带图标：去掉该图标，四项同级。
- 关系标签像通用 tooltip、会压住容器框线且有两个几乎相贴：改为奶油纸底、墨色字、与线同色的下边线；标签整体上移到线的上方，拥挤时向下让位，绕外侧的标签再向右让开容器边框。
- 素材一览第二排（尤其深绿“卷”）压过四种形状：第二排表面高度从 122px 降到 100px，四种事件形状仍是主角。
- 展开时的位移：被推开的模块从原位滑到新位（220ms）。容器自身高度仍是直接切换，没有做连续的框体延展动画。

**删掉的文字（已处理）**

- 素材一览底部“与纸本画布设计稿共用”。
- 容器设置抽屉标题下的重复面包屑：只在节点层级深于两层时显示，保留定位价值。
- 窄屏抽屉里重复的“故事结构”和固定品牌块。

**保留（未改动）**

- 纸面／框线／透明文本的材质分工；四种事件形状不合并。
- 就地展开与进入容器的空间区分，以及展开时邻居让位。
- 奶油点阵、深绿卷脊、京华老宋标题与四色关系线；修图例只改线型，未改色板。

评审明确无法判断：动效中间帧、拖拽手感、性能，以及窄屏下的设置抽屉与素材一览。动效由状态断言与截图复核；未做逐帧录屏，截图工具会等待画面稳定。
