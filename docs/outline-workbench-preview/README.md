# 大纲工作台 · 纸本画布 × 层级容器

预览：<http://127.0.0.1:5173/docs/outline-workbench-preview/>

把两张已确认的设计稿合成一个设计稿，用连续的写作流程模拟正式版的使用情况：

- [纸本叙事画布](../outline-canvas-preview/)：纸面材质、四种事件形状、细连线与四种关系色、自由拖动。
- [层级大纲](../outline-blocks-preview/)：容器封装、就地展开、进入容器、面包屑、结构树、跨容器关系投影。

仍然是独立前端设计稿：使用《山海来信》示例数据，不读写正式作品、数据库或自动保存；刷新恢复初始状态。素材直接复用纸本画布的图片，不重复打包。

## 一次真实的使用流程

1. **全书情节**：首屏看到「第一卷 · 潮声」和三个章容器，章与章之间是投影后的因果／伏笔／关联线；便签、引用、写作备忘散在下方。左侧结构树同步显示 8/12 事件与各章进度。
2. **就地展开**：点章容器右上「就地展开 ＋」，子项以两列迷你卡出现在容器内，下方同列模块自动让位；相邻容器和面包屑不变。
3. **进入容器**：点左下「进入容器」，画布切换到该章内部，面包屑变为「全书 › 灯塔疑云」，顶部／底部出现「前接」「后续」接续卡；返回时恢复上层的相机与展开状态。
4. **继续搭建**：在内部添加事件、便签、引用、文本、锚点或子容器；容器可以再套容器（示例有「灯塔疑云 › 守塔人的证词 › 十年前的暴风夜」四层）。
5. **整理与查找**：多选同层模块「用容器封装」；Ctrl+K 跨层搜索并定位到隐藏事件；「总览 / 展开一层 / 收起已完成 / 整理布局」快速收拢。
6. **编辑内容**：双击任意模块打开右侧设置抽屉，改标题、正文、事件形状与状态，或改容器名称、颜色、摘要；底部「撤销」逐步回退内容修改。

## 两稿如何合并

| 问题 | 处理 |
| --- | --- |
| 自由画布 vs 层级画布 | 每一层容器都有自己的一份画布坐标；进入容器切换坐标系，就地展开改用紧凑网格，不读取内部坐标 |
| 就地展开的内容密度 | 两列迷你卡，保留纸面、状态与进度；只读快览，不承担精细摆放 |
| 展开后压住下方内容 | 展开时把下方同列模块同步推开；收起不回收，避免误挪别人的故事，「整理布局」可重新打包 |
| 隐藏端点 | 关系始终存真实事件编号；收起时投影到最近可见容器，线变淡并在落点画空心圆点 |
| 关系穿过展开的容器 | 跨容器边界的关系绕到容器外侧的通道，再进入目标卡，不横穿容器标题 |
| 同一对模块多条关系 | 按横向或纵向错开 24px，标签不再叠在一起 |
| 跨层关系 | 进入容器后，范围外的关系收进「前接／后续」接续卡，点击可定位；容器设置里列出全部外部联系 |
| 首屏可读性 | 初始按 74% 的可读下限显示故事开头，整图过宽时靠左并可平移；「适应画布」才显示全图 |

## 可体验的交互

- **画布**：拖动模块、空白处平移、Ctrl/⌘ + 滚轮以指针为中心缩放、底部缩放／100%／适应画布；方向键微调选中模块；双击编辑。
- **容器**：就地展开／收起、进入／返回（约 440ms 推进、300ms 收回，可被快速导航或 Esc 打断）、换色、摘要、删除（两步确认）、内部添加模块、多层嵌套。
- **连线**：拖动模块端口到另一个模块建立关系；点线或标签选中后可改关系类型、单向／双向／无箭头、关系标签；双击连线或点「详情」查看这条线实际连接的事件；流畅曲线／圆角折线切换；四种关系色与伏笔虚线；投影线变淡并带空心落点；关系线会绕开展开的容器，不横穿内部的卡片与标题；标签是纸片式注解，自线上方让开并自动避让重叠。
- **整理**：多选同层模块后用容器封装（保留内容与全部连线）、总览、展开一层、收起已完成、整理布局。
- **查找**：Ctrl+K 或顶部搜索，结果显示完整路径，点击直达隐藏事件并高亮；窄屏用工具条左侧「结构」打开结构抽屉。
- **内容**：事件状态（已完成／正在写／待修改／待展开）参与进度统计；事件形状切换会同步更新纸面与尺寸；便签、引用、锚点、卷沿用各自纸面；容器与文本框不使用图片材质。
- **其他**：素材一览（四种事件形状与四种内容卡，可下载原图）、纸面材质开关、撤销最近 40 步内容修改。

## 边界

没有接入正式持久化、重做、完整避障布线、手动路径调整、容器解散与导入导出；未验收生产规模性能与全部皮肤。容器内部坐标与展开网格是两套呈现，正式接入时应复用现有画布几何、端口与业务数据，并保存每层的相机状态。
