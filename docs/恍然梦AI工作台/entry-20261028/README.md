# 恍然梦入口调整 · 2026-10-28

用户指定的两个入口均置于顶栏：

- **恍然梦-入梦**：AI 主写的故事现场。工坊顶栏可进入，四套书架皮肤的公共顶栏也提供入口。
- **恍然梦-浅眠**：工坊内置 AI 助手。工坊顶栏展开/收起，入梦顶栏可切换到工坊并展开；若助手已拆窗则聚焦持有窗口。

书架点击入梦后可以“开始新故事”或选择已有作品。新故事名称可留空，不要求先创建正文、手写段落或章纲。创建沿用作品服务，进入时不发送模型请求；空故事可由既有故事服务直接准备第一章。失败时展示错误，已创建但尚未成功打开的作品可重试进入，避免反复新建。

模式切换先保存并检查作品身份与待保存状态，保留同一作品/工作稿。由工坊重新入梦时回到故事现场，不停留在上次打开的高级工具页。原书卡菜单也统一命名。

验证：`tools/ai-entry-unit-verify.mjs` 检查模式路由、拆窗定位、空书架、保存失败与作品切换；`tools/ai-entry-verify.mjs` 在独立 `booksource-verify` profile 验证六条应用路径，涵盖四套书架、空书架、新故事、浅眠、模式切换和指定作品接续。使用已注册验证作品；临时创建的验证作品在结束后软删除。截图覆盖 1440 与 1080 桌面，检查顶栏按钮完整可达；结果见 [验证记录](verification.json)。

本批只调整入口、命名与书架启动流程，四模块联动方案仍待审阅，未开始实施。没有变更模型协议、版本号或发布安装包。
