# 恍然梦 AI 主力创作模式

当前方案：[共同创作模式重设计方案（2026-10-28）](共同创作模式重设计方案-20261028.md)。首批故事主写界面已实施，交付范围、验证与后续边界见 [本批实施记录](story-ui-20261028/实施记录.md)。

新增待审方案：[设定、大纲、角色、灵感四模块联动方向（2026-10-28）](四模块联动产品与实施方案-20261028.md)。本轮仅做方案，建议按“引用与实际选材 → 原位编辑同步 → AI 起草资料与作者确认”三批实施。

目标：AI 从空白开始并持续主导故事创作，作者可选干预和手改；选择故事模板、给一句想法或让 AI 构思即可开始。AI 工作稿与小说工坊共享，切换时稿件、位置、资料和意见相互连接。创作、规划与审阅在同一现场完成。

- [本地角色卡游玩流程调研](本地SillyTavern游玩流程调研-20261028.md)：12 份去重聊天文件、7 份多消息样本、10 张关联卡的匿名结构分析，明确 AI 主写默认路径。
- [匿名游玩证据](共同创作重设计-20261028/local-play-evidence.json)：只读重扫脚本、文件哈希、消息结构和状态/版本统计。
- [源码研究固定记录](共同创作重设计-20261028/source-ledger.json)：本地工坊、书童及 SillyTavern 的 22 个文件、SHA-256、符号位置和官方参考链接。
- [旧产品方案与 Skill 研究](产品方向与界面方案-20261027.md)：保留旧方向、源码对照与内置 Skill 的来源。
- [首版实现验收档案](implementation-20261027/README.md)：历史机制测试与画面；不能代表新共同创作模式已经实现。

入口：书架与作品顶栏的 **恍然梦-入梦** 进入 AI 故事主写模式；工坊顶栏的 **恍然梦-浅眠** 展开内置辅助创作助手。入梦顶栏也可切回浅眠。书架入梦支持直接新建空白故事或选择已有作品；**工坊编辑**打开同一工作稿。原六页流程保留在 **高级创作工具**。入口调整及验证见 [入口记录](entry-20261028/README.md)。

本批提供空白开场、持续主写、可选角色参与、同稿手改、最新一幕换版、讨论后续写、六轮内自动推进、独立审修与作者确认。未确认多章分支、独立场景状态快照、文档级多窗口并行仍属后续范围。确定性机制、实际界面与真实模型叙事质量分别报告。
