## 一、项目概况

**小说工坊**是一款本地优先的小说创作软件（Electron + Vue 3 + Dexie/IndexedDB），面向个人作者，核心主张：正文/大纲/人物/设定/灵感一站式管理，**输入即存、永不丢稿**，所有数据留在本机。

| 项 | 状态 |
|---|---|
| 技术栈 | Electron 33 + Vue 3 + Pinia + Naive UI + TipTap（正文富文本）+ 自研幕布编辑器 + Dexie + ECharts + 自研画布引擎（graphview.js）+ 多窗口面板（panels.js） |
| 版本演进 | v0.1.0 初版 → v0.2.x 富文本+导入 → v0.3.0 幕布设定库 → v0.3.2 书签 → v0.3.3–0.3.5 双链 → v0.4.0 大纲导图重构 → v0.4.1 自由模块画布+人物关系图 → v0.4.2 画布交互打磨 → v0.4.3–0.4.5 画布修复批次 → **v0.4.6 功能面板多窗口（当前）** |
| 规模 | 45 个源码文件（28 组件 + 16 服务/存储/引擎）；核心：OutlineCanvas.vue 904 行、work store 1653 行、panels.js（主进程窗口管理）205 行 |
| 交付物 | 231MB（v0.4.1 打包冒烟实测；v0.4.x 打包待出，见待办） |

## 二、已完成功能清单

### 1. 核心写作（v0.1–v0.2）
- **自动保存**：输入防抖 1s 落盘 + 30s 兜底 + 失焦/切章/关窗前强制保存；顶栏常驻保存指示；章节版本快照（滚动保留 30 份）可回滚；崩溃恢复经强杀进程验证。
- **正文编辑**：卷-章两级树（拖拽/按钮排序）；TipTap 富文本 + Word 风格工具栏；正文右键快捷菜单（20 项，含二级飞出菜单）。
- **五模块**：正文、大纲、人物、设定（见 2）、灵感；**导入导出**：TXT（GBK 识别+智能分章）/ MD / DOCX / PDF / EPUB / 图片；整库 JSON 备份恢复。
- **其他**：全局搜索、回收站、统计看板（ECharts）、三套主题、沉浸模式。

### 2. 设定模块幕布化重构（v0.3.0）
- 统一节点树（任意节点平权、无限嵌套）：回车新建、Tab/Shift+Tab 升降级、Alt+↑↓ 排序、行首合并、拖拽移动（三区插入指示/悬停折叠展开/FLIP 动画）；
- 内联格式（粗斜下删/颜色/底色）+ 快照式撤销重做；MD/TXT 导入；侧边栏层级树双向同步；旧数据无损迁移。

### 3. 书签系统（v0.3.2）
- 三入口（章节侧栏右键 / 正文工具栏 ☆ 键 / 顶栏 🔖 下拉）；Dexie v4 书签表，备份自动包含。

### 4. 双链 / 多模块内容互联（v0.3.3–v0.3.5）
- 五模块互引：`[[链接]]` 令牌（纯文本区）+ `dl-link` span（富文本区，精确到 id 改名不断链）；
- 右键「添加双链」选择面板（全局关键词搜索+高亮选段）、悬停预览浮窗、反向链接查询与引用统计；验收脚本 dl-verify 20 项。

### 5. 大纲模块重构（v0.4.0）
- 大纲节点树 olnodes（一次性迁移，旧 outlines 表保留回滚）+ 思维导图视图（双链卫星/缩放平移/双击跳转）+ 侧边栏自定义增删改 + Word 式工具栏；
- 修复 repo 层响应式对象直写 IndexedDB 的 DataCloneError 存量缺陷。

### 6. 自由模块画布 + 人物关系图（v0.4.1，计划书 8.8.2/8.8.3）
- **大纲 = 流程图式白板**：取消固定结构，事件/便签/引用卡/容器/章节锚点自由摆位（吸附/双密度/pin/整理）；四向锚点拖线（因果/伏笔/冲突/关联 + 箭头 + 标签原位编辑），贝塞尔/折线切换；容器拖入归组、折叠；断线检测（烂尾/缺铺垫）；三幕式/章级清单骨架模板；olTypes 自定义类型；撤销重做；
- **人物关系图**：头像节点+关系边，画布拖线建关系、点边改标签（与关系列表双向同步），圆形/网格排布，悬停高亮一度关系网，角色/标签筛选，孤岛提示，一键发送为大纲引用卡；
- 双实现统一：并行的 OutlineMap 退役，保留其侧栏与 olTypes，统一到 OutlineCanvas。

### 7. 画布交互打磨（v0.4.2）
- **前批**：连线对齐接口（fromSide 存储随边 + 换侧自动回退）、实线/虚线/点线三线型、连线粗细设置、标签中段上方显示、模块边缘调整大小（放大显示全文）、容器与普通模块同级化、**文本框独立模块**（虚线框/透明度滑杆/双链卫星/拖入归组）、容器八向调整与右键七色调色板、**侧栏层级树**（容器从属缩进+折叠，与画布同步）、**文本视图容器内容**（子模块内容卡片+所属容器面包屑）；
- **本轮（2026-09-02 晚）更新**：
  1. **模块可拖拽出容器**——落点判定与容器派生盒计算排除被拖子树（否则盒子随节点扩张永远"拖不出"），拖出即回根级、拖入即归组；
  2. **双击行内编辑修复**——编辑态给节点显式高度（修复 absolute 编辑器撑不开节点）+ `.oc-node.editing` 解除 clip-path 并恢复边框底色，五类形状（矩形/菱形/平行四边形/便签/文本框）编辑区完整可见；
  3. **菱形/平行四边形改 SVG 描边**——弃用 clip-path 方案（裁掉边框、锚点悬空），节点内嵌 SVG polygon（viewBox 拉伸铺满），形状顶点恰在连线锚点上，hover/选中描边高亮，锚点与缩放手柄恢复贴边；
  4. **事件高度拖拽 + 四角同时调宽高**——根因是非容器节点 `height:'auto'` 不渲染落库高度；改为显式高度渲染（与连线锚点几何一致），resize 只落库被拖轴（横拖不再钉死高度），四角手柄补方向光标。

### 8. 功能面板多窗口（v0.4.6，计划书 9.2-W5 首批）
- **五类模块拆出为独立面板窗口**：顶栏「⧉ 拆窗 ▾」入口，正文（当前章节）/ 大纲（画布）/ 人物 / 设定（幕布）/ 灵感可与主窗口并行观看操作（如主窗口写正文、副窗口看大纲画布）；
- **架构**：面板窗口加载同一应用（`?panel=<type>:<workId>:<entityId>` 启动参数），PanelHost 精简布局（迷你工具条=实体名+保存状态+保存并关闭），既有功能组件零改动复用；面板持有自己的 work store 与 Dexie 连接，写经锁互斥、保存复用 autosave 链路；
- **实体/模块级锁**：主进程锁表（electron/panels.js）保证同作品同实体全应用仅一个可写面板，重复拆出自动聚焦已开窗口；`panel:event` 广播（opened/closed+锁列表）同步各窗口状态；
- **主窗口只读占位**：章节面板打开时该章编辑器只读（提示条+「前往窗口」，标题/状态禁写，关闭自动恢复）；大纲/设定为模块级锁（对应页签整体占位），人物/灵感按选中实体锁；
- **生命周期**：面板按类型记忆几何（userData/panel-geometry.json，夹取可见屏），关闭前 `__flushNow` 优雅保存，主窗口关闭级联关闭全部面板。

### 9. 交付形态
- **软件本体**：免安装直接运行（`npm run dist` 产出；v0.4.1 冒烟 231MB；当前交付目录停留在 `软件-0.3.6`，v0.4.2 打包待出）；
- **网页版**：`npm run web`（http://127.0.0.1:18688，零依赖静态服务器，数据与桌面版独立）；
- **工程命令**：`npm run dev / build / start / dist / stop / web`；`--profile=名字` 多配置隔离。

## 五、重要决策与回退记录

1. **v0.4.0 插件化尝试 → 已回退**：插件架构不满意，回退至 v0.3.1，存档 `backup/v0.4.0-plugins`。踩坑记录：`git reset` 不回退被 ignore 的 `dist\`，**回退后必须重新 build 再打包**（实际发生过）。
2. **v0.3.7 大纲文本优化实验 → 回退**：存档 `backup/v0.3.7-outline-text`。
3. **OutlineMap 退役（v0.4.1）**：画布与导图两套并行实现统一到 OutlineCanvas，保留侧栏与 olTypes。
4. **clip-path → SVG 描边**：clip-path 天然裁掉边框/锚点/手柄，形状渲染改节点内 SVG polygon，描边随形状走。
5. **面板锁粒度分两级**：章节用实体级锁（主窗口该章只读、其余章节照常可写）；大纲/设定幕布为跨节点树编辑，用模块级锁（对应页签整体占位）——粒度跟随编辑面，避免"锁了半个模块"的假安全。
6. **取消安装程序/便携版**：仅保留免安装本体；node_modules 裁剪 504MB→279MB（v0.4.1 实测 231MB）。

## 八、协作规范（沉淀）

1. **调试纪律**：调试/验收结束必须 `npm run stop` 完全退出（优雅关闭确保落盘）；
2. **测试纪律**：自动化仅跑一轮，失败即止不重试；修复后复验同样只跑一轮；
3. **数据红线**：自动化只走 `--profile=test`；用户正在运行的实例绝不动；
4. **打包流程**：改源码 → `vite build` → electron-builder 新输出目录（规避文件锁）→ pack-smoke；
5. **git 纪律**：构建产物不入库；**单分支直推**——所有开发与发布都在 `main`（开发主体，最新可用版本），每次代码更新推送时同步变更版本号（package.json / README / CHANGELOG / 提交信息四处一致），不新建/删除版本分支，里程碑发布点打 tag 存档；
6. **源码写入**：一律用 Write/Edit 工具（Mimosa hook 会拦截 Bash 写源码文件）；验证脚本等临时文件不受限；
7. **CDP 验证**：画布处于 pan-zoom 变换层内，DOM 测量用 CSS px（offsetWidth/offsetHeight），勿用 getBoundingClientRect（被变换缩放）；
8. **环境备忘**：中文路径走 spawn 数组传参（execSync 经 cmd 会 GBK 乱码）；网页版固定端口 18688。
