# 恍然梦预设体验与生成控制优化实施说明

日期：2026-10-13。本次继续实现已确认的预设体验优化方案，以本地 SillyTavern 1.15.0 核心源码及预设文件为对照。没有连接、同步或改写酒馆数据目录。

## 使用方式

1. 打开作品，在恍然梦对话面板点击“预设编辑”。独立窗口与打开时的作品关联。
2. 顶部选择或搜索预设。“提示库”保存条目定义，“发送顺序”决定本次发送的条目及顺序；移出顺序不会删除库中的条目。可拖动排序、启停、编辑、复制自定义提示或恢复内置默认提示。
3. 在条目弹窗编辑角色、相对／深度位置、优先级、触发和提示文本。保存条目只更新编辑区；点击窗口的“保存并启用”才持久化并启用于关联作品。未保存编辑不会影响对话，已经开始的生成继续使用冻结的旧版本。
4. 在生成设置中配置采样、输出预留、名称、续写和流式开关；小说工坊材料来源、范围及预算在独立适配区配置。模型、API 地址和密钥仍由小说工坊设置管理。
5. 在“正则”标签页编辑规则和测试样本。在检查器查看真实会话的展开结果、最终消息角色与位置、裁剪原因和实际参数。关联作品未在主窗口打开时会明确报告，预览不会伪造空历史。
6. 对话默认输出文本。重新生成在同一助手轮次增加候选，可用左右按钮切换；后续历史只使用当前候选。继续生成不增加虚构的作者消息，旧候选仍保留。
7. 回复或实际选中的可见文本可以转为正文草稿。先查看转换预览，再确认转换；追加、替换和新建章节仍需作者确认，并受原有版本、锁、快照与撤销保护。

## 导入与导出

- 完整 Chat Completion 文件导入为新资产，提示文本不静默改写。
- Prompt Manager 文件支持默认合并到当前预设或建立新预设。同 identifier 的替换先显示差异；实际导出中省略的内置定义按引用补齐。
- 合并时保留当前预设的内置定义，避免由补齐默认值覆盖作者的现有提示。发送顺序采用导入的顺序。
- 可分别导出完整预设与 Prompt Manager 文件。原字段与小说工坊适配配置分别保留；补齐的内置提示使用小说工坊写作助手默认身份，需要原酒馆内置文本时应导入完整预设。
- 新资产格式为 version 2；兼容读取已有预设，不批量覆盖用户资产。新建默认预设关闭工具，旧预设显式配置保持原值。

## 生成行为

发送和预览共用 `prepare-dialogue.js`、预设编译器及预算计算。预设控制启停、触发、顺序、深度、同深度优先级、角色、作者要求的位置、对话示例、新会话提示、名称和续写提示。动态槽遵循配置角色，来源材料明确标明性质，正文材料中的宏不会被执行。

默认写作助手身份、语言及表达要求放在可编辑预设中。固定应用约束仅说明来源性质、作品范围及确认写入。纯文本模式不附加工具定义或提案格式；工具需在预设中显式启用，仍为只读检索和待确认提案。

预设显式参数优先于模型／全局默认值，并受已知模型能力上限约束。支持显式 `seed`、`reasoning_effort`、`verbosity` 和流式开关，自动值不发送。服务商拒绝参数会显示具体字段，不静默删除预设设置。输出预留不再固定受上下文一半限制；提示、材料、历史、工具定义、工具结果、输出及安全预留共同核算。

常用宏包括作者／助手、作品／章节／选段、消息编号、当前候选、最后消息、生成类型、局部／全局变量、日期时间及随机／确定性选择。生成编译后提交变量一次，重试和工具轮次复用展开结果；预览使用副本。首条实际发送历史的编号在预算裁剪后解析。

续写支持助手前缀／后缀和预设续写提示。服务商拒绝 assistant prefill 时显示降级说明，使用同一次编译得到的续写提示，不重新执行变量宏。返回的推理内容与正文分开展示。

## 正则与显示

- 支持常用 `placement`、`disabled`、`markdownOnly`、`promptOnly`、`runOnEdit`、深度范围、`substituteRegex`、捕获组、`{{match}}` 及 `trimStrings`。
- 原始文本、常规处理文本、发送视图和展示视图分开保存。历史从原始文本按当前规则处理，展示变换不会成为下次发送的内容，也不会反复处理已经变换的文本。
- 覆盖作者输入、助手输出、发送历史、世界材料和推理文本；工具 JSON、数据库来源正文及知识卡不直接修改。
- 正则在 Worker 中执行，单条 500ms、阶段 3 秒超时即终止，恢复该阶段输入并报告失败规则。流式显示从累计原文重新计算。
- 正则测试和文本视图中的宏使用变量副本，不持久化规则里的变量写入；提示编译中的变量写入按作品会话持久化。
- Markdown、代码块和静态折叠内容经净化渲染。第三方脚本、事件处理器、iframe 和 HTML 小应用不执行。

## 写作控制评测

对话面板的“预设对照”提供作者手动启动的 A/B 评测：选择两套预设，以相同作品范围、会话和问题各生成三次。评测不修改作品、会话候选或持久化宏变量，可取消、记录人工评分并导出结果。语言、人称、格式和说明文字检查仅作为辅助；文风差异仍需人工判断。

本次没有调用真实付费模型进行文风质量评估。mock 验证的是预设进入真实请求、参数执行、候选操作及保护机制，不能证明任何模型都能严格服从预设。

## 实现入口与兼容范围

| 文件 | 职责 |
|---|---|
| `src/components/ai/PresetWindow.vue` | 独立 Prompt Manager、保存启用、导入差异、正则测试及检查器 |
| `src/services/ai/presets.js` | 导入导出、兼容诊断、宏、编排、参数及预算 |
| `src/services/ai/prepare-dialogue.js` | 预览／发送共用准备，主窗口真实会话快照 |
| `src/services/ai/regex-core.js`、`regex-worker.js`、`regex.js` | 正则行为、阶段隔离及超时恢复 |
| `src/services/ai/candidates.js`、`src/stores/ai.js` | 候选、继续、重新生成、取消及状态冻结 |
| `src/services/ai/chat-text.js` | 静态 Markdown 净化与草稿纯文本转换 |
| `src/components/ai/PresetEvaluation.vue` | 手动 A/B 评测 |
| `src/db/preset-repo.js` | 资产与关联作品启用的原子保存、修订冲突保护 |

兼容目标是本地 1.15.0 的核心 Chat Completion／Prompt Manager 和常用正则，不是完整酒馆运行环境。未知宏、插件字段及未支持位置保留并警示，第三方脚本、实验宏引擎、完整角色卡生态不执行。知识库仍独立使用事实提取提示；审稿、文风档案及工作流专项入口没有恢复。
