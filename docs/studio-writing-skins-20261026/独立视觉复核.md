# 正文目录与写作界面：独立视觉复核

评审方式：按 `oil-ui/references/reviewer-manual.md` 的「存量已有界面润色评审」执行，仅检查提供的静态截图，不修改代码、不打分。以交接指定的品牌色、用户字体、三种纸面和原功能为规范；没有从截图推断未操作过的菜单、保存或滚动功能已经通过。

已实际查看：`gravity-booklet.png`、`glaze-booklet.png`、`gravity-window-800.png`、`glaze-window-800.png`；补看两张 before 和两主题的 manuscript、hardcover。主窗口为 CSS1440×900，独立窗口为 CSS800×500，截图均按系统125%输出。测试文字重复和0字不计为缺陷。

## 优先问题

1. **高优先：800×500独立窗口中，场景抬头和底部区域挤掉了目录的有效阅读高度。** 两主题都出现。引力目录约在截图 y322–434、琉光约在 y341–446，换算后可用高度约80–90 CSS px。长卷名已经占两行，当前章节只剩选中底色和标题的零星上沿；用户打开窗口后无法直接看清当前章节标题。不是要求取消三栏，而是应在短视口压缩目录抬头的装饰留白和底部统计留白，优先让当前卷和当前章节完整出现。验收：用同一800×500视口、长卷名及两行章节标题，初始可看清完整当前章节；滚动目录时底部工具不压住当前行。

2. **中优先：窄窗卷名仍然发生省略，长标题保留不完整。** 两张独立窗口中，目录卷名分别显示为 `TheLongestVol / umeNameWi...` 与 `TheLongestVo / lumeName...`。这是两行后的主动省略，不是完整自然换行；中央同一长卷名却能跨三行完整排出，说明目录和正文对长名称的规则不一致。若交接中的“长标题换行”包括卷名，应让目录卷名完整换行并由目录自身滚动承接高度；至少不应通过永久省略来消化短视口空间。验收：长中文卷名、无空格英文卷名、两行以上章名都不横向溢出、不被固定行高截断；同第1项一起验收，避免完整换行后目录变得更难用。

3. **中优先、需功能核验：独立窗口里看不到“纸面”入口。** 主窗口工具条在“更多格式”右侧有“纸面”，两张独立窗口的两行工具条中均未见该入口。静态截图不能证明功能被删除，但当前可发现性低于主窗口，也会影响三种纸面的原功能保留。应确认窄窗入口所在位置；若已合入菜单，菜单名称或提示要能让用户找到纸面；若是响应式隐藏，应在现有工具条空间内保留可达入口。验收：800×500下能从可见控件进入并切换三种纸面，切换后工具条、状态栏和正文都不横向裁切。

## 精修建议

- **精致度：主窗口已形成稳定层级，优先修短视口密度。** 新建章节、目录当前项、正文标题和正文的视觉层次清楚；左右栏的分隔和正文边界也没有明显错位。无需为统一而抹平两主题的圆角差别：引力的直线档案框和琉光的柔和叠册边界都有品牌依据。窄窗应由抬头装饰与额外留白让空间，不建议缩小用户正文字号来容纳。
- **设计感：两主题已有各自的场景语言。** 引力的暗行星、铜橙轨道和编号像档案舱；琉光的浅青玻璃环、半透明卷栏和左置编号像折光叠册。装饰主要留在目录抬头与页边，正文中央仍为安静底面。继续精修应控制在已有材质和边缘层级，不需增加场景文案、徽章、折角或装饰件。
- **三种纸面：当前截图中的差别非常克制。** 三种纸面在页脚叠线、底色/纹理有细微变化，但缩到正常工作尺寸并不容易凭外观叫出名称。这不是要求扩大纹理；应首先确认实际切换有效、当前菜单状态明确，保持正文中央低干扰。仅凭静态截图无法确认三种状态是否正确绑定。
- **动效：未提供录屏，也未操作页面，无法核验。** 用户已明确不增加动画；本轮没有新增动效建议。需由制作方确认原来的展开、菜单和保存反馈未受样式覆盖影响。

## 可删减文字与功能边界

没有发现必须删掉的填缝文案；“章节目录”、新建入口和章数统计都有对象。短视口需要腾空间时，先压缩目录场景抬头和统计区的垂直留白，无需删去章节标题、字数或操作名称。改版前直接出现的“+卷、上移、下移、改名、删除”已收进两个图标菜单；截图无法确认菜单内容，需在功能复核中逐项验证仍可达，且悬停提示能解释箭头菜单与省略号菜单的区别。

## 保留

保留两主题现有品牌配色与用户字体；保留主窗口目录的多行章节标题、清楚的当前项标记和正文中心的低干扰表面。保留全局导航、右侧批注栏和AI区域现有结构。主窗口已呈现出“引力轨道档案舱 / 琉光折光玻璃叠册”的区别，修复应集中在短视口可用高度和控件可发现性，不需要重做主题方向。

## 修正后复核

复核依据：重新实际查看已覆盖的 `gravity-window-800.png`、`glaze-window-800.png`，以及新增的 `gravity-window-paper-menu.png`、`glaze-window-paper-menu.png`。以下更新处理结论，前面的原始问题记录保留。

1. **目录高度问题已在最新截图中修正。** 两主题的场景铭牌和页脚均已收紧；当前卷名、当前章节的两行标题及字数能够完整显示，选中行底部位于目录工具条上方，没有再被工具条切掉。引力当前项为完整深色选中块，琉光当前项的两行文字与字数也均在滚动区内。按本轮相同800×500视口的截图，该项通过视觉复核。

2. **长名称省略按用户确认的密度规则处理，不列为未完成项。** 制作方补充了用户已确认的方案：章名默认最多两行，完整名称通过悬停和键盘聚焦提示查看；卷名采用同一规则，并已实际验证焦点提示。由此，原报告提出的“所有长卷名完整展开”不再作为验收要求。最新截图的当前卷和章名均可读；长名称提示的真实操作结果由制作方验证，本独立视觉复核没有重做交互验证。

3. **纸面入口及三种选项的可达界面已确认。** 两张新增截图都显示了从“更多格式”展开的工具条，以及“纸面”子菜单；“轻装帧书册”“旧纸手稿”“摊开的精装书”三项名称、说明和当前选中勾号完整可见，菜单自身没有可见的横向裁切。纸面不再属于截图中无法确认入口的未完成项。制作方另已在真实800×500界面逐项切换并验证无横向溢出，并补充了说明“更多格式”包含纸面的tooltip；这些操作与tooltip结果属于制作方提供的验证记录，当前截图直接证明的是入口展开后的可达界面和三项状态呈现。

本轮没有新增必须修改的视觉问题。保留收紧后的窄窗铭牌密度、当前章节完整展示，以及两主题现有的边缘材质与正文留白；不建议继续压缩正文字号或给正文中央增加装饰。
