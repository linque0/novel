## 一、现状盘点

### 1.1 主题体系（ strengths，应保持并强化）
- CSS 变量驱动，三主题一键切换：`.theme-xuan`（宣纸）/ `.theme-parchment`（羊皮纸）/ `.theme-night`（暗夜书房），见 `themes.css:26-65`。
- 变量目前有：`--bg / --bg-panel / --bg-editor / --bg-hover / --text / --text-dim / --border / --accent / --card-ink / --shadow / --editor-font`。
- 「单字竖排导航」（文/纲/人/设/灵，`.nav-rail`）与纸质感是本产品的**差异化识别点**，美化应强化而非掩盖。

## 二、设计原则（先立规矩，再做美化）

1. **内容为王**：写作工具的一切装饰服务于"长时间读写不疲劳"，动效克制（150-250ms、ease-out），禁止大面积 blur/阴影动画。
2. **纸感统一**：宣纸/羊皮纸主题往"文具感"做（细分隔线、印章色点缀、低饱和），暗夜主题往"台灯夜读"做（暖金 accent、面板分层）。
3. **一套令牌管所有**：新增视觉参数一律走 CSS 变量，三主题同步补齐，禁止组件内硬编码色值/圆角。
4. **不加重依赖**：图标用内联 SVG（手工挑选 20-30 个）或 `unplugin-icons` 按需引入，不引全家桶图标库。

## 三、方案清单

### P0 设计令牌补齐（地基，建议最先做） ★性价比最高

**目标**：G1/G2/G3 一次解决，后续所有美化建立在令牌上。

**方案**：在三主题块中新增令牌（三套同步微调）：

```css
.theme-xuan {
  /* 既有变量不动，新增： */
  --radius-sm: 6px;  --radius-md: 10px;  --radius-lg: 14px;
  --space-1: 4px; --space-2: 8px; --space-3: 12px; --space-4: 16px; --space-5: 24px;
  --fs-xs: 11px; --fs-sm: 12.5px; --fs-md: 13.5px; --fs-lg: 15px; --fs-title: 17px;
  --border-strong: #d0c4a6;          /* 强分隔（输入框聚焦/拖拽把手） */
  --shadow-pop: 0 6px 24px rgba(90,70,40,.18);   /* 浮层专用 */
  --accent-soft: rgba(140,111,78,.12);           /* accent 的淡底（选中态背景） */
}
```

配套：
- **滚动条**（G2）：全局 `::-webkit-scrollbar { width: 10px }` + 半透明 thumb（`var(--border)` 常态、`var(--text-dim)` 悬停），纸感主题可做 2px 内边距的"细条"样式。
- **焦点态**（G3）：全局 `:focus-visible { outline: 2px solid var(--accent); outline-offset: 2px }`，鼠标点击不出现（`:focus:not(:focus-visible)` 清除）。
- 分批把 92 处硬编码圆角替换为 `var(--radius-*)`（可按组件逐步换，不强求一次清零）。

**涉及**：`themes.css` 头部 + 全局块。**工作量**：0.5-1 天。**风险**：低（纯增量；替换圆角可能引起个别组件观感微变，逐批替换可控）。

### P1 组件质感统一

#### P1-1 浮层/菜单语言统一（G5）
**现状**：`.oc-ctx`、`.rg-ctx`、`.rg-eedit`、`.rg-relinput`、`.oc-eedit` 各自定义圆角/阴影/边框。
**方案**：抽一个公共 class `.pop`（或公共 CSS 块）：
```css
.pop {
  background: var(--bg-panel);
  border: 1px solid var(--border);
  border-radius: var(--radius-md);
  box-shadow: var(--shadow-pop);
  padding: var(--space-2);
}
.pop::before {  /* 可选：顶部 1px 高光，玻璃感不引入 blur */
  content: ''; position: absolute; inset: 0 0 auto 0; height: 1px;
  background: rgba(255,255,255,.35);
}
```
浮层出现加 120ms `opacity + translateY(4px→0)` 过渡（`@starting-style` 或 Vue `<transition>`）。
**工作量**：0.5 天。**风险**：低。

#### P1-2 图标体系统一（G4）
**现状**：emoji 跨 Windows/macOS 渲染差异大（📌🗒🏷 在不同系统观感割裂），且与单色 UI 风格冲突。
**方案**：
- 精选 **20-30 个高频操作**（新建/删除/固定/编辑/搜索/导出/形状切换…）改为**内联 SVG 单色图标**（1.5px stroke，继承 `currentColor`，可直接用 Lucide 的 path 数据手工内联，零运行时依赖）；
- 封装 `<OIcon name="pin" />` 组件统一管理；
- emoji 仅保留在**内容语境**（便签 🗒 表情），交互图标全部去 emoji 化。
**涉及**：新建 `src/components/OIcon.vue` + 图标表，替换 OutlineCanvas / CharacterGraph / Workbench 工具栏。**工作量**：2-3 天（量大在替换）。**风险**：中低（纯视觉替换，注意保留 title/tooltip）。

#### P1-3 顶栏信息层级（G7）
**现状**：顶栏书名、保存状态（"已保存 18:47"）、搜索/导出等 9 个按钮平铺，视觉权重相同；Naive UI 按钮与手写按钮混排。
**方案**：
- 书名升级为页面主标题（`--fs-title` + `--editor-font`），左侧竖排导航已含模块名，顶栏只保留**书名 + 保存态 + 全局动作**三层；
- 保存状态做**轻动效**：保存中转圈（1 个 SVG spinner）、已保存淡入后 3s 自动淡出（不打扰）；
- Naive UI 主题打通：`NConfigProvider` 的 `themeOverrides` 读取同一套 CSS 变量（`common.borderRadiusSmall/primary` 等），消灭两套按钮观感。
**涉及**：`Workbench.vue`、`App.vue`、`themes.css`。**工作量**：1 天。**风险**：低。

#### P1-4 左侧导航 rail 精修（差异化重点）
**现状**：`.nav-rail` 单字导航已是特色，但选中/悬停态层级不足。
**方案**：
- 选中项：字块背后加 `--accent-soft` 圆角方 + 左侧 2px accent 竖条；悬停：文字色 `--text-dim → --text` 过渡；
- 模块切换加 180ms 的字块位移微动效（transform，不触发 layout）；
- 底部加主题切换的「昼/夜」小月亮图标位（现藏于下拉框，做成一键切换更顺手）。
**工作量**：0.5 天。**风险**：低。

#### P1-5 空状态设计
**现状**：空书架/空模块画布只有一句文字。
**方案**：统一空状态组件（一句话 + 一个动作按钮 + 单色小图形——可用 2-3 个内联 SVG「纸页/墨滴」图形呼应纸感主题），应用于：书架空态、大纲空画布、人物空列表、搜索无结果。
**工作量**：1 天。**风险**：低。

### P2 编辑器阅读体验（写作工具的"主战场"）

#### P2-1 正文排版精修（G8）
**方案**（全部走变量，三主题微调）：
- 正文区限宽：`max-width: 46em` 居中（长行是疲劳首因），两侧留白配极淡的分隔或纸纹理；
- 行距 1.9-2.0、段距 0.8em、字距 0.02em（中文正文黄金区间）；
- `--editor-font` 预设扩充：霞鹜文楷（开源，可打包，最贴合纸感主题）/ 思源宋体，设置里三选一；
- 段落首行缩进 2em 作为可开关选项（中文网文习惯）。
**涉及**：`EditorPane.vue` 样式 + 设置项。**工作量**：1-2 天（含设置项）。**风险**：低。

#### P2-2 沉浸模式强化
**现状**：`ui.focusMode` 仅隐藏侧栏。
**方案**：沉浸态下顶栏/侧栏滑出（transform 过渡）、鼠标移到边缘滑回；可选"打字机模式"（光标恒居屏幕 40% 线，CodeMirror 有现成 API）与"逐段淡出"（非当前段落 60% 透明度）作为设置开关。
**涉及**：`Workbench.vue`、`EditorPane.vue`。**工作量**：1-2 天。**风险**：中（涉及编辑器滚动行为，需充分自测）。

#### P2-3 暗色主题对比度校准
**方案**：`theme-night` 按 WCAG AA 校验正文对比度（现 `--text #d9d2c0` on `--bg-editor #1e1c17` 对比度约 10:1 合格，但 `--text-dim #8f8878` on `--bg-panel` 约 4.2:1 压线），微调至 ≥4.5:1；选中态/错误态/成功态补语义色令牌（`--danger/--success/--warning` 三主题各配）。
**工作量**：0.5 天。**风险**：低。

### P3 画布专项（大纲/人物图）

#### P3-1 节点卡质感分级
**方案**：
- 阴影分级令牌：`--shadow-node`（常态 2px）/ `--shadow-node-hover`（4px）/ `--shadow-pop`；常态更轻、悬停抬起，替代现 hover 只变边框；
- 容器/事件/便签/引用四类卡片配**左侧 3px 类型色条**（与图标色一致），扫一眼可辨类型；
- 选中态统一为 `accent` 2px 描边 + 4px 淡光晕（现各画布略有差异）。
**工作量**：1 天。**风险**：低。

#### P3-2 连线视觉（配合 v0.4.16 新路由）
**方案**：
- 悬停连线加粗 + 命中区域提示（现 `.rg-edge-hit` 透明命中区已存在，只差视觉反馈）；
- 「因果/伏笔」类连线可选**流动虚线动画**（`stroke-dashoffset` 动画，仅悬停或选中该节点的一度网时开启，避免常驻动效干扰）；
- 箭头端点随线色（已实现），补线中点标签的背景底色令牌化。
**工作量**：0.5-1 天。**风险**：低（注意 dashoffset 动画对大量连线时的性能，限悬停范围）。

#### P3-3 画布背景
**方案**：宣纸主题加极淡的网点/米纹（CSS `radial-gradient` 生成，纯背景层，不影响交互）；暗夜主题加 24px 网格淡线（透明度 3-4%），增强"工作台"感；缩放时网格随动（背景层与 inner 同 transform，实现简单）。
**工作量**：0.5 天。**风险**：低。

## 四、落地注意事项

1. **令牌先行**：P0 未完成前，不要开始 P1/P3 的批量样式改写，否则返工。
2. **三主题同步**：每个新令牌三主题必须同时给出值；验收脚本跑一遍三主题截图对比（可扩展现有 CDP 截图脚本做三主题巡检）。
3. **Naive UI 打通**：`App.vue` 的 `NConfigProvider themeOverrides` 从 CSS 变量取值，避免两套设计语言（G7）。
4. **性能红线**：禁止对带 `box-shadow` 的元素做常驻动画；`backdrop-filter` 只允许用于顶栏/浮层，且暗色主题降级为实色。
5. **验收**：沿用项目惯例——每批改动跑 `canvas-model-test` + 相关 CDP 验收脚本，UI 批次补截图对比入库 `tools/_shot-*.png`。
