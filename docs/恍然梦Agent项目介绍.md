# 恍然梦 Agent · 项目介绍

> 恍然梦是本地优先小说写作软件「小说工坊」（Electron + Vue 3，Windows 桌面）内置的写作 Agent。
> 本文提供 300 字与 1000 字两个版本，可直接用于简历、分享或发布说明；事实口径以已实施文档为准（截至 v1.0.26 / 前端重置分支）。

---

## 一、三百字版

恍然梦是本地优先写作软件「小说工坊」内置的写作 Agent。它先把整部作品读成可用资料：正文、设定、大纲、人物、关系、灵感与批注被投影为带来源坐标的统一文档和连续分块，支持跨来源中文检索与全文分页阅读，并区分"已发生事实、作者设定、未来计划、待采纳灵感"。生成由酒馆式预设引擎控制：可导入 SillyTavern 预设，编译提示顺序、宏与正则，按需装配章纲、设定、人物状态与前情。它提供五个模块共十五类专用任务——续写、选段改写、反推大纲、设定与人物提取等，先只读检索、最多六轮工具调用，再提交结构化提案。红线是永不直接改稿：一切经作者确认后整批事务写入，可审计、可撤销，来源一变即拒绝旧提案。隐私模式与本地存储保证稿件不出本机。

---

## 二、一千字版

恍然梦是「小说工坊」内置的写作 Agent。小说工坊是本地优先的 Windows 桌面写作软件（Electron + Vue 3，数据存于本机 IndexedDB，不联网、不登录），恍然梦负责其中的 AI 创作与资料维护。

第一层是全书读模型。正文、设定、大纲、人物、关系、灵感、批注被规范化为带来源坐标的统一文档并连续分块，建立实体与引用图，支持跨来源中文检索、全文游标分页与最多两跳的关联查询。投影严格区分资料性质：正文是已发生事实，设定与人物档案是作者设定，大纲是计划，灵感与批注另有标记；人物同场出现不会自动升级为关系。索引按批次发布并校验来源版本、作者裁决与作业租约，正文改动后相关知识自动失效、按需重建。

第二层是预设驱动的对话引擎。它兼容 SillyTavern 预设（对照本地 1.15.0 核心实现，并以 1.19 的世界书与状态数据调研作为后续路线）：可导入 Chat Completion 与 Prompt Manager 文件并给出槽位映射与兼容报告，编译提示顺序、相对位置、历史深度与同深度优先级，支持变量、作品、章节、选段、消息状态、时间、pick/roll 等核心宏，正则清洗在独立 Worker 中执行。采样参数按预设实际发送，生成支持候选、继续与重新生成。作品材料在发送前冻结版本，默认事实范围截至当前章，未来正文不会泄漏给过去人物。

第三层是提案式工具与写回安全。恍然梦提供正文、大纲、设定、人物、灵感五个模块共十五类专用任务（续写、选段改写、反推大纲、设定与人物提取、关系与阶段状态提取等）。Agent 先做只读检索、最多六轮工具调用，再提交结构化提案。红线是永不直接改库：提案经作者确认后在一个事务内整批写入，失败回滚；应用可审计、可撤销，目标资料变化即拒绝应用；空证据、重复摘引与错误坐标不能被标记为有效；作者修改过应用结果后撤销自动失效。隐私模式下不发送正文原文与摘引，只使用已有摘要和结构信息。

质量上，该项目以 CDP 真实事件驱动的端到端验收为核心：AI 数据层与预设定向用例分别 13/13、18/18、19/19、20/20、16/16 通过，五模块 Agent 任务与多窗口回归 39/39、10/10 通过。当前明确未完成的部分包括：分场景整章生成、正文反推纲与人物联合建卡的完整闭环、生成后的语义一致性修正，以及真实模型的文学质量与百万字性能评测；恍然梦也不是完整的酒馆运行环境，不执行第三方脚本与扩展。

## 使用注意（对外引用口径）

- 可宣称：全书读模型、预设驱动对话、十五类模块任务、提案确认与撤销、来源版本保护、隐私模式、本地存储。
- 不可宣称：完整酒馆兼容（脚本 / EJS / 角色卡生态不执行）、"AI 已学会全书"（是可追溯的外部记忆与检索，不训练模型）、创作质量已达标（真实模型评测未完成）。
