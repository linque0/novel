# 恍然梦助手对话前端改版

用户已批准对话主界面、输入框功能栏、对话内可编辑卡片与四皮肤适配。只改前端呈现和入口接线，不改模型、提示词、检索、冻结位置、生成、存储及应用规则；保留既有改动，不自动提交。

## 任务

1. 为消息与写作会话的 UI 关联补纯逻辑检查；记录当前业务核心文件 hash 及界面基线。
2. 抽取现有专用任务表单状态与参数视图，模块快捷入口改为定位统一输入框；调用原有 store 动作与原参数。
3. 统一消息区及输入框，方向与候选嵌入对应真实消息；保留历史来源，不写入伪消息；实现不抢滚动和新内容提示。
4. 精简方向与候选卡操作，移除重复标题，完成局部主题和300/400/640px适配；主浮层和独立AI窗口共用。
5. 定向 UI 检查、原工作流/Agent/阅读/多窗口相关回归；异步用例三次；四皮肤前后截图；一次独立审查并交付。

## 验收

- 顶部只有一个品牌标题，保留拆窗和关闭；没有独立“正文工作流/作品讨论”页面。
- 功能调整、当前模型、当前预设、发送/停止位于输入框内；窄宽度收纳预设。
- 方向完整返回即能编辑，选择独立；更多菜单保留换版、复制、恢复、删除。
- 候选编辑、预览、采纳、撤销及记忆提取保持；同卡只展示一次并使用原状态源。
- 请求、参数、来源、持久化和作品隔离不变；关闭不取消、不清空。
- 四皮肤默认/菜单/编辑/预览均可读，无横向溢出；旧业务核心文件hash保持。

## 环境

复用当前包含所有既有未提交修复的 checkout。独立 booksource-verify profile，CDP 9333，main inspector 9229；登记验证书、本地固定响应，不请求真实模型。
