# 原版纯书单验收

用户决定：只保留书单；强化封面质感与文字排版；大量作品时底部内容和操作必须容易到达。

## 实现

- 原版入口移除书架模式、切换入口及Three场景导入；保留原版以外的皮肤与工作台。
- 默认每页6本，可选12/24本；页码跳转、首页/末页、前后页；筛选/搜索/切换页数回首页，删除末页时夹取到有效页。
- 列表独立滚动；搜索、筛选、分页、当前作品和继续写作在滚动区域之外。窄屏短窗口使用紧凑布局，保留上一页/下一页、跳页和页容量。
- 书封/封底/书脊/纸页采用共享CSS3D结构；字数映射厚度；布面、纸面和皮面以材质明暗区分；当前作品保留书签。
- 四字以内纯中文竖排；较长中文横排；英文、数字、混排采用独立横排策略。封面局部省略时，完整标题可从书单、可访问名称和详情获取。
- 完整简介移至详情弹窗，避免展开内容不断撑长列表。现有创建/编辑/删除、真实章节接续与导航保持接入。
