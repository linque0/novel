# 琉光横向画架长廊

用户确认：立体书放在浅木画架上，横向长廊，首尾循环。中央作品放大，相邻作品缩小侧转。保留浅青色、文楷、绘画封面和后台渲染。下方统一展签（标题、作者、简介、统计、续写章节、续写/大纲/菜单）与紧凑横向作品目录。

交互：点击侧书/目录只选中，点击主书/续写才打开；鼠标拖动、触屏、左右按钮和方向键切换；拖动超过8px取消点击，松手就近吸附；约300ms过渡，减少动态时直接更新。首尾无逆向跨排；1本居中无控件，2本不重复。过滤重置首项，列表更新保留有效选择；选择不持久化、不记录打开。

接口：GlazeShelf 增加 select-work(id|null)，Bookshelf 续写查询跟随琉光选中作品并校验归属；赤月戏仍用第一部作品。gallery 纯逻辑模块，主展位最多7节点，缓冲不可交互，沿用渲染缓存。

验收：0/1/2/3/6/100部，长标题、缺作者/章节、搜索、编辑/删除；全部输入方式、首尾循环、过期章节；1440×900/1080×680/800×680/200%缩放；6本首屏P95≤200ms、渲染不引入>100ms主线程任务。交付实际截图和录屏。
