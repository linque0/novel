OVERVIEW

五个创作要素，
收进同一个工作台

面向个人作者的本地优先写作软件 · Windows 桌面端

小说工坊把「正文 / 大纲 / 人物 / 设定 / 灵感」收进同一个工作台， 并以输入即存作为第一原则：输入防抖 1 秒落盘、30 秒兜底、 失焦与切章与关窗前强制保存，配合章节自动版本快照，尽力让每一句话都不丢。 所有数据存于本机，不联网、不上传、不登录。

它要解决的是长篇小说创作中最常见的三个断裂：

01 · 产品概览
WORKSPACE

一个书架，管住全部作品

入口是书架页：每部作品一张封面卡，显示书名、总字数、章节数与创作状态（构思 / 连载 / 完结）。 卡片右上角是编辑与删除（软删除，可回收站恢复）菜单。 顶栏常驻备份、恢复、统计与帮助入口，右上角「＋ 新建作品」一键开书。

整库备份 / 恢复

导出 JSON 全库快照（含图片 base64），可整体还原；跨设备迁移或换机重装都靠它。

多配置隔离

命令行加 --profile=名字 即使用独立数据目录，多开互不干扰，写作与试稿可分开存放。

单实例保护 同一数据目录同时只允许一个实例运行，后启动者会给出「数据库被占用」提示——数据不会损坏， 这避免了两个窗口同时改写同一份稿件。

02 · 正文
MANUSCRIPT

正文 · 写作的主战场

卷—章两级树 + TipTap 富文本编辑器 + Word 风格工具栏

左侧是卷—章两级树：支持拖拽排序与按钮上下移动，行内显示每章字数， 顶部提供 ＋卷 / ＋章 / 改名 / 删除 一组快捷操作。 中间是富文本编辑区，右侧「本章大纲 / 本章出场人物 / 本章插图 / 本章信息」随当前章节实时联动。

工具栏能力

加粗 / 斜体 / 下划线 / 删除线，正文与 H1–H3 标题，字号、字体颜色、突出显示，超链接， 左中右两端对齐，有序与无序列表、引用，撤销重做与清除格式。

章节状态与书签

每章可标记草稿 / 完成 / 待修改；书签三入口——侧栏右键、工具栏 ☆ 键、顶栏 🔖 下拉跳转。

输入即存的三道保险 输入防抖 1 秒落盘 + 30 秒兜底 + 失焦 / 切章 / 关窗前强制保存； 顶栏常驻保存状态点。另有章节版本快照（5 分钟冷却、保留最近 30 份）可一键回滚。

02 · 正文
CONTEXT MENU

右键即用：Word 式操作栏

在正文中右键会就地弹出快捷操作栏，把最常用的编辑动作一次摊开， 免去来回移动鼠标到工具栏。含二级飞出菜单（标题 / 字号 / 字体颜色 / 突出显示 / 对齐）， 以及「添加双链…」——把选中文字直接链到任意章节、人物或设定。

  • 遵循 Word 习惯——右键落在选区内保持选区（菜单作用于选中文字），落在选区外则先把光标移到该处，不会莫名丢掉已选内容。
  • 剪贴板走安全 IPC——复制粘贴经主进程剪贴板接口，不在渲染层直接访问系统能力。
  • 在链接上右键可编辑链接、在系统浏览器打开、或清除链接。

03 · 大纲
OUTLINE CANVAS

大纲 · 自由模块画布

流程图式白板：没有固定结构，你把想法摆到哪里，它就是哪里

六类模块 · 四种形状

事件（矩形 / 菱形 / 平行四边形 / 椭圆，SVG 真实描边）、 便签、引用卡（双链到设定 / 章节 / 人物）、 文本框（透明度可调）、容器（拖入归组 / 拖出回根级 / 可折叠）、 章节与卷锚点（点击跳回正文对应位置）。

摆位与操作

拖拽摆位（网格吸附、双密度切换、pin 固定、八向调整尺寸），双击行内编辑， 空白处右键新建，Delete 删除选中模块。侧栏点击定位、双向高亮。

断线检测 画布底部常驻「烂尾情节 / 缺铺垫」提示——无出边的事件被标为烂尾，无入边的被标为缺铺垫， 结构漏洞一眼可见（图示作品当前为「断线 0 · 共 17 模块」）。

EDGES

连线：四类语义，严格端口，全局最短绕行

语义默认色说明
关联蓝常规关系，默认线型
因果红事件之间的推动关系
伏笔紫默认虚线，用于铺垫与回收
冲突橙对抗与张力
  • 每条连线可独立设置单向 / 双向 / 无向箭头与实线 / 虚线 / 点线，单条线宽与箭头大小可覆盖全局（↺ 一键恢复跟随全局）。
  • 严格端口锁定——建立连线时记录两端接口方向并落库，渲染只认记录值；节点挪到任何位置，连线绝不漂移到别的边。
  • 全局最短绕行——连线途经任何模块（含两端节点本体）一律自动绕行，采用 Hanan 稀疏网格 A* 求解全局最短路，再做直连 / L 形拉直收敛。

03 · 大纲
JUNCTIONS

线连到线：连接点

除了「模块 ↔ 模块」，还支持连线与连线互连：从模块锚点拖线， 若落点在既有连线上（12px 容差命中），会在落点自动创建一个连接点并完成接线。 连接点采用「连线寄生」模型——以路径参数挂在宿主连线上，节点怎么挪都钉在线上不脱线； 一条连线可建多个连接点、各自引出多条线。

拖拽塑形

左键按住连线拖动，连线随鼠标弯曲；拖回接近直线（垂距 < 6px）自动拉直，或双击直接拉直恢复自动路由。

浮层避线放置

编辑浮层按上 / 下 / 左 / 右四方位自动避开连线本体落位，不遮住正在修改的那条线。

03 · 大纲
TEXT VIEW

文本视图：幕布式大纲

同一份数据的两种看法，随时切换

画布之外还有文本视图——把同一份大纲数据以缩进树呈现，适合快速罗列与调整层级。 两个视图共享同一份数据，右上角一键切换，改动即时互通。

双视图共享

画布与文本不是两套数据，改一处另一处立即同步。

容器面包屑

文本视图显示节点所属容器，归组结构不会在文字里迷路。

侧栏层级树

容器从属缩进、折叠状态与画布同步，支持搜索筛选定位。

一个模块，两种工作节奏 构思阶段用画布摆结构、看全貌；梳理阶段用文本视图列条目、调层级。 数据同源，所以两种节奏可以随时来回切换而不丢上下文。

04 · 人物
CHARACTER GRAPH

人物 · 关系图

人物是节点，关系是连线 — 拖线即建立关系

拖线 = 建立与改变关系的统一手势

在画布上从人物拖线到另一人即建立关系；拖线落到已有关系上则打开该关系的编辑浮层，就地改标签或删除。

布局与筛选

圆形 / 网格一键排布；悬停节点高亮一度关系网；按角色或标签筛选；孤岛人物单独提示，避免「写了却没用上」的角色。

  • 与关系列表双向同步——画布上连线改动，列表视图「人物关系」区即时反映，反之亦然。
  • 一键发送为大纲引用卡——把人物或关系直接送到大纲画布，作为剧情设计的素材。
  • 本章出场人物自动检测——正文中提及的人物自动归入「本章出场人物」，写作时不必手动维护。
  • 线与观感统一——关系边的线型、颜色、粗细与大纲画布共用同一套偏好。

05 · 设定
LORE

设定 · 幕布式大纲树

一棵统一节点树：任意节点平权、可无限嵌套、自由拖拽

结构自由

没有「文件夹 / 条目」二分，任意节点地位平等。拖拽移动带三区插入指示，悬停折叠节点自动展开， 拖到空白处即移到顶层，配 FLIP 衔接动画。

内联格式与编辑

节点内容支持加粗 / 斜体 / 下划线 / 删除线 / 颜色 / 底色 / 清除格式， 带快照式撤销重做，以及节点级复制 / 剪切 / 粘贴（纯文本优先）。

  • 侧边栏是同一棵树的镜像——点击定位、逐级折叠展开，与编辑区双向同步。
  • MD / TXT 导入——标题层级自动转为节点层级，正文行转为子节点，旧笔记可直接迁入。
  • 旧数据无损迁移——早期「分类 / 条目」结构首次打开时自动迁移，不丢内容。

06 · 灵感
SNIPPETS

灵感 · 随手记

写正文时冒出的念头，不必打断思路

灵感是一张随时可用的纸条：在输入框记下一句话，Ctrl+Enter 提交， 列表按时间倒序排列。任何一条灵感都能一键转为章节或设定， 从「想到」到「落在结构里」只差一次点击。

随手记

不打断正文写作，占用一个侧栏位置即可记录。

一键转章节

灵感直接变成章节节点，省去复制粘贴。

一键转设定

世界观构想转为幕布节点，即刻进入设定树。

双链让灵感长在结构上 灵感内容同样支持 [[双链]]——写「钟楼的第十二响」时把关键词链到设定节点， 日后检索与追溯都能回到源头。

ENTITY LOCK

实体锁：不会双写，也不会互相打断

为防同一内容被两个窗口同时改写，软件内置实体锁： 面板占用的章节，主窗口该章转为只读占位并给出「前往窗口」按钮， 其余章节照常可写。面板内切换条目时，锁随选中自动迁移。

锁粒度跟随编辑面

章节 / 人物 / 灵感用条目级锁（只有被占用的那条转只读）； 大纲 / 设定幕布是跨节点树编辑，用模块级锁（对应页签整体占位）—— 避免「锁了半个模块」的假安全。

窗口生命周期

面板按类型记忆窗口几何（并夹取到可见屏内）；关闭前优雅保存； 主窗口关闭时级联关闭全部面板。

数据一致性 每个面板持有自己的数据连接，写入经主进程锁表互斥，保存复用同一套自动保存链路—— 面板里敲下的字与主窗口走完全相同的落盘路径。

THEMES

三套主题 · 沉浸写作

提供宣纸（默认，暖米色纸纹）、羊皮纸、暗夜书房（深色）三套皮肤。 全局采用衬线排版与纸张纹理，配统一的图标体系与视觉令牌（圆角 / 间距 / 投影 / 动效时长）， 并支持 prefers-reduced-motion 降级与键盘焦点环。

宣纸

暖米色纸纹底色，默认主题，长时间阅读最柔和。

羊皮纸

偏暖黄的旧纸质感，适合偏好复古阅读感的作者。

暗夜书房

深色低亮配色，夜间写作减少屏幕刺激。

沉浸模式 隐藏侧栏与导航栏，只留正文与工具栏，专注写作；Esc 或再次点击即可退出。

10 · 内置帮助与数据安全
HELP & SAFETY

内置帮助 · 回收站 · 数据安全

手册与源码同源

顶栏「帮助」按钮（书架页与书内均有）打开内置手册。手册以 Markdown 原文打包进构建、 marked 实时渲染，与源码手册同源——功能一变，手册跟着变，永不失同步。

回收站

删除的章节 / 人物 / 设定 / 灵感进入回收站，按类型分页，可恢复或彻底删除。

数据与安全
  • 全部数据存于本机（Electron 用户数据目录下的 IndexedDB），无任何网络请求，不登录、不上传
  • 「备份」导出 JSON 全库快照（含图片），「恢复」可整体还原
  • 超链接仅接受公网 http/https 地址（拒绝本地 / 私有 / 保留 IP），交由系统默认浏览器打开
