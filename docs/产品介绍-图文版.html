OVERVIEW

五个创作要素，
收进同一个工作台

面向个人作者的本地优先写作软件 · Windows 桌面端

小说工坊把「正文 / 大纲 / 人物 / 设定 / 灵感」收进同一个工作台， 并以输入即存作为第一原则：输入防抖 1 秒落盘、30 秒兜底、 失焦与切章与关窗前强制保存，配合章节自动版本快照，尽力让每一句话都不丢。 作品数据全部存于本机；除你主动配置的 AI 服务外，不联网、不上传、不登录。

它要解决的是长篇小说创作中最常见的三个断裂：

01 · 产品概览
WORKSPACE

一个书架，管住全部作品

入口是赤月戏的书架舞台：76px 页头承载品牌、七模块导航、皮肤选择器与设置入口； 主舞台按作品切换布景，左侧竖排书名与简介，中央是生成式书封与「接续上次的故事」首章票根； 右侧 316px「未完的剧目」栏列出其余作品，显示字数、章数与上次打开时间。底部 40px 底栏汇总作品数并提供「重播演出」。 顶栏同时保留本地搜索（书名 / 作者 / 类型）与「＋ 新建作品」。

整库备份 / 恢复

「⚙ 设置 → 数据」导出 JSON 全库快照（含图片 base64），可整体还原；跨设备迁移或换机重装都靠它。

多配置隔离

命令行加 --profile=名字 即使用独立数据目录，多开互不干扰，写作与试稿可分开存放。

单实例保护 同一数据目录同时只允许一个实例运行，后启动者会给出「数据库被占用」提示——数据不会损坏， 这避免了两个窗口同时改写同一份稿件。

02 · 正文
MANUSCRIPT

正文 · 写作的主战场

卷—章两级树 + TipTap 富文本编辑器 + Word 风格工具栏

赤月戏把正文拆成章节目录 + 稿本 + 页边札记三栏：248px 章节树按卷分组、可收到 56px； 296px 起的稿本包含居中章题、花饰、状态行与页脚 folio；252px 札记栏承载本章批注、资料、字数目标与恍然梦入口。 正文继续尊重你的中文字体与字号偏好。选中文字可添加批注与关系链接： 批注是带用途色的实线下划线，关系链接是点状下划线，两者可叠在同一段文字上；悬停关系链接会弹出可拖动的预览窗。

工具栏能力

加粗 / 斜体 / 下划线 / 删除线，正文与 H1–H3 标题，字号、字体颜色、突出显示，超链接， 左中右两端对齐，有序与无序列表、引用，撤销重做与清除格式。

章节状态与书签

每章可标记草稿 / 完成 / 待修改；书签三入口——侧栏右键、工具栏 ☆ 键、「⚙ 设置」面板书签区跳转。

输入即存的三道保险 输入防抖 1 秒落盘 + 30 秒兜底 + 失焦 / 切章 / 关窗前强制保存； 顶栏常驻保存状态点。另有章节版本快照（5 分钟冷却、保留最近 30 份）可一键回滚。

02 · 正文
CONTEXT MENU

右键即用：Word 式操作栏

在正文中右键会就地弹出快捷操作栏，把最常用的编辑动作一次摊开， 免去来回移动鼠标到工具栏。含二级飞出菜单（标题 / 字号 / 字体颜色 / 突出显示 / 对齐）， 以及「添加批注」「添加关系链接」——把选中文字直接链到任意章节、人物或设定。

  • 遵循 Word 习惯——右键落在选区内保持选区（菜单作用于选中文字），落在选区外则先把光标移到该处，不会莫名丢掉已选内容。
  • 剪贴板走安全 IPC——复制粘贴经主进程剪贴板接口，不在渲染层直接访问系统能力。
  • 在链接上右键可编辑链接、在系统浏览器打开、或清除链接。

03 · 大纲
OUTLINE CANVAS

大纲 · 分层自由画布

根层只显示直接子节点；容器可进入、可就地展开；面包屑返回上级并恢复各层相机

七类模块 · 四种形状

事件（矩形 / 菱形 / 平行四边形 / 椭圆，SVG 真实描边）、 便签、引用（关系链接到设定 / 章节 / 人物）、 文本框（透明度可调）、锚点（绑定章节）、 卷（绑定分卷）、容器（归组 / 折叠 / 可进入 / 可就地展开）。

根层与容器

根层只渲染直接子节点，容器以章节卡呈现（标题 / 摘要 / 章节 / 事件进度 / 嵌套数）。 点「进入容器」切换到次级画布；「就地展开」把容器展开为两列迷你卡（窄容器单列）。 容器八向缩放（宽 260–720），内容超出时迷你卡在内容区内部滚动，连线与端口跟随滚动。

分层画布 容器内部是独立的一层：只显示它的直接子节点，面包屑可逐级返回，并恢复离开时各层的相机位置。 工具条的「展开全部 / 收起全部」递归处理当前作用域的所有层级容器；「总览」会自动收起容器并适配全图。

EDGES

连线：四类语义，严格端口，全局最短绕行

语义默认色说明
关联蓝常规关系，默认线型
因果红事件之间的推动关系
伏笔紫默认虚线，用于铺垫与回收
冲突橙对抗与张力
  • 每条连线可独立设置单向 / 双向 / 无向箭头与实线 / 虚线 / 点线，单条线宽与箭头大小可覆盖全局（↺ 一键恢复跟随全局）。

  • 全局最短绕行——连线途经任何模块（含两端节点本体）一律自动绕行，采用 Hanan 稀疏网格 A* 求解全局最短路，再做直连 / L 形拉直收敛。

03 · 大纲
JUNCTIONS

线连到线：连接点

除了「模块 ↔ 模块」，还支持连线与连线互连：右键连线 →「在此处创建连接点」， 连接点会直接钉在右键位置对应的连线路径上。连接点采用「连线寄生」模型——以路径参数挂在宿主连线上， 节点怎么挪都钉在线上不脱线；它既可作为模块拖线的终点，也可直接按住拖出连线作为起点； 一条连线可建多个连接点、各自引出多条连线，右键连接点可删除（接到它上面的、从它引出的连线一并删除）。

拖拽塑形

左键按住连线拖动，连线随鼠标弯曲；拖回接近直线（垂距 < 6px）自动拉直，或双击直接拉直恢复自动路由。

浮层避线放置

编辑浮层按上 / 下 / 左 / 右四方位自动避开连线本体落位，不遮住正在修改的那条线。

NODE ACTIONS

模块操作与画布工具

右键菜单项

设置 / 详情、形状（矩形 → 平行四边形 → 菱形 → 椭圆循环切换）、画布内编辑、 透明度滑杆（文本框）、固定 / 取消固定、发送给恍然梦、删除（红标）。容器另有分支调色板。

画布工具条

总览、展开全部 / 收起全部、整理布局、文本视图；画布透明度 20–100%、 连线粗细、箭头大小、卡片密度、曲线 / 折线切换、16px 网格吸附、缩放与适应。

03 · 大纲
TEXT VIEW

文本视图：幕布式大纲

同一份数据的两种看法，随时切换

画布之外还有文本视图——把同一份大纲数据以缩进树呈现，适合快速罗列与调整层级。 两个视图共享同一份数据，右上角一键切换，改动即时互通；Ctrl+K 会搜索全部层级，自动进入目标父层并定位。

双视图共享

画布与文本不是两套数据，改一处另一处立即同步。

状态与所属容器

文本视图顶部显示条目性质与完成状态，节点仍保留所属容器的层级关系。

侧栏层级树

容器从属缩进、折叠状态与画布同步，支持搜索筛选定位。

一个模块，两种工作节奏 构思阶段用画布摆结构、看全貌；梳理阶段用文本视图列条目、调层级。 数据同源，所以两种节奏可以随时来回切换而不丢上下文。

04 · 人物
CHARACTER GRAPH

人物 · 关系图

人物是节点，关系是连线 — 拖线即建立关系

拖线 = 建立与改变关系的统一手势

在画布上从人物拖线到另一人即建立关系；拖线落到已有关系上则打开该关系的编辑浮层，就地改标签或删除。

布局与筛选

圆形 / 网格一键排布；悬停节点高亮一度关系网；按角色或标签筛选；孤岛人物单独提示，避免「写了却没用上」的角色。

  • 与关系列表双向同步——画布上连线改动，列表视图「人物关系」区即时反映，反之亦然。
  • 一键发送为大纲引用卡——把人物或关系直接送到大纲画布，作为剧情设计的素材。
  • 本章出场人物自动检测——正文中提及的人物自动归入「本章出场人物」，写作时不必手动维护。
  • 线与观感统一——关系边的线型、颜色、粗细与大纲画布共用同一套偏好。

05 · 设定
LORE

设定 · 幕布式大纲树

一棵统一节点树：任意节点平权、可无限嵌套、自由拖拽

结构自由

没有「文件夹 / 条目」二分，任意节点地位平等。拖拽移动带三区插入指示，悬停折叠节点自动展开， 拖到空白处即移到顶层，配 FLIP 衔接动画。

内联格式与编辑

节点内容支持加粗 / 斜体 / 下划线 / 删除线 / 颜色 / 底色 / 清除格式， 带快照式撤销重做，以及节点级复制 / 剪切 / 粘贴（纯文本优先）。

  • 侧边栏是同一棵树的镜像——点击定位、逐级折叠展开，与编辑区双向同步。
  • 设定详情页——双击条目进入：面包屑路径、关联关系列表、可拖动关系图谱与子条目树；「幕布中定位」关闭详情并闪烁定位原条目。
  • MD / TXT 导入——标题层级自动转为节点层级，正文行转为子节点，旧笔记可直接迁入。
  • 旧数据无损迁移——早期「分类 / 条目」结构首次打开时自动迁移，不丢内容。

06 · 灵感
SNIPPETS

灵感 · 随手记

写正文时冒出的念头，不必打断思路

灵感是一张随时可用的纸条：在输入框记下一句话，Ctrl+Enter 提交， 列表按时间倒序排列。任何一条灵感都能一键转为章节或设定， 从「想到」到「落在结构里」只差一次点击。赤月戏把它做成三栏： 220px 灯笼河布景、420px 手记墙与 1fr 阅读纸；手记卡错落排布，选中后在右侧阅读纸里继续编辑。

随手记

不打断正文写作，占用一个侧栏位置即可记录。

一键转章节

灵感直接变成章节节点，省去复制粘贴。

一键转设定

世界观构想转为幕布节点，即刻进入设定树。

关系链接让灵感长在结构上 灵感内容同样支持关系链接——写「钟楼的第十二响」时把关键词链到设定节点， 日后检索与追溯都能回到源头。

EXPORT

导出：按章节勾选 · 三种格式 · 智能批量

选中范围导出行为
1 章直接以 章节名.格式 导出
多章（≤ 阈值，默认 30）逐章分批：仅首次确认位置，之后自动写入同目录，每章一个文件；首步取消即中止
超过阈值可选「合并为单个文件」或「按章打包 zip」（按卷分目录、序号-章节名 命名）
  • 三种格式：TXT 纯文本 / Markdown / Word (docx)。
  • docx 零新依赖——由 JSZip 手组 OOXML 生成，保留加粗、斜体、下划线、删除线、字色、标题样式、对齐、列表与引用缩进，A4 版式，元数据写入书名作者。
  • 阈值可调——批量选择区数字控件直接改（2–500），即改即存。
  • 整库备份——导出菜单另备「备份 / 恢复」整库 JSON（含图片），用于换机与存档。

08 · 多窗口
MULTI-WINDOW

多窗口 · 边看大纲边写正文

拆出的是完整功能界面，不是只读预览

顶栏「⧉ 拆窗 ▾」可把正文 / 大纲 / 人物 / 设定 / 灵感任一模块 拆出为完整功能界面的独立窗口（侧栏 + 编辑区 + 调宽手柄）， 面板内可自由切换条目——它是完整的第二编辑现场。

典型用法：双屏写作 主窗口写正文，面板窗口放大纲——落到「第十二响」这一章时抬头就能看到它前面挂着哪几条伏笔， 不必来回切页。

08 · 多窗口
ENTITY LOCK

实体锁：不会双写，也不会互相打断

实体锁

为防同一内容被两个窗口同时改写，面板占用的章节 / 人物 / 灵感条目， 主窗口对应条目转为只读占位并给出「前往窗口」按钮，其余条目照常可写。 面板内切换条目时，锁随选中自动迁移。

锁粒度跟随编辑面

章节 / 人物 / 灵感用条目级锁（只有被占用的那条转只读）； 大纲 / 设定幕布是跨节点树编辑，用模块级锁（对应页签整体占位）—— 避免「锁了半个模块」的假安全。

窗口生命周期

面板按类型记忆窗口几何（并夹取到可见屏内）；关闭前优雅保存； 主窗口关闭时级联关闭全部面板。

数据一致性 每个面板持有自己的数据连接，写入经主进程锁表互斥，保存复用同一套自动保存链路—— 面板里敲下的字与主窗口走完全相同的落盘路径。

09 · 视觉与主题
SKINS

四套皮肤 · 折屏戏台

软件内置四套皮肤：原版工坊、引力书舱、琉光画境与赤月戏。皮肤覆盖书架、工作台与独立窗口， 在书架页头或设置窗口一键切换；切换皮肤不改变作品数据、功能与操作习惯。 赤月戏的设计语言是「金屏为台，折缝为幕，纸页为文，朱印为场，书签为序」： 深墨舞台承托暖纸页面，旧金细线分隔大栏，朱砂只用于印章、当前书签与主 CTA。

赤月戏

墨纸旧金、折屏戏台与宋体竖题；76px 顶栏 + 86px 模块条 + 40px 底栏，正文 248 / 296 / 252 三栏。

引力书舱 · 琉光画境

深海蓝铜色轨道，或浅青玻璃叠册；两套都覆盖书架、工作台与独立窗口。

原版工坊

熟悉的书架与工作台，含宣纸 / 羊皮纸 / 暗夜书房三套主题与色带书封。

沉浸模式 隐藏侧栏与导航栏，只留正文与工具栏，专注写作；Esc 或再次点击即可退出。

09 · 视觉与主题
CRIMSON STAGE

赤月戏的布景 · 字体 · 设置窗口

赤月戏为不同模块准备了独立布景：人物页的红月、设定页的天象图与灵感页的灯笼河； 正文、大纲与设置也各有自己的舞台。标题用京华老宋体，文学性文字用霞鹜文楷， 正文继续尊重你的中文字体与字号偏好；纸页带错位背纸、软影与折角，大栏之间用 11px 折缝分隔。

正文字体支持中 / 西文分离切换：中文六款（思源宋体 / 霞鹜文楷 / 京华老宋体 / 朝华标题 / 云游手书 / 系统黑体）、 西文三款（跟随中文 / Playfair Display / Montenegrin Gothic One），全部为随包本地 OFL 字体、零网络请求； 赤月戏下标题自动使用京华老宋体，正文与字号仍按你的偏好渲染。

人物 · 红月

人物页整幅红月布景，330×420 拱顶肖像与竖排演员表。

设定 · 天象图

左侧天象图布景列，中间纸面幕布树，右侧设定目录。

灵感 · 灯笼河

220px 灯笼河布景 + 420px 手记墙 + 1fr 阅读纸。

原版工坊的色带书封 竖版 2:3 开本、平涂单色、书脊装订带、书名与作者名圆印；六款配色冷暖对位，仍在原版工坊下可选。

10 · 内置帮助与数据安全
HELP & SAFETY

内置帮助 · 回收站 · 数据安全

手册与源码同源

「⚙ 设置 → 帮助与键位手册」（书架页与书内均有）打开内置手册。手册以 Markdown 原文打包进构建、 marked 实时渲染，与源码手册同源——功能一变，手册跟着变，永不失同步。

回收站

删除的章节 / 人物 / 设定 / 灵感进入回收站，按类型分页，可恢复或彻底删除。

数据与安全
  • 全部数据存于本机（Electron 用户数据目录下的 IndexedDB），不登录、不上传；仅当你主动使用恍然梦 AI 助手时，才会按你配置的模型服务发起请求
  • 「备份」导出 JSON 全库快照（含图片），「恢复」可整体还原
  • 超链接仅接受公网 http/https 地址（拒绝本地 / 私有 / 保留 IP），交由系统默认浏览器打开
