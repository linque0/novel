小说工坊 ·「色带书封」全界面设计稿

以 G 色带书封（Fitzcarraldo 式双色制）为主体的完整界面规范：封面双色制 + 作者名圆印（替代原「坊」字盖章）+ 封面特殊字体 Noto Serif SC（思源宋体，SIL OFL，已随稿本地化）；全文 Playfair Display 作拉丁展示字。色板收敛为克莱因蓝 #002FA7 / 象牙白 #FBF9F3 / 墨黑 #1E1E1E 三色 + 一枚朱备用。含书架、编辑器、大纲画布、人物关系图、设定幕布、素材、弹窗浮层共 8 屏，红色编号为规格说明。本稿不经软件渲染，浏览器直接打开即可。

封面三规则

① 双色制：虚构类 = 克莱因蓝满地 + 象牙白衬线书名；非虚构（设定/考据向）= 象牙白底 + 蓝字反相；墨黑/朱仅作特殊状态备用。② 作者印：圆 27px 单线描边，作者名两行竖排（2 字拆分 / 3-4 字两行），替代原「坊」字盖章，颜色随封面反相。③ 特殊字体：封面书名与作者印一律使用 Noto Serif SC 600/500（思源宋体），字距 .12em——全站唯一使用衬线展示字的封面区。

【面板新增句】他抬头看去，三百六十枚铜刻星辰沿界脊缓缓归位，雪落无声。

雪落在界脊之上，盖住了昨夜巡山人的脚印。他握紧提灯，向隘口走去——这世上最后一座观星台，今夜只剩他一个守夜人。

「若星辰尽归天上，人间会记得谁？」老人说过的话在耳边响起。他没有答案，只有灯，和一场越下越大的雪。
