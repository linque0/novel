# 独立窗口关闭验收的 CDP 竞态

最终复验的一次工作台第三轮在 52 条通过输出后没有返回，父执行器于 180 秒超时退出。最后两条输出为 800px 大纲面板可用及画布／目录空间断言通过，下一步是直接求值 `native.panelCloseSelf()`。

窗口实际已关闭，调试目标也随之销毁；共享 CDP helper 对目标销毁时仍待响应的求值不会主动拒绝，因此 Runtime.evaluate 等待的回复丢失。失败表现为 `spawnSync ... ETIMEDOUT`，未出现业务断言失败。

修正仅在本次琉光验证脚本中：先通过返回 true 的求值排队关闭，再轮询 /json/list 等待原目标消失，随后等待主窗口锁恢复。原生关闭和拆窗业务代码不变。

中断轮次的当前测试作品经独立 profile 路径与 fixture 标记确认后软删除。正式 results.json 为修正后的完整回归：两份琉光集成脚本各连续三轮退出码 0，每轮工作台 68 条通过输出、书架 32 条通过输出。
