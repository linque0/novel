## 二、视觉语言定位

**一句话**：文房纸感 × 台灯夜读——一套"书写文具"的视觉隐喻，而非通用 SaaS 后台。

三个关键词（所有视觉决策的裁判标准）：

| 关键词 | 含义 | 视觉转译 |
|---|---|---|
| 纸 | 内容是写在纸上的 | 低饱和暖底、细分隔线、无重投影、正文区"页面感" |
| 墨 | 强调用墨不用色块 | accent 只做**细线/文字/小面积淡底**，禁止大面积色块铺陈 |
| 灯 | 暗色主题是台灯下的书桌 | 暖金 accent、面板分层（桌面→纸→内容）、暗处不刺眼的柔对比 |

**禁忌清单**（评审一票否决）：纯蓝 #1890ff 类科技色、冷灰、大面积渐变、彩色大按钮、glow 发光标题、>14px 粗体正文。

## 三、设计原则

1. **内容为王**：一切装饰服务于"长时间读写不疲劳"，动效克制、只动 transform/opacity。
2. **纸感统一**：宣纸/羊皮纸往"文具感"做（细分隔线、印章色点缀、低饱和），暗夜往"台灯夜读"做（暖金 accent、面板分层）。
3. **一套令牌管所有**：新视觉参数一律走 CSS 变量、三主题同步，禁止组件内硬编码色值/圆角。
4. **不加重依赖**：图标用内联 SVG（精选 20-30 个）或按需引入，不引全家桶。
5. **规格先行**（G9 教训）：新组件先在本文登记规格再写代码。

### 4.2 字体

| 属性 | 值 |
|---|---|
| UI 字体栈 | 'Microsoft YaHei', 'PingFang SC', system-ui, sans-serif（既有） |
| 正文字体栈 | `--editor-font` 设置可选：默认雅黑 / 霞鹜文楷★（与纸感最搭，建议内置）/ 思源宋体 |
| 字号 | `--fs-xs 11 / sm 12.5 / md 13.5 / lg 15 / title 17`，全站只取五档 |
| 行高 | UI 1.5；正文 1.9–2.0；标题 1.3 |
| 字重 | 400 常规 / 600 卡片标题 / 700 仅 brand 与书名，禁止 800+ |
| 字距 | 中文 UI 0；正文 0.02em；brand 2px；数字统计 `font-variant-numeric: tabular-nums` |

### 4.3 形状 · 阴影 · 间距

**圆角**：`--radius-sm 6`（按钮/输入框/chip）、`--radius-md 10`（卡片/节点/浮层/菜单）、`--radius-lg 14`（容器/弹窗/大面板）、标签徽章 999 或 50%。

**阴影三级**（★新增令牌，只表达"悬浮高度"，禁止彩色阴影与多层叠加）：

```css
--shadow-node: 0 1px 3px rgba(60,45,20,.10);        /* 卡片常态：贴纸 */
--shadow-node-hover: 0 4px 12px rgba(60,45,20,.14); /* 悬停抬起 */
--shadow-pop: 0 6px 24px rgba(90,70,40,.18);        /* 浮层（✅ 已落地；暗夜 0 8px 28px rgba(0,0,0,.55)） */
```

**间距**：`--space-1..5 = 4/8/12/16/24`；组件内 padding 取 space-2/3，组件间 3/4，分区 5；对齐以 4px 网格为准。

### 4.4 动效令牌（★新增）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--ease` | cubic-bezier(.2,.6,.3,1) | 全站默认曲线 |
| `--dur-fast / --dur / --dur-slow` | 120ms / 180ms / 250ms | 微反馈 / 浮层卡片 / 面板切换 |

已落地：浮层入场 140ms、`prefers-reduced-motion` 全局降级。

## 五、纹理与装饰（纯 CSS 零资源）

**纸纹**（宣纸/羊皮纸的 `--bg` 与 `--bg-editor` 叠加）：

```css
background-image:
  repeating-linear-gradient(0deg, rgba(140,111,78,.022) 0 1px, transparent 1px 3px),
  repeating-linear-gradient(90deg, rgba(140,111,78,.016) 0 1px, transparent 1px 3px);
```

**暗夜网格**（`--bg`）：

```css
background-image:
  linear-gradient(rgba(212,169,92,.035) 1px, transparent 1px),
  linear-gradient(90deg, rgba(212,169,92,.035) 1px, transparent 1px);
background-size: 24px 24px;
```

**分隔线语言**：常规 1px `--border`；强调分隔（面板头/编辑器上方）= 1px `--border` + 紧贴 1px 高光 rgba(255,255,255,.25)（暗夜 rgba(0,0,0,.4)）成"刻痕"；禁止色块分段。

**选中色**：`::selection { background: var(--accent-soft); }` 全站统一。

## 六、组件视觉规格（逐个定稿，新增元素必须先在此登记——G9 规则）

### 6.1 顶栏（52px）
底 `--bg-panel` + 强调分隔线；书名 `--fs-title` + `--editor-font` + 700 + `--accent`；保存状态 8px 圆点（保存中 `--warning` 转圈、已保存 `--success` 静置 3s 淡出）+ `--fs-xs` 文字；右侧动作统一 `btn-ghost`（sm 圆角、`--fs-sm`、间距 space-2）。

### 6.2 导航 rail（60px）——差异化担当，✅ 激活态已落地
已落地：激活 = accent-soft 底 + accent 字 + 内缘 2px 竖条；按压 scale(.94)。
追加：小字改 `--fs-xs` + `--text-dim`；悬停"单字先变色、底色 80ms 后到"的微节奏；rail 底部新增昼/夜一键切换圆钮（44px 同规格）。

### 6.3 按钮（一屏最多一个主按钮；危险操作必须二次确认）
| 类型 | 底 | 边 | 字 | 悬停 |
|---|---|---|---|---|
| 主 | `--accent` | 无 | #fff（暗夜 #1e1c17） | `--accent-deep` |
| 幽灵（默认） | 透明 | 1px `--border` | `--text` | 底 `--bg-hover`、边 `--border-strong` |
| 危险 | 透明 | 1px `--danger` | `--danger` | 底 `--danger-soft` |

### 6.4 输入框
高 30px、sm 圆角、1px `--border`；聚焦边 `--accent` + `--ring: 0 0 0 3px var(--accent-soft)`（★新令牌）；placeholder `--text-faint`。

### 6.5 画布节点（按类型）
公共：md 圆角、`--shadow-node`→hover `--shadow-node-hover`、1.5px 边框；标题 `--fs-sm` 600，副行 `--fs-xs` `--text-dim`；选中 = 边 accent 2px + `0 0 0 4px var(--accent-soft)` 光晕。
左侧 3px 类型色条（★新增，与图标同色）：事件=`--accent`、便签=#b9770e、引用卡=#2980b9、文本框=无边框仅底色；锚点/卷保留既有左侧 4px accent。
状态点徽标：9px 右上角（✅ v0.4.17 已实现：灰=草稿/绿=完成/橙=待修改）。

### 6.6 连线
常态 1.7px @ .85 透明度；悬停 2.5px 不透明；所属节点选中时的一度网可开流动虚线（`stroke-dashoffset` 1.2s linear infinite）；中点标签 = `--bg-panel` 底 + `--border` 胶囊 + `--fs-xs`。

### 6.7 浮层/右键菜单（`.pop` 公共语言）
md 圆角、`--shadow-pop`、1px `--border`、padding space-2；入场 140ms 淡入+4px 上移（✅ 已落地，flip 变体仅淡入）；菜单项高 32px、悬停 `--bg-hover` + 左 2px accent 条。

### 6.8 空状态
单色线稿小图形（24px、`--text-faint` 描边）+ 一句话（`--text-dim`）+ 一个幽灵按钮；三主题共用图形仅描边色随主题。

### 6.9 图标规范
内联 SVG：24 viewBox、1.5px 描边、圆帽圆角、继承 `currentColor`；emoji 退出全部交互位（仅允许出现在便签内容中）。

### 6.10 登记示例（G9 规则示范）
`.ol-dot` 章节状态徽标：9px、`position:absolute; top:-4px; right:-4px`、50% 圆角、1.5px `--bg-panel` 描边环、三状态色取 `--st-*`。（✅ v0.4.17 已实现，作为登记格式范例）

## 九、落地注意事项

1. **规格先行**：新组件/元素先在 §6 登记规格再写代码（G9 教训：`.ol-dot` 事故）。
2. **令牌先行**：批次二起的所有样式改写必须基于批次一令牌；新增 CSS 禁止出现令牌之外的 hex。
3. **三主题同步**：每个新令牌三主题同时给值；UI 批次跑三主题逐屏截图对比（扩展 CDP 截图脚本，一屏三图）。
4. **Naive UI 打通**：`NConfigProvider themeOverrides` 从 CSS 变量取值。
5. **性能红线**：禁止对带 box-shadow 元素做常驻动画；`backdrop-filter` 仅限顶栏/浮层且暗色降级实色；动效只动 transform/opacity。
6. **测试数据口径**（v0.4.18 规则）：视觉截图/验收在 `npm start`（真实书目）与 `npm run dev`（验证书）两个实例各跑一轮并注明数据目录；同一数据目录禁止双开。
