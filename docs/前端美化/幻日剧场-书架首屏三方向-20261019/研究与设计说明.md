# 幻日剧场 · 诸界登台

2026-10-19。使用 oil-ui 的方向卡、差异检验与首屏对比页流程。

## 本轮任务

主题以用户最新表述为准：**剧场中上演的不同剧目，是一个个不同的真实世界。**

书架是作者回到当前小说、继续写作及浏览其他作品的入口。三版共同保留七模块导航、搜索、新建作品、六部作品、字数与章节数、最近编辑状态、当前章节和继续写作。以《星尘旅人》及其天文港城作为同一个主对象，比较不同媒介和构图。书目与文本仅在 `data.json` 维护，页面由 `build.py` 生成；剧情摘要、章节与时间是设计用内容，不来自用户的真实作品库。

本轮交付三个 **1440 × 900 静态 HTML 首屏** 和 oil-ui 生成的对比页。候选页面的操作用于展示布局，不连接数据库、AI 或业务路由，不制作候选交互、响应式、开场动画与完整产品。对比页自身支持并排和单张查看、实际尺寸查看、选择与复制方向。

## 六站调研：资料、观察与转译

### 1. MotionSites：先建立有主次的视觉构图

来源：[官网](https://motionsites.ai/)。已读取网页资料并查看本轮浏览器截图 `research/motionsites/page.png`。网页文本快照与浏览器实时列表不同，视觉观察以截图为准，不将快照中未实看作品说成已经研究的画面。

实际首屏：深色画布；大字号紧密标题；单个高对比主操作；筛选条与案例内容分离；四列案例中有全幅汽车、角色头像与粒子主视觉；图像先建立对象识别，名称在图外；导航占高很小。截图中的 Roadster 用宽大实物与贯穿画面的地面建立尺度，3D Portfolio 把单个主体置于强排版之下。

转译：A 用舞台的台口与地面建立前后关系；B 将世界画面置于上半屏、大字号书名放在下方；C 让版画成为唯一的大面积色彩。保留“图像承担识别、主动作单一”的层次，不复制官网的营销标题、案例网格、胶囊按钮或渐变文字。没有访问付费提示词，不宣称采用其完整提示词。

### 2. Aceternity UI：分层透视必须服务对象

来源：[3D Card Effect](https://ui.aceternity.com/components/3d-card-effect)。读取组件说明、安装方式及 CardContainer / CardBody / CardItem 属性，查看 `research/aceternity/page.png`。

观察：预览把标题、说明、图像与操作放在同一个透视对象里，各层可设置 translateZ、translateX/Y 与旋转；组件目录和预览区域分开，避免复杂控件压住展示对象。

转译：A 的书册用书脊、页口、封面建立三层物理关系；舞台的前景帷幕、近景建筑与远方地平线形成更强的尺度差。暂不添加悬停倾斜，避免静态比较依赖动画。选定方向后可按层重建，不将完整 React 组件直接塞入当前 Vue 项目。

### 3. Showreel.design：研究镜头语言，明确观看限制

来源：[官网](https://showreel.design/) 与 [James Gardner Reel 2025 作品页](https://showreel.design/videos/james-gardner-james-gardner-reel-2025/)。读取分类、作品简介及作者链接。介绍涉及 3D 空间、视觉叙事与运动排版。

浏览器主页和作品页均返回 403，分别记录于 `research/showreel/report.json`、`research/showreel-detail/report.json`。**未实际观看视频，不能声称核实过其具体剪辑节奏或过渡。**

进一步访问其链接的[作者官网](https://www.j-gardner.com/)，已查看 `research/showreel-author/page.png`：黑色全幅画布、极小的顶部导航、右下角观看入口，但主体预览没有显示，存在两项远程资源 404。没有将空画面当作已观看作品。

转译为本项目独立提出的镜头原则：A 正面观看，B 斜向观看转台，C 平面的剧目版画。让媒介差异落实为真实的视角差异。后续建议的 500–800ms 帷幕/景墙切换是本项目设计设想，不是该作品的测量结果。

### 4. Uiverse：拆开控件的结构与风格

来源：[按钮集合](https://uiverse.io/buttons)、[vinodjangid07 按钮](https://uiverse.io/vinodjangid07/chilly-newt-81)、[cssbuttons-io 按钮](https://uiverse.io/cssbuttons-io/funny-dog-69)。读取分类、组件记录和 MIT 授权说明；浏览器按钮集合返回 403，见 `research/uiverse/report.json`。因此不声称看过其实际 hover 演示或完整 CSS。

取舍：当前任务需要“继续写作”的动作识别与导航的选中识别；选择实色按钮、可读对比、足够点击面积、固定箭头位置，而非霓虹、持续发光或与页面无关的夸张材质。所有候选 CSS 均为本轮原创，没有复制未取得的组件源码。

### 5. React Bits：目录的选中关系可以成为构图

来源：[Flowing Menu](https://reactbits.dev/components/flowing-menu)、[官方仓库](https://github.com/DavidHDev/react-bits)。读取组件说明及四种代码形式，查看 `research/reactbits/page.png`。本次截图没有成功呈现交互预览，视觉依据仅限导航和说明，组件运动机制来自官方文字。registry 地址未成功读取，不宣称检查过源文件。

学习点：选择随目录行移动，内容与选中行有连续关系。B 将该关系转译为整行薄荷色的剧目选择，纵向目录与大舞台分工明确；不做文字跑马灯，以免书名在浏览时移动。后续可让行选择、景墙和书名沿同一方向切换，静态版仅展示选中终态。

### 6. Anime.js：用时间线组织因果，不堆叠动画

来源：[Timeline](https://animejs.com/documentation/timeline/) 与 [Spring](https://animejs.com/documentation/easings/spring/)。读取 `createTimeline()`、位置标签和相对位置用法，了解 spring 的 duration 会被计算出的稳定时长覆盖。

后续动作建议：A 先收侧幕，再换世界，随后揭幕；B 景墙先行，书名与选中行以小幅错时跟随；C 先展开版画，再落定标题。大面积场景避免明显回弹，小按钮才考虑轻量 spring。减少动态效果时直接呈现终态。**本轮按 oil-ui 的方向探索范围保持静态，没有安装 Anime.js，也未实现或验证这些动画。**

## 三张方向卡

| 项目 | A · 幕启诸界 | B · 世界转台 | C · 万象剧目志 |
|---|---|---|---|
| 北极星 | 台口有边界，幕内的真实世界没有 | 转动剧场空间，让另一个现实登场 | 剧目志记录一个个正在发生的世界 |
| 骨架 | 顶部横向导航；节目笺并置舞台；下方六本横排书册 | 头部导航；左侧六行目录；右上大舞台；右下标题与动作 | 刊物式刊头；左侧两行书名；右侧版画；下方三列两行目录 |
| 主体 | 有气候、居民、船舶和远方海岸的幕内港城 | 活动景墙后相互独立的港城与沙漠世界 | 细线版画描绘港城中的街道、船舶与居民 |
| 字体 | 京华老宋体，65px 作品名 | 微软雅黑，66px 粗体作品名 | 朝华标题，72px 两行作品名 |
| 色彩 | 象牙纸、午夜蓝、哑光铜金 | 炭黑、薄荷绿、石灰白 | 暖棉纸、矿物蓝、砖红 |
| 控件 | 近直角、深蓝实色、细线 | 近直角、薄荷整行选中、黑白清晰分组 | 印刷式直角、砖红主操作、连续细线 |
| 密度 | 精致、温和、适中；世界是唯一大图 | 精确、庄重、适中；目录安静，大舞台突出 | 文学、工艺、适中；字号层级强，容器最少 |
| 刻意放弃 | 全屏金属雕饰、虹彩云海、漂浮装饰 | 通用紫蓝发光、并排三座门、玩具式微缩世界 | 逼真的纸页翻折、仿旧污渍、目录逐项卡片化 |

差异检查：三版分别采用横向书册、纵向剧目行和三列目录；标题的字族/字重/分行不同；配色家族与图像媒介不同。A 与 C 均为浅底并不等同于同一风格，C 通过跨页、版画和两行标题建立独立骨架。B 走到现代黑盒剧场一端，避免三套相同模板换颜色。

## 新素材、字体与来源

- 三张主视觉分别调用内置 image_gen 全新生成，**没有引用之前制作的图片**。原图在 `assets/source/`，页面使用压缩后的 WebP；仅做格式转换及尺寸优化，没有裁接已有图片。
- 三张主视觉的完整英文提示词在 `素材提示词.json`；生成文件对应关系见 `prepare_assets.py`。
- 书名、章节、导航、目录、统计、按钮与封面文字均为 HTML，图片不包含界面文字。A 的小书封使用原创 SVG 线图和色面，由共享书目生成。
- 京华老宋体与朝华标题复用项目已有授权字体，按本轮内容做 WOFF2 字形子集，源字体位于 `src/assets/fonts/files/`，原始字体资料位于 `docs/前端美化/字体/`。没有复用原图片。
- Hindsight 工具在本次会话的可调用工具清单中缺失，未读取知识页、未登记 initiative；不将此前的记忆声明作为已验证依据。本轮以用户新主旨及本地设计文件为准。
