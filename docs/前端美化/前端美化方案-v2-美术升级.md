## 三、视觉规格（v2 新增部分；v1 §四/§六既有规格继续有效）

### 3.1 字体系统（核心升级）
| 位 | 字体 | 字号/字重 |
|---|---|---|
| 品牌/书名/封面字 | 霞鹜文楷 Screen 700 | 封面单字 44-52px；书名 17px |
| 章节标题（编辑器内） | `--editor-font`（用户三选，默认雅黑）+ 600 | 22px |
| UI 界面 | 雅黑 / PingFang（不变） | v1 §4.2 五档 |
| 正文 | 用户三选（雅黑/文楷/思源宋），文楷档行距 1.9→2.05（文楷 x-height 小需补偿） | v1 §4.2 |
| 数字 | `font-variant-numeric: tabular-nums`（字数/统计/进度） | — |

落地通路：`ui.js` FONT_MAP 追加 `wenkai` 档（font-family 栈：`'LXGW WenKai Screen', '霞鹜文楷 Screen', serif`）+ 设置面板三选；标题/封面/brand 位直接用文楷栈不经设置。

### 3.2 色彩：墨 + 朱（点睛色体系）
保留现有暖纸底与棕金 accent（纸墨基调不变），新增第二强调色，全站只在此两色间做「墨与朱」的呼吸：

| 令牌 | 宣纸 | 羊皮纸 | 暗夜 | 用途 |
|---|---|---|---|---|
| `--accent-cinnabar` ★ | #9D2933（胭脂） | #A03A2E | #E05C55（暗夜提亮保对比） | hover 边框点睛、选中印章、保存状态点、批注「待改」、破坏性确认强调 |
| `--cinnabar-soft` ★ | rgba(157,41,51,.08) | 同系 | rgba(224,92,85,.14) | 选中底、hover 淡染 |

使用纪律：**朱色只做细线/文字/小面积淡底/印章**（面积 < 视口 2%），禁止大色块；主按钮仍是墨（accent 系）——v1 §二「强调用墨不用色块」原则不变，朱是墨的「落款」。

配套调整：
- 画布连线默认色：默认蓝 → `--ink-rel` 蓝保留为「关系」语义色，但**画布默认连线改黛青 #4A4266 → 主题推导色**，悬停/选中才上语义色
- 书架封面色板：从现有 mud 色板换为传统色去饱和系（黛/竹青/檀/绾/玄/缃 六色 + 明度两档 = 12 变体，按作品 id 哈希取色，仍支持自定色）

### 3.3 质感与层次
- **纸纹噪点**：`--bg` 与书架桌面叠 feTurbulence 噪点（透明度 2.5%，暗夜 1.5%），编辑器保留现有竖线稿纸纹理不动
- **卡片去框**：书架卡片/画布节点去掉常驻 1px 边框，只留 `--shadow-node`（贴纸感），hover 换 `--shadow-node-hover` + `translateY(-2px)`；选中态才出现边框（朱/accent 2px + soft 光晕，v1 §6.5 规格）
- **分隔刻痕**：顶栏/面板头用 v1 §五「1px border + 高光」刻痕语言（未落地项）

### 3.4 书架封面重设计（批次 A 主菜，2026-09-19 修订）
封面 = 32% 高的「封面区」，**书籍装订质感**：
1. 底：传统色系 + 右下角大号半透明文楷字水印（作品首字，12% 白）
2. 中：书名居中（文楷 700，21px，letter-spacing 3px），暗色封面上米白字
3. **装订三件套**：书脊棱条（左 15px 深色渐变 + 右缘折线高光）+ 5 枚竖向等距装订眼（线装书意象，墨点 2.4px）+ 极淡布纹交叉线；书口上/下/右三缘纸厚内阴影（inset 8px/4px，rgba 黑 28-30%）
4. 卡体：书名（文楷 17px）+ 字数/章数（tabular-nums）+ 底部 2px 细进度条（`--accent-soft` 轨道 + accent 填充，替代现有不可见的方块）
5. 悬停：抬起 + 影升 + 边框变朱 1px（editorial 风格）；朱色不上面，留给顶栏品牌印与状态点

### 3.5 顶栏与工具栏层级（收编 v1 §6.1 批次二）
- 顶栏：左 = 返回 + 书名（文楷）+ 保存状态点（朱/绿）；右 = **唯一主按钮**（工作台内为「沉浸」，书架为「新建作品」，主按钮规格 v1 §6.3）+ 图标化 ghost 按钮（OIcon），低频操作（备份/恢复/统计/回收站/帮助）收进「⋯」菜单
- 编辑器工具栏：B/I/U/S/对齐/列表全部 OIcon 图标化（新增 14 图标见素材清单），按钮 28px 方形、hover 边框变朱；保留文字的仅「正文/H1/H2/H3/引/清除」
- `--ring` 焦点环令牌 + `.pop` 浮层公共类补落地（v1 §6.4/§6.7 遗留）

### 3.6 空态与品牌
- 四处空态（书架/画布/人物/搜索）= 线稿小图 + 一句话 + 幽灵按钮（v1 §6.8 规格不变，补自绘 SVG 线稿素材）
- 品牌位：书架左上「小说工坊」旁加 12px 朱文小印；关于/帮助页放大版

### 3.7 动效（收编 v1 批次六）
沿用已落地的 `--ease/--dur` 令牌：列表交错入场 30ms 步进、拖拽 scale(1.02) 抬起、保存状态点 3s 淡出呼吸、hover translateY(-1~2px)。性能红线照 v1 §九（只动 transform/opacity，禁止 box-shadow 常驻动画）。

## 五、约束与验收

1. **类名兼容**：所有改动不得重命名 CDP 验收脚本依赖的选择器（`.book-card` `.dl-pop` `.note-mark` `.oc-eedit` `.ob-editor` `.ol-editor` `.ol-side` `.side-item` `.rg-ctx` 等）；纯视觉改动优先走 themes.css 令牌与伪元素
2. 三主题同步：每令牌三主题同批给值；每批验收跑「一屏三图」对比（宣纸/羊皮纸/暗夜）
3. 对比度红线沿用 v1 §4.1（正文 ≥7:1、dim ≥4.5:1、faint 仅 ≥12px 非关键信息）；朱色在暗夜主题需提亮档保证 4.5:1
4. 包体：字体 vendor 后 `npm run build` 产物体积对比入验收说明；dist 冒烟（v1.0.8 三项）重跑
5. 回归：每批跑 dl / annotation / dlpop / shelf 相关 CDP 脚本防布局回归；olcanvas「容器高度」存量失败照旧计入待办不算新账
6. 新 UI 元素（朱印/进度条/空态图）先在本文 §3 登记规格再写代码（G9）
