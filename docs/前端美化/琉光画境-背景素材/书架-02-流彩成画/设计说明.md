# 流彩成画 · 动态书架背景探索

## 方向

北极星：让小说的书架坐落在一幅缓缓成形的青绿画作里。

本次为「琉璃书境」的动态方向探索，延续琉光的浅青、透光与温润气质。右侧以矿彩干刷笔触组成开放回环，颜料沿画迹洇染，香槟金色游丝呼应轮廓。左侧保留浅色画纸留白，作品、书名和操作位置固定。没有把静态背景图片整体平移或晃动，也未生成新封面和人物。

## 动态与使用

- Canvas 2D 原生自绘，无位图、外部库、网络请求和新增依赖。
- 底层为稳定画迹；上层色素沿既有笔触缓慢铺开，约 27 秒一轮，各色错开时间。
- 极细光痕沿同一笔触行进，不添加散乱粒子或鼠标跟随。
- 提供书架效果、纯背景、暂停／播放；暂停保留当前画面，不重置进度。
- 尊重系统减少动画偏好；首次进入默认静止，用户仍可手动播放。
- 标签页隐藏时取消动画帧；两种预览仅当前可见的一种运行；离开页面清理监听。
- 请求绘制上限 30 帧／秒，像素比上限 1.5；这属于实现限制，不表示经过帧率实测。
- 全背景不接受指针事件；不会遮挡书架操作。

## 范围与证据

仅新增本目录的独立预览，复用 C 版原型示例内容。未改软件源代码、皮肤 CSS、作品数据、其他皮肤或上一版静态素材。

局部背景概念由主执行者自检，未进行独立评审；检查实际画面、切换与暂停恢复。没有新增业务流程或承诺原型中的模拟操作已接入。界面制作说明放在本文件，预览顶栏仅提供素材查看控制。
