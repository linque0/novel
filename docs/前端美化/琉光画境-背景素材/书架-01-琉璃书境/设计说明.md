# 琉光画境书架背景 01 · 琉璃书境

本轮仅制作书架背景素材及隔离预览，不修改软件组件、皮肤 CSS、作品数据或既有设计稿。

## 参考与设计意图

已读取聊天「读取线程了解工作进展」（01a145f4-aa57-79d3-8bdc-5f8a6285f7dd）中的背景探索记录，并查看「幻日实体景组」素材。采用其中关于统一空间、实物厚度、接触阴影、前中后景与一致光源的经验。

琉光采用浅青、象牙白与极少量香槟反光。右侧弯曲玻璃如正在展开的书页，与低矮透光展台构成实体空间；左侧留给作品信息。玻璃材质参考现有 glaze-ribbon.png，未生成新的书封和人物。

## 文件与使用

- glaze-shelf-sanctuary.png：生成原始背景，1672×941 PNG，无 UI 和文字。
- prompt.txt：完整生成提示词。
- index.html：隔离预览，复用 C 版书架原型和示例内容，提供新背景／原背景／纯素材切换。

通过项目开发服务器打开 index.html。纯素材也可直接打开 PNG。

预览为文字区域保留低细节留白，在底部加入 CSS 浅青渐隐，以衔接作品集合；顶栏与作品卡采用轻透白底保证阅读。生成图中的低矮展台用于承托整体叠册舞台，书封及章节仍由界面呈现。预览隐藏原型额外的装饰圆球，避免同时出现多个视觉焦点。

预览所用作品为原型示例，不表示真实用户作品；未接入软件生产界面。当前用于先判断背景美术方向，正式接入时仍需依据真实界面的各窗口尺寸校准裁切和玻璃卡片透明度。

## 自检标准

- 左侧标题、简介、按钮所在区域没有密集物体边缘。
- 右侧玻璃具有厚度、遮挡、折射与落地阴影，共用自然光。
- 背景不包含固定书籍、界面或文字，不把装饰写入数据。
- 图像作为环境使用，作品卡片与真实操作继续由前端呈现。
- 仅含静态背景，不增加持续动画或漂浮点击目标。
