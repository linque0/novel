# 青岚入画 · 动态书境重做

## 设计判断

上一版「流彩成画」的问题在于：等距色带缺乏真实笔触，S 形构图像挤出的颜料，材质薄且机械。此次重做主视觉，以透光青玉山水、雾中远近层次和湖面倒影形成完整画境。

北极星：一幅有深度、会呼吸的青绿琉璃山水，安静地承托写作空间。

右侧山体具有重量、光学厚度、矿彩纹理与稀疏金色脉络；左侧保持浅色留白。界面沿用既有书架排布与封面，不再添加额外色带、光球、粒子或鼠标跟随。

## 动效

- 使用生成原画作为空间与材质基底，原生 WebGL 着色器实时改变局部水面折射、倒影明暗、山脚薄雾和极细微的玉色透光。
- 山体与界面不整体平移、缩放或晃动。水面像素扰动受湖面遮罩限制；光泽与雾气均控制在局部。
- 可切换书架／画境、暂停／恢复。系统减少动画默认静止；无 WebGL 时保留同一原画。
- 页面隐藏时停帧；书架与画境仅可见的一种运行；限制请求绘制为 30 帧／秒、设备像素比 1.4。上述是代码上限，未作为实测性能报告。
- 本轮为视觉方向重做与隔离预览，未改软件功能、皮肤源码或旧版资产。
