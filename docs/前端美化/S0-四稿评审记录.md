## 2. 字体边界（本次出稿的关键约束，必读）

- **现象**：OpenPencil v1（插件 0.2.3 / 上游核心 0.14.0）内置字体仅 Inter 与 Noto Naskh Arabic；其 README「已知边界」明确「**系统字体与在线字体未接入（CJK 会走上游替代逻辑）**」。实测：任何含中文字符的文本节点导出为**空白**（连混排英文一并丢失）；指定任何未加载字族同样空白。
- **决策**：设计稿内全部中文文本采用「**文本转图片**」管线，而非放弃中文字形：
  1. `tools/opencil-textshot.mjs`：Electron 无头截取（2× 像素密度、透明底、`force-device-scale-factor` 固定倍率）；字体**直接引用应用内建 woff2**（`src/assets/fonts/fonts.css` 的思源宋体/Playfair + `fonts-user.css` 的霞鹜文楷等），字号与行高按 v3 规格 1:1 渲染；
  2. `tools/opencil-render.mjs`：JSX 屏幕描述中 `<TextImg id=…/>` 自动展开为精确尺寸的占位矩形并产出放置清单；
  3. `tools/opencil-place.mjs`：经本机 MCP HTTP 将 PNG 以 FILL 填入对应矩形（支持同名多次放置）。
- **影响与不覆盖**：
  - .fig 内中文为图片：面板中**可移动/换图，不可改字**；改字流程 = 改 `specs/text.json` → 重跑 textshot → render → place（本次按此迭代 4 轮）。
  - 不覆盖：字重亚像素渲染差异、面板内联编辑文本、用户自定义字体预览（`--editor-font` 动态设置）。
  - **实机实现（S1+）不受限**：应用自带完整字体管线，本次仅为设计物料的渲染约束。
- **字体映射**：`--font-ui` = Microsoft YaHei（设计）→ 应用默认栈同名；`--font-title` / `--font-cover` / `--font-body` = Noto Serif SC（设计引用应用打包 woff2，与实机同源）。

## 6. 限制与偏差（诚实记录）

1. **页组织**：面板「切页」在当前插件会话不生效（`switch_page` 无效果），故 8 屏集中排布在页 01 的排布矩阵（两列 × 四行，板下方）；页 02–05 为候选预留（空）。如需分页归档，可在面板中人工拖放/整理。
2. **中文为图片**（§2）；改字需重跑管线。
3. **变量集合形态**：插件暂无「集合加模式」工具，故一主题一集合（`design_to_tokens` 导出仍可用）；三个主题变量**没有**共用同一集合的 mode 切换。
4. **设计≠实现**：naive-ui 组件（按钮/输入/下拉等）外观为设计**目标态**；实机映射按 v3 §3.4（NConfigProvider 覆盖 + 令牌）在 S1 处理，本轮未做实机校验。
5. **不覆盖的状态**：hover/focus 等交互态仅以静态样例登记（组件板 + A 稿封面 ⋯ / C 稿筛选 / D 稿按钮），未做动效样张（v3 M0–M2 规格待 S1 落地）。

## 8. 复现方式（工具链命令）

```bash
# 1) 文本块 → PNG（Electron 无头，2×）
node tools/opencil-textshot.mjs docs/前端美化/designs/specs/text.json

# 2) 屏幕 JSX → .fig（--prefix 隔离同名文本；--place 产出图片放置清单）
node tools/opencil-render.mjs docs/前端美化/designs/specs/screens-A-shelf.jsx \
  --page <页id> --prefix Ashelf \
  --manifest docs/前端美化/designs/exports/text/manifest.json \
  --place docs/前端美化/designs/place/A-shelf.json

# 3) 放置清单 → 填图
node tools/opencil-place.mjs docs/前端美化/designs/place/A-shelf.json

# 4) 令牌 → .fig 变量（幂等）
node tools/opencil-tokens.mjs docs/前端美化/designs/specs/tokens.json
```

注意事项：`.fig` 只能通过 OpenPencil 面板工具编辑（二进制，禁止手写）；导出同名文件需先删除（导出工具不覆盖）；MCP 直连的会话由 `tools/opencil-mcp.mjs` 自动发现/复用。
