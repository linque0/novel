# 小说工坊 · 视觉重构第二轮

本轮回应「普通、与原版差距不够」的反馈，重新设计四种构图与美术语言。四版均有书架、正文、大纲、设定、人物、灵感、设置，共 28 个视图。产物是设计评审原型；没有替换应用业务代码。

## 打开

- [28 屏总览](index.html)：可离线打开，选择功能后查看四版截图，点击画面进入原型。
- [Oil UI 对比](style-explorer.html)：并排或单张查看、100% 实际尺寸、复制选择。本页使用本机服务器加载可操作候选。启动命令见 manifest.json；本轮服务为 http://127.0.0.1:8879。
- [A 引力书舱](a.html)、[B 电光剪辑室](b.html)、[C 琉光画境](c.html)、[D 赤月剧场](d.html)：独立打开，内部导航切换七个功能。

## 交互与动效

可演示：七模块切换、书架筛选与作品选择、人物切换、灵感选择、节点选择与属性联动、画布缩放、正文专注模式、字体/字号/行高/阅读主题预览、减少动态开关、创作提案侧栏和对话框。

动效围绕实际对象：书架书册 600ms 入场，主要内容 500ms 入场，书册列表延迟 100ms；模块切换约 250ms；按钮反馈与对话框约 180–280ms。支持系统 prefers-reduced-motion 和设置内减少动态。没有持续自动播放的粒子或光效。

原型的正文与表单修改只保留在当前视图；未接真实保存、模型请求、全文搜索、导入导出、图谱拖拽和持久化。页头「已保存」是状态视觉样例。新建/转为章节/AI 展开仅展示输入与对话框，不声称已调用模型或保存成功。设置展示外观完整面板，其余分组为入口占位。实际落地应保留应用独立 SettingsWindow 的窗口边界。

## 本轮验证与边界

原生桌面视口 1440×900；适合桌面软件评审，未制作手机适配版。28 屏均有真实渲染截图，见 gallery；完整初轮取证见 evidence，最终受影响状态复查见 final-check。取证包括遮字图、首屏 2 倍图和入场录屏。脚本检查不能判断审美，独立视觉评审及具体修改见 [REVIEW.md](REVIEW.md)。

保留的检查提示：面包屑标识当前书籍与模块；「偏好设置」标识设置分组；章节序号表达真实顺序；设定子条目具有父子关系，并非装饰性卡片堆叠。可读性检查未发现低于阈值的对比度、过小正文、过紧行高或停在透明状态的文字。

## 参考、素材与重建

公开参考：[Ulysses](https://ulysses.app/) 的编辑器工具层级；[mymind](https://mymind.com/how) 的收藏与视觉检索；[Cosmos](https://www.cosmos.so/) 的视觉收藏空间。只借鉴组织方式，没有复制界面或下载其作品。Cosmos 截图中部分外部图片未加载，仅用作布局观察；mymind 根页面的失败截图不计入参考。

构图、组件、CSS 与脚本均为本轮定制；[素材与提示词](assets/SOURCES.md) 记录原创生成美术与项目字库。app.js、style.css、data.js 为可编辑源文件，build.py 用项目原字库生成子集字体并编译四个页面，随后用 Oil UI build_explorer.py 生成对比页。build.py 需要 Python fontTools 与原项目字库；已编译产物不需要安装依赖。
