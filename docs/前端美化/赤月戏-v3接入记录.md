## 六、有意偏差

1. **真实数据页面**：v3 原型是静态示例；应用继续用真实章节、人物、设定、灵感与关系数据，空数据时保留应用空态。
2. **设置分类**：应用只有外观 / 模型设置 / 数据 / 关于四个真实页，不新增 v3 原型里的“编辑器 / 快捷键”假页面；视觉语言按 v3 书签分类。
3. **大纲节点**：应用画布可拖动、缩放、连线；不硬编码 v3 示例坐标，只移植纸片节点、胶带、切边与工具条视觉。
4. **设定舞台**：按用户选择只使用 v6 竖幅；不引入 v7 全幅，避免和 v3 版面冲突。
5. **品牌文案**：保留应用真实“小说工坊 / 赤月戏”，不改成原型的“妙笔 / 林间”。
