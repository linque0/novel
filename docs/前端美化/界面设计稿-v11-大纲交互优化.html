前往 ↗拆窗打开关闭
双链卫星词 · 同一语义hover 轻预览不变
卫星词与引用卡统一：hover=轻预览（跟随鼠标，现状保留），单击=详情浮窗（钉住宽体），双击=直跳。跳转从「被动传送」变成浮窗里的显式决定；「拆窗打开」把目标章节/设定拆成独立窗口，边看边写。
复用而非新建：详情浮窗是 DLinkPopover 的宽体变体——previewFor 六类富预览、拖拽钉住、进出场动画、「跳转 ↗」全部现成，本次仅加统计行、拆窗按钮与三处点击改线（citeJump / om-sat / 双击直跳保留）。边角：目标被删时走「目标不存在」missing 视图（已有），不再发生「点了直接跳到空气」；面板窗口内画布行为一致（PanelHost 已挂浮窗）。
D分期与验收三期相互独立 · 零数据库迁移 · 全部复用现有机制
期内容主要落点验收口径
M1引用浮窗详情方案三全部（改线为主，成本最低、收益直接）DLinkPopover 详情模式 + OutlineCanvas 三处改线单击不跳转且浮窗出现（钉住含「前往/拆窗」）、浮窗跳转落点正确、双击直跳保留、目标缺失走 missing 视图；新增 outline-detail-verify + olcanvas 回归
M2侧栏关系方案二全部OutlineSidebar relsOf + 关联子列表 + 筛选/联动关联明细与画布连线一致（抽样方向/标签/对端）、点击定位对端并 flash、孤岛筛选正确、选中联动滚动
M3嵌套收纳方案一全部（几何改动最重，放最后）OutlineCanvas + canvas-model（拓扑序派生盒 + 摘要卡 + marquee）容器套容器含循环拒绝、父盒包住子容器派生盒（截图断言）、递归折叠、摘要卡徽标、整组搬运、框选归组/解组与快捷键；olcanvas 回归 + 文本视图回归
顺序建议M1 → M2 → M3（M3 最重放最后；M1/M2 可并行）。不做的事：不引入强制「总纲/卷纲/章纲」类型系统、不做自动布局、不改 olnodes schema、不动现有画布手势（拖线/塑形/吸附/端口）。落地按《开发流程》纪律：每期一个版本一个提交，先登记规格再写代码。
