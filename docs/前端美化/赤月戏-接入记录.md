## 二、2026-10-18 还原优化（关键修正）

1. **运行时 bug**：`TaskLauncher` 原由每模块各挂一份，切模块时 Teleport 与目标同时移动，Vue patch/unmount 会偶发抛错，导致正文不挂载。现工作台/面板各挂一份，模块内仅非编辑皮肤保留内联入口；`#crimson-bar-tools` 常驻 DOM，正文页只隐藏模块条。`crimson-workbench-verify` 因此可稳定跑绿。
2. **正文结构归位**：左栏从「竖排章名」改为设计稿的「竖排书名 + 朱印 + 简介/统计」；页头居中、格式条单行、札记页边留白、字数目标移入札记、章条贴底。
3. **各页从“套色”改为真实结构**：大纲目录内嵌 214、画布右侧留景；设定/人物/灵感不再用绝对定位贴边，改为设计稿栏宽与纸面；人物与灵感原先表单落在布景上的可读性问题已消除。
4. **设置窗口**从旧两栏改为设计稿三栏纸面；面板窗口补上同一外壳。
5. **证据页**：`docs/前端美化/赤月戏-验收/对照/` 10 张真机截图与 `对照.html` 并排页，由 `node tools/crimson-evidence.mjs` 生成。

## 四、有意偏差

1. **品牌字**保留「小说工坊 / 赤月戏」，不采用原型虚构的「妙笔 / 林间」；原型个人资料、完整设计稿链接、静态查看等演示件不伪造。
2. **书封**为生成式（纸色 + `kind` 配色 + 月轮/山影/题签/朱印），不复用设计稿的参考封面图。
3. **长书名**：≤4 字竖排，5–8 字两行，更长两行截断 + `title`；设计稿只给了四字示例。
4. **灵感分类**（伏笔/场景/人物）没有数据模型；用真实条数、最近编辑排序、快速记录补足同一位置，不伪造分类。
5. **设置**是应用的真实独立窗口 1000×700，三栏按同比例适配为 181 / 纸 / 250 预览，不强行套 1440 画布。
6. **设计稿没画但应用已有**的功能全部保留：保存态、搜索、书签、历史、阅读、拆窗、恍然梦、目标字数、自定义字段、关系、导入导出、存储位置、回收站、统计等，并按同一纸面/金线语言放置。
7. **顶部导航**在应用里是单窗口模块切换（同一视觉语言），不是设计稿的页面级 `<a>` 跳转。
