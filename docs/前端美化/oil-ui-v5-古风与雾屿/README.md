# 小说工坊 · 古风与雾屿

这是两版纯外观设计评审稿。范围是美术风格、构图、字体、材质、色彩和控件摆放；具体功能实现留待后续。只修改本设计目录，没有修改软件本身。

打开 `index.html` 看两版并排总览，点击功能按钮切换截图，点击画面进入原型；`g.html` 为溪山书院，`h.html` 为雾屿。单版原型可直接打开，不依赖网络。`style-explorer.html` 为 Oil UI 交互对比页，预览地址默认使用本地 8882 服务。

每版包含书架、正文、大纲、设定、人物、灵感、设置七个主界面，以及大纲文本、设定详情、人物关系图三个补充视图，共 20 张正式界面图。`gallery` 存放截图，`final-evidence` 存放检查、遮字图、高清首屏和入场录屏。

## 画面范围

- 书架：作品陈列、当前作品、续写入口与导航。
- 正文：章节目录、编辑版心、批注和资料区。
- 大纲：模块目录、类型控件、自由画布与文本视图。
- 设定：幕布节点层级、条目详情、关联资料与关系图谱。
- 人物：档案、字段、小传、人物关系与关系图。
- 灵感：灵感收藏、展开内容与创作助手面板。
- 设置：分类、字体和阅读偏好控件、阅读预览。

预览使用共用示例故事数据。页面切换及少量既有演示行为仅方便查看画面，不代表软件功能实现；没有连接保存、模型、AI、账户、同步或业务服务。

## 设计尺度

原生桌面视口为 1440×900。该轮以桌面布局、美术方向及原版操作结构为验收范围；不是手机或小窗口适配稿。纸面与雾面为自绘矢量和界面材质，无书籍封面或人物图片。

设计取舍见 `DESIGN.md`，视觉评审与验证见 `REVIEW.md`；9 个原软件组件的只读比对记录见 `software-readonly-verification.json`。
