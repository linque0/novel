# 第五轮：溪山书院 / 雾屿

用户已确定两个方向：古风，以及参考 Folia 截图的简约高级风。本轮重做首屏空间、导航位置、作品选择方式、字体与表面语言；继续以原软件的编辑功能为基准。仅交付独立设计稿。

## G · 溪山书院

北极星：让创作像在案头展开一部自己的藏书。

书架从右向左排列竖题线装册签，左边展开当前作品的续写页；右侧模块导航采用竖排题签。宣纸底、远山、淡墨绿与小面积朱印建立东方书房气质，避免堆砌宫廷纹样。主操作仍用「继续写作」「新建作品」等日常文字。

正文、大纲、设定、人物共用展开的双页工作区：目录在册页左边，横排内容在右边。正文保持横排，竖排仅用于模块题签、藏书和灵感纸签。人物表单用下划线字段、行笺式小传；设置将阅读页和调整项排在同一展开册页中。

## H · 雾屿

北极星：把故事放在柔和空间里，让当前作品成为唯一清晰的焦点。

从用户参考借鉴的是全屏雾化背景、胶囊导航、作品纵深和悬浮控制条之间的关系。背景为自行绘制的抽象矢量绸面，不使用参考图的专辑封面、图案或品牌。当前作品居中清晰，邻近作品按距离缩小、淡化，底部胶囊承载续写和资料入口。

编辑页用稳定的深色工作面保证阅读，环境雾化只留在面板之间；长段内容采用常规字重无衬线，作品与章节题名保留宋体。人物小传先于自定义字段阅读；灵感以一张展开主卡和三张紧凑浮卡构成松散纵向节奏。设置使用独立阅读预览与偏好浮板。

## 两版区别

| 维度 | 溪山书院 | 雾屿 |
|---|---|---|
| 导航 | 右侧竖排册签 | 顶部居中胶囊 |
| 书架 | 右向左线装藏书、左侧展开页 | 中心清晰、两侧纵深退隐 |
| 页面表面 | 连续纸页、书脊中缝、下划线 | 分离浮板、半透明边缘、圆角 |
| 文字 | 宋体、文楷与竖排题签 | 无衬线界面与正文、宋体题名 |
| 灵感 | 四张竖题纸签 | 展开主卡与分离浮卡 |
| 设置 | 一部展开的册页 | 阅读浮板与偏好浮板 |

## 原版功能约束

大纲保留自由模块、容器、便签、引用卡、章节锚点和文本框，画布与文本双视图不变；设定默认幕布节点编辑，双击才进入详情，详情可定位回节点；人物默认列表与可编辑档案，保留姓名、角色、别名、标签、自定义字段、小传、人物关系和跨模块关联。为保持原操作习惯，这三类编辑页继续采用目录和编辑工作区。美术探索不以重新发明编辑流程为代价。

## 动效与静态状态

进入：G 续写页短距离展开、册签轻微抬起；H 中央作品和续写胶囊短距离浮现，约 450–650ms 后停止。

停留：背景静止；编辑区域没有呼吸、漂移或持续视差。

交互：册签悬停抬起，当前作品切换时构图重排；按钮、胶囊与节点有清楚的选中和焦点状态。减少动态效果后去除过渡，系统减少动态偏好也生效。
