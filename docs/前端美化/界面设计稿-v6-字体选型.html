读法每个候选三件套：蓝色封面样（书名+作者印+NOVEL 微标签全用该字体）、界面微排版样（顶栏/菜单/正文小字号）、字样行（永国风长夜将尽 0123 检测可读性与数字形态）。下方结论行给出适用场景判定。授权备注：得意黑官方明确「不推荐正文/手机界面」；霞鹜文楷适合中等长度文本而非大段正文；站酷小薇与思源宋体通用性最好。

构造规则：100×100 字身，横画 5–8% 字重、竖画 7% 字重、撇捺为折线多段；所有笔画末端一律斜切 20°（刀刻感），无圆头无衬脚。字标「小说工坊」四字按 1:0.72:1:1.15 字面宽排布；印文取 2×2 传统读序（左上起）。混排策略：已定义字形直接呈现，未定义字回退 Noto Serif SC 600——封面书名可先按「坊刻本标题 + 思源兜底」混排上线。

场景推荐理由
封面书名（丛书墙主角）得意黑 Smiley Sans窄斜字身+美术字细节，6 本书并排时斜势统一、序列感最强；官方推荐场景即书报标题。代价：风格强，需接受「现代感」而非「古典型」
封面书名（文学备选）站酷小薇 ZCOOL XiaoWei高挑娟秀的展示衬线，与 Fitzcarraldo 的居中衬线传统最同构；气质文气内敛
作者印 / 微标签同封面字体（印用该字 500 字重）印与书名同族，保持封面只有「一种声音」；圆印内小字用该字体的数字标点集
品牌字标 / 空态大字自绘坊刻本（+思源兜底）全 App 仅此处使用自绘字，形成独家记忆点；零授权风险（自有绘造）
界面 UI / 工具栏 / 菜单系统黑体（不变）五候选无一适合界面小字（得意黑官方不推荐界面、楷书太浓）——界面保持中性，把性格让给封面，这是「高级感」的分寸
正文阅读（可选档）霞鹜文楷 → 思源宋体沉浸/夜读模式正文用霞鹜文楷（温润手书），默认档思源宋体保稳
底线：全部 SIL OFL-1.1，允许嵌入软件与商用；得意黑/霞鹜文楷保留名限制仅影响改字命名，直接原样嵌入不受影响。
