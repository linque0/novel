# 小说工坊前端界面美化建议 · 竞品调研

调研日期：2026-10-09。

本次使用 Exa 做了小说写作、视觉笔记、开源创作项目、排版与主题四组检索，共 40 条候选结果；筛选后以官方产品页、帮助文档与官方项目仓库为依据。下文“借鉴建议”是针对小说工坊的设计判断，参数为建议起点，并非竞品的实测规格。

本地依据：两版美化方案、v5–v11 的关键设计说明、《前端美术提示词库》、G 色带书封及墨白编辑部等方向图；查看了当前资料中的书架、正文、夜间主题、大纲总览/细节、设置、六种封面截图，并核对 `themes.css`、`Bookshelf.vue`、`Workbench.vue`、`EditorToolbar.vue`、`App.vue` 和 `ui.js`。本次为资料审阅与设计建议，未启动应用做实时交互验收。

## 1. 建议的整体方向

**延续已选定的 G 色带书封，升级成“出版物式书架 × 简洁编辑部 × 卡片式创作白板”。**

三种场景共享字体角色、色彩语义、间距、控件和浮层规范，但装饰强度分别设计：

| 场景 | 视觉任务 | 建议风格 | 装饰强度 |
|---|---|---|---|
| 书架 | 让作品有识别度，产生继续创作的意愿 | 双色丛书、海报排版、作者圆印、细书脊 | 中，主要集中在封面 |
| 正文 | 连续阅读与写作，随时查资料 | 暖白纸面、墨色正文、清楚的字阶和留白 | 低 |
| 大纲/人物/设定 | 看清结构，快速组织信息 | 克制的卡片、分组、关系线、局部强调 | 低至中，色彩表达业务含义 |
| 夜间主题 | 保持阅读层次 | 炭黑、暖灰、米白正文、小面积暖金强调 | 低 |

目录中的 v2 古风方向已被记录为暂缓；v5 明确以 G 为主，v8–v10 探索海报书封，v11 处理大纲交互。建议把这些当作已经形成的设计决策继续推进。

当前最需要的，是把封面的美术气质与工作台的阅读体验连起来。v10 的复杂封面适合新建预览、作品详情或大尺寸展示；日常书架使用简化版，正文则依靠排版建立质感。

## 3. 对现有资料与界面的具体判断

### 3.1 值得保留的基础

- G 体系的蓝/象牙反相、作者圆印、2:3 竖封面，已经有自己的识别度。
- 三套主题、设计令牌、OIcon、焦点环和 reduced-motion 已有基础，不必从头搭建。
- 顶栏低频操作已收进设置；已有沉浸模式、多窗口和大纲双视图。建议围绕已有能力优化呈现。
- v8 的书名长度分流、v10 的小尺寸退化、v11 的折叠摘要和引用详情浮窗，均值得继续细化。

### 3.2 优先解决的六件事

| 问题 | 本地依据 | 建议 |
|---|---|---|
| 稿纸纹理抢正文注意力 | 正文与夜间截图均有明显竖纹；`Workbench.vue` 中心区和 `EditorPane.vue` 正文容器都挂了 `paper-texture` | 正文默认纯色纸面，稿纸纹理成为可选外观；纹理仅在一个层级绘制，避免叠加 |
| 封面、品牌与正文的字体设置耦合 | `cover-tt`、`cover-seal`、`brand` 等使用 `--editor-font` | 分离 `--font-ui`、`--font-title`、`--font-cover`、`--font-body`；保留“封面跟随正文”作为可选项，默认由封面模板决定 |
| 格式按钮占据较多注意力 | `EditorToolbar.vue` 常驻正文/H1/H2/H3、对齐、颜色等；资料截图中工具栏出现两行 | 合并标题样式下拉，按格式类别分组；低频项收进菜单；统一图标尺度，保留 B/I/U 等熟悉的格式符号 |
| 次要文字过浅 | 当前宣纸、羊皮纸的 `--text-dim` 色值对面板底色不足 4.5:1 | 先调文字令牌，再调整装饰；具体数值见下节 |
| 画布操作层次仍可梳理 | 大纲截图有多个工具区，撤销/重做在中心顶部和画布工具区重复出现 | 分成“视图”“创建”“选中项操作”“画布导航”四组；同一功能保留明确入口 |
| 基础组件与手写面板的风格衔接不完整 | `App.vue` 的 Naive UI 覆盖目前主要设置 primary 色；设置面板同时使用蓝色标题和棕色激活按钮 | 统一按钮圆角、高度、边框、文字和背景令牌；给品牌色、当前操作色和业务语义色明确分工 |

书架截图含大量验证书，默认均为蓝色；当前代码和六色截图已经支持其他封面色。因此“蓝块重复”应通过真实书目、同色系列和混合系列分别验证，不能据验证数据直接判定色板失败。

### 3.3 已核算的文字对比度

按 sRGB 相对亮度公式计算，以下为**纯色令牌配对**，不含实际纹理、透明叠层和抗锯齿影响：

| 主题/用途 | 现有文字/底色 | 现有对比度 | 建议候选文字色 | 候选对比度 |
|---|---|---:|---|---:|
| 宣纸次要文字 | `#8D8271` / `#FAF7EC` | 3.52:1 | `#766C5B` | 4.82:1 |
| 羊皮纸次要文字 | `#94826A` / `#F4EAD2` | 3.10:1 | `#77654D` | 4.68:1 |
| 暗夜次要文字 | `#8F8878` / `#232019` | 4.61:1 | `#AAA18E`，需要更清楚时使用 | 6.34:1 |

宣纸正文 `#3C3427` 对 `#FCFAF2` 为 11.73:1，当前正文主色已有充足对比度。

[WCAG 对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)要求普通文本通常至少 4.5:1，大字号文本可为 3:1。项目原方案的正文 ≥7:1 是更高的内部目标。重要的小字、时间、字数也需要可读；字号小或信息次要并不自动获得豁免。

## 4. 美术风格与 UI 规格建议

### 4.1 颜色：分清封面、操作与状态

封面保留克莱因蓝、象牙白、松绿、藤紫、绛红、墨黑六款。新一轮先将蓝/象牙与松绿/麦金两组做完整，其他色组沿用相同构造。

系统纸面以现有暖色为起点，可先对比“现有宣纸”与“更接近象牙白”的样稿。减少大面积黄色和棕色文字同时出现造成的陈旧感，正文墨色继续保持。

日间系统操作强调色可试用 G 的蓝色，用在当前导航细线、焦点环和主要操作；夜间保留暖金。每个主题的操作强调色由一套令牌控制。封面配色是作品装帧，不承担草稿/完成/错误状态含义。

状态使用固定语义：保存成功配绿色勾选与文字，正在保存配进度标记，失败配红色图标与文字。资料中“朱色落款”可用于封面装饰，但不同时承担正常保存与危险操作两种相反的提示。

### 4.2 字体：四个角色各有职责

| 角色 | 建议 | 初始规格 |
|---|---|---|
| 小字号界面 | 系统黑体 | 普通操作 13–14px，辅助信息 12px 左右 |
| 页面与章节标题 | 思源宋体或现有文学标题字体 | 页面 24–28px，章节 22–24px |
| 封面展示 | 思源宋体用于文学款；得意黑用于实验款，是否正式打包需核对现有资产 | 随书名长度与卡片宽度变化，不固定全站字号 |
| 正文 | 现有用户可选字体 | 起点 17–18px，行高 1.8–2.0；提供字号、行距、宽度调节 |

正文建议默认约 **34–40 个汉字/行**，舒展模式可到 42–46 字。以 18px 全角字估算，默认内容宽度约 612–720px，最终按真实字体和缩放验证。当前正文用响应式左右 padding，尚未建立固定阅读宽度；建议改为居中内容容器与可调最大宽度。

英文大写微标签保留在品牌、封面等展示位置。设置项、时间、状态、字数保持清楚的中文标签；装饰性微标可以退化，关键操作不可依赖 6–9px 文字。

### 4.3 形状与材质：把装帧和控件分开

- 封面继续方角，保留细书脊与作者圆印；纸粒建议静态、低透明度，在缩略图中进一步弱化。
- 普通按钮/输入框可先试 4–6px 圆角，浮层 8px，卡片 6–8px；控制全站档位数量。
- 正文依靠排版、留白和底色形成纸面感。画布网格可作为吸附辅助，默认极淡或关闭，独立于正文纹理。
- 阴影表达浮层高度和拖拽状态。节点正常态只需轻边框或浅阴影，选中态用轮廓清楚的边框与操作控件。
- 材质使用本地 CSS/SVG；现有字体继续离线加载。先整理已拥有的素材，再决定是否增加资源。

## 5. 分屏设计建议

### 5.1 书架：从封面墙补上“下一步写什么”

书架顶栏现有搜索、设置、新建的层级已经较清楚。建议内容区补一个轻量的“继续创作”入口，显示作品、最近章节和最近编辑时间；若数据层没有这些记录，需要与对应能力一起实现。

封面保留 2:3，增加紧凑/舒展密度。以当前 160px 最小卡宽为基础，比较 160、190、220px 三档；宽屏限制最大卡宽，避免少量作品无限拉伸。封面之外保留完整可识别的横排书名、字数和章数。

书名模板建议：

| 书名 | 默认展示 | 备用展示 |
|---|---|---|
| 2–4 字 | P1 巨字或简洁中轴竖排 | P4 几何线描 |
| 5–8 字 | 双列/分行竖排，保证完整书名 | 常规竖排 |
| 9 字以上 | 横排分行 | 紧凑字阶模板 |

v8–v10 的分流策略存在不同版本，建议统一成一份模板规则，并允许手动换款。不要只按字符串长度处理所有语言：混合英文、数字、标点和长副标题需要额外样例。

P2 散落、P3 光栅、P5 海境适合做可选艺术封面。默认整架采用相同版式纪律，艺术封面通过用户选择形成变化。即便封面裁字，卡片标题、搜索结果和详情也要完整显示作品名。

进度百分比仅在存在字数目标或明确定义的完成度时显示；已有总字数、章数和作品状态可以直接使用。

### 5.2 正文：以居中内容页组织工作台

建议布局：左侧现有模块 rail → 可调章节树 → 居中正文 → 可收起的资料面板。

- 保留“文/纲/人/设/灵”的单字识别，将它们作为导航符号；小标签和 tooltip 补足完整名称。
- 章节树提供清楚的选中底、章节名、字数与状态；少用全行强调色，展开/折叠符号保持一致。
- 顶部只突出作品/章节和保存状态；保存成功静态显示，失败持续提示并提供重试入口。
- 工具栏分为撤销重做、文字样式、段落格式、插入四组；标题用一个下拉，对齐与颜色收进组菜单。
- 右栏的批注、摘要、人物、插图、信息改为可折叠分组或少量标签页，记忆最近使用区。
- 已有沉浸模式继续保留，进一步提供“收起格式栏”和“仅正文”层级；进入后正文宽度与滚动位置保持稳定。
- 段落聚焦作为可选功能，弱化其他段落时仍需可辨认；用户选择文本、批注或查找期间恢复正常显示。

### 5.3 大纲：让结构与操作分别清楚

参考 Milanote 的创作卡片与 Obsidian 的上下文控件，同时保留项目已有的自定义形状能力：

- 事件卡显示标题、两行摘要、类型；引用卡显示来源和“预览”入口；便签用淡底；章节锚点显示章节与写作状态。
- 标题、摘要、类型、写作状态分开表达。节点类型用小图标/侧条，关系类型用线标签与线型，状态用文字或标记。
- 关系色保留因果、伏笔、冲突、关联语义，调整为适合纸面的饱和度；颜色之外始终有标签或线型说明。
- 悬停节点时突出一度关系，其他关系轻度弱化；连线标签默认仅保留必要信息，选中时显示完整操作。
- 创建入口集中；视图切换靠上，缩放/适配靠画布角落，选中项操作出现在节点附近。
- 延续 v11：折叠容器变为摘要卡，显示名称、模块数、告警；展开恢复原来的空间位置。
- 延续 v11：引用先开详情浮窗，明确“跳转”和“拆窗”操作；拖拽钉住沿用现有双链浮窗能力。
- 缩放较小时隐藏长摘要，保留标题和结构。建议先以约 60% 作为样稿观察点，再按实际可读性定阈值。
- 新建空画布提供“放置事件”“三幕式模板”“章节清单”三个入口，与现有模板能力衔接。

### 5.4 人物、设定、灵感与搜索

人物卡统一头像尺寸、姓名字阶、角色标记、小传摘要；无头像时用姓名首字。关系图沿用大纲的连线规范，选中人物时清楚显示相关关系。

设定幕布突出缩进、折叠和当前行，减少每层独立的框。灵感默认用轻列表，标题、两行摘要、标签、时间即可；“转为章节/设定”在选中时出现。

全局搜索按正文、大纲、人物、设定、灵感分组；每个结果包含来源、摘要、命中高亮。设置页外观区增加即时样例预览；数据操作与外观操作保持清楚分组。

## 6. 动画建议：把动效放在有意义的变化上

以下时长为起点，沿用已有 `--dur-fast / --dur / --dur-slow` 与统一曲线。正文阅读期间保持静止。

| 场景 | 建议效果 | 时长/限制 |
|---|---|---|
| 书架首次展示 | 可见卡片淡入并上移 4–6px | 180–220ms；步进 20–30ms；总等待限制在约 400ms |
| 封面悬停 | 轻抬 2px，书脊有一次很淡的光扫 | 抬起 160–180ms，光扫 320–400ms |
| 新建作品预览 | 巨字揭幕、细线展开、圆印落款 | 280–320ms 主动画；一次播放；大尺寸展示启用 |
| 菜单/浮窗 | 淡入并移动 4px | 140–180ms；关闭更短 |
| 列表排序 | 拖拽项抬起，其他项平滑让位，落点线清楚 | 位移动画 160–200ms；拖动本身直接跟手 |
| 容器展开/折叠 | 摘要卡与内容淡入切换，保留空间关系 | 180–220ms；大图优先即时切换 |
| 搜索定位 | 目标一次短暂描边强调 | 500–800ms 后结束 |
| 保存完成 | 保存中标记替换为勾选与“已保存” | 120–180ms；完成后静态 |
| 侧栏/沉浸 | 面板短淡出，正文切换到稳定宽度 | 180–220ms；保持光标和视口锚点 |
| 主题切换 | 背景或静态叠层轻淡入 | 150–200ms；输入过程中可即时切换 |

v10 的封面揭幕、光扫、印章落款可以保留；“待机呼吸”“全架长时间错峰”“连线持续流动”不作为日常默认。连线强调可在用户触发追踪时短暂播放一次。

减少动态效果时：位移、缩放、光扫、循环动画全部停止，状态仍可立即识别；必要的淡入也压短或取消。当前代码已有全局降级，需要把新增动画纳入同一规则。

实现优先使用 transform/opacity。`clip-path`、大型 SVG、画布重排不能仅凭动画属性名称认定性能无问题：封面揭幕可用带 overflow 的包裹层配合位移；几何变更需要更新真实画布状态，再决定是否增加视觉过渡。拖拽、文字输入和多窗口编辑时，优先保证跟手与正确性。

## 7. 建议实施顺序

| 优先级 | 内容 | 主要文件/范围 | 验收重点 |
|---|---|---|---|
| P0 | 正文纹理分层、次要文字对比度、正文限宽、字体角色拆分 | `themes.css`、`ui.js`、`EditorPane.vue`、`Workbench.vue` | 三主题长文可读；字体设置互不误影响；缩放后不溢出 |
| P1 | 工具栏分组、章节树/右栏层级、基础控件与 Naive UI 统一 | `EditorToolbar.vue`、`ChapterTree.vue`、`RightPanel.vue`、`App.vue` | 关键操作易找到；编辑选区稳定；焦点、禁用与激活态完整 |
| P1 | 书架模板收敛、长书名、密度和继续创作入口 | `Bookshelf.vue`、书架样式及所需数据 | 88/120/160px 封面识别；长书名和同色系列可用 |
| P2 | 大纲工具层级、卡片摘要、折叠容器、引用详情 | `OutlineCanvas.vue`、`OutlineSidebar.vue`、`DLinkPopover.vue` | 路由与坐标正确；选中态清楚；大图仍流畅 |
| P2 | 人物/设定/灵感/搜索沿用统一样式 | 对应列表、中心面板和搜索组件 | 相同动作使用相同控件，信息字阶一致 |
| P3 | 封面揭幕、一次光扫、列表让位、局部定位等动效 | 动效令牌与对应组件 | reduced-motion、重复打开、多窗口和大数据情况 |

第一批应优先让写作界面更舒服，同时把字体和色彩基础统一。封面复杂动效在静态三屏样稿收敛后添加。

验收建议：

1. 同一作品、同一字体，比较书架/正文/大纲三屏；三主题各有截图。
2. 覆盖 1280×800、1440×900、1920×1080，以及 Windows 125%/150% 缩放。
3. 书架使用少量真实作品、同色系列、多色系列、长书名与中英混排；验证书单独检查。
4. 正文使用多章长文；确认工具栏收纳、选区、滚动锚点与沉浸切换。
5. 大纲使用少量节点和数百节点；检查缩放、折叠、浮窗与重排。
6. 校验普通/悬停/选中/禁用/键盘焦点五态，文字对比度和减少动态效果。
7. 视觉变更保持现有验收选择器兼容，按改动范围运行项目已有的书架、双链、批注和画布检查。
