# 幻日剧场 · 书架首屏三方向

## 任务与边界

- 目标：为「幻日剧场」皮肤重新设计书架首屏。
- 主题北极星：**剧场中上演的不同剧目，是一个个不同的真实世界。**
- 本轮只交三份方向稿：每份一张 1440 × 900 的真实首屏，静态主状态，不含交互、响应式和动效。
- **未修改应用代码**；三份稿子独立放在本目录，选定方向后再进入完整页面和接入。
- 三稿共用同一份示例数据（`data.js`）：星尘旅人为主作品，另有长夜将尽、雪落界脊之上、山海拾遗录、第七位访客、青鸾纪事五部。

## 参考调研与借用

调研了 MotionSites、Aceternity UI、Showreel.design、Uiverse、React Bits、Anime.js。共同趋势是：电影感暗场、超大字级、层叠景深、聚光/光束、幕布揭示、3D 倾斜卡片、滚动/悬停的微动效，以及“编辑式排版”和“画廊式留白”两条路线。本轮把可落地的部分转成静态构图：

- MotionSites：画廊式留白、超大标题、戏票/节目单式的分类。
- Aceternity UI：背景光束、聚光、3D 卡片、视差层叠。
- Showreel.design：电影感配色、光晕、材质与节奏感。
- Uiverse / React Bits：按钮与卡片的手感、发光边框、文字入场。
- Anime.js：幕布揭示、聚光灯、层叠视差的时序能力（留到选定方向后再实现）。

三份稿子分别选择了三种不同的借用方式：A 用舞台/聚光/幕布，B 用编辑式排版/木刻印刷，C 用三联画廊/光谱折射。

## 三份方向

### A · 幕启三界

- 骨架：左侧文案柱 + 中央镜框舞台 + 底部横向剧目票根。首屏就是一座正在开演的剧场。
- 主视觉：自制 SVG 镜框台口、穹顶檐幕、左右丝绒幕、三块拱形世界景片（雾港 / 赤城 / 青苑）、幻日与两侧映日、台唇与尘埃。主作品书封立在台唇。
- 字体：京华老宋体做大题与书封；霞鹜文楷做正文、标签与票根信息。
- 色彩：午夜蓝黑、旧金、象牙白；三块景片分别带入雾蓝、赤陶、青绿。
- 信息：主作品标题、简介、继续写作、故事大纲、字数/章数/世界/状态、上次写到、五部续演票根。
- 适用：最像“书架”，主操作和其他作品都在首屏；舞台语法可继续延伸到正文、设定等模块。

### B · 演出年册

- 骨架：纸本节目册。左侧是超大宋体题名 + 节目表，右侧是木刻版画海报 + 世界索引。没有常规“卡片栅格”。
- 主视觉：自制 SVG 木刻/线刻风海报：三层拱形景片、幻日、台口、脚灯；用网点与排线模拟印刷。
- 字体：京华老宋体大标题；霞鹜文楷正文；数字用衬线体。
- 色彩：象牙纸、墨色、朱红、青绿、旧金。
- 信息：本季主打、题名、简介、继续写作、数据、上次写到、五部续演节目表、三个世界的索引。
- 适用：安静、文学、出版物气质；更像一本可以带走的演出年册。

### C · 折光镜厅

- 骨架：三联世界门。左中右三块拱形玻璃各是一个世界，中央门更亮更高；顶部光谱幻日横贯，底部是完整剧目索引。
- 主视觉：自制 SVG 三联景：赤城的落日与城墙、雾港的月与航线、青苑的月洞门与园林；玻璃高光、颗粒与光谱弧线。
- 字体：京华老宋体做大题；霞鹜文楷做正文；小标签用无衬线。
- 色彩：近黑紫底、光谱蓝 / 珊瑚 / 青绿、珍珠白、旧金。
- 信息：主题宣言“三界同台”、三个世界的题名与一句话、主作品在中央门内、底部六部剧目索引。
- 适用：最现代、最概念、最直接把“一戏一世界”画出来；适合展览感更强的品牌表达。

## 差异检验

| 维度 | A 幕启三界 | B 演出年册 | C 折光镜厅 |
| --- | --- | --- | --- |
| 首屏骨架 | 左文案 + 中央舞台 + 底部票根 | 左编辑正文 + 右海报栏 | 三联世界门 + 底部索引 |
| 主视觉 | 暗场镜框台口、丝绒幕、三联景片 | 纸本、木刻海报、网点排线 | 玻璃世界门、光谱幻日、颗粒 |
| 字体主角 | 宋体大字 + 文楷 | 宋体大字 + 文楷 + 印刷数字 | 宋体大字 + 文楷 + 无衬线标签 |
| 色彩 | 午夜蓝黑 + 旧金 | 象牙纸 + 墨 + 朱红 | 近黑紫 + 光谱三色 |
| 书架形态 | 舞台票根 | 节目表 | 底部索引 |
| 气质 | 沉浸、戏剧、正在开演 | 安静、文学、出版物 | 现代、概念、展览 |

三稿没有共用同一模板：A 是“舞台 + 票根”，B 是“纸本 + 节目表”，C 是“三联 + 索引”；骨架、字体、色彩、主视觉和信息密度都拉开了。

## 素材说明

- 本轮**没有使用此前生成的幻日剧场图片**（mist / light / lacquer 等）。
- 生成图片的在线链路本轮不可用；改用**自制矢量插画**：三套世界景片、书封、海报、标志、光晕和纹理全部为内联 SVG / CSS。这样三份稿子共享同一套“幻日”视觉语法，也不依赖外部图片授权。
- 字体使用项目已有的京华老宋体与霞鹜文楷子集，放在 `assets/fonts/`。

## 检查结果

- 三份稿子均在 1440 × 900 下截图：`screenshots/a/page.png`、`screenshots/b/page.png`、`screenshots/c/page.png`。
- 截图工具报告：无控制台错误、无横向溢出、无加载失败的图片；三份均无可读性问题（对比度、字号、行高）。
- 已修正的问题：
  - A：左文案柱的硬边、世界名被底部票根遮住、章节眉标样式、页脚对比度。
  - B：简介出现“外。”孤字、人物名被拆行、海报竖题被裁切、印章与标题重叠、右栏下方空白。
  - C：主题宣言压到左侧世界门、底部“正在上演”与作品数据重叠、主标题层级弱于主题宣言、索引小字对比度。
- 截图工具的“默认做法提示”：
  - A 的 `SUNDOG THEATRE`、`STARDUST VOYAGER`，C 的 `PARHELION HALL`、`NOW SHOWING` 等英文大写：这是剧院节目单的 bilingual 语法，作为装饰性副标保留；中文信息均在主层级。
  - B 的朱红单侧边线（上次写到、海报竖题）和 C 的眉标：属于纸本/节目单的版式装置，保留。
  - 三份都没有遗留对比度或字号问题。
- 方向探索阶段按 oil-ui 流程由主 Agent 查看画面，不派独立评审；本轮不做完整证据包、不录屏。

## 推荐

**推荐 A · 幕启三界。** 理由：

1. 它最像“书架”：主作品、继续写作、其他五部作品、七个功能入口全部在首屏可达。
2. 它把主题讲得最完整：镜框台口 + 三联世界景片 + 世界题名 + 底部剧目票根，一眼看出“同一座剧场里上演不同世界”。
3. 它最容易继续生长：舞台语法可以平移到正文、设定、人物模块；工作台不需要另起一套视觉语言。
4. 它的暗场 + 旧金 + 宋体与“幻日剧场”的名字最匹配；B 更文学，C 更概念，都可以作为后续品牌物料或局部视觉的参考。
