纪律只动 transform / opacity（v1 性能红线）；封面是唯一允许 >240ms 编排的界面位置；--dur-cover: 320ms 为新令牌。尺度门控揭幕编排只在 ≥120px 尺度播放——书架缩略卡只保留 A1/A2（悬停抬起 + 光扫），实现用容器查询 @container (min-width: 120px) 或 JS 尺度类。reduced-motion全部降为静态或 opacity 200ms。
