# 引力书舱：首批接入

> 本文保留首批“仅书架”的历史范围。2026-10-16 已扩展工作台和独立窗口，当前实现与验收见 [工作台与独立窗口接入](./引力书舱-模块接入.md)。

本批将已确认的“引力书舱”接入真实书架，默认保留原版。正文、大纲、设定、人物、灵感与独立设置窗口继续使用原界面。原设计稿未改动。

## 使用

在书架右上角“工坊皮肤”中选择“引力书舱 · 书架试用”；也可在设置 → 外观 → 工坊皮肤选择。选“原版工坊”即可切回。皮肤跨重启保存，设置窗口修改后同步主窗口。

三种配色主题与皮肤独立保存：引力书舱书架使用深蓝／铜橙，进入工作台恢复原主题，返回书架恢复引力书舱。

单击书籍或聚焦后按 Enter 直接打开。主展示为最近更新的作品，搜索时为首个匹配作品。底部各创作入口打开主展示作品的对应原版模块；无匹配作品时禁用这些入口。

## 结构与功能对齐

- `src/skins/registry.js` 登记皮肤标识、名称、支持页面与配色；当前仅 `original`、`gravity`，未知标识回退原版。
- `ui.skin` 对应现有 `appconfig` 的 `skin` 键，不升级数据库；保存成功后更新显示并复用偏好广播，失败保留当前皮肤。
- App 根据当前页面解析生效皮肤，镜像到根容器和 body，兼顾传送到 body 的菜单、弹窗；工作台及面板始终解析为原版。
- Bookshelf 保留检索、打开、新建、编辑、删除及共享表单；GravityShelf 负责呈现和事件转发，不直接操作数据库。
- 搜索维持书名／作者／类型；新建编辑保留书名、作者、类型、状态、简介、六种封面款式，以及新建时的默认分卷选择。
- 删除仍为原有软删除，可通过设置内回收站恢复。作品列表不会因舞台只陈列三本书而截断。
- 已有星球素材只作环境装饰，六种封面仍依作品 `kind` 显示；没有增加作品图片字段或生成新图。

## 验证

单元验证：`node tools/skin-unit-verify.mjs`。

集成验证：保持开发预览服务在 5173，另启 Electron 独立配置后运行 `node tools/skin-verify.mjs`：

```powershell
.\node_modules\electron\dist\electron.exe . --dev --profile=gravity-skin-verify --remote-debugging-port=9223 --disable-renderer-backgrounding --disable-backgrounding-occluded-windows
node tools/skin-verify.mjs
```

脚本核对配置目录及实际数据目录，拒绝重定向的资料目录；创建的测试作品最后软删除，并恢复测试前皮肤与主题。截图保存在 Git 忽略的 `tools/_skin-*.png`。请只针对上述独立配置运行。

覆盖：有效范围与 CSS 变量隔离、最低 1080×680 窗口、全部作品可达、导航避让、搜索及空状态、六种封面、分卷、新建、编辑、软删除、单击与 Enter、原模块导航、可见皮肤控件、写入失败、设置窗口同步、重载读回及三种原主题；减少动画模式也已检查。

不新增依赖、后端接口、IPC 或创作业务实现。本批尚未扩展其他页面的皮肤，也未打包新的安装程序。

2026-10-15 验证结果：最终集成检查连续三轮通过；皮肤单元检查、七个 Vue 组件编译检查通过；原有预设 16 项、内容投影 13 项、任务边界 15 项单元检查通过。独立代码复核无阻断问题。独立视觉复核为 7/10，之后已进一步压缩短窗口舞台以完整露出首排作品，删去重复文案；书籍材质仍可继续精修。
