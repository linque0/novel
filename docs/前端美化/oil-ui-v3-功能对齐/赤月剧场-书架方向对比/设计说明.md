# 赤月剧场 · 三种书架方向

2026-10-17。交付目标：同一组作品，分别构造三种具有不同空间组织、材质与演出语言的书架，供用户先看画面再选方向。

## 打开与选择

- `index.html` 是可离线打开的三版对比页，支持并排、单张、实际尺寸查看及复制所选方向。各版底部提供「重播演出／静态查看」。
- `演出与截图.html` 收录三段正常速度的演出录屏、完整截图、高清截图入口和原 D 版对照。
- 三个独立原型分别为 `opera.html`、`nouveau.html`、`avant.html`。标准视口均为 1440×900。
- 也可以在本目录运行 `python -m http.server 8880 --bind 127.0.0.1`，访问 http://127.0.0.1:8880/ 。

## 方向与取舍

| 方向 | 构图与美术 | 演出 | 取舍 |
|---|---|---|---|
| 赤月歌剧院 | 正面镜框舞台、深绛丝绒、乌金雕饰、象牙白书名；主书位于中央，简介和接续章节分列两翼；作品集横排 | 双幕揭开、背景由暗到明、主书进入追光 | 剧场身份最明确，适合强调开场仪式；后续正文需要减少装饰占比 |
| 赤月戏 | 乳白、孔雀青、朱砂与旧金；曲线花饰和彩绘纸景形成非对称舞台；竖排题名与右侧节目册 | 前后纸景错层、题名遮罩显形、书封轻落位 | 细部与层次最丰富，文学感较强；后续长标题需要另行适配竖排空间 |
| 先锋旋转舞台 | 银黑机械景、赤月圆盘、钴蓝景片；倾斜粗黑巨字配偏轴圆台；作品序列连续横排 | 圆台布景转入、景片落位、灯阵逐个点亮 | 冲击力最直接，适合实验戏剧气质；后续编辑区应降低红蓝对比面积 |

推荐歌剧院：它把「剧场」变成了页面的空间骨架和开场动作。幻戏更偏纸上艺术，先锋更偏当代舞台装置。本轮三版都保留，供用户选择，不自动推广到其他页面。

三版分别编写 DOM 与样式；共享的只有作品数据、基础控件、书封构造和预览控制。与原 D 版对照，变化包括导航位置、舞台结构、题名形式、作品集组织、光影材质及动画，不是同布局换色。

## 内容与交互边界

- 六部作品及「星尘旅人」简介、156,824 字、42 章、最近编辑和「第一章 · 初雪」均来自既有原型的虚构内容。
- 可演示搜索、无结果、恢复列表、选择作品、书封与按钮悬停、开场重播和静态模式；选书更新书名、字数、章节数、时间及书封。章节摘录与简介保持统一样稿内容，不假定各部作品的真实章节。
- 导航、新建、继续写作与大纲保留为书架构图中的设计入口；本轮未制作对应业务页面。没有接数据库、真实作品资料、AI、网络服务或安装包。
- 以 1440×900 方向比较为验收目标，最小画布宽度 1100px；不是移动端或小窗口适配交付。对比页通过统一缩放呈现同一画布，不把缩小后的文字认作实际尺寸可读性。

## 动画约定

- 关键内容使用真实 HTML；舞台图只承担材质、布景与静态光影。动画在字体和图片准备好后播放，避免加载中白闪。
- 每次开场最长 1.2 秒，题名与主操作的进入在前 600ms 完成。演出结束后全部稳定停留，不运行持续旋转或闪烁循环。
- 重播可以连续触发，静态模式会取消演出；系统减少动画偏好优先于手动重播。书封悬停仅抬升 4px，保留各自透视关系。
- 录屏是浏览器实际界面的 1 倍像素正常速度回放，包含点击重播前的稳定画面和演出后的停留。高清截图为相同逻辑视口的 2 倍像素密度，不是浏览器缩放后重新排版。

## 检查与证据

- 主执行者完成一轮首屏自检和一轮修正后的复查。修正了歌剧院标题断行、幻戏竖排标题与简介的重叠、入场遮罩裁切绝对定位内容、辅助文字对比度及底部重复文案。
- 对比入口使用 Oil UI 的对比页生成器；其静态展示帧与可操作帧并存。离线检查只核对三个可操作候选是否加载，避免误将静态预览帧当作额外方案。
- `screenshots/`：三版各一张 1440×900 和一张 2880×1800 高清图；`three-directions.jpg` 是三版缩略对照。
- `closeups/`：实际截图中书名、书封、章节卡和主操作的 200% 局部。
- `evidence/<方向>/record-replay.mp4`：正式采用的三段 1 倍像素演出录屏。
- `evidence/verification/`：预览交互、快速重播、系统减少动画、离线加载的脚本记录及 600ms 截图。
- 原工具还输出了 2 倍像素录屏，报告指出其视频末帧与静止截图不一致，因此未纳入演出查看页，也不作为动画验收依据；原始报告与文件保留便于追溯。高清检查使用静态 PNG。
- 截图工具未报告控制台错误、横向溢出、图片加载失败或需修复的文字对比度问题。保留的眉标是「最近编辑」与「接续上次的故事」，分别表达时间与章节归属，属于作品信息。
- 本轮是三种方向的小样，按 oil-ui 的方向探索流程由主执行者看图，不做独立评分评审。

## 减法与构建

去掉歌剧院底部与作品列表挤在一起的重复口号；幻戏去掉与原画不一致的简化山形装饰，改为原画前景分层；没有删除作品名称、统计或主要操作。

`build_previews.py` 读取上级目录的既有作品数据，复用字体与书封，在本目录生成三个 HTML 与 manifest。运行后再用 oil-ui 的 `build_explorer.py manifest.json --output index.html --force` 更新离线对比页。生成器不运行上级的 `build.py`，避免重写原有四版设计稿。`verify.mjs` 使用本机已有 Playwright 与 Edge，验证时只操作此独立原型。
