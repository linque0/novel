# 赤月戏：美术、排布与色调重设计

## 目标与边界

上一轮三套配色仍显平面，用户要求同时重设计 UI、界面排布和色调，并学习有明确美术依据的高级风格。本轮沿用三张真实首屏对比的范围，重新组织三套独立布局；每套都是同一章节的写作界面，1440 × 900。原完整设计稿与上一轮配色稿留作参考，选择后再扩展。

这是静态设计稿。没有新增业务功能、后端、AI 服务或页面演出；按钮与文本使用真实 HTML，布景只承担美术与材质。

## 参考如何转为设计

- **维也纳分离派**：[Secession《贝多芬饰带》](https://secession.at/beethovenfrieze)。研究装饰、绘画与空间的整体构想，转为金箔壁画、纸面与连续剧目册之间的材质关系。画面中的几何镶嵌、金箔接缝、象牙白与乌金层级用于建立一体化的舞台感。
- **慕夏的剧场海报**：[Mucha Foundation](https://muchafoundation.org/en/gallery/mucha-at-a-glance-46)。资料强调长幅比例、光环式构图与庄重静态人物的关系。本稿将长幅和聚焦弧线转为珠宝花窗及拱顶稿纸；朱红月盘、珍珠飞蛾为新生成的原创布景元素。
- **琳派金地屏风**：[大都会博物馆《八桥图屏风》](https://www.metmuseum.org/art/collection/search/39664)、[Rinpa 展览解读](https://www.metmuseum.org/exhibitions/listings/2003/great-waves/photo-gallery)。借鉴金地与非对称疏密构图，形成偏轴双页稿本、竖向书名与横向章节条之间的关系。新布景使用赤月与梅枝，并非原作复制。

原作资料用于提取构图与材料关系，网页本身没有作为 UI 模板。原型保留写作工具所需的正文、章节、备忘、线索、字体工具和主操作。功能阅读顺序清晰，密集装饰集中在工作区边缘；正文不叠加纹样。

## 三个方向

### ① 月金壁画 · 维也纳分离派

北极星：在一座金箔壁画围合的私人艺术剧场里写作。

- 贯穿左侧的壁画建立赤月、镶嵌与白天鹅主题；中央是象牙稿纸；右侧是无卡片分割的连续剧目与备忘。
- 乌金底、象牙纸、旧金边、局部暗酒红主操作。金色只用于材料边缘和少量状态，正文为深棕墨。
- 主标题与正文采用京华老宋体，札记采用文楷。纸页压边、细镜框与金属书夹形成可辨识细节。
- 适合兼顾长期阅读和华丽舞台感。

### ② 月蚀花窗 · 珠宝新艺术

北极星：弧线、珠母贝与彩绘玻璃共同围拢一页稿纸。

- 左侧为剧目册，中间为拱顶珍珠稿纸，右侧花窗与札记连成一张长幅景片。
- 午夜蓝、珍珠灰、玫瑰金及月盘酒红。局部半透明珐琅、金属轮廓与纸面形成材质对照。
- 小型工具置于稿纸外沿，避免占用正文；弧形页框在顶部聚焦章题。
- 装饰表现最丰富，正文宽度也较紧凑。本轮推荐优先深化，最贴近用户提出的华丽新艺术方向。

### ③ 金屏夜梅 · 琳派折景

北极星：金箔屏风前展开的双页稿本。

- 横向屏风贯穿舞台，竖向书名形成左侧重心，偏轴双页稿本承载正文与札记，底部用连续章节条取代竖向目录。
- 墨黑、金箔、纸白与暗朱红。纸页中缝、折屏竖缝与章节横向节奏彼此呼应。
- 正文保持规整的水平排版，竖向字只用于书名；辅助信息集中在右页。
- 空间层次和版式差异最大；有更明显的东方剧场气质。

## 首屏自检

三张 1440 × 900 最终截图均已逐张查看，修正了前两张网格行高导致的页底遮挡，并调深纸页辅助文字、压暗花窗札记背后的景片。最终截图报告均无文字对比度问题、控制台错误、横向溢出或失败图片。第①版当前章节的细侧线表示书签式定位；第①③版景片上方的小字用于标示剧场归属，均按主题保留。正文超过首屏可继续滚动。此轮为方向首屏探索，未派独立评审，未添加动画或运行产品功能测试。
