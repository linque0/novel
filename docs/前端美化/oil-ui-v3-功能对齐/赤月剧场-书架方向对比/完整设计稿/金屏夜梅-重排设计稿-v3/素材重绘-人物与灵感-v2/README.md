# 人物与灵感素材重绘 v2

## 本轮修正

用户反馈 v1 美术元素复用严重。本轮重新生成两张图，移除银杏、花枝、金色藤蔓、山水楼阁、书卷等上一轮反复出现的主体和装饰。每个模块使用独立的主题元素，统一性来自纸雕材质、轮廓工艺、微雕纹理、细铜边和投影方式。

## 两套元素

| 模块 | 主题 | 专属元素 | 功能含义 |
| --- | --- | --- | --- |
| 人物 | 众相剧场 | 面具、人物剪影、朱红牵引线、舞台景片 | 身份、性格、人物关系与作者塑造角色 |
| 灵感 | 想象折光 | 透镜、棱镜、色光纸带、悬浮碎片 | 捕捉、折射、关联与组合念头 |

人物：钴蓝、赭橙、灰绿、象牙色，构图从左前景面具退向后方剪影，右侧保留蓝灰色空间。

灵感：淡紫、青绿、藏黄、珊瑚色，近景棱镜与后景透镜形成纵深，光带和纸片向左上散开，左侧保留粉砂色空间。
