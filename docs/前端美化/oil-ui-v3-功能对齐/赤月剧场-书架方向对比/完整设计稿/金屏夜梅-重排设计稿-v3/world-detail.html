星图系统

核心设定观测航线

铜星是星图中最稳定的导航基准。所有航船据此校正航线，观测局负责记录铜星的位置与明暗。

一枚铜星的熄灭，意味着一条航线从记录中消失。失去坐标的人，会先忘记归途。

观测与记录

观测者将每一枚铜星的变化写入星图。只有当记录与天空再次重合，新的航线才会显现。

不要相信一张永远不会改变的星图。
