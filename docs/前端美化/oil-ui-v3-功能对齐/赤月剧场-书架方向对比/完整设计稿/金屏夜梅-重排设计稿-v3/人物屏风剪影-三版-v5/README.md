## 人物页排版约束

依据 `../characters.html`、`../rework.css`、`../visual-v3.css` 和原稿截图：

- 主视口 1440 × 900；顶部导航 76px，底栏 40px，背景舞台为两者之间的区域。
- 模块工具条高 86px，顶部需要深色、低对比背景，承托浅色文字。
- 左列 380px；拱顶肖像原规格 330 × 420，下接名册。
- 右侧从约 x=438 开始为档案纸，背景主体放到右边会被遮挡。
- 三版都将主要屏风安排在左侧，肖像周围与上缘承担可见装饰；右侧保留平静纸色。
- 插图使用 `object-fit: cover; object-position: left center`。沿用原稿全部内容区尺寸；只将原来的居中裁切改为从左侧锚定，减少窄窗裁掉左侧布景。
- 素材本身与真实页面分别提供预览，页面中的肖像仍是用户设定的人物照片；剪影是背景布景，并非对肖像的替换。
