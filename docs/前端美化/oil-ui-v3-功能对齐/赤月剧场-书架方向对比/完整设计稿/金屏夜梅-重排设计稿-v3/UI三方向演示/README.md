# 金屏夜梅 v3 · 人物 UI 三方向演示

## 查看

直接用浏览器打开 `style-explorer.html`。该文件包含字体、图片和交互代码，可离线查看。现状为指定 v3 人物页截图，随后是三个可操作候选。

建议先并排看构图，再点「单张查看」，用「实际尺寸 100%」看文字与细节。演示画布统一为 1440 × 900；窄窗口由对比页等比缩放，本轮没有设计手机布局。

| 方向 | 布局与记忆点 | 交互动效 |
| --- | --- | --- |
| 01 朱墨破格 | 朱色日轮、斜切肖像、超大宋体姓名；小传与资料散落在开放画面中 | 姓名横向切入，肖像错位落定，文字分层跟进 |
| 02 赤月转景 | 夜色花鸟景片、月门肖像、竖排题名、单张人物笺；以场景纵深组织信息 | 背景、人物、人物笺从不同方向转景 |
| 03 星轨织书 | 中心肖像、卫星人物、章节与所属节点；关系本身成为导航 | 焦点收束、弧线浮现、人物节点联动 |

## 可以操作的内容

- 三个人物之间切换，姓名、肖像、身份、年龄、所属、小传、动机、标签与关系同步更新。
- 切换「人物小传 / 关系脉络」，点击关系人物跳转。星轨方案也可点击轨道上的人物。
- 「执笔 · 编辑人物」打开编辑对话框，修改后更新当前演示；数据只在本页会话中保留，刷新恢复。
- 「初次登场」打开对应章节预览：林远为 v3 正文节选，沈砚和白鸽为 v3 大纲提要。
- 「v3 原稿」打开原人物页截图；Esc 或关闭按钮退出对话框。
- 「重演入场 / 静态查看」控制动效；也遵循系统的减少动态效果偏好。

## 范围与素材

本轮仅制作人物档案的三个方向演示，供选型。未接入主程序、业务数据或服务，原 v3 设计文件及应用源码没有改动。顶部其他模块名称用于展示整体导航位置。

肖像、花鸟素材、OldSong 与 WenKai 字体来自指定 v3 素材。人物主体资料、首章正文与大纲提要沿用 v3；额外的引言、关系称谓、别名和标签是用于三个方向一致比较的展示数据。

少量卷次眉标用于表达人物在书卷中的位置；朱墨方向的角色朱批和舞台方向的动机竖线用于形成卷轴与人物笺的语言。这些元素没有扩展成字段卡片或每段文字的边框。

## 文件

- `style-explorer.html`：离线对比入口（由 oil-ui 自带生成器生成）。
- `ink.demo.html` / `stage.demo.html` / `orbit.demo.html`：三个可单独离线打开的完整演示。
- `ink.html` / `stage.html` / `orbit.html`、对应 CSS、`shared.css`、`data.js`、`demo.js`：可编辑源文件；交付候选由打包脚本生成。
- `screenshots/*-final/page.png`：最终 1440 × 900 首屏截图。
- `screenshots/*-checked/`：人物切换、关系跳转、编辑与预览操作的录屏、关键帧及检查报告。
- `manifest.json`：方向描述与候选索引。
