## 排版依据

### 人物

沿用 `../characters.html` 的 380px 左列、330×420 肖像、名册以及右侧档案纸，不挪动内容区。
原稿中可见背景主要为肖像上缘、两侧和底边。人物素材仍从左侧锚定，尽量将剪影安排在上缘可见区；背景并非替代用户肖像的整幅人物画。主界面保持前景肖像与后景屏风的层级，实际遮挡在对比页中可直接查看。

### 设定

依据 `../world.html`、`../world-detail.html`，新素材按窄长竖幅设计：
- 主界面左布景宽 220px，详情页宽 200px，1440×900 下高约 673px。
- 画面上部保留暗色空间，适配既有标题、副标题和说明。
- 天仪与疆域图层集中于中下部，中央构图保证两种窄幅裁切仍可辨认。
- 原 HTML 文案、树形编辑区、目录与关系栏沿用，图片不生成 UI 字样。
- 左布景的图像定位改为 `center center`，以配合专门制作的竖幅；保留原拱顶裁切和文字遮罩。
