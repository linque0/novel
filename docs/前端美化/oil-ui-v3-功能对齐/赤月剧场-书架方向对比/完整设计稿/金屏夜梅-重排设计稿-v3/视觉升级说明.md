# 折屏戏本 · v3 视觉升级说明

> 在 v2 的版式与空间重排之上，建立一套可记忆、去方框、贴合赤月戏皮肤的视觉语言。
> v2 原稿与 v1 均保留；本目录为 v3 视觉版。设计稿与交互原型，不接真实数据。

## 一、一句话概念

**金屏为台，折缝为幕，纸页为文，朱印为场，书签为序。**

“折”既是**折屏**，也是**折子戏/剧情转折**。界面单位不再是“卡片”，而是：

| 结构 | 语义 | 表现 |
|---|---|---|
| 金屏 | 场域 | 深墨底、局部金线，不铺满金色 |
| 折缝 | 分幕 | 栏与栏之间的一道折线 + 明暗带 |
| 纸页 | 文 | 装裱纸、错位背纸、书角/毛边 |
| 朱印 | 场次/身份 | 每屏最多一枚小印，标记当前卷或剧场 |
| 书签 | 顺序/当前 | 从列表左缘探出的窄签，标记当前项 |
| 月洞 | 焦点 | 每屏最多一个拱形媒体（肖像、布景） |
| 折角/票根 | 手工感 | 非滚动纸面的右下折角、切角 CTA、票根首章 |
| 角标 | 分组 | 用 L 形角标代替闭合虚线框 |

## 二、调研结论

1. **去框化不等于删掉所有矩形。** 编辑式版式靠强网格 + 少量破格；Shopify 的破格原则强调移动端要回到常规堆叠。正文、输入、列表、画布必须保持稳定矩形，设计感放在边缘、媒体、页头、空状态与当前状态。
2. **最贴合皮肤的结构是“装裱 + 屏风”。** 卡纸装裱（passe-partout）用宽纸边和略重底边托起作品；屏风（byōbu）用折缝组织连续画面；琳派金屏靠裁切、留白与左右不对称，而不是满屏纹理。参考 Mat、Byōbu、尾形光琳《红白梅图屏风》。
3. **高级感来自克制与层级。** 每屏最多 2 条折缝、1 枚朱印、1 个异形媒体；金色不上纸——旧金 `#cfb06b` 在纸白上只有 1.66:1，不能做文字。纸上金色改用深金 `#7a5f2c`，朱红文字用 `#a84135`。
4. **可访问性是设计的一部分。** 正文对比度 ≥ 7:1；焦点环 2px、双色、不被裁切；异形只作用于媒体/背景，不作用于文字、输入、滚动容器；点击热区不因造型缩小；尊重 `prefers-reduced-motion`。
5. **中文排版不套拉丁参数。** 桌面正文约 30–40 字/行，行高 1.6–1.8；标题用宋/明体，UI 用系统黑体；正文不用书法体、不用伪斜体、不用负字距。

参考来源（详见文末）：Smashing 杂志版式、Shopify 破格、Mat/passe-partout、Byōbu、Rinpa、Moon gate、Chinese seal、Deckle edge、WCAG 2.2、CLReq、CSS clip-path/mask。

## 三、视觉系统

### 颜色

| Token | 值 | 用法 |
|---|---|---|
| 墨 | `#151918` | 顶栏、舞台、正文 |
| 场 | `#1b211e` | 暗色目录、关系暗场 |
| 纸 | `#eee5cc` | 主阅读面 |
| 纸亮 | `#f4ecd9` | 纸面高光、书签 |
| 纸深 | `#e2d5b7` | 背纸、纸边 |
| 装饰金 | `#cfb06b` | 深底金线、当前项、深底文字 |
| 纸上金 | `#7a5f2c` | 纸面小标题/辅助文字（对比 4.77:1） |
| 朱印 | `#a84135` | 印章、当前书签（纸上对比 4.81:1） |
| 朱亮 | `#b64b3d` | CTA、图钉、装饰边缘 |

### 形状与层级

- **纸页**：取消 `.paper` 的 1px 闭合边与 3px 硬偏移；改成“一张错位背纸（`5px 6px 0`）+ 软影”。滚动纸面不裁切；仅正文稿本使用右下折角。
- **深色目录/暗场**：去外框与阴影，改为暗色渐变 + 顶部 1px 金线（用 inset shadow，不占边框）+ 栏间折缝。
- **折缝**：11px 明暗渐变带，只出现在大栏交界；不围合，不用于卡片。
- **主 CTA**：14px 切角纸牌；切角只做在伪元素背景上，按钮本身保持矩形热区与焦点环。
- **次级操作**：文字 + 悬停金线；不再有一排小方框按钮。
- **标签**：行内文字 + 小菱形 `◇`；筛选项目保留文字点击区与当前下划线。
- **当前项**：书签（左侧金/红窄条或纸签）+ 文字变色；不铺满整行色块。
- **朱印**：编辑章节卷名、设置剧场名、书架首章“续”印；每屏最多一枚。
- **月洞媒体**：人物肖像、设定/详情布景；只裁图片，不裁标题、按钮与文字。
- **折角/票根**：正文稿本右下折角；书架首章票根；灵感便签纸片。

### 字体

- 展示/标题：OldSong；文学性文字：WenKai；UI/表单：系统黑体。
- 正文保持 19px / 2.05 行高；不因视觉升级改变行长与字号。
- 数字使用等宽数字；卷号/页码用小号 OldSong + 字距。

## 四、逐页改动（v2 → v3）

### 正文
- 删除 `.c-page:before` 与 `.c-margin:after` 两层内框；`.c-book` 去掉 1px 边和三层硬影，改为背纸 + 软影 + 右下折角。
- 章节目录去外框/大阴影，改暗场 + 顶部金线 + 右侧折缝；搜索只留下划线。
- 当前章从满铺米色改为“左侧朱红书签 + 金色章题 + 细线”，保留 44px 行热区；卷名“雾港纪事”改为竖排朱印。
- project-line 操作去深色胶囊，改文字 + 金色圆点分隔 + 轻描边；1080 下仅保留一层渐变底以保证对比度。
- 收起态：56px 窄轨内用“月相进度盘”（章号 + conic-gradient 进度弧）替代方形按钮组；上下章为无框箭头。
- 稿页与札记之间用一道折缝；札记引用行改发丝线；正文、输入、滚动与焦点轮廓均不裁切。

### 人物档案
- 肖像改“月洞/拱顶装裱”：只裁图片，外有错位背纸与细金弧；保留 330×420、换肖像、签名层，脸部落入安全区。
- 演员表从两列卡片改单列缩略图行（44px 行高、头像 + 姓名 + 定位），当前项用书签；`＋ 人物` 从空卡改为文字入口；列表外加深色帘幕以保证对比度。
- 移除只作气氛的肖像注块，把空间还给演员表；人物多时列表可滚动。
- 卷宗去双层硬影，改单张装裱纸；字段保留下划线；标签改行内文字；小传/关系区保持矩形。

### 设置
- 分类栏去外框/阴影，改暗场 + 顶部金线；当前分类从满铺亮块改为向右探出的纸书签（红色三角尖），其他行只留发丝线。
- 设置纸去闭合边；下拉从完整边框改下划线 + 小箭头；开关保留。
- 预览纸不再做“第二张同构纸框”：改为样张（顶部细线 + 底部页码 + 纸色明度差），宽度/高度贴合 300px 栏与栏高。
- 剧场名改为竖排朱印；每屏一枚朱印。

### 大纲
- 目录去外框/阴影，改暗场 + 折缝；搜索下划线；类型筛选文字化，当前下划线；当前项书签。
- 画布去闭合边/阴影，保留矩形拖动面；`.plot-container` 虚线整框改 L 形角标 + 行内标签。
- 节点去 1px 边 + 3px 硬影，改纸片：顶部 3px 类型色、右上切角、图钉/胶带、软影；按钮热区保持矩形。事件/便签/引用/章节锚点用不同纸色与钉色区分。
- 画布底右控制条去胶囊，改文字 + 渐变底；1080 下重排节点（190px 宽、三列）并隐藏连线，避免右缘裁切。

### 设定 / 设定详情
- 布景去金相框/阴影，图片改拱顶/卷轴头（每页一个异形媒体），顶部金杆，右侧折缝接纸面。
- 纸面去闭合边，改单张装裱纸；标签行内化；引用块改金色竖线 + WenKai，不用填充框。
- 详情右栏去外框，改深墨暗场 + 顶部金线；轨道矩形卡改压在轨道线上的文字签（保留透明热区），只留中心圆做“月洞”核心；添加关系用切角主 CTA。

### 人物关系图
- 画布去外框/硬影，保留矩形；节点去硬偏移，改装裱肖像 + 顶部金线。
- 关系标签去边框/底色，直接压在关系线上，用纸色光晕保证可读。
- 工具栏“圆形/网格”统一为文字标签 + 当前下划线；名册去外框，改暗场 + 书签当前行。

### 灵感
- 布景去相框，保留拱门/竖排标题与右侧折缝；不抢阅读纸。
- 便签去边框与硬偏移，保留纸片明度、图钉、1–2° 旋转与软影；当前态用朱红图钉 + 右上书签，删除外圈 outline。
- 阅读纸改单张装裱纸；标题/正文输入保持无框；主 CTA 切角，次级文字。

### 书架
- 剧目栏去左边框，用折缝接舞台；行只留发丝线。
- 首章卡从纸卡改“票根/书签条”：左上切角、左侧朱红书签、右上“续”朱印，保留整块点击与跳章。
- `继续写作`、`新建作品` 改切角纸牌；二级操作文字化。

### 全局
- 顶栏当前项从下划线改“金色场次缺口”（短金条 + 小三角）；不加框。
- 模块标题下加短金线；动作区仅主 CTA 保留切角纸牌。
- 非交互标签去边框；可点击项保留 padding 与焦点环。

## 五、必须保持矩形的区域

- 正文：`.prose`、`.lore-prose`、`.long-document`、`.idea-prose`、预览正文。
- 表单：`.dossier-fields`、`.setting-row`、`.type-tools`、`.dialog`。
- 列表/表格：章节列表、目录、演员表、名册、树形节点行。
- 画布：`.plot-canvas`、`.character-graph` 保持矩形平面；节点包围盒与拖动热区不变。
- 滚动容器：不应用 mask/clip；折角只用于非滚动主纸。

## 六、可访问性

- **对比度**（实测）：正文 9.32:1、导航 14.44:1、深底金 8.51:1、印章纸字 5.14:1、纸上金 4.77:1、纸上朱 4.81:1、关系词 6.20:1。
- **焦点**：2px 纸白外环 + 4px 墨色外晕；键盘 Tab 实测 outline 2px solid；切角 CTA 的按钮本身不裁切。
- **热区**：章节行、演员表行 44px；工具栏 35px；切角仅改变背景，不缩小按钮。
- **异形边界**：拱形/切角/折角只作用于图片、背景伪元素、非交互纸片；文字、输入、焦点环、滚动条不裁切。
- **动效**：`prefers-reduced-motion: reduce` 下动画/过渡降至 0.00001s；保留状态变化，不保留入场位移。
- **当前态不只靠颜色**：`visual-v3.js` 为当前章节、目录、演员、分类、灵感项补 `aria-current="true"`；书签有文字/位置提示。

## 七、验收

在本目录运行：

```bash
node capture-v3.mjs
```

最近一次结果：`PASS fold-screen v3`，`fail: []`。

覆盖：
- 10 屏 × 1440×900 与 1080×900，共 20 张截图（`screenshots/`、`screenshots/narrow/`）。
- 无横向溢出、坏图、运行时错误；76px 顶栏、7 项导航。
- 去框检查：主要纸面/目录/布景无边框；内框隐藏；灵感当前项无 outline；演员表当前项无填充底色；类型筛选当前项无填充底色。
- 结构：书架上无左竖栏；正文无底部章条；章节列表可滚动；稿本高 680；大纲画布右缘 1408；关系图左缘 32；人物列 380/330；设置样张贴栏。
- 1080：大纲 6 个节点全部在画布内；连线隐藏；人物列 330；设置样张不越界。
- 交互：章节栏 248→56→248、稿本 296→104；搜索 24→1→24；收起态下一章 01→02、上一章 02→01；月相进度 `0.0417`，进度弧 `conic-gradient(..., 15.012deg, ...)`。
- 焦点、对比度、减少动画均通过。

人工逐张查看 10 屏（1440 与 1080）：每屏折缝 ≤2、朱印 ≤1、异形媒体 ≤1；正文与表单没有被造型裁切；1080 大纲 6 个节点完整；窄窗未出现横向滚动。

## 八、目录与边界

- `visual-v3.css` 是唯一视觉覆盖层；`rework.css` 保留 v2 版式，`studio.css`/`shelf-approved.css`/`editor-approved.css` 保持原实现。需要回退视觉层时，移除 10 个页面的 `visual-v3.css` 引用即可回到 v2 视觉。
- `visual-v3.js` 只同步当前态与月相进度，不读写业务数据。
- `assets/` 为指向 v1 素材的目录联结；`studio.js`、`design-data.js`、`rework.js` 为硬链接；单独移动目录时需重新建立联结/复制。
- v1、v2 目录未改动；本轮不改 `src/`、数据库、AI 链路。v3 为设计稿与交互原型，确认后再谈应用接入。
