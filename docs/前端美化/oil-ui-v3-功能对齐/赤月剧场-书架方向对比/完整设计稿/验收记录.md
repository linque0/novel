## 90 项交互检查的范围

- 20 个状态的渲染、图片、正文内容与页脚位置。
- 单击作品直接进入正文、当前作品上下文。
- 正文编辑跨页读回、分章内容隔离、返回章节读回、沉浸与 Esc、查找替换。
- 大纲模块编辑、实际指针拖动、类型筛选、自由画布与文本大纲切换及文本读回。
- 连续设定节点的折叠、内容搜索、无结果、详情和幕布定位往返。
- 人物字段和自定义字段跨页读回、人物图谱网格切换、单击图谱节点返回档案。
- 灵感筛选无结果、新建、插入正文；字号实时预览与正文联动。
- 静态模式、系统减少动画、刷新恢复初始会话数据。
- 两套各 4 个关键工作区在 1100px 窗口中的文档边界。
- 离线对比页的页面选择、单版实际尺寸、截图切换及两版静态模式。

检查脚本为 `verify.mjs`。动画检查等待可观察的完成状态；隐藏 iframe 的状态检查采用定时轮询，避免浏览器暂停其绘制帧后产生假超时。最终三个轮次均为 90/90。

## 独立评审后的修正

| 评审发现 | 修正与复看 |
| --- | --- |
| 幻戏灵感短正文落在按钮分隔线处，形成双层滚动 | 收回叶片与题名前的装饰留白；操作固定，正文单独滚动；最终首屏完整显示三段短文及最后“回音。” |
| 幻戏人物页底部只露动机标题 | 收紧字段行、章头和小传间距；最终林远的动机标题与完整首段一起可见，左肖像保持主视觉 |
| 幻戏设定详情关系不清楚 | 三条曲线从中心设定延伸到人物、事件与章节，移除无关系语义的通栏细线，连接位于纸片下方 |
| 章首留白压缩阅读区 | 两套缩短章首装饰与正文之间的间距，正文仍用原 19px 字号 |
| 幻戏卷叶重复 | 去掉人物图谱与设置阅读样张右下角的大卷叶，大纲保留较小的低调角饰 |
| 小字对比度 | 加深设定编号、灵感日期/标签及关联提示，最终报告无对比度告警 |
| 无用说明文字 | 按评审删去正文/大纲/设定/灵感中的重复句子，详见 `设计说明.md` |

交互复查另发现按下样式用 `transform` 覆盖了人物图谱节点原有居中定位。现已在本目录复制的基线样式中移除该旧规则，用独立 `translate` 表达 1px 按压；已用真实指针点击复验，三轮均通过。原已通过页面未被改写。

## 文件与边界

- `index.html`：并排、单版原尺寸、截图与视频入口。
- `opera.html`、`nouveau.html`：可独立离线打开的完整设计原型。
- `screenshots/overview.jpg`：正文与人物两页的四图概览。
- `screenshots/<方向>/<状态>.png`：最终首屏。
- `details-2x/`、`closeups/`：高分辨率与 200% 局部。
- `evidence/`：正常速度视频、回放截图、浏览器检查与结果 JSON。
- `check/`：制作过程中的局部截图，不作为最终视觉基准。

本轮未连接真实 AI、数据库、文件保存与导出系统；复杂关系操作、历史记录及导入导出是界面设计入口，不能据此声称软件业务已经实现。会话编辑不是持久保存，刷新恢复初始内容这一行为已明确检查。
