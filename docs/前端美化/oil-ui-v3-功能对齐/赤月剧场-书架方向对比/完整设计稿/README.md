# 赤月剧场 · 完整设计稿

打开 `index.html`，逐页比较两套设计。可双击离线打开，也可继续使用原预览服务：

<http://127.0.0.1:8880/完整设计稿/index.html>

- `opera.html`：赤月歌剧院。
- `nouveau.html`：赤月戏。
- `设计说明.md`：20 个页面状态、布局差异、交互范围与素材说明。
- `验收记录.md`：截图、录屏、窗口与交互检查。
- `视觉评审.md`：一轮独立视觉评审原始报告。

本目录为独立桌面设计原型，基准 1440×900。数据与编辑只保留在页面会话中，刷新恢复初始内容。没有接入真实作品、数据库或 AI。

## 维护

修改 `studio.js` 与 `studio.css`。`build.py` 用于从已通过书架中复制视觉基线、准备本地素材和生成两套入口；运行它不会改写父目录。

```powershell
python build.py
node verify.mjs
```

`verify.mjs` 只检查这两套原型，需要本机 Edge 和已安装的 Playwright；不运行应用构建或业务测试。
