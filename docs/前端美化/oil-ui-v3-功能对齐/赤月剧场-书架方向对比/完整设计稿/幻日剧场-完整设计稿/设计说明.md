## 目标

将「赤月歌剧院」更名并发展为「幻日剧场」。保持原方向的镜框舞台、古典巴洛克雕金、丝绒、象牙稿本与宋体标题；主题变为梦幻绮丽的幻日，不混入赤月戏的纸雕植物语言。

设计北极星：**七幕幻日，同一座剧场里的不同创作现场。**

作者仍在同一批作品中续写、规划结构、建立世界与人物、收集灵感、调整排版。本次交付独立 HTML 设计稿，不改产品业务代码。沿用七模块、十状态的功能与数据基线，包含书架的七张布景全部重做。
