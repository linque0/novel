# 幻日折光 03 · 书架首屏

## 本轮依据

用户指出上一轮过于朴素，剧场主题不够明确。新的核心是：**同一束幻日，经过不同介质的折映，显出不同的故事世界。写作是让世界登台，书籍与剧场都是故事的载体。**

三个方向均补入可辨认的镜框台口、侧幕、前后景片、台面与幻日光源。蓝色港城、赤色古城与青绿园林作为同一组故事意象，便于比较不同美术媒介的表达。保留相同六部作品及主要书目信息，星尘旅人为主展示。文字、书封、导航和按钮均为真实 HTML。

## 三版区别

| 编号 | 方向 | 表达与界面 |
| --- | --- | --- |
| 01 | 绢幕折光 | 手绘色层与透明绢幕，景色在交叠处融合。纸本留白、两行宋体书名与下方横排剧目册，适合长期创作。优先推荐：舞台、层叠世界与柔和绘画质感结合较均衡。 |
| 02 | 镜幕万象 | 错角镜幕将幻日分为冷暖不同的世界。全幅深蓝舞台，主作品立于台座，横向大标题与底部作品册。舞台临场感最强，图像细节和明暗变化也最密集。 |
| 03 | 漆彩幻景 | 如翻页的景片、细金嵌线与漆彩材质，把舞台做成收藏故事的艺术品。竖排书名、深色书封展台与右侧连续目录，更具装帧感。 |

## 范围与检查

- 本轮是三个 1440 × 900 的静态书架设计方向，待用户选择后再扩展其他模块和动画；业务操作没有连接数据库或 AI。
- 使用内置 image_gen 为三个方向分别生成一张舞台美术素材。完整提示词记录在同目录“素材提示词.json”。
- 素材源图：assets/source/mist.png、light.png、lacquer.png；页面加载 assets 下对应 WebP。
- 逐版生成并查看实际首屏截图；修正了绢幕版章节文字底色、换行，以及漆彩版按钮和字数统计间距、章节区域与布景的叠压。
- 截图位于 screenshots/mist/page.png、screenshots/light/page.png、screenshots/lacquer/page.png。截图工具报告没有控制台错误、横向溢出或图片加载失败。
- 三版保留“正在续写 · 今天 14:32”，它是作品最近编辑状态，帮助识别继续创作的对象。
- 方向探索按 oil-ui 流程由主 Agent 查看画面，未启动独立评审；本轮没有添加动效。其余现有原型不变。
- 上一轮素材与截图归档在 archive/美术02-偏简素。
