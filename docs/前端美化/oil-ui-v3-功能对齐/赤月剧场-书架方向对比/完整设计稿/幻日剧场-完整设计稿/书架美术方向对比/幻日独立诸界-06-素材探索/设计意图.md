# 幻日独立诸界 06 · 素材探索

## 本轮修正

用户提供正面镜框舞台参考，要求各世界明确隔离、正面展示、真实立体、有完整景深，世界在舞台中占比充分。透过舞台开口看到真实的不同世界，避免投影、画屏、世界相互交融。

## 三张构图

1. 三联镜框：绛红丝绒与旧金镜框，中央星海世界稍大，两侧冰原、山海以实体立柱和独立内幕隔开。
2. 深台分舱：午夜蓝、象牙白与旧铜，中央山海主台，两侧星海与冰原分舱，层层门洞强调建筑纵深。
3. 拱廊诸界：乳白、茄紫与细金，三个巨大拱廊入口后分别通往山海、冰原、星海，各自保持独立地貌、天空与透视。

## 共同约束

- 正面平视剧场，实体分隔贯穿上下，不使用透明叠图或跨世界反射。
- 世界具有近景地面、中景路径与远景地平线，并保持足够大的舞台开口。
- 幻日作为上方建筑式灯光冠，以日盘与两侧小型伴日光学件建立主题；分向照明，避免横跨世界的彩虹光束。
- 装饰集中于构造节点，优先空间比例、材质和光色层次。
- 本轮仅生成素材图，不继续制作书架 UI。

由内置 image_gen 生成，原始 PNG 保存在“原始素材”。完整提示词与参考关系见“素材提示词.json”。

## 结果

三张原始素材均已生成、逐张查看并保存。三图均为正面剧场：实体立柱和内幕分隔三个完整世界；每个入口内都有较大的近景、中景与远景，天色和地貌在入口边界内独立。实际生成的第二张使用略带弧角的深门洞，记录以实际图像为准。本轮没有制作 UI、录屏或动画。
