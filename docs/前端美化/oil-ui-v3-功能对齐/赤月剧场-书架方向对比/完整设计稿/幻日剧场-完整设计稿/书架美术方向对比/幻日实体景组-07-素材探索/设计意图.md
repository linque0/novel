# 幻日剧场 · 实体景组 07

## 设计主旨
同一座剧场，三组各自成立的世界布景。

针对第 06 轮反馈：取消并排三座门洞的生硬分隔，将世界变为有厚度、可落地、能投影的实体舞台景组。用错位、高差、独立地台和窄侧幕留出边界，世界内容保持独立。

## 三张素材
1. **错台景深**：星海观测城居中后置，冰原左前，山海右侧高台。强调错位与台面高差。
2. **旋台分幕**：三组曲线地台，山海居前，星海与冰原分列后方。强调地台厚度及承重关系。
3. **侧幕叠景**：冰原居中，山海与星海左右展开；斜置窄侧幕与影区区分世界。强调前中后景和灯光塑形。

三者均正面观看，统一实体舞台材质语言。幻日是上方带伴日透镜的灯光装置，以克制的光束照亮不同景组。图中不包含文字、UI 或导航。

## 素材方法与范围
- 使用 oil-ui 的构图、视觉主角和材质减法方法，配合内置 image_gen 生成。
- 输入图片只参考外部剧场实体感、正面视角、舞台地面与幕布；不保留赤月，不复制原画内部景色。
- 本轮只提供素材，不修改原型页面，不制作动画，不运行业务测试。
- 原始 PNG 另存于本目录，保留历轮。
- 本轮为方向素材探索，由主执行者看图检查，不进行独立评审。

## 检查重点
三个世界是否可辨，是否仍像平面画框；舞台比例、地台侧面与桥梁底面、根部落地、灯光投影、世界分隔及上方灯光装置的完整性。
