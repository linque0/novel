# 幻日灯场 05 · 素材探索

## 最新范围

用户要求先看素材图效果，本轮暂停书架 UI 制作，仅交付三张原创舞台美术图。

## 艺术表达

剧场是一座讲述故事的空间仪器。幻日是悬吊在剧场内的光学灯光系统；光经过透镜和少量景面折映，在深台上展开体积、地貌、尺度和空间规则不同的世界。万花筒感来自观看角度、折射和遮挡关系。

三个视角分别为高位包厢、侧台与近台口斜视。共享剧场建筑、太阳灯具与颜料、织物、细金属的材质语言，不制作三张正面拼接的风景屏。

构图采用大面积安静暗部与集中受光区。装饰集中于必要的构造节点，保持世界的主次和完整光路，避免闪粉、霓虹、宝石及满屏金饰。

素材由内置 image_gen 生成。前轮设计保留在原目录，不作为本轮最终交付。

## 本轮交付

- 01 包厢俯观：高位斜看剧场，前景包厢栏杆、深台与侧面包厢说明观看位置，呈现整体灯场。
- 02 侧台折界：从右侧舞台侧翼横看，近处幕布、镜面与地板连接远处的世界，强化错位映像。
- 03 台口入境：从近台口低位斜看，灯光装置与景物产生较强尺度反差，镜面拼接不同世界的碎片。

三图均为 1672 × 941 PNG，完整保存于“原始素材”目录。逐张查看过生成结果。提示词和参考关系记录于“素材提示词.json”。未追加书架界面。
