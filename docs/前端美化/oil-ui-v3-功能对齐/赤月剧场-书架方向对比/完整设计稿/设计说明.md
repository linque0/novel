# 赤月剧场：两套完整设计稿

用户已通过「赤月歌剧院」与「赤月戏」书架。本轮保留这两张首屏，分别扩展为完整桌面创作空间。设计基准为 1440×900；窗口变窄时保留实际字号，通过独立面板滚动容纳内容。

## 两套方向与取舍

| 页面 | 赤月歌剧院 | 赤月戏 |
| --- | --- | --- |
| 总体 | 正面镜框舞台、深绛红、雕金与象牙剧本。横向导航，老宋大题名。 | 非对称纸景、孔雀青、朱砂与乳白。左侧拱形导览，文楷题名。 |
| 书架 | 沿用中央舞台、双幕揭开、中央作品与横向剧目册。 | 沿用竖向题名、多层林景与右侧节目册。 |
| 正文 | 左侧章节册，中央有金边的象牙稿纸，右侧场记笺与引用线索。 | 左侧页边札记，中央展开的稿纸，右侧章节目录。 |
| 大纲画布 | 较为端正的剧目票签、细金连线与舞台容器。目录在左。 | 高低错落的折角纸片、弧形连接、拱形人物引用。目录在右。 |
| 文本大纲 | 带内框的剧本整页，目录与编辑区分开滚动。 | 大幅弧形纸页，目录贴在右侧，沿用手写感文楷。 |
| 设定编辑 | 左索引、中央连续节点、右关联线索，保持幕布编辑能力。 | 主折页占据左侧，索引、标签与关联集中到右侧页边。 |
| 设定详情 | 左侧大题名与正文、右侧轨道式关联图。 | 上方打开的折页、下方横向关系纸景，中心设定通过曲线连接对象。 |
| 人物档案 | 横向演员册，基本字段和小传并排，右侧大幅雕金肖像。 | 左侧拱形肖像与人物签，右侧可编辑档案折页。 |
| 人物图谱 | 深色舞台上的金框肖像，关联对象置于上方。 | 浅纸面上的错落拱形肖像，人物名录在右。 |
| 灵感 | 左札记目录、中间象牙写作笺、右侧恍然梦入口。 | 左侧错位标本墙、右侧展开详情，正文与固定操作区分离。 |
| 设置 | 左侧纵向分类、中央偏好、右侧窄幅剧本预览。 | 横向分类、左侧宽幅阅读预览、右侧排版偏好。 |

歌剧院更强调庄重、秩序与章节的登场仪式；幻戏更强调纸页层次、曲线和开放的空间。二者共享作品与字段，导航骨架、工具位置、详情构图和对象形态分别编写。

## 页面清单

每套均提供下列 10 个状态：

| 状态参数 | 内容 |
| --- | --- |
| `shelf` | 六部作品与主作品舞台 |
| `editor` | 正文、章节目录、备忘与引用 |
| `outline` | 自由画布大纲 |
| `outline-text` | 可编辑文本大纲 |
| `world` | 连续节点设定编辑 |
| `world-detail` | 设定详情与关联对象 |
| `characters` | 可编辑人物档案 |
| `characters-graph` | 人物关系图与布局切换 |
| `inspiration` | 灵感收集、编辑与插入正文 |
| `settings` | 字体、字号、行高、动画与其他偏好分类 |

例如：`opera.html?state=characters`、`nouveau.html?state=world-detail`。对比入口支持逐页切换、两版并排、单版 1440×900 实际尺寸、截图与独立动画重播。

## 交互设计范围

可操作并观察到变化：

- 单击作品进入正文；全局导航、浏览器前进后退、详情与定位往返。
- 正文、章节备忘、文本大纲、设定节点、人物字段与自定义字段、灵感文字编辑；切换页面仍保留当前会话内容。
- 章节切换和新建、章节筛选、查找替换、沉浸写作与 Esc 返回。
- 自由模块拖动、双击/右键编辑、增删模块、类型筛选、目录定位、缩放和整理。
- 设定内容/标签筛选、无结果状态、展开折叠、同级/子级新增、缩进、详情与定位。
- 人物切换、档案/图谱切换、圆形/网格布局、自定义字段、头像选择入口与人物引用卡。
- 灵感新建、筛选、选择、编辑、插入正文；字号、字体、行高的即时预览与正文联动。
- 同一设计页面独立打开、书签、阅读与历史记录的界面。

本轮是独立设计原型：编辑内容在当前页面会话中保留，刷新恢复初始内容，没有写入数据库、浏览器持久存储或真实作品文件。独立窗口使用新的预览会话。导入导出、备份、复杂连线/图谱编辑、关系选择、历史快照和 AI 对话提供界面与入口，未实现真实文件解析、持久保存、历史版本系统或模型请求；真实接入时必须复用软件已有能力，不能把这些原型入口当作业务实现。数据沿用原设计稿中的虚构作品与人物。

## 动效

- 书架保留已通过的约 1.2 秒开场：歌剧院揭幕与追光，幻戏前后纸景错速展开。之后稳定停留。
- 内页使用一次 450–650ms 的题名与工作区入场：歌剧院轻落位，幻戏纸页横向展开；信息在前 600ms 内出现。
- 画布模块依次轻移入场，图谱布局短距过渡，弹窗从操作现场短距展开；按钮和对象具备悬停、按下与焦点反馈。
- 修复按下反馈覆盖节点定位变换的问题，采用独立 `translate` 属性保留原有旋转与定位。
- 静态开关及系统 `prefers-reduced-motion` 均直接显示完成状态；没有持续旋转、闪烁或空闲大幅运动。

## 评审与减法

完成 1 轮独立视觉评审，采用「存量已有界面润色评审」，不打分。完整原始意见见 `视觉评审.md`。

已处理：幻戏灵感正文与详情双层滚动、人物动机标题孤立于底边、设定关联缺少连线；收紧章首阅读区的垂直间距；去掉关系图与设置页重复的大号卷叶；统一加深低对比度的小字。保留歌剧院横向人物册与右肖像、幻戏左侧拱形肖像与错位灵感墙。

删去或收短：正文侧栏“每一页，都是新的启程”、幻戏状态栏“一页一世界”、文本大纲“故事的骨骼”、设定详情“从这里，故事开始交会”、灵感墙“也有自己的花期”、关联栏“没有孤立的一颗星”。保留作品名、章节归属、字段名称、分类、日期和当前状态。

截图工具保留项：幕/页签眉标表示当前位置；札记编号表示对象顺序；画布中的模块是实际内容对象；灵感单侧细线表示当前项。这些均有明确用途。未修改已通过书架的构图。

## 素材与文件

- 舞台布景沿用上一轮生成的 `opera.webp`、`nouveau.webp`；书封沿用四方向设计资产，人物肖像沿用原功能对齐稿三张画像，均使用本地 WebP。
- 文字、导航、按钮、编辑字段与关系标签均为 HTML，不烘焙进图片。
- 字体使用仓库中的京华老宋体与霞鹜文楷本地 WOFF2；新页面使用完整字库，避免新题名中途回退。
- `build.py` 仅生成本目录的两套 HTML、书架数据和素材，不改已通过的原页面、原 D 版或真实应用源代码。
- 截图、200% 细节、录屏、交互记录位于 `screenshots/`、`closeups/`、`evidence/`；检查结果见 `验收记录.md`。
