# 独立视觉评审

> 本文件从 v1 原稿复制，评审对象是 v1 的十张截图；v2 的版式变化见 `重排说明.md` 与 `before-after.html`。

评审方式：按《视觉与交互评审手册》的“存量已有界面润色评审”执行，不打分。仅查看当前 1440×900 的十张 page.png、对应 report.json 和选中正文基线截图；未读实现代码、未运行测试、未查看其他制作说明。

评审基准：保留现有书架和“金屏夜梅”正文；沿用纸白、墨色、旧金的 UI 规范，允许模块图像拓展配色；北极星为“一纸一幕，每种创作任务有自己的舞台”。

## 必要修正

1. **设置／右侧排版预览的末段截断。** 纸张底部的第二段停在“上。冰凉的触感顺着指骨攀”，下方紧接“纸白 · 墨黑 · 旧金”，没有完整句尾或可辨认的续文提示。它与正文基线已有的底部渐隐不同，容易被理解为字号或行高设置导致内容裁掉。目标：预览至少以完整的可读语义单元收尾，并把示例正文与样式脚注分开。可直接缩短示例文本，不必扩大预览或遮盖更多图像。验收：在当前尺寸和当前字号下，最后一行完整可读，脚注不接在被截断的句子后。

## 布局、层级和风格判断

- **遮挡和可读性：** 除上述预览末段外，未发现文字相互覆盖、主按钮被图像遮挡或主体内容落在高频纹样上读不清的情况。大纲卡片、设定幕布、人物卷宗及灵感手记都有稳定的纸面承载文字。正文底部渐隐与选中基线一致，不列作本次缺陷。
- **构图：** 书架是立体书与远景；正文是金屏与稿纸；大纲是连线纸片；设定是壁画侧屏与层级幕布；人物是肖像与卷宗，关系态改为节点图；灵感是便笺与手记；设置是选配与即时排版样张。没有需要纠正的连续模板复读。
- **图像：** 新增大纲的蓝绿枝蔓、人物的梅紫粉羽、设置的珍珠蓝绿与旧金，已形成模块间的色彩差异。原天鹅壁画与珠宝花窗分别用于设定和灵感；新旧图像共享植物曲线、珠宝镶嵌、纸艺／浮雕层次。未看到必须重做的风格断层。
- **图像露出：** 书架景深最完整；人物关系态能看到完整鸟形与尾羽，档案态保留鸟头、羽翼和藤蔓；大纲右侧枝干、设置右侧珠母曲面仍可辨识。现有 UI 没有把所有主视觉压成看不出题材的碎边。设定与灵感作为窄幅侧屏露出，符合原图的竖向构图。
- **规范：** 书架按既定选择保留其浅底竖导航；其他模块的墨色顶栏、旧金选中状态、纸面边缘及衬线标题一致。截图中没有足够证据证明使用了规范外的字号、圆角或组件；未读变量与组件源码，不作该项实现判断。

## 可精简文字

以下均为减法建议，不是阻断交付的缺陷；删除后保留具体书名、卷宗、类别、引用对象与操作名称。

- **大纲自由画布：** “一张会改变的星图”与“所有航线，终将交会。”只表达气氛，底部又与事件卡、便签和人物引用争抢一层视觉注意力。建议删去，留出画布呼吸空间。
- **灵感左侧海报：** “尚未成形的故事，也有自己的回声。”与页头“收集尚未成形的故事”重复，建议删除其中海报上的这一句，让花窗下部纹样完整露出。
- **设置右侧：** “让文字，拥有自己的光。”没有说明任何设置结果，可删去其整条半透明文字带，让珍珠光面更连贯。
- **设置字号／行高：** “随心调整阅读的呼吸”“为段落留出思考的空隙”可删，控件名称、数值和右侧预览已足以说明效果。“用于正文编辑与阅读”“跟随系统的减少动画偏好”属于范围或行为说明，应保留。
- **书架右下：** “故事藏在纸页深处，等下一束光将它唤醒。”不指向当前作品或操作，可删；书架图像和布局按约定保留。

## 提升建议

1. **精致度：** 目前最值得处理的是设置预览的完整收尾，以及上述气氛文案的减法。修完应让预览与控件互相解释、让图像自己的材质承担气氛，无需再增加框线、数字或装饰。其他截图暂未发现需要统一的大面积对齐问题。
2. **设计感：** 现有各模块已经有独立舞台，继续保持。删除画布和海报上的气氛句时，应释放原位置并显露图像，不要填入另一句口号或新增面板。
3. **动效：** 仅看到静态截图，未看到动效，不能确认进场、状态切换、减少动画偏好或操作反馈已经通过。报告中的 animationWaitMs 只是截图等待参数，不作为动效合格证据。
