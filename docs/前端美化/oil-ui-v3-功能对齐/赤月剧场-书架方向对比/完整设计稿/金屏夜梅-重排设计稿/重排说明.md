# 金屏夜梅 · 重排设计稿 v2

> 本目录是《金屏夜梅-完整设计稿》的重排版。原稿保持在同级 `金屏夜梅-完整设计稿/`，未改动，可随时回退与对照。
> 本轮只做设计与交互原型，未修改 `src/`、数据库或 AI 链路；应用接入在重排稿确认后另起一步。

## 一、要解决的问题

1. **外壳不统一**：书架是唯一使用 84px 左侧竖栏的页面，其余模块使用 76px 顶栏，切换模块时版式骨架会变。
2. **正文无法浏览长章节**：章节被放在底部 76px 横条里，一屏只能看到 6 章，更多章节只能横向滚动；没有卷分组、字数、状态，也不能搜索。
3. **把插画当留白**：大纲右侧预留 170px、关系图左侧预留 310px，纸面与画布被压缩；人物演员表横向挤成一条；设置预览纸固定 322px，越过 300px 右栏并压到内容边距。
4. **缺少窄窗规则**：画布固定 1440px，窗口变窄时只能整体裁切。

## 二、统一外壳

10 个状态共用同一套骨架：

| 层 | 规格 | 说明 |
|---|---|---|
| 顶栏 | 76px，深墨 `#151918` | 左：妙笔 / 赤月·幻戏；中：书架、正文、大纲、设定、人物、灵感、设置；右：个人印。当前项旧金下划线。 |
| 模块条 | 86px | 模块题 + 真实上下文（书名/卷名/条目名）+ 本模块动作；按钮统一 35px 高。 |
| 底栏 | 40px | 左：完整设计稿入口；中：稿名；右：重播演出 / 静态查看。 |
| 内容边距 | 左右 32px（≤1200px 为 16px） | 纸面、布景、目录使用同一层级：布景最底，目录为深色浮层，纸面最上。 |

书架删除竖栏后，主内容从 0 开始；顶栏、模块条、底栏与正文页完全同构。

## 三、逐页重排

### 1. 书架

| | v1 | v2 |
|---|---|---|
| 外壳 | 84px 左竖栏 + 87px 浅色页头 | 76px 深墨顶栏，无竖栏 |
| 舞台 | `margin-left:84` 后 `calc(100% - 316px)`，约 1040px | 从 0 开始 `calc(100% - 316px)`，1440 下 1124px |
| 书封 / 首章卡 | 49% / 41% | 47% / 38%（随舞台宽度重算） |
| 剧目栏 | 316px | 316px，动作与行距不变 |

竖栏的 84px 全部给舞台，不新增装饰；纸景、竖排书名、书封/书脊、首章卡与剧目行都保留。窄窗下剧目栏 280px、舞台同步收窄。

### 2. 正文（重点）

| | v1 | v2 |
|---|---|---|
| 章节入口 | 底部 76px 横条，一屏 6 章，横向滚动 | 左侧 248px 章节目录，纵向滚动 |
| 稿本 | `left:246`，高 604px | `left:296`，高 680px |
| 左栏 | 158px 竖排书名装饰列 | 目录头（书名/卷名/朱印）+ 卷分组 + 搜索 + 24 章示例 |
| 右栏 | 252px 札记 | 252px 札记不变 |
| 底部 | 章条占 76px | 章条删除，稿本 +76px 全给正文 |

章节目录：

- 每行显示章号、章名、字数与状态点；当前章旧金底 + 朱线，长章名省略并保留 `title`。
- 顶部搜索按章名过滤；底部显示「共 42 章 · 156,824 字」与「＋新章」。
- 可收起为 56px 窄轨；收起后保留当前章号与上一章/下一章按钮，仍可翻章。
- 目录顶部提供 `‹ / ›` 切换；project-line 跟随稿本左缘（展开 296、收起 104），不再停留在旧稿本的 246。

### 3. 大纲

| | v1 | v2 |
|---|---|---|
| 目录 | 214px | 240px |
| 右侧空景 | `right:170`（画布右缘 1270） | `right:32`（画布右缘 1408，+138） |

画布底右控制条、左上题注、节点/连线/筛选全部保留；目录与正文使用同一套深色浮层。

### 4. 设定与设定详情

- 幕布：`248 / 1fr / 220` → `220 / 1fr / 240`。布景栏收窄 28px，目录加宽 20px，纸面净增 8px。
- 详情：`210 / 1fr / 355` → `200 / 1fr / 340`。布景栏收窄 10px，关系折景收窄 15px，纸面净增 25px；图谱与关系行更靠近纸面。

### 5. 人物档案

## 四、1080 × 900 规则

不靠整体缩放，只调整栏宽与边距：

| 位置 | 1440 | 1080 |
|---|---|---|
| 内容边距 | 32 | 16 |
| 书架剧目栏 | 316 | 280 |
| 正文章节目录 | 248 | 216（收起仍 56） |
| 正文稿本 | left 296 / 高 680 | left 248 / 高 680，右缘 1064 |
| 大纲目录 / 右缘 | 240 / 32 | 216 / 16 |
| 设定幕布 | 220 / 1fr / 240 | 190 / 1fr / 200 |
| 设定详情 | 200 / 1fr / 340 | 180 / 1fr / 280 |
| 人物肖像列 | 380（框 330×420） | 330（框 300×380） |
| 关系图 | 左 32 / 右 32 / 名册 260 | 左 16 / 右 16 / 名册 220 |
| 灵感 | 220 / 420 / 1fr | 190 / 380 / 1fr |
| 设置 | 200 / 1fr / 300 | 180 / 1fr / 260 |

`html/body` 在 ≤1200px 时由固定 1440 改为 `width:100%; min-width:0`，页面本身不再产生横向滚动。

## 五、交互原型

- 正文：`‹ / ›` 收起与恢复目录；搜索过滤；收起态 `↑ / ↓` 切换上一章/下一章（同步章号、页题与正文示例）；点击章节行切换当前章。
- 其余页面沿用原 `studio.js`：模块导航、视图切换、原型浮层、沉浸写作、重播/静态查看。
- 所有交互只发生在当前页面会话，刷新恢复初始设计内容；不读写真实数据。

## 六、验收

在 `金屏夜梅-重排设计稿/` 下运行：

```bash
node capture.mjs
```

脚本使用 Playwright（Edge channel）逐页打开 10 个状态：

- 1440 × 900：截图到 `screenshots/<state>.png`；检查 76px 顶栏、7 个导航项、无横向溢出/坏图/运行时错误、模块动作不裁切。
- 1080 × 900：截图到 `screenshots/narrow/<state>.png`；重复上述检查，并检查章节栏收起后稿本右缘不出界。
- 正文交互：目录 248 → 56 → 248，稿本 296 → 104；搜索 24 章 → 1 章 → 24 章；收起态下一章 01 → 02、上一章 02 → 01。
- 结构：书架无 `.nouveau-rail`；正文无 `.c-chapters`；章节列表 `scrollHeight > clientHeight`；稿本高 680；大纲画布右缘 ≥1400；关系图左缘 32；人物肖像列 380；设置预览纸右缘 ≤1408 且填满栏高。

最近一次结果：`PASS design v2 capture`（20 个页面检查 + 8 项交互/几何检查全部通过）。完整数据见 `capture-report.json`。

对照页与预览器另跑：

```bash
node verify-gallery.mjs
```

检查 10 个对照区块、20 张 v1/v2 截图、alt 文本、坏图、页面溢出、预览器标题/标签/素材总览与旧视频链接清理；最近一次结果 `PASS design v2 gallery`。

## 七、目录与来源

- `assets/` 是指向 `../金屏夜梅-完整设计稿/assets/` 的目录联结，不复制 71MB 素材；`studio.js`、`design-data.js` 为硬链接，与原稿共用实现。
- 因此移动或单独打包本目录时，需要重新建立联结/复制文件。
- 本目录中的 `设计说明.md`、`验收说明.md`、`独立视觉评审.md` 是从 v1 复制的记录，仍描述 v1（例如底部章条），只用于素材与评审溯源；v2 的版式以本文件为准。
- `before-after.html` 提供 v1 ↔ v2 十屏并排对照。

## 八、边界与下一步

- 未修改应用源码；若本方案确认，下一步按同一套外壳与栏宽接入 `src/`，并保留旧皮肤回退。
