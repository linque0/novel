# 金屏夜梅 · 夜戏台 v4

> 设计稿与交互原型。**未修改** `src/`、数据库、AI 链路，也未改动 v1 `金屏夜梅-完整设计稿`、v2 `金屏夜梅-重排设计稿`、v3 `金屏夜梅-重排设计稿-v3`。
> v4 沿用 v2 的版式骨架（76px 顶栏、248px 章节目录、内容线 162 / 底 65），视觉与动效层从 v3 的 `visual-v3.*` 重新起步，不叠加 v3 样式。

## 一、为什么还要做 v4

v3 已经把 1px 边框全部去掉，但用户仍然觉得“条框感没有改善”。审计后发现原因不在边框颜色，而在**几何**：

- 每屏仍是**等高栏 + 整块面板 + 面板内工具条/表格行**。`5px 6px 0` 的硬偏移背纸只是把边框换成了另一道矩形边。
- 顶栏、底栏、模块工具条是三条贯穿全屏的横杠。
- 正文的章节目录、右侧留白、设置分类、大纲目录、图谱名册都是整块暗底；行分隔、标签框、3×2 字段表让界面仍像仪表盘。
- 只有入场与 hover 动效；章节切换、人物/灵感选择、设置切页、页面跳转全是瞬间替换。

v4 因此不再加纹理，而是改**构图、层级与转场**：

> **金屏为台，折幕为场，戏牌为引，落印为选，纸页为文。**

## 二、五条硬规则

| 规则 | 做法 | 落点 |
|---|---|---|
| **场字压边** | 每屏一个巨型场字（书/文/纲/境/人/谱/灵/设），低透明度压在舞台或纸边，配竖排“第 X 场”题签；`aria-hidden` | 正文右留白、大纲画布右下、设定/详情纸角、关系图暗场、书架舞台等 |
| **折幕转场** | 模块切换时 4 扇带折纹的墨色屏风落下/升起，中央落目标场字与朱印 | 全部站内模块跳转 |
| **戏牌/票根** | 顶栏当前项是垂挂米色戏牌；章节当前项是探出书签；书架剧目是叠放票根；设置分类是竖排场签 | 顶栏、正文、书架、设置 |
| **纸上留白** | 每屏只保留一个主阅读纸面；目录/名册/分类/留白栏去底、悬浮或压到插画上；每屏至少一个主元素交叠/出血，最多两个通高面板 | 全部屏幕 |
| **落印为选** | 选择章节/人物/灵感/分类时朱印按下 + 墨晕扩散；主 CTA 切角纸牌，其余按钮文字化 | 章节、演员表、灵感、设置、关系图 |

**安静核心**：正文、输入、下拉、焦点环、滚动区域永远不旋转、不裁切；异形只给媒体、纸边和背景层。Persona 的可借鉴点是“视线引导、强对比、节奏感、转场标点”，不是把正文做成海报。

## 三、调研结论

### 3.1 Persona 系列（只学思路）

- **一条视线**：Persona 5 的界面用高对比色块、斜切与大字把视线压到当前选项。v4 把它转译为“场字 + 书签 + 朱印”，每屏只留一条主视线。
- **控制反差**：Atlus 在 CEDEC 分享里提到，最初斜切菜单“几乎无法阅读”，后来收敛了角度与数量。v4 只让标题/标签/纸边倾斜，正文与表单保持水平。
- **动效是标点**：转场、cut-in、落印只出现在“换场/选择”这类有意义节点，不在保存、输入、每次面板打开时出现。

### 3.2 其他作品与编辑设计

- **Hades**：手绘边框与角色框，但阅读区域仍然稳定；v4 保留纸面矩形，只把边框换成纸边/胶带/票根。
- **Guilty Gear**：界面风格强，但共同屏幕分区不能乱；v4 保留 76px 顶栏、章节目录、内容线，肌肉记忆不变。
- **Arknights**：单画布、浮动层、逻辑一致的转场；v4 的“纸压插画”“浮批注”“墨色关系场”借用的是层级关系。
- **Monument Valley**：留白与安静几何；v4 的正文核心不参与环境光与装饰。
- **编辑设计**：破格网格、叠放、页边批注、票根/节目单、竖排标题；v4 用它们替代等宽卡片。
- **不要复制**：满屏斜体正文、每屏一套完全不同的布局、长时间循环的环境动画、3D 人物模型、把红色当大面积底色、给输入框加异形裁切。

## 四、全局外壳：拆掉三条横杠

- **插画满屏**：`.scene{inset:0}`，内容线仍为 162 / 底 65；模块工具条改为 162px 高 + 76px 上内边距。编辑器 `.c-stage{inset:0}`，project-line 138px、book top 141、rail top 148；书架 `.frame` 铺满 900，工具栏 top 96、剧目 top 171。所有功能坐标与 v2 一致。
- **顶栏**：背景透明、去底边；当前导航项变成 44px 米色戏牌（微旋转、上缘金针、朱红小印），其余项只留金色下划线。设置屏是浅色插画，顶栏同步改为墨色文字 + 浅色雾化，不再出现深色横条。
- **底栏**：透明、去顶边，只留柔和暗色渐隐与等宽小字。
- **模块工具条**：去通栏底，改文字 + 金色圆点；仅主 CTA 保留切角纸牌。设置屏用浅色纸雾托住标题与“恢复默认”。
- **场字/场签**：JS 按 `body[data-state]` 注入，不进入会被 `innerHTML` 重建的 `settings-panel`。设置屏不放大场字，改由竖排场签承担记忆点。

## 六、动效规格

只使用 `transform / opacity`；不动画 `box-shadow/filter/backdrop-filter`；不劫持滚动；正文、输入、IME 区域静止。

| 场景 | 效果 | 时长 / 缓动 | 减少动画 |
|---|---|---|---|
| 模块切换 | 4 扇折幕落下（30ms 错峰）→ 目标场字 + “场”印 → 升起 | 300ms 出 / 340ms 入，`cubic-bezier(.05,.7,.1,1)` / `.3,0,.8,.15` | 直接跳转，无幕 |
| 首次进入 | 场字淡入、主纸上升 16px、戏牌落下、批注 30ms 错峰 | 220–700ms | 仅透明度 |
| 章节切换 | 纸页遮罩从左侧滑过，遮住内容替换；当前书签滑动；月相进度弧更新 | 340ms / 200ms | 立即切换 |
| 人物/灵感/选择 | 朱印按下 1.16→1；肖像墨色显影；阅读纸上升 | 240ms / 360ms / 260ms | 颜色变化 |
| 设置切页 | 旧内容 80ms 退、新内容 240ms 进 | 260ms | 立即 |
| 导航/悬停 | 金色下划线绘制；戏牌轻抬 | 120–160ms | 立即 |
| 大纲/关系线 | `stroke-dashoffset` 描画，最多同时 40 条边 | 350–620ms | 完整显示 |
| 主 CTA | 按下 1.5px；切角纸牌；hover 提亮 | 100–160ms | 只变颜色 |
| 对话框/Toast | 戏折展开 220ms；Toast 落印滑入 180ms | 220ms / 180ms | 淡入 |
| 环境光 | 极轻跟随光斑（0.06 透明度，rAF 节流），只作用于舞台背景 | 连续 | 关闭 |

- 落印反馈：按下时在指针处扩 66px 墨晕，420ms 消失；当前项同时做 240ms 朱印回弹。
- 书页翻动：`.v4-turn` 在稿页上从 -104% 滑到 104%，340ms；内容替换在遮罩下完成。
- 折幕：4 扇面板从 -102% 落到 0；导航等 430ms 后再跳转，确保最后一扇落完；到达页升起并在 620ms 后移除。
- `prefers-reduced-motion`：折幕/光斑/墨晕/翻页全部不渲染；跳转立即执行；入场只保留透明度。

## 七、可访问性

- **对比度**（token 计算，`capture-report.json`）：正文 9.32、导航 14.44、深底金 8.51、朱印纸字 5.14、纸上金 4.77、纸上朱红 4.81、关系文字 6.20、设置标题 11.24、图谱名册 8.89、样张 8.77。
- **焦点**：2px 纸色外环 + 4px 深色托底；顶栏、章节目录、设置场签、演员表、关系名册均保留矩形热区。
- **减少动画**：`matchMedia` + CSS 双保险；路线跳转不等待动画，Spotlight 不创建，入场类不添加。
- **静态查看**：`[data-static]` 后隐藏 Spotlight、墨晕、翻页与折幕，所有动画停止。
- **1080**：无横向溢出；设置场签回退横排；预览回栏；人物字段两列；大纲节点重排且连线按 viewBox 重算；编辑器目录 216 / 稿本 816；书架剧目 280。
- **中文排版**：正文 19px / 2.05，行宽约 30–40 字；标题字距 4–9px；正文不倾斜、不裁切。

## 八、验收

```
node capture-v4.mjs
PASS night-stage v4

node verify-gallery.mjs
PASS night-stage v4 gallery
```

`capture-v4.mjs` 覆盖：

- 10 屏 × 1440 / 1080 截图（`screenshots/` 与 `screenshots/narrow/`），外加 `curtain.png`、`page-turn.png` 两个中间帧。
- 无溢出、坏图、运行时报错；header 76 / footer 40 / nav 7；内容线 162（书架 96、正文 141）。
- 顶底栏背景透明；所有主要表面 `border-width:0`；`.paper/.c-book/.dossier/.settings-paper/.preview-paper/.idea-paper/.plot-node` 无硬偏移阴影。
- 真实交叠：人物肖像 × 卷宗、设置样张 × 表单、灵感阅读纸 × 便签、设定纸 × 插画、书架续写票 × 书封均 > 0。
- 大纲 6 个节点在画布内；连线 `viewBox` 与画布宽度一致；1080 仍显示连线。
- 折幕在跳转前出现、到达后移除；翻章触发 `v4-turning`；设置切页、人物/灵感显影、对话框、Toast、图谱描线全部触发。
- 焦点 ≥2px；减少动画下无 Spotlight/无 `v4-motion`/时长 0s；静态查看隐藏环境光。
- 1080：设置场签横排、预览不越界、编辑器 216/248、人物 330、关系图与灵感不溢出、动作区不裁切。

`capture-report.json` 的 `fail` 为 `[]`。

## 十、边界

- 这是设计稿与交互原型，不接真实数据；`src/`、数据库、AI 链路未动。
- v1/v2/v3 原样保留；v4 可单独打开、单独回退。
- 素材目录使用 Junction；`studio.js/design-data.js/rework.js` 为小文件副本/硬链接，未改业务逻辑。
- 若确认视觉方向，下一步才是把 `visual-v4.css` 的 token/结构规则按同一 DOM 接入应用；本轮不做应用集成。
