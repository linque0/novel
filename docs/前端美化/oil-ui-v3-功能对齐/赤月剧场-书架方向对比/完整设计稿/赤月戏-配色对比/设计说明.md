# 赤月戏：配色首屏对比

## 本轮范围

用户希望先看三套配色各一个界面，再决定全套设计稿的最终颜色。采用当前写作界面作为固定样本，1440 × 900；章节正文、中文字体、字号、非对称折页排布和拱形控件保持一致。本轮为静态设计稿，不扩展到其他页面，不增加动画或业务交互。

1. **月白 · 墨紫 · 香槟金**：月白阅读区，墨紫框架与主操作，香槟金用于花饰、书页星标和上沿细线。推荐方向，兼顾明亮阅读和剧场气氛。
2. **冰白 · 雾蓝 · 银铂**：冰白阅读区，雾蓝界面层级，银铂装饰。整体更通透、清冷。
3. **曜黑 · 鸢尾紫 · 月银**：紫黑舞台与深紫阅读区，鸢尾紫选中态，月银装饰。夜间幻戏感最强。

## 交付

- `style-explorer.html`：离线配色对比入口，支持并排、单张及实际尺寸查看。
- 三份以英文配色 ID 命名的 HTML：可独立打开的静态页面。
- `screenshots/`：三张 1440 × 900 首屏。
- 原完整设计稿保留，最终选择后再统一其他页面、主视觉素材及演出光色。
