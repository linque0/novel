1. **赤月歌剧院**：丝绒镜框、中央台口、雕金与揭幕追光。推荐从这一版开始。
2. **赤月戏**：彩绘纸景、竖排题名、花饰与前后景错层。
3. **先锋旋转舞台**：红蓝银黑、悬吊景片、偏轴转台和灯阵。

对比页可离线打开。在「单张」模式查看实际尺寸；点击「可操作」进入动画预览，底部可重播演出或切到静态。也可以直接打开各独立页面。

本轮只交付三种书架设计方向，作品数据为既有原型的虚构内容。搜索、选书与动画控制可以演示，其余模块入口仅呈现外观。选定方向后再扩展其他页面。
