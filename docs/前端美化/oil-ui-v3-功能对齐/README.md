# 小说工坊 · 第三轮功能对齐设计稿

**后续皮肤接入与前端重置要求：** 以设计稿还原整体布局、模块卡片、UI 样式、字体大小和界面排版；完整保留原版功能，设计稿未展示或表现不同的实际功能也应按同一美术语言同化，并保证成熟、顺滑、符合使用习惯的操作体验。统一实施与验收口径见 [功能对齐说明.md](功能对齐说明.md)。以下“本轮”均指第三轮独立原型制作的历史范围。

本轮只修改独立设计稿。四种美术方向沿用第二轮：A 引力书舱、B 电光剪辑室、C 琉光画境、D 赤月剧场。书架、灵感、设置已获用户通过，正文也沿用。本轮集中调整大纲、设定、人物，按原软件功能基准恢复结构与操作入口。

打开 [总览](index.html) 切换七个主界面及三个补充视图，共 40 个评审状态；点击截图进入可操作原型。[Oil UI 对比](style-explorer.html) 支持实际尺寸查看。运行 `python -m http.server 8880 --bind 127.0.0.1` 后访问 http://127.0.0.1:8880/ 。直接打开 index.html 也能离线查看截图。

## 本轮的三个变化

- 大纲：左侧模块目录与类型过滤；主区恢复文本/自由画布双视图，含容器、事件、便签、引用卡、文本框和章节锚点。属性编辑以双击编辑或右键操作展开，释放画布面积。
- 设定：默认连续的幕布节点编辑，支持目录定位、内容/标签搜索、折叠、同级/子级及缩进。用户认可的「星图系统」美术编排放进独立详情页，保留返回、面包屑、原节点定位、关联关系、关系图谱与子条目。
- 人物：默认列表 + 可编辑档案，保留姓名、角色定位、别名、头像、标签、自定义字段、人物关系、跨模块关联与小传。新版肖像作为档案头部美术；关系图独立切换，保留筛选、布局、缩放与人物详情入口。

完整原版组件对照与边界见 [功能对齐说明.md](功能对齐说明.md)。只读核对组件的哈希见 software-readonly-baseline.json。本轮没有修改软件源码、数据库或应用配置。

## 原型范围

使用虚构内容。视图切换、节点折叠/目录定位/搜索/同级子级/缩进、字段增删与编辑、详情往返、人物图谱、模块编辑浮层、缩放及画布设置可以演示；状态留在预览会话。图谱布局中的圆形/网格用于比较排布；导入、持久化、复杂自由连线/吸附/拖拽、删除确认、头像文件、真实 AI、拆窗只展示设计入口，不连接原应用。页头已保存为状态示例。

素材沿用第二轮原创生成 PNG 与项目字体子集，详见 [assets/SOURCES.md](assets/SOURCES.md)。源文件为 app.js / aligned.js / style.css / aligned.css / data.js，build.py 生成四版 HTML 与 manifest。原型不依赖原软件运行。

## 验证

1440×900 桌面视口。修订的六种状态在四个方向各取证一次，含遮字图与入场录屏；已通过的四种主界面截图沿用第二轮。默认做法提示中的「画布内模块/容器」表示实际可编辑对象和真实归组，属于本轮用户明确要求保留的原版功能结构，不是装饰性嵌套卡片。层级目录折叠后的行数为数据状态，不能用截图数量推断节点丢失。
