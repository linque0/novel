# 小说工坊 · 第四轮双风格设计稿

仅修改独立设计稿，不修改小说工坊软件。沿用第三轮已经与原软件对齐的功能结构，新增 E / F 两种美术语言，每版包含书架、正文、大纲、设定、人物、灵感、设置，以及大纲文本、设定详情和人物关系图，共 20 个状态。

本轮不调用图片生成服务，也不使用旧版书籍封面或人物肖像。作品通过题名、编号、纸页和目录表达；人物使用姓名首字标记。这些是 UI 元素，不是生成插画。

## E · 铬蓝索引

北极星：把长篇创作变成一套精密而清晰的出版索引，每部作品都有自己的位置。

结构来自创作者管理多部长篇时的作品目录。银灰台面、细网格、等宽编号与钴蓝当前页组成主视觉；书架左侧六部作品完整呈现，右侧选中作品提供续写入口。顶端水平模块导航，工具无衬线，题名与正文老宋体。强调色用于当前作品、当前模块、选中对象与主操作；字体、关系和层级仍保持原版可编辑语义。

色彩：底色 #E9E9E6、表面 #F8F8F4、墨色 #202526、辅助字 #58626A、钴蓝 #1E40D1、选中底 #DDE5FD、描边 #C1C6C9。银灰呼应排版台面，钴蓝取作品数据既有的蓝色，把注意力留给正在编辑的故事。没有悬浮海报或插画背景。

字体：工具标题微软雅黑 27–31px，作品题名老宋体 22–51px，正文老宋体 18px/1.95，编号 Consolas 13px。硬边 0–2px；选中对象短投影，其他层级用线与留白。

动效：咔嗒式按下 1px，目录/选中页首次进入 420–450ms，模块切换沿用短视图过渡；高频输入立即生效。

## F · 紫幕折页

北极星：让故事像一叠被展开的手稿，纸页有层次，编辑有秩序。

结构来自小说草稿与资料页的展开。侧边垂直导航、窄作品目录、大面积淡紫手稿页；书架以题名、章节片段和续写按钮构成一张展开的作品，而非封面。灵感页用四张轻叠的想法页与正文、创作助手并列；人物仍是可编辑档案，正文留在清晰浅纸面上。

色彩：李紫底 #211B2A、表面 #2D2637、浅纸 #EADFF1、墨色 #34243D、主字 #F1E9F4、辅助字 #C0B2CA、强调 #D8B1F2、选中底 #45334F、描边 #5A4966。颜色取创作时“夜幕—展开手稿”的关系，而非紫色发光背景。没有弥散光晕、粒子与霓虹轮廓。

字体：题名老宋体 34–66px，正文老宋体 18px/1.95，姓名字标文楷；工具无衬线 13–14px。纸页一角 20–36px，其他角 3–5px；仅书架、灵感页保留浅角度层叠，工作区不倾斜，避免影响编辑。

动效：纸页首次展开 520ms，目录晚 60ms 接入；按钮按下 2px，预览纸面和浮层短滑入。开启减少动态效果后全部直接到位。

## 功能基准与边界

原版模块布局以第三轮对齐说明和只读源码为准：大纲自由模块/容器及文本双视图；设定幕布为默认、独立详情为补充；人物列表与编辑档案为默认、关系图独立切换。没有把编辑工作区改成纯展示海报。

目标视口 1440×900 桌面。独立 HTML 原型保留上轮演示交互，数据只存在预览会话。文件操作、复杂自由连线/拖拽/吸附、持久化、真实 AI、拆窗等仅呈现入口。本轮不写入原应用服务，不安装产品依赖。

本轮基准来自现有软件工作区及用户认可的第三轮结构；未引入新外部产品的视觉规范。前四版为已交付成果，本轮单独目录保存，不覆盖。
