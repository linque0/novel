## 2. 顶栏：排序 → 功能入口

原来顶栏是「书架 / 最近 / 合集 / 草稿」——那是在给书架换排序。现在改成**应用级功能入口**，
与 `src/components/app-navigation.js` 的 `APP_NAVIGATION` 对齐：

| key | 标签 |
|---|---|
| shelf | 书架 |
| chapters | 正文 |
| outline | 大纲 |
| lore | 设定 |
| characters | 人物 |
| snippets | 灵感 |

行为：

- 点「书架」回到封面流；点其它项进入该模块的占位态
- 占位态：背景继续流动，中央是宋体大字模块名 + 一行说明 + 「回到书架」
- 顶部计数胶囊（全部 · 12 / 12）只在书架态显示
- 参数：`?module=outline` 可直接进占位态截图

## 附：v8.1 修掉的一处真实 bug

封面文字发暗不是颜色问题，是**层级问题**：玻璃里的压暗层用的是 `.glass::after`，
伪元素排在所有子元素之后绘制，等于给文字盖了一层灰纱。

修法：画面 `z-index:0` → 压暗/柔光 `z-index:1` → 所有文字 `z-index:2`。
改完书名是真正的纯白（截图 `01-shelf.png`，局部见发布说明）。
