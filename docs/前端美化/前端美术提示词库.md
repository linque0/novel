## 1. 美术方向总纲（master prompt，所有下游提示词的母本）

**中文：**

> 为一部中文小说工坊桌面应用设计丛书封面海报系统：瑞士国际主义编辑海报 × 日文展览海报 × Fitzcarraldo 丛书纪律。严格双色制——克莱因蓝 #002FA7 满地配象牙白 #FBF9F3 衬线书名（虚构），或象牙底蓝字反相（非虚构）；仅雪松绿 #2F5D50 配麦金 #E8C989 一个备用色组。2:3 竖版，极端字号对比（78px 巨字 vs 6.5px 微标），思源宋体 / Playfair Display，未涂层棉纸颗粒 2.5%，letterpress 印刷质感，零投影、零彩虹渐变（仅允许同色相明度阶），大留白，四角微信息标 + 底部编号锁定行。张扬在封面，纪律在系统。禁止：古风堆叠、3D 斜面、发光字、第三种色相。

**English（Midjourney / Flux 用）：**

> Swiss editorial book-poster system for a Chinese novel-writing desktop app, Fitzcarraldo series discipline. Strict two-color palette: Klein blue #002FA7 field with ivory #FBF9F3 serif title (fiction), or ivory field with blue type inverted (non-fiction); one alternate pair only: cedar green #2F5D50 with wheat gold #E8C989. 2:3 vertical format, extreme type-scale contrast (78px giant character vs 6.5px tracked micro-labels), Noto Serif SC + Playfair Display, uncoated cotton paper grain at 2.5%, letterpress print feel, no drop shadows, no rainbow gradients (same-hue value steps only), generous negative space, corner micro-marks and a bottom series lock row. Expressive on the cover, disciplined in the system. No Chinese-style ornamental stacking, no 3D bevels, no glow, no third hue.

**参数习惯**：一律 `--ar 2:3`；`--stylize 100–150`（再高模型会自作美观化）；生成后**必须**过 §5 的 duotone 映射后处理——不要相信模型能直接命中十六进制色值，色彩纪律由 gradient map 强制执行，不由生成端保证。

## 2. 封面/海报风格提示词（P1–P5 各一组，按体裁选轨）

**体裁总分流**（承接 v9 矩阵）：虚构默认 P1/P3；诗集别藏 P4/P5；实验短篇集 P2。

### P1 巨字立骨（《蜃楼》×《劳伦斯》）

> 编辑海报构图：单个巨大中文衬线字占据画面上部三分之二，顶缘出血被裁掉半个字，画面只剩左下与右下 6.5px 级微信息块，大面积留白，克莱因蓝底象牙白字，纸张颗粒，无渐变无投影。参考：《蜃楼》封面与《阿拉伯的劳伦斯》海报的巨型首字母锚。

EN: `Editorial poster: one giant Chinese serif character occupying the upper two-thirds, bleeding off the top edge (half the character cropped), only 6.5px micro info blocks remaining, vast negative space, Klein blue field, ivory type, paper grain, no gradient no shadow --ar 2:3 --stylize 150`

### P2 解构笔画（《山海亂》）

> 解构主义中文排版海报：笔画脱位、单字散落浮空、字大可撑破版面，三组轮换的确定性位移与旋转，穿插一两根 floating 笔画细线，包豪斯几何混达达拼贴气质，双色，riso 错版质感。参考：《山海亂》封面。

EN: `Deconstructed Chinese typography poster, detached strokes, floating characters breaking the frame, deterministic displacement in three rotating groups, one or two floating stroke hairlines, Bauhaus geometry meets Dada collage, two-color only, riso misregistration texture --ar 2:3`

### P3 光栅错层（Dust in the Wind）

> riso 错版印刷海报：同一段文字复制三层、横向错位 3–4px、扫描线切带、麦金与象牙两个偏移色，主层永远完整可读，动势而不伤读，纸质颗粒。参考：Dust in the Wind 2024 故障感海报。

EN: `Risograph misprint poster: same text in three offset layers, 3-4px horizontal displacement, scanline bands, wheat gold and ivory offset inks, main layer fully legible, print registration feel, paper grain --ar 2:3`

### P4 几何线描 + 双语锁定（《檀香刑》）

> 文学出版风封面：单一 weight 连续线描几何插画（圆 + 水滴四边形 + 斜线 + 一枚实心点）压场上部，标题中文加拼音双语居中锁定，一句引文小字补文学性，雪松绿底麦金线描，纸张颗粒。参考：《檀香刑》封面几何线描。

EN: `Literary hardcover cover: single-weight continuous line geometric illustration (circle, teardrop quadrilateral, diagonal, one solid dot) anchoring the upper half, bilingual title lockup with pinyin below, one-line quote, cedar green field with wheat gold line work, paper grain --ar 2:3`

### P5 渐变海境（岛の眺め）

> 日式展览海报：同色相三阶渐变海面（深到浅），天际线一道，标题对半切分两列竖排分置左右、下列下沉 28px 成夹岛构图，中间一个拉丁词作渡，底部编号锁定行，纸张颗粒。参考：まなじの島の眺め。

EN: `Japanese exhibition poster: same-hue three-step gradient sea, single horizon line, title split into two vertical columns left and right with the lower column sunk 28px, one Latin word bridging the center, series lock row at the bottom, paper grain --ar 2:3`

## 3. 排版提示词与规格（五层制 + 字号阶 + 字体双轨）

**提示词（描述给图像模型时附加在风格提示词后）：**

> 极端字号对比：主标题 78px，次级信息 21px，微标 6.5px 字距 0.26em 全大写；相邻层级字号比不小于 1.5 倍；标题与微标的字号跳变不小于 12 倍；五层信息封顶，不加第六层。

**规格表：**

| 项 | 值 |
|---|---|
| 字号阶（√2 近似） | 78 → 52 → 34 → 21 → 13 → 8 → 6.5 |
| 巨字:微标跳变 | ≥12 倍（「海报感」刻度尺，v9 已确立） |
| 字距 | 巨字 .12em；竖排书名 .2–.32em；横排小字块 .1em / line-height 1.65；微标 Playfair uppercase .26em |
| 边距 | 左右 9%（15px @168px）；上微标带 13px；底锁定行 12px |
| 五层制 | ① 巨字锚 ② 书名 ③ 拼音/引文 ④ 作者圆印 ⑤ 锁定行——禁第六层 |
| 字体双轨（L2 待定项） | 虚构/实验款 → **得意黑 Smiley Sans**（斜势海报张力，v6 已选型，OFL 保留名「得意/Smiley」原样嵌入不受限）；文学/别藏款 → **思源宋体 600**（v8-v9 现行骨架）；拉丁微标恒 Playfair Display |
| 对齐 | 巨字光学出血（top 负值）；微信息块右对齐共享「信息柱」；圆印与锁定行共享底轴 |

## 5. 色彩提示词与纪律

**提示词（母本附加）：**

> 严格双色：一个主色相加一个纸底色，另组仅雪松绿加麦金；每色相展开同色相五阶明度阶；金色面积小于 5% 且只出现在雪松组；禁纯黑 #000 与纯白 #fff（用 ink #1E1E1E 与象牙 #FBF9F3 代替）；纸张颗粒叠加不超过 3%；任何位图母题必须先做双色调映射再上封面。

**后处理执行链（成熟度的真正来源，不由生成端保证）：**

1. 生成图去饱和 → gradient map 到色板三色（暗部→主色最深阶 / 中间调→主色 / 亮部→ivory，雪松组亮部可用麦金）；
2. 阈值化为 3 个明度值（保住 letterpress 的「色块感」）；
3. 叠纸纹颗粒 2.5%（multiply）；
4. 色相计数验收 ≤2（金仅雪松组）。

## 6. 图像资产生成提示词（补 L1 图像锚，六类资产）

### 6.1 纸纹颗粒（先做，全款受益）

> macro photograph of uncoated cotton paper, subtle fiber texture, even diffuse light, warm ivory tone, seamless, no pattern

EN 同上。后处理：去饱和至近灰、叠 2.5% multiply。**基线方案仍是内联 SVG feTurbulence（零依赖）**，位图纸纹仅作为更富纤维感的可选增强层，须登记来源。

### 6.2 双色调摄影母题（雾/海/夜窗，P1 下半部或 P5 背景）

> 极简摄影：雾中海面地平线，大面积空天空，双色调印刷（克莱因蓝暗部 + 象牙白亮部），高对比，颗粒感，无文字，risograph 美学。

EN: `Minimal photograph of a foggy sea horizon, vast empty sky, duotone print in Klein blue shadows and ivory highlights, high contrast, film grain, no text, risograph aesthetic --ar 2:3`

放置：P1 底部信息带之下、P5 下半部。必须过 §5 四步后处理链。

### 6.3 按作品题材生成母题（公式，供将来「自动封面」功能）

> [题材意象，如：雾中港口 / 机械心脏 / 星尘] + 极简几何或摄影构图 + 双色调（克莱因蓝 / 象牙白）+ 无文字 + 纸纹 + --ar 2:3

纪律：生成图须过四道关——**去字、双色映射、颗粒 ≤3%、无第三色相**；不过关不进封面层。母题只做「锚」，不做「主角」——主角永远是巨字。

### 6.4 riso 错版纹理（P3 专属增强）

> risograph misprint texture sheet, offset ink layers, faint registration marks, paper grain, two colors only

后处理：降到 8% 透明度叠于 P3 主层之下，强化「印刷错位」的可信度。

### 6.5 烫金/专色细节（雪松组）

> matte paper with subtle gold foil stamping, soft metallic sheen, macro

CSS 替代（推荐，零资产）：圆印描边与锁定行细线用麦金渐变 sheen（`linear-gradient` 高光带），面积 <5%。真烫金位图仅在做「实体书导出预览」时才值得。

### 6.6 线描插画升级（P4）

P4 现有 SVG 已成立；成熟化只做三件事：stroke-weight 三档化（0.8 / 1.4 / 2.2）、每体裁一组弧/斜线变体（海=弧线、机械=斜线、星=圆点阵）、实心点恒一枚。仍走内联 SVG path，零图片依赖。

## 7. 动画效果提示词与 CSS 规格（补 L3）

**原则**：只动 transform / opacity（v1 性能红线）；封面是唯一允许 >240ms 编排的界面位置；全部尊重 `prefers-reduced-motion`；动画必须过 88px 检验——只在 ≥120px 尺度可读的动画，用尺度门控（容器查询或 JS）限制生效范围。

**提示词（向图像/视频模型描述分镜时用）：**

> 封面揭幕：巨字自上缘 clip-path 划入（320ms），四角微标随后 80ms 错峰淡入，底部锁定行细线自左向右 draw-in，作者圆印最后落款 scale(.92)→1；悬停时书脊一道光扫过；待机时扫描带极缓慢呼吸。全部缓动一致，无弹跳。

**七个动画规格：**

| # | 动画 | 规格 | 令牌 |
|---|---|---|---|
| A1 | 上架交错入场 | opacity 0→1 + translateY(6px)→0，30ms 步进 | v1 既有 |
| A2 | hover 抬起 | translateY(-2px) + 书脊光扫（伪元素 gradient translateX，400ms，仅 hover） | `--ease` |
| A3 | 巨字揭幕 | `clip-path: inset(0 0 100% 0)` → `inset(0 0 0 0)`，320ms ease-out | 新 `--dur-cover: 320ms` |
| A4 | 微标错峰淡入 | 每层延迟 +80ms，opacity 0→.72/.8 | — |
| A5 | P3 扫描带呼吸 | translateX ±3px，8s infinite alternate；reduced-motion 关闭 | — |
| A6 | 圆印落款 | scale(.92)→1 + opacity，200ms，挂载时一次 | — |
| A7 | 主题切换封面过渡 | 双层叠加 opacity 交叉淡入 200ms（不走 background-color transition，守住红线） | — |

**reduced-motion 降级**：A3/A5/A6 直接静态；A1–A4 统一降为 opacity 200ms。

## 8. 负面提示词（全维度禁用清单）

- 古风堆叠、大面积水墨 diffuse、祥云、印章滥用（用户已判「粗糙」）
- 3D 斜面、金属字、发光字、外投影、bevel 浮雕
- 彩虹渐变、第三种色相、大面积金色
- 纯黑 #000 / 纯白 #fff
- 网格底纹、斜向速度线（P3 之外的故障滥用）
- 中文斜体、标题字重 <500、字距过密
- 未做 duotone 映射的摄影原图直接上封面
- 任何 CDN / 外部链接依赖

## 9. 验收 gate（新资产进系统前的检查）

1. 色相计数 ≤2（金仅雪松组且 <5%）；
2. 88px 实截：巨字第一视觉、编号行可读或已按规则退化为「01—」；
3. 颗粒 ≤3%；
4. 巨字:微标字号跳变 ≥12 倍；
5. reduced-motion 下无残留动效；
6. 资产 provenance 登记（来源 / 提示词 / 授权 / 放置位）——延续零 CDN 与开源授权纪律；
7. 包体：新增位图资产总量 <2MB；能走 SVG 的优先 SVG。

## 10. 落地顺序建议

1. **先补 L2 质感层**（不生成任何图）：封面颗粒 2.5% + 同色相明度阶 + 巨字字体双轨定稿——零资产成本，观感收益最大；
2. **再补 L1 图像锚**：只做 6.1 纸纹与 6.2 雾海母题两张，P1/P5 各置一位；
3. **最后补 L3 动效**：A3 巨字揭幕 + A2 hover 光扫先行，其余随书架交互迭代。
