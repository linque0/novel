# 引力书舱：工作台与独立窗口接入

2026-10-16。本批以用户提供的七张界面图为视觉基准，将已接入书架的引力书舱扩展到正文、大纲、设定、设定详情、人物、灵感及设置。它是实际软件中的可切换皮肤，沿用原有组件、编辑器、存储和操作处理。原版工坊与三种原配色继续保留，已有设计稿未改动。

## 使用与视觉方向

在书架或设置 → 外观 → 工坊皮肤选择“引力书舱”。进入作品后沿用该皮肤；底部胶囊导航切换模块。顶栏“更多”保留拆窗、章节书签、沉浸、阅读及切回原版入口。设置继续使用独立窗口。

以深海军蓝、铜橙、宋体标题和细分隔线形成统一的创作舱。正文是视觉中心，其他模块使用开敞布局，避免每个区块套一层卡片。书架沿用已有舞台；本批未生成封面、头像或其他图片，仅在设置阅读预览中复用已有星球素材。人物没有头像时显示姓名首字。

## 实现边界

- `src/skins/registry.js` 为 gravity 登记 `shelf`、`work`、`panel`；缺失／非法值或未知页面回退 original。沿用 `appconfig.skin` 和窗口间偏好同步，不改变数据库结构、接口或 IPC。
- 配色主题与皮肤分开保存。引力皮肤通过页面属性应用变量与样式；切回原版后恢复原主题。body 同步皮肤属性以覆盖传送到外部的菜单和弹窗。
- 新样式集中在 `src/styles/skins/gravity-workbench.css`。只为表现加入结构、标签及少量视图状态，不复制创作业务逻辑。主窗口与原生面板共用同一套业务组件。
- 任务启动按钮移入顶栏，仍打开原任务表单；恍然梦完整对话与任务面板、独立窗口和锁定机制继续使用原实现。灵感快捷指令不会自动发送模型请求。
- 主窗口检查 1440×900、1400×880、1080×680。独立模块面板另检查 800×500；该宽度灵感目录改为单列，人物表单改为顺序排列。阅读内容和长表单可滚动；保存的侧栏宽度在窄窗口中视觉收缩，偏好值不被改写。
- 导航使用短时颜色过渡，保留原交互反馈；不添加持续的大幅运动。减少动画媒体偏好会停用引力界面的动画和过渡。保留可见键盘焦点。
- 删除了引力界面重复的任务提示和目录说明，但保留原操作按钮、对象名称、归属信息及保存状态。设置没有加入缺少业务实现的行高、首行缩进等控件。

### 大纲页对齐设计稿（本轮补充，oil-ui-v3 方向 A）

左栏「模块条目」改为设计稿口径：标题行「模块条目 · N 项 · ⚙」，筛选 chip 行在本轮复查中恢复，支持全部原类型及自定义类型；普通窗口换行、800px 独立窗口使用同源类型下拉，⚙ 展开浮层、自定义类型的新建/删除照旧；两列新建按钮 7px 间距、末项通栏、文案「＋ 事件」；模块行最小高 49px、细分隔线、行首铜色圆点（容器为描边方点）、行尾类型文字（事件／便签／引用卡／章节锚点／卷），行操作改为常显更多菜单，辅助类型及关联计数排在次行，名称优先；底部断线开关保留，计数上移后显示「点击条目定位画布」。

页头与画布工具条按钮统一为 6px 圆角细边矩形（替下 20px 药丸与描边方钮），模块统计与缩放读数 13px 等宽次级色。画布卡片新增顶部类型行（13px 次级色 + ⋯ 打开既有节点菜单，文本框按设计稿不显示），标题改宋体 23px（便签、引用和章节锚点 20px）；事件卡 1px 细边 + 柔和投影；便签不对称圆角 1px 1px 13px 1px ；本轮取消动态倾斜，避免悬停时移动点击目标；引用卡与章节锚点改实线卡（虚线胶囊与左侧粗条取消，状态点与字数行保留）；文本框为无框无底裸文本（铜色宋体）；容器 1px 描边 + 3% 分支色底、头部常规字重与纯文字计数。

引力皮肤新增放大卡片档位（事件 210×130、便签 196×130、引用卡／锚点／卷 190×130、文本框 240×110、容器基准 300×180；容器子项网格步长 226×150），只换布局口径，原版与「紧凑」不变；形状变体、缩放手柄、关系卫星、连接点与连线塑形均保留。文本框默认尺寸随皮肤（原版 180×64）。

## 验证与证据

所有写入验证在开发配置（`npm run dev`，CDP 9222）或隔离的 `gravity-skin-verify` Electron 配置（CDP 9223）上运行；脚本按默认资料目录名判定「非默认配置」并打印实际写入目录，创建临时作品、结束后软删除并恢复偏好。不要对日常用户配置运行这些集成脚本。

大纲页设计稿对齐的验收脚本为 `node tools/gravity-outline-verify.mjs`（27 项，含原版对照：筛选 chip 行、药丸按钮与旧卡片档位只应存在于原版），端口走 `CDP_PORT`（默认 9223，`CDP_PORT=9222` 直接跑 dev 实例）。

开发服务在 5173、独立 Electron 调试端口在 9223 时运行：

```powershell
node tools/gravity-compile-verify.mjs
node tools/skin-unit-verify.mjs
node tools/skin-verify.mjs
node tools/gravity-workbench-verify.mjs
```

模块集成验证覆盖：原版／引力的控件和编辑字段对齐；热切换保持编辑器实例、文本和选区；实际任务表单；阅读与沉浸；自由画布与人物关系图；人物编辑保存；设定详情层级与搜索浮层；详情内书签／底部导航跳转；灵感进入原对话和转设定；最低窗口按钮可见且可点击；原生拆窗锁定／关闭恢复；设置页、偏好广播，以及关闭作品后重新读回编辑内容。

书架集成验证覆盖原有六种封面、新建／编辑／默认分卷、搜索、打开／Enter、菜单隔离、软删除、空态、多作品可达、皮肤保存失败、重载读回与三种原配色。另通过 18 个 Vue 组件及皮肤 CSS 编译检查，以及原有预设 16 项、内容投影 13 项、任务边界 15 项单元检查。

独立代码与视觉复核发现并修正了最小窗口灵感助手被底栏遮挡、详情边缘露底、文本大纲底部越界、灵感独立窗口卡片过窄，以及详情内书签跳转未退出详情等问题。验证脚本已加入相应边界断言。

最终模块集成检查连续三轮通过；书架集成、皮肤契约、组件编译及上述 44 项原有单元检查均通过。最小独立窗口灵感卡片修正后已再次通过独立视觉复核。

实际截图由模块验证脚本生成，位于仓库的 `tools/_gravity-work-*.png`（本地验证产物）：`chapters`、`outline`、`outline-canvas`、`lore`、`lore-detail`、`characters`、`snippets`、`settings`；`*-1080` 为最小主窗口，`panel-*-800` 为最小独立模块窗口。截图使用隔离配置中的测试作品，不代表用户作品内容。

本批未改后端、未新增皮肤种类，也未生成安装程序。未配置模型服务，因此没有实发远程模型请求；验证止于原任务／对话入口和输入传递。
