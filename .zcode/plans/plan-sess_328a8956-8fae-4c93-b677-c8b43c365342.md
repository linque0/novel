# 关系链接（双链改名）+ 条目级关联关系 + 设定详情页与关系图谱

## 一、总览与兼容底线

三项交付：
1. **改名**：「双链」→「关系链接」（行内文内链接，机制不变，只动界面文案/注释/文档）。
2. **条目级关联关系**（新数据）：在 设定↔设定、设定↔人物 之间设置「类型 + 描述」的关系（如 人物—属于→地点），双向展示、互相跳转；设定行尾出现关系卡片，悬停显示具体关系（图二样式）。
3. **设定详情页**：双击设定条目进入全屏详情页（面包屑 + 标题 + 关系列表 + 可拖动关系图谱 + 子条目树，图一风格）。

**兼容底线（不动）**：存量数据标记 `data-dl-target` / `data-dl-title` / `class="dl-link"`、TipTap `dlLink`、`[[标题]]` 令牌**不改名**——否则用户已写的正文/设定/大纲里的全部链接失效；`relations` 表与人物关系图不动。改名只发生于界面文案与注释。

**面板/组件命名**：`LoreRelationPanel.vue`（设置面板）、`LoreDetail.vue`（详情页）、`LoreGraph.vue`（图谱）、`LoreRelRows.vue`（共享关系行）、`services/relation-kinds.js`（类型预设）。

## 二、数据层

**1) Dexie v12 新表**（`src/db/database.js`，与 v8 同款增量声明）：
```js
db.version(12).stores({ lorelinks: 'id, workId' })
```
行模型（行数少，随作品全量载入内存，同 mubu 模式）：
```js
{ id, workId, fromKind:'mubu'|'character', fromId, toKind, toId,
  label,          // 正向类型（from 视角），如「位于」，≤12 字
  reverseLabel,   // 反向显示名（to 视角，如「包含」），'' = 同 label
  description,    // 描述（图二右侧灰字），≤120 字
  color,          // '' = 按类型 hash 取色（复用 tagcolors）
  createdAt, updatedAt }
```
单向存储、双向展示；同一 (from,to,label) 去重；禁止自连；删除 = 硬删（同 relations 表惯例）。

**2) `src/db/repo.js`**：`loadWorkBundle` 增载 `lorelinks`；备份表清单（第 170 行）加入 `'lorelinks'`（导入走 `db.tables` 全清全建，自动覆盖）。

**3) `src/stores/work.js`**：
- state：`lorelinks: []`；`open()` 装载；`loreGraph: {}`（内存缓存）。
- getters：`liveLoreLinks`（端点仍存活的边）；`loreLinkIndex`（`Map<'kind:id', count>`，供行尾卡片 O(1) 查询）。
- actions：
  - `loreLinksOf(kind, id)` → `[{ linkId, dir:'out'|'in', label(入向取 reverseLabel||label), otherKind, otherId, description, color }]`（out 在前，按 createdAt 稳定排序）；
  - `addLoreLink({...})` / `updateLoreLink(id, patch)` / `removeLoreLink(id)`（清洗、去重、自连/空目标拒绝）；
  - `loadLoreGraph()` / `saveLoreGraph(map)`：appconfig `loreGraph:<workId>`，结构 `{ '<kind:id>'(中心): { '<kind:id>'(邻居): {x,y} } }`——按中心条目分别记忆图谱布局（复用 charGraph 的按作品隔离风格）。
- 级联清理：`mubuPurge`（含子树 id 集合）与 `purgeItem`（mubu/characters 单行）硬删相关 `lorelinks`；`mubuRemove`（软删）与 `deleteCharacter`（软删）**保留**关系行——回收站还原后关系回来；显示层由 `liveLoreLinks` 自动过滤。
- 不加入 `SOURCE_TABLES`（AI 读模型投影/哈希不在本期，避免动 project 管线与既有验收基线）。

**4) `src/stores/ui.js`**：`loreRelationPanel: null | { kind, id, x, y }`、`loreDetailId: null`（全屏详情页当前设定节点）。

## 四、界面

### 4.1 幕布行尾「关系卡片」+ 悬停浮层（`MubuView.vue`）
- 行内顺序：文本 → 标签卡片 → **关系卡片** → hover 操作。
- 卡片样式与标签卡片同款彩色胶囊；内容 = 首条关系的图标+类型名，多条时追加 `+N`（如 `📍位于 +2`）；颜色按首条类型取色。
- **悬停浮层**（自绘 fixed，参照 DLinkPopover 的进出宽限模式，不依赖 NPopover，验收脚本可控）：列出全部关系，图二行样式（`类型pill(图标+色) · 目标名(粗) · 描述(灰)`，出向 `→` / 入向 `←`）；鼠标移入浮层保持，移出 220ms 关闭；点击行 `jumpTo` 跳转（设定=定位闪烁，人物=切人物模块）。
- 响应性：卡片计数读 `loreLinkIndex` computed（store 变更即刷新，无需重建行）。

- 面包屑：根→当前祖先链，点击祖先**就地切换**为该节点详情页；另有「幕布中定位」按钮（关闭页面 + `ui.loreFocusId` 闪烁定位）。
- 标题（大号 serif）+ 标签卡片行（点击 → 设为侧栏检索词并关闭页面，同现有联动）。
- 关系列表：`LoreRelRows`（图二行样式），行点击：目标为设定 → 切换详情；目标为人物 → 关闭页面并跳人物模块；行尾 `↗` 按钮 = 跳转到原位置（关闭页面 + `jumpTo`）。
- 子条目：`work.mubuChildren` 递归渲染（缩进引导线 + 圆点），点击切换为该子节点详情；空则「暂无子条目」。
- Esc / 返回 关闭；Esc 时若 `ui.mubuTagPanel || ui.loreRelationPanel` 打开则不抢。

### 4.4 关系图谱（`LoreGraph.vue`，可拖动 + 位置记忆）
- 复用既有引擎（不改引擎代码）：`services/graphview.js` 的 `usePanZoom`（空白平移、Ctrl+滚轮缩放）+ `canvas-model.js` 的 `anchorsOf/sideBetween/routeEdge/dashOf/freeSpotFor`（贝塞尔优先、A* 正交避障），与人物关系图同套技术。
- 节点：中心条目固定在 (0,0)（.lg-node 中心样式，按类型着色）；一度邻居环形自动排布（无记忆位置时），节点 = 图标 + 名称 + 类型角标（设定/人物两种形态）。
- 连线：带方向箭头（出向 → 邻居，入向 → 中心）+ 中段关系类型标签（styled与 edge label 类似）。
- 交互：邻居节点可拖动（mouseup 后 350ms 防抖 `saveLoreGraph`，按中心条目分组记忆）；点击邻居：设定 → 切换详情页，人物 → 关闭并跳转；悬停节点/连线 → 高亮该关系并**联动高亮下方关系列表行**；角落「适应视图」按钮。
- 中心节点名旁显示「关系 N」计数。

## 六、验收

**新脚本 `tools/lorelink-verify.mjs`**（《星尘旅人》真实书 + 基线/还原 + `__检验` 幂等清理；CDP 真鼠标，需窗口可见）：
1. 打开书 → 设定 tab → 记录 `lorelinks` 与关系基线；
2. 行右键「设置关系…」→ 面板打开、标题含节点名；
3. 新建关系（目标 = 星尘旅人某设定节点，类型「位于」，描述 A）→ `db.lorelinks` 落库 + 行尾 `.ob-relchip` 出现；
4. 悬停卡片 → 浮层出现且含 类型/目标名/描述；鼠标移入浮层保持、移出后消失；
5. 反向验证：目标节点行尾卡片/详情关系列表出现入向行（reverseLabel「包含」）；
6. 人物侧：人物详情「关联关系」区出现该关系（目标 = 该人物时的对偶用例）；
7. 双击条目 → 详情页打开：面包屑路径、标题、子条目列表（含层级缩进）断言；
8. 详情页关系行点击 → 设定=原位闪烁定位 / 人物=切人物模块；`↗` 跳转关闭页面；
9. 图谱：节点数/连线数断言；**真鼠标拖动**邻居 → `appconfig loreGraph:<workId>` 落库；重开详情页 → 位置保持；点击邻居 → 切换详情；
10. 删除关系（面板 ×）→ 卡片消失、列表与图谱同步收缩；
11. Esc / 返回关闭详情页，状态清空；
12. 还原基线（关系清空、`lorelinks` 计数回基线、无 `__检验` 残留）+ 三态截图（行尾卡片+浮层 / 详情页全貌 / 图谱拖动后）。

**更新既有脚本**：`dl-verify.mjs`（50/52/114/153/155 行「添加双链/插入双链」→ 新文案）、`dlpop-verify.mjs`（如有文案引用）、`preset-verify.mjs:131`（regex `/批注|关系链接/`）。
