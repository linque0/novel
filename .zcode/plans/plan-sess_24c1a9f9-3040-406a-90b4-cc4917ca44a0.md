# 赤月戏 v3 接入（真实应用）+ 三张新背景

## 一、结论与范围

以 `docs/前端美化/oil-ui-v3-功能对齐/赤月剧场-书架方向对比/完整设计稿/金屏夜梅-重排设计稿-v3/` 为唯一视觉基线，把 v3 的版式与视觉层接入真实应用；**不采用 v4 夜戏台**。v1/v2/v3/v4 设计稿目录全部保持不动。

用户已确认的背景选择：

| 模块 | 文件 | 用法 |
|---|---|---|
| 人物 | `characters-03-staggered-light-v6.png` | 全舞台背景，`object-position:left center` |
| 设定 | `world-celestial-atlas-v6.png`（724×2172 竖幅） | 只用于左侧 220px 拱顶布景列；设定舞台底图改为深墨绿渐隐，不再叠旧天鹅图 |
| 灵感 | `inspiration-lantern-river-v3.png` | 全舞台底图（左对齐保留左侧留白）+ 左侧 220px 布景列（右对齐裁切灯河） |

只改 `crimson` 皮肤；`original / gravity / glaze`、数据库、AI、业务逻辑不改。

## 二、应用现状与 v3 差距

当前 `crimson` 皮肤基于 v1：书架 84px 竖栏、正文 158px 竖题列 + 76px 底部章条、设定 248/220、人物 443 列 / 298×414 肖像、灵感 245/462、设置 181/250、纸面普遍保留闭合边与硬偏移。

v3 目标（按 1440×900 实测）：

- 书架：76px 顶栏内 7 模块导航，去掉 84px 竖栏；剧目栏 316px；首章变票根。
- 正文：左侧 248px 章节目录（可收起为 56px），稿本左 296、右札记 252、无底部章条。
- 大纲：目录 240px，画布右 32；节点为切角纸片 + 胶带 + 软影。
- 设定：左布景 220 / 纸面 / 右目录 240；详情 200 / 纸 / 340。
- 人物：肖像列 380，肖像 330×420 拱顶，演员表竖排；卷宗纸左 440。
- 灵感：220 / 420 / 1fr；便签纸片 + 红钉 + 阅读纸。
- 设置：200 / 纸 / 300；分类当前项是探出的纸书签。
- 全局：双色焦点环、透明工具按钮、文字化标签 `◇`、切角纸牌 CTA、无框搜索、深色目录顶部金线、栏间折缝。

v3 的 `visual-v3.css` 是原型专用类名，不能直接加载；本轮把它按应用 `crimson-*` DOM 逐条移植。

## 四、样式层

新增 `src/styles/skins/crimson-v3.css`，在 `App.vue` 中于 `crimson-workbench.css` 之后 import。所有规则以 `body[data-skin='crimson']` 作用域，尽量少用 `!important`，只在覆盖旧 v1 硬规则时使用。

分区：

1. 令牌、双色焦点环。
2. 顶栏当前项金色三角缺口；模块条标题短金线；工具按钮文字化；主 CTA 切角纸牌；底栏去横杠感。
3. `.tag` 改文字 + `◇`；搜索只留下划线；纸面 `border:0` + 错位背纸 + 软影。
4. 书架：单列外壳、剧目栏无左边框、作品行票根感、首章卡切角 + 朱线 + “续”印、继续写作朱红切角。
5. 正文：章节目录、书签当前章、月相进度、稿本纸边/折角、札记折缝、project-line 文字化。
6. 大纲：目录无框/顶部金线、当前项纸签、画布 L 角标、节点切角纸片/胶带、底右控制条渐变。
7. 设定/详情：拱顶布景、纸压画、右目录透明 + 金线、关系标签文字化、月洞核心。
8. 人物：拱顶肖像、竖排演员表（30×38 小像、当前项金线）、卷宗纸、字段下划线、标签 `◇`。
9. 关系图：浅纸画布、装裱肖像节点、线上关系词、深色名册。
10. 灵感：便签纸片（不同底色/角度/图钉/书签）、阅读纸无框。
11. 设置：竖排书签分类当前项探出 + 朱箭头、无框设置行、300px 预览纸、恢复默认文字化。
12. 1080 与面板窗口适配：竖排签回横排、栏宽收缩、节点不裁切、无横向溢出。
13. `prefers-reduced-motion` 降级。
