# 封面排版：严格对齐设计稿（竖幅卡 + 书名两行 + 封面内部层级）

## 一、从你给的图里读出的三点硬差异

1. **卡片是竖幅 2:3，现在是「扁的」。** 设计稿的卡高由封面自身比例决定（228 宽 → 内径 206×309 → 卡高 331）；应用给 `.glaze-stage-book` 写死了 `height:300px`，而我上一轮只改了各卡的**宽度**（228/190/158）没改高度 → 三张都是 228×300（比例 0.76），所以扇形显得矮胖、叠压关系也读不出来。**这条最影响观感。**
2. **书名是「两行大字」并贴在卡面上方。** 设计稿一律拆两行（`title.slice(0,2)` + 其余 →「星尘 / 旅人」），紧跟在顶部小字下方（`margin-top:22px`）；应用的 `.glaze-cover strong` 是**单行**且 `margin:auto 0` **垂直居中**，书名飘在卡面中间。
3. **封面内部三层的字号/间距与稿不一致。** 设计稿：顶行小字 13px / 字距 2px / `#315862`、**无下划线**（应用是 10px + 一条 1px 下划线）；书名行高 1.25、字距 3px、字色 `#173f49`（应用 1.35 + 无字距 + `#214c5c`）；作者行 13px / 字距 3px / `#315862` 且贴底（应用 11px）。

## 二、改法（都限琉光作用域）

**A. 卡片恢复 2:3 竖幅（纯 CSS）**
- `.glaze-stage-book{height:auto}` + `.glaze-stage-book .glaze-cover{aspect-ratio:2/3;height:auto}`：卡高改由封面比例驱动 → 228→**331** / 190→**274** / 158→**226**（与设计稿逐值一致）。
- 三张卡的宽·左距·上距·旋转·rotateY·层叠沿用上一轮（228/190/158 · 100/262/400 · 30/70/108 · −9°/8°/18° + rotateY(−12/−15/−20)° · z 3/2/1）。
- ≤1200px 的紧凑位保留（比例同样 2:3）。

**B. 书名两行（`GlazeCover.vue` 小改）**
- 加 `titleLines` 计算属性，按设计稿规则拆 `[title.slice(0,2), title.slice(2)]`（≤2 字只有一行），渲染成两个 `display:block` 的行元素。**`textContent` 不变**（只是把「星尘旅人」变成两个 span），既有验收对书名文本的断言不受影响。
- 底部缩略封面共用同一组件 → 也会两行（设计稿的 mini-book 同样是两行）。

**C. 封面内部层级（覆盖 glaze.css L602-606 的现值，仅作用于舞台卡）**
- 书名：`margin:22px 0 0`（贴顶，不再垂直居中）+ 行高 **1.25** + 字距 **3px** + 字色 `#173f49`；每卡的 34/28/22px 分级沿用。
- 顶行小字：13px / 字距 2px / `#315862` / **去掉那条 1px 下划线**。
- 作者行：13px / 字距 3px / `#315862` / `margin-top:auto` 贴底。
- 缩略封面（58×87、12px 书名）保持既有紧凑规则，不受上面这些外边距影响。

## 三、有意不动

封面美术（`kind` 配色 + `glaze-ribbon.png` 玻璃丝带 vs 设计稿的摄影海报——既有边界）；顶行小字的**内容**（应用放的是「类型 · 状态」这块真实信息，设计稿的「林间作品 · 01」是示意；位置与字号对齐，文案不动）；六款封面款式（note/cedar/violet/claret/ink 的差异化排版是真实功能）；白卡与玻璃球位置（上一轮已按稿）。

## 四、验收

1. `glaze-fidelity-verify` 书架段补断言：三张卡的**高/宽比 ≈ 1.5**（2:3）与卡高 331/274/226；书名是**两行**且 `margin-top` 为 22px（不再居中）；顶行 13px 且无下边框；作者 13px。
2. `glaze-shelf-verify` 32 项仍全绿 —— 重点是卡变高后 **1080×680 无横向溢出**这条红线复测，以及 DOM 契约与降动效断言。
3. `glaze-regression` 全绿 → `glaze-evidence` 重拍对照页（书架那组更新）；`npm run build` 通过。
4. 文档：`琉光画境-接入记录.md` 补「封面排版对齐」一段 + `CHANGELOG.md`。

## 五、风险

- 卡高 331 后舞台仍放得下（top 30 + 331 = 361，舞台高 410，余 49）；≤1200 的紧凑位需复测溢出红线（脚本会跑）。
- 超长书名（>10 字）第一行 2 字、第二行很长 → 仍由 `line-clamp` 兜底（与设计稿同规则）。
