## 二、修订 v3 文档 → v3.2（新增「Agent 能力缺口补全」章）

修订 `docs/AI助手优化方案-恍然梦v3-酒馆式注入引擎.md`：

- 头部修订记录加 v3.2 行；关联文档补评估报告；新增第十三章「Agent 能力缺口补全（v3.2）」，含六个小节：

**13.1 缺口总表**：对照评估报告 14 项体检，标出 v3.2 新增任务（规划器/反思闭环/统一循环/工作记忆/高优缺陷）与 v3 原 W 线的分工。

**13.2 规划器（Planner）——半自主「计划-确认-执行-重规划」**
- 新元任务 `plan`：输入=作者目标（如「完成第二卷初稿」）+ 作品状态快照；输出=**任务计划草案**（步骤列表 `{id, task('plot'|'outline'|'lore'|'character'|'review'|'rewrite'|'knowledge'), scope(章/卷/节点), instruction, dependsOn[], status}`）；
- 作者在计划卡上编辑（勾选/排序/删步骤/改指令）后执行；执行器逐步调用现有 runCardTask/professional，每步产物作为后续步骤上下文，每步仍是提案制逐项应用；
- 偏离处理：步骤失败或产出被大量放弃 → 自动带「已完成步骤摘要+问题」重调 `plan` 修订剩余步骤（重规划，上限次数可配）；
- 与硬编码 workflow 的关系：workflow 降为「固定模板快捷方式」，与 planner 共用租约/检查点/阶段报告机制；计划存 `airuns`（type:'plan'，含步骤状态检查点）；
- UI：AiStudio 新增「计划」区（目标输入→计划卡编辑→执行/暂停/从步骤续跑/重规划）。

**13.3 反思闭环（补齐三处）**
- 直接审稿路径补 `reviewProposals` 复核（与工作流一致）；
- verify 结果驱动修正：warnings 升级为可一键「按复核意见重生成」（自动带问题重跑 1 次，可配置自动/手动）；
- 卡片任务可选「生成后自检」开关：生成→复核调用→warnings 展示（默认手动模式不自动重跑以控成本）。

**13.4 统一 Agent 循环抽象**：`runAgent({kind, goal, ...})` 统一 phase/abort/usage/report/checkpoint/lease 接口，card/chat/workflow/planner 收敛为同一接口的四种实现；渐进式重构——先抽接口行为不变，后逐项迁移。

**13.5 工作记忆与状态持久化**：chat 历史持久化（`aichat` 表：workId/sessionId/role/content，上限裁剪）；`creativeMode` 持久化；每日预算增加按作品维度（全局+按作品双记）。

**13.6 高优缺陷修复清单（P0，可与 W 线并行先行）**：提取分块按 token 折算+重叠（修复长章系统性失败）；compact 失败降级保留旧弧线；摘要失败回退节选；chat 检索中文 2-gram 切分+低分保底 top-k；向量构建单卡失败跳过；工具 JSON Schema 参数校验与执行内 abort 点；审计（airuns）清理/归档策略。

- 修订「十一、实施阶段」：新增 V3.2 线（P0 缺陷修复 → P1 反思闭环 → P2 工作记忆与统一循环 → P3 规划器），标注与 K/W 线的并行与衔接关系；
- 修订「十、验收」：补用例——plan 计划生成与重规划、verify 驱动重生成、chat 刷新后历史保留、长章提取成功、分词检索命中、自检 warnings 展示；
- 修订「十二、风险」：补规划器误用（计划需作者确认、步骤仍走提案制）、自动重生成成本（上限+可关）、统一循环重构风险（先接口后行为）。
