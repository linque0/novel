# 大纲画布接入设计稿（v1.2.0）

## 目标与口径

把 `docs/outline-workbench-preview/` 的分层画布、纸面素材与编辑体验接入正式 `OutlineCanvas.vue`，同时保留现有大纲画布的全部能力（端口连线、连接点、重连、手动路径、右键菜单、行内编辑、引用跳转、模板、撤销/重做、搜索、缩放平移、四套皮肤、文本视图）。

按你的三个决定执行：

1. **分层视图 + 两种编辑入口**：容器既能「就地展开编辑」，也能「进入容器」进入次级画布；严格按 `parentId` 层级维护面包屑、相机、展开状态与关系投影。
2. **四套皮肤全部适配**：原版、引力书舱、琉光画境、赤月戏都接入纸面材质，按皮肤调整纸面明度与文字色，不覆盖皮肤个性。
3. **素材只用于界面**：素材库展示并应用纹理，不提供原图下载，不打包 PNG 原图/压缩包。

## 一、视图与层级模型

### 1. 分层画布
- 新增 `scopeId`（`null` = 全书根层，容器 id = 进入该容器）。画布只渲染**当前层的直接子节点**；子容器以「章节卡」呈现，不再把全部后代铺在同一平面。
- 所有节点继续使用现有全局 `canvasX/canvasY`，进入容器时按该容器子节点包围盒适配相机，不迁移坐标、不破坏旧布局。
- 根层显示：卷、章节容器卡、便签、引用卡、文本框、事件、锚点；容器卡显示标题、摘要、事件进度、进入/就地展开按钮。

### 2. 就地展开（直接编辑）
- 容器卡内按两列紧凑网格展示直接子卡；子容器可继续就地展开，支持任意层级。
- 迷你卡可**直接编辑**：单击选中、双击就地编辑文字、设置按钮打开右侧抽屉（标题/正文/状态/形状/颜色）、四向端口可拖线、可接收其他节点拖来的连线。
- 迷你卡不做自由拖拽/缩放，位置由网格自动计算；需要自由摆放时进入次级画布。
- 展开后容器高度增加，同列下方模块自动下移（220ms 位移动画）；收起不回收空间，「整理布局」统一重排。
- 迷你卡布局与连线端点由纯函数计算绝对坐标，DOM 与边几何共用同一套矩形，避免“看到的卡”和“线连到的点”错位。

### 3. 进入容器（次级画布）
- 容器卡「进入容器」或面包屑进入；当前相机写入 `cameras[scopeId]`，再按目标层适配（首屏可读下限 74%，过宽时靠左）。
- 返回上级或点击面包屑时恢复该层相机与就地展开状态；支持任意深度嵌套。
- 层级关系严格以 `parentId` 为准：面包屑、侧栏树、侧栏定位、搜索定位、断线定位都会先进入节点所在父层，再选中与闪烁。
- 进入/返回带轻量 portal 过渡（320–440ms，`prefers-reduced-motion` 时关闭）。

### 4. 关系投影与分组
- 关系仍保存真实事件/节点 id；渲染时按当前层投影：
  - 可见端点直接渲染；
  - 当前层子树内但被收起的端点，投影到最近可见祖先（容器卡或迷你容器卡）；
  - 当前层之外的端点进入「前接 / 后续」接续卡，不画穿出画布的线；
  - 投影后的边变淡，落点用空心圆标记。
- 同一对可见端点、同一关系类型的多条真实关系合并为一条视觉边；同对多组关系横向/纵向错开 18–24px，标签用纸片样式并做碰撞避让。
- 可见的单条边继续支持现有编辑（类型/箭头/标签/颜色/线型/线宽/箭头大小/连接点/手动路径）；合并边使用轻量「关系组」浮层批量改类型/箭头/标签，并提供「详情」列出每条真实关系与定位按钮。
- 跨层连接点：宿主边在当前层可见时保留连接点几何；宿主不可见时投影到宿主节点，不丢关系。

### 5. 接续卡与进度
- 画布上方「前接」、下方「后续」显示跨层关系；单个端点直接定位，多个端点打开关系列表。
- 事件新增状态：`done / writing / revise / planned`。新事件默认 `planned`；旧事件未标记时显示「未标记」，进度只统计 `done`，不伪造迁移。
- 容器进度只统计后代事件，显示 `已完成 / 总数`、嵌套容器数与完成状态。

## 二、数据与状态

### `src/stores/work.js`
- `canvasPrefs` 增加并持久化：
  ```js
  {
    textures: true,
    scopeId: null,        // null = 根层
    expanded: [],         // 就地展开的容器 id（可任意层）
    cameras: {}           // scopeId -> { zoom, tx, ty }
  }
  ```
  加载时校验：`scopeId` 必须存在且为容器；`expanded` 过滤失效 id；旧作品默认根层。默认连线粗细改为 1.6（已保存的旧偏好保留）。
- 新增 action：
  - `olnodeSetStatus(id, status)`
  - `olnodeSetChapter(id, chapter)`（容器章节标签，可空）
  - `olnodeWrap(ids, fields)`：一次 undo 内创建容器、迁移选中节点、归一化 sortOrder，返回容器行。
- 保留现有 `olnodeAdd`、`olnodeMoveTo`、`olnodeRemove`、关系事务、撤销/重做全部语义；新增 action 不改变旧快照格式。

### 新增纯逻辑模块
- `src/components/outline/outline-scope.js`（零 Vue，可 node 直跑）：
  - `scopePath`、`layerIds`、`scopeStats`
  - `buildMiniLayout`（递归两列网格、迷你容器整行展开、绝对矩形）
  - `projectRelations`（可见层、投影、外部 in/out、按 `from|to|kind` 分组）
  - `scopeConnections`（容器跨边界关系）
  - `packLayer`（当前层整理：按阅读顺序左到右、行高取最高、pin 豁免）
  - `containerCardSize`（固定卡宽 + 折叠/展开高度）
- `src/components/outline/outline-paper.js`：
  - 事件四形态元数据、纸面材质、状态、容器色板、素材导入。

### 新增组件
- `src/components/outline/OutlineNodeDrawer.vue`：节点/容器设置抽屉，实时编辑、两步删除、外部联系列表、进入/展开/移出容器。
- `src/components/outline/OutlineMaterials.vue`：素材库（四种事件纸面 + 五种内容卡），只展示与说明，不提供下载。

### 资源落点

  - 复制 5 张内容卡 WebP：`event.webp`、`note.webp`、`cite.webp`、`anchor.webp`、`volume.webp`。

- 字体沿用现有 `src/assets/fonts` 的 KingHwa OldSong / LXGW WenKai，不重复打包。

### 视觉实现
- 新增 `src/styles/outline-paper.css`，在 `src/main.js` 中紧跟 `themes.css` 导入，皮肤文件仍在其后覆盖。
- 事件：`<span class="oc-paper">` 绝对铺底，按 `process/para/diamond/ellipse` 使用 CSS `clip-path`，纸面图 + 形态色调 + 细边 + 内压边；文字、端口、手柄保持在上层。
- 便签/引用/锚点/卷：纸面背景图 + 现有卡片结构；便签保留轻微倾斜；卷保留深色布纹与浅色文字；文本框与容器继续无纸面纹理。
- 选中、悬停、端口、缩放手柄、连线命中层全部保留现有行为。
- 关闭纹理开关（`canvasPrefs.textures=false`）时隐藏所有纸面层，回到纯色卡片。
- 关系色板改为设计稿的低饱和四色；容器色板改为苔绿/麦金/雾蓝/灰紫/陶红/石绿六色；原有自定义颜色与自动配色保留。

### 四皮肤适配
- 基色与纸面透明/明度通过 CSS 变量：
  - 原版：米色纸面 + 灰绿主色，沿用现有暖色背景。
  - 引力书舱：深色画布上保留浅纸卡片，降低纸面亮度/透明度，文字色切换为深墨或按卡片明度适配。
  - 琉光画境：浅青画布，纸面更轻，标题保持 LXGW WenKai。
  - 赤月戏：在现有折角纸卡/暗红画布上叠加纹理，保留金线、印章与衬线标题。
- 在 `gravity-workbench.css`、`glaze.css`、`crimson-v3.css` 追加各自的作用域覆盖；不改动现有皮肤骨架。

## 七、边界与说明

- 迷你卡是“就地编辑 + 自动网格”，不支持自由拖拽/缩放；需要自由摆放时进入容器次级画布。
- 旧作品不做坐标/状态迁移；打开后位于根层，所有后代仍可通过就地展开或进入容器到达。
- 合并边（多条真实关系投影到同一对端点）不提供逐条手动路径手柄；单条边保持全部原有塑形能力。
- 跨层连接点在宿主边不可见时投影到宿主节点，属有意取舍，保证关系不丢失。
- 素材库不提供原图下载；纹理开关按作品隔离持久化。
